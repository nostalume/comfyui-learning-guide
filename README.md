## 📖 项目简介

这是一个全面的 **ComfyUI 中文学习指南**，从零基础入门到企业级应用，为您提供系统化的学习路径。文档参照官方规范编写，包含完整的实战案例、性能优化方案和团队协作指南。

### 为什么选择 ComfyUI？

- 🧱 **节点化工作流** - 可视化的节点连接，精确控制生成流程
- ⚡ **高性能** - 比传统WebUI更高效的推理引擎
- 🔧 **高度可定制** - 丰富的插件生态和自定义节点支持
- 📐 **精确控制** - 通过ControlNet等技术实现精准的生成结果
