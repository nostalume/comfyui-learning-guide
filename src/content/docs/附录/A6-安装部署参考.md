## A6.1 系统要求

### 操作系统

| 系统 | 支持情况 |
|------|----------|
| Windows | ✅ Windows 10 或更高（64 位 / ARM64） |
| Linux | ✅ 桌面端提供 AppImage 与 `.deb` |
| macOS | ✅ 仅 **Apple Silicon（M1 及以后）**，需 macOS 13 Ventura 或更高 |

### Python 版本（手动安装时关心）

| 版本 | 官方态度 |
|------|----------|
| **3.13** | ✅ 支持良好，**推荐** |
| 3.14 | ⚠️ 可用，但部分自定义节点会有问题；free-threaded 变体未完全支持 |
| 3.12 | ✅ 3.13 上遇到依赖冲突时的退路 |

### 显卡后端

| 硬件 | 安装方式 | 说明 |
|------|----------|------|
| NVIDIA | `pip install torch torchvision torchaudio --extra-index-url https://download.pytorch.org/whl/cu130` | **RTX 20 系及以上要求 CUDA 13.0 及以上的 PyTorch**；10 系及更早需用旧的 CUDA 12.6 包 |
| AMD（Linux） | ROCm 7.2（稳定版或 nightly） | `--index-url https://download.pytorch.org/whl/rocm7.2` |
| AMD（Windows） | ROCm 10.0 多架构 PyTorch 包 | 覆盖 RDNA 2 / 3 / 3.5 / 4，无需单独装 HIP SDK |
| Intel | Arc 系列，`torch.xpu` | — |
| Apple Silicon | Metal（MPS）加速 | **不用 MLX**，ComfyUI 走的是 PyTorch + MPS |
| CPU | `--cpu` 或 `run_cpu.bat` | 很慢，仅适合验证流程 |

**PyTorch 版本：** 支持 2.7 及以上，强烈建议用更新的版本。部分特性只在较新版本上生效。

### 浏览器

建议 **Chrome 143 或更高**。更早的 Chrome（142 及以下）在 ComfyUI 上会有画面错乱与性能问题。

### 磁盘与内存

| 项 | 参考值 |
|------|--------|
| 程序本身 | Comfy Desktop 官方建议**每个实例预留 4.85 GB 以上** |
| 模型 | 一个 SD 1.5 大模型约 2-4 GB；SDXL 约 6-7 GB —— **这部分远大于程序本身** |
| 长期使用 | 建议 100 GB 以上可用空间 |
| 内存 | 16 GB 起步（社区经验值，非官方硬性要求） |

## A6.2 三条安装路径

### 路径一：Comfy Desktop（官方推荐）

一个**多实例管理器**：装一次启动器，由它创建、管理、更新若干彼此独立的 ComfyUI。

| 平台 | 安装包 | 关键步骤 |
|------|--------|----------|
| Windows | `.exe`（NSIS 安装程序） | 运行 → 从开始菜单启动 → 在 Welcome 页创建实例 |
| macOS | `.dmg` | 拖进「应用程序」→ 首次打开需在「隐私与安全性」里点「仍要打开」 |
| Linux | AppImage / `.deb` | 见官方文档 |

- 桌面端默认跟踪 ComfyUI 的 **stable** 版本；想要每个最新提交，改用便携版或手动安装
- 更新：顶部 `Desktop Update Ready` 按钮，或 菜单 → `Desktop Settings` → `Updates`
- 旧版桌面端（Legacy Desktop）可被新版自动识别并迁移，旧安装会原样保留作为备份

### 路径二：Windows 便携版

自带独立 Python（`python_embeded`），解压即用。**目前只面向 Windows。**

| 显卡 | 解压后的启动脚本 |
|------|------------------|
| NVIDIA | `run_nvidia_gpu.bat` |
| AMD | `run_amd_gpu.bat` |
| Intel | `run_intel_gpu.bat` |
| 无独显 | `run_cpu.bat` |

更新用 `update/` 目录里的脚本：`update_comfyui.bat`（最新提交）/ `update_comfyui_stable.bat`（稳定版）。

### 路径三：手动安装

官方把它拆成四步，**第一步是建独立虚拟环境**（避免污染系统 Python）：

```bash
# 1. 虚拟环境（官方示例用 Conda）
conda create -n comfyenv
conda activate comfyenv

# 2. 克隆源码
git clone https://github.com/Comfy-Org/ComfyUI.git
cd ComfyUI

# 3. GPU 依赖（NVIDIA / CUDA 13.0）
pip install torch torchvision torchaudio --extra-index-url https://download.pytorch.org/whl/cu130

# 4. ComfyUI 依赖
pip install -r requirements.txt

# 5. 启动
python main.py
```

更新：`git pull` 后重跑一次 `pip install -r requirements.txt`。

### 附：comfy-cli

官方另有一个命令行工具，可以装 ComfyUI 并管理依赖：

```bash
pip install comfy-cli
comfy install
```

## A6.3 目录结构

### 手动安装 / 便携版

```text
<ComfyUI 目录>/
├── models/                  # 所有模型 —— 详见 2.1
│   ├── checkpoints/
│   ├── lora/
│   ├── controlnet/
│   ├── vae/
│   ├── clip/
│   ├── clip_vision/
│   ├── embeddings/
│   ├── ipadapter/
│   ├── upscale_models/
│   └── ...
├── custom_nodes/            # 自定义节点
├── input/                   # 输入图片
├── output/                  # 生成结果
├── user/                    # 用户数据
├── main.py                  # 启动文件
└── extra_model_paths.yaml.example
```

### Comfy Desktop（与上面不同）

桌面端把「启动器」与「每个实例」分开管理，路径**不在程序目录下**：

| 内容 | Windows | macOS |
|------|---------|-------|
| 各个实例 | `%LOCALAPPDATA%\Comfy-Desktop\ComfyUI-Installs` | `~/ComfyUI-Installs` |
| 共享模型与输入/输出 | `%LOCALAPPDATA%\Comfy-Desktop\ComfyUI-Shared` | `~/ComfyUI-Shared` |
| 设置与安装记录 | `%APPDATA%\Comfy Desktop` | `~/Library/Application Support/Comfy Desktop` |
| 日志 | `%APPDATA%\Comfy Desktop\logs` | `~/Library/Logs/Comfy Desktop` |

> 💡 早期版本把实例装在 `%USERPROFILE%\ComfyUI-Installs` / `%USERPROFILE%\ComfyUI-Shared`（macOS 同路径）。

### 让模型放到别处：额外搜索路径

模型不一定非得放在 `models/` 下 —— 官方提供了「额外搜索路径」机制。拷一份示例文件改成自己的即可：

```text
# 手动安装 / 便携版：文件放在 ComfyUI 根目录
<ComfyUI 目录>/extra_model_paths.yaml.example  →  extra_model_paths.yaml
```

内容形如：

```yaml
my_custom_config:
    base_path: D:/Models/
    checkpoints: checkpoints/
    loras: loras/
    vae: vae/
    controlnet: controlnet/
```

**桌面端不走这个文件**，而是：

| 平台 | 配置文件 |
|------|----------|
| Windows | `C:\Users\<你的用户名>\AppData\Roaming\ComfyUI\extra_models_config.yaml` |
| macOS | `~/Library/Application Support/ComfyUI/extra_models_config.yaml` |

也可以在桌面端顶部的胶囊菜单 → `Storage` 标签页里直接添加模型目录。

> ⚠️ 改完后必须**重启 ComfyUI** 才生效。桌面端上修改配置文件前先备份，别覆盖安装时生成的路径配置。

## A6.4 启动参数

> 官方参数表的权威来源是源码 [`comfy/cli_args.py`](https://github.com/Comfy-Org/ComfyUI/blob/master/comfy/cli_args.py)。下面是常用部分。
> **便携版**要给 `.bat` 加参数时，用记事本打开对应脚本，在 `main.py` 后面追加。

### 常见误区：这些参数 ComfyUI 没有

初学者最容易从 WebUI 教程里抄到下面几个 —— **它们在 ComfyUI 里不存在，写了会导致启动失败**：

| 不存在的参数 | 真实情况 |
|--------------|----------|
| `--normalvram` | 不传任何 VRAM 参数**就是**默认模式 |
| `--use-xformers` | xFormers 装了即**自动启用**；要关掉用 `--disable-xformers` |
| `--auto-devices` | 无此参数 |
| `--cpu-clip` | 无此参数（VAE 有 `--cpu-vae`） |
| `--split-memory` | 无此参数（选卡用 `--cuda-device`） |

### 网络与服务

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--listen [IP]` | `127.0.0.1` | 监听地址。不给值时等价于 `0.0.0.0,::`（所有网卡） |
| `--port` | `8188` | 服务端口 |
| `--tls-keyfile` / `--tls-certfile` | — | 启用 HTTPS（两者必须成对） |
| `--enable-cors-header [ORIGIN]` | 关闭 | 开启 CORS，可指定来源 |
| `--max-upload-size` | `100` | 上传体积上限（MB） |

### 目录

| 参数 | 说明 |
|------|------|
| `--base-directory PATH` | 模型、自定义节点、输入输出等目录的根 |
| `--extra-model-paths-config PATH` | 加载额外的 `extra_model_paths.yaml`，可多次指定 |
| `--output-directory` / `--temp-directory` / `--input-directory` / `--user-directory` | 分别覆盖对应目录 |

### 显存与内存

> VRAM 模式组**互斥**，只能选一个。

| 参数 | 说明 |
|------|------|
| `--gpu-only` | 全部常驻 GPU（含文本编码器） |
| `--highvram` | 模型用完后不卸载回内存 |
| `--lowvram` | 开启动态 VRAM 时**无效果**；否则让文本编码器跑在 CPU |
| `--novram` | `--lowvram` 仍不够时用 |
| `--cpu` | 全部用 CPU（很慢） |
| `--reserve-vram GB` | 为系统/其它软件预留的显存 |
| `--disable-smart-memory` | 更激进地往内存卸载 |
| `--disable-mmap` / `--mmap-torch-files` | 控制是否用 mmap 加载权重 |

### 精度

> 同一组内互斥。

| 参数 | 说明 |
|------|------|
| `--force-fp32` / `--force-fp16` | 全局精度 |
| `--fp32-unet` / `--fp16-unet` / `--bf16-unet` | U-Net 精度 |
| `--fp8_e4m3fn-unet` / `--fp8_e5m2-unet` / `--fp8_e8m0fnu-unet` | 以 FP8 存 U-Net 权重（后缀是三种 FP8 布局） |
| `--fp16-vae` / `--bf16-vae` / `--fp32-vae` / `--cpu-vae` | VAE 精度（`--fp16-vae` 可能出黑图） |
| `--fp8_e4m3fn-text-enc` / `--fp16-text-enc` / `--bf16-text-enc` / `--fp32-text-enc` | 文本编码器精度 |

### 注意力

> 互斥；xFormers 生效时 split / quad 会被忽略。

| 参数 | 说明 |
|------|------|
| `--use-pytorch-cross-attention` | 用 PyTorch 2.0 的 SDPA |
| `--use-flash-attention` | 用 FlashAttention |
| `--use-sage-attention` | 用 SageAttention |
| `--use-split-cross-attention` / `--use-quad-cross-attention` | 旧的切分注意力实现 |
| `--disable-xformers` | 关闭 xFormers（它默认启用） |

### 缓存

> `--cache-ram` / `--cache-classic` / `--cache-lru` / `--cache-none` 互斥，只能选一个。

| 参数 | 说明 |
|------|------|
| `--cache-ram [GB] [GB]` | 默认模式，按内存压力决定缓存多少 |
| `--cache-none` | 不缓存，每轮重算，省内存 |
| `--cache-lru N` | 最多缓存 N 个节点结果 |
| `--cache-classic` | 旧的激进缓存策略 |

### 预览

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--preview-method` | `none` | 取值 `none` / `auto` / `latent2rgb` / `taesd` |
| `--preview-size` | `512` | 预览图最大边长 |

### 性能与调试

| 参数 | 说明 |
|------|------|
| `--fast [OPT...]` | 实验性优化；单独写 `--fast` 表示全开，可选 `fp16_accumulation`、`fp8_matrix_mult`、`cublas_ops`、`autotune` |
| `--deterministic` | 尽量用确定性算法（更慢，且不保证像素级一致） |
| `--disable-auto-launch` | 启动后不自动开浏览器 |
| `--verbose [LEVEL]` | 日志级别（DEBUG/INFO/WARNING/ERROR/CRITICAL） |
| `--quick-test-for-ci` | 初始化后立即退出，用于 CI |

### 自定义节点与前端

| 参数 | 说明 |
|------|------|
| `--disable-all-custom-nodes` | 不加载任何自定义节点（排错用） |
| `--whitelist-custom-nodes FOLDER...` | 配合上一条，只放行指定目录 |
| `--disable-metadata` | 输出文件里不写提示词元数据 |
| `--enable-manager` | 启用 ComfyUI-Manager |
| `--front-end-version` | 指定前端版本，如 `owner/repo@latest` |
| `--comfy-api-base` | ComfyUI API 基础地址，默认 `https://api.comfy.org` |

### 多卡

| 参数 | 说明 |
|------|------|
| `--cuda-device 0,1` / `all` | 指定使用哪些 CUDA 设备（Windows 上默认只用 GPU 0） |
| `--default-device ID` | 指定默认设备，其余仍可见 |

### 常用组合

```bash
# 局域网内其它设备可访问
python main.py --listen

# 显存紧张：降低占用
python main.py --lowvram --fp16-unet

# 显存充裕：追求速度
python main.py --highvram --bf16-unet

# 排错：不加载任何自定义节点
python main.py --disable-all-custom-nodes

# 服务器上跑：不开浏览器、只监听内网
python main.py --disable-auto-launch --listen 127.0.0.1 --port 8188
```

## A6.5 快捷键

> ⚠️ 随前端版本可能变化。

| 快捷键 | 功能 |
|--------|------|
| `Ctrl + Enter` | 把当前工作流加入队列 |
| `Ctrl + Shift + Enter` | 优先加入队列 |
| `Ctrl + Alt + Enter` | 取消当前生成 |
| `Ctrl + Z` / `Ctrl + Y` | 撤销 / 重做 |
| `Ctrl + S` / `Ctrl + O` | 保存 / 加载工作流 |
| `Ctrl + D` | 加载默认工作流 |
| `Delete` / `Backspace` | 删除选中节点 |
| `Ctrl + Backspace` | 清空当前图 |
| 按住 `Space` | 拖动画布 |
| `Ctrl + C` / `Ctrl + V` | 复制 / 粘贴节点 |
| `Q` / `H` | 切换队列 / 历史面板 |
| `R` | 刷新图 |
| `.` | 适应视图到选中内容 |
| 双击空白处 | 打开节点搜索面板 |

**macOS 用户：** `Ctrl` 可替换为 `Cmd`。

## A6.6 常见问题排查

| 现象 | 处理 |
|------|------|
| `Torch not compiled with CUDA enabled` | 装错了 PyTorch 版本 —— 按 A6.1 的显卡后端重装 |
| 报错 `unrecognized arguments: --xxx` | 该参数不属于 ComfyUI（见 A6.4 的「常见误区」），删掉即可 |
| 界面打不开 | 先看服务是否还在跑；再查防火墙与端口占用 |
| 显存不足 | `--lowvram` / `--novram`，或调小尺寸、降低精度 |
| 模型加载不出来 | 检查目录与后缀，见 [2.1](../2-模型体系与管理/2.1-项目结构与模型存放.md) |
| 便携版解压失败 | 右键文件 → 属性 → 解除阻止；换 7-Zip 重解 |
| 装扩展时的 SSL 错误 | 在 Manager 的 `config.ini` 里加 `bypass_ssl = True` |
| 想停掉 ComfyUI | 在运行它的终端/命令行窗口按 `Ctrl + C` |
