> ⚠️ **两个版本号体系，别对号入座：** ComfyUI 本体的版本号（`v0.37.x`）与 Comfy Desktop 的版本号（`v1.1.x`）**各自独立**。桌面端是启动器，它管理的每个实例各自装一个 ComfyUI 版本 —— 所以「桌面端版本比 ComfyUI 低」是正常的。

#### 1.2 装法差异

三条安装路径（**Comfy Desktop / Windows 便携版 / 手动安装**）的能力对照与选择建议，见 [A4 版本差异指南](./A4-版本差异指南.md)；目录与模型放置位置见 [2.1 项目结构与模型存放](../2-模型体系与管理/2.1-项目结构与模型存放.md)。本文不重复。

> ⚠️ **重要提示：** 本学习文档的**路径写法**以「手动安装 / 便携版」为准（`<ComfyUI 目录>/models/…`）。用 Comfy Desktop 的话，模型在它统一管理的共享库里，路径不一样 —— 但节点名、参数、工作流全都一样。

#### 1.3 版本检查方法

```bash
# 手动安装：查你的 git 克隆停在哪个提交
cd ComfyUI
git log -1 --format="%H %ci"

# 手动安装 / 便携版：启动时日志开头会打印版本号
python main.py

# Comfy Desktop：实例卡片 → ⋮ → Manage → About 标签页里写着
# （含 ComfyUI 版本、Python 版本、PyTorch 版本与安装路径）
```

#### 1.4 版本门槛（按官方口径）

| 你要做的事 | 要求（核对于 2026-09-24） |
|-----------|----------------------|
| 跑 ComfyUI 本体 | **PyTorch 2.7 及以上**受支持，官方强烈建议用更新版本；**NVIDIA 20 系及以上要求 cu130 及以上的 PyTorch** |
| 浏览器 | 官方建议 **Chrome 143 或更高**（更早的版本有已知的渲染与性能问题） |
| 文生图 / ControlNet / InstantID / AnimateDiff v3 / SDXL | **与 ComfyUI 版本无关** —— 这些取决于「有没有对应的模型文件」和「有没有对应的节点包」，不是靠升级本体解锁的 |

> 📅 原文那张「每个功能对应一个 ComfyUI 版本号」的表**已经作废**：ComfyUI 的发布是每周级的，某项功能能不能用取决于模型与节点包，写死版本号只会误导。官方要求见 [System Requirements](https://docs.comfy.org/installation/system_requirements)。

> ⚠️ **三条容易踩的坑：**
> - 不同模型需要不同的节点支持 —— 模型装好了，节点包里没有对应加载器也跑不起来。
> - 大模型（SDXL、Flux 等）吃显存，先确认你的显卡，见 [7.5 显存优化](../7-性能优化与显存管理/7.5-显存优化.md)。

> 💡 建议从 **SD 1.5** 开始：它对显存最宽容，出问题也最好排查；熟悉之后再换大模型。

### 三、一键下载脚本

> ⚠️ **使用前必读：** 以下脚本基于示例安装路径，如果你的路径不同，请相应修改！

#### 3.1 Windows 用户（PowerShell）

```powershell
# 你的 ComfyUI 安装路径
$ComfyUI路径 = "<ComfyUI 目录>"

mkdir -p "$ComfyUI路径\models\checkpoints"
mkdir -p "$ComfyUI路径\models\vae"
mkdir -p "$ComfyUI路径\models\controlnet"

Invoke-WebRequest -Uri "https://huggingface.co/runwayml/stable-diffusion-v1-5/resolve/main/v1-5-pruned-emaonly.safetensors" -OutFile "$ComfyUI路径\models\checkpoints\v1-5-pruned-emaonly.safetensors"
Invoke-WebRequest -Uri "https://huggingface.co/stabilityai/sd-vae-ft-mse-original/resolve/main/vae-ft-mse-840000-ema-pruned.safetensors" -OutFile "$ComfyUI路径\models\vae\vae-ft-mse-840000-ema-pruned.safetensors"
Invoke-WebRequest -Uri "https://huggingface.co/lllyasviel/ControlNet-v1-1/resolve/main/control_v11f1p_sd15_depth.pth" -OutFile "$ComfyUI路径\models\controlnet\control_v11f1p_sd15_depth.pth"
Invoke-WebRequest -Uri "https://huggingface.co/lllyasviel/ControlNet-v1-1/resolve/main/control_v11p_sd15_openpose.pth" -OutFile "$ComfyUI路径\models\controlnet\control_v11p_sd15_openpose.pth"
```

```bash
#!/bin/bash
# check_comfyui_version.sh

echo "=== ComfyUI Version Check ==="
cd ComfyUI
echo "Git commit: $(git log -1 --format='%H %ci')"
echo "Branch: $(git branch --show-current)"
echo "Remote: $(git remote -v | head -1)"
```

#### 8.2 检查节点包版本

```bash
#!/bin/bash
# check_nodes_version.sh

echo "=== Custom Nodes Version Check ==="
for dir in ComfyUI/custom_nodes/*/; do
    if [ -d "$dir/.git" ]; then
        name=$(basename "$dir")
        commit=$(cd "$dir" && git log -1 --format='%h %ci')
        echo "$name: $commit"
    fi
done
```

### 九、依赖门槛速查

> ComfyUI 对依赖的要求**写在代码里，不写在文档里** —— 写死的对应表一定会过期。官方口径（核对于 2026-09-24）：

| 你要做的事 | 要求 |
|-----------|------|
| 跑 ComfyUI 本体 | **PyTorch 2.7 及以上**（官方强烈建议用更新版本）；**NVIDIA 20 系及以上要求 cu130 及以上的 PyTorch** |
| 装依赖 | `pip install -r requirements.txt` —— 仓库里的清单才是权威 |
| 看有哪些启动参数 | `python main.py --help` 的实际输出；官方参数表见 [A6 安装部署参考](./A6-安装部署参考.md) |
| 装 xFormers | 与 PyTorch 版本**严格配对**，直接装最新版；装了即自动启用 |

> 📅 原文那张「v0.3.x → PyTorch 2.5+」的对应关系早已作废：ComfyUI 的版本号与依赖要求**不是一一对应**的，照那种表装环境一定会装错。

## 常见问题

> **排查顺序：** 先用[八、版本检查脚本](#八版本检查脚本)确认环境 → 再确认模型放对了位置（[四、目录结构总览](#四目录结构总览)）→ 再看节点包是否与本体版本匹配（[5.7 维护状态说明](#57-维护状态说明)）→ 最后查有没有用到[已停止维护的项目](#56-已废弃停止维护的项目)。

### Q1: 模型下载速度很慢怎么办？

**解决方案：**
- 使用 HuggingFace 镜像站（如 hf-mirror.com）
- 使用下载工具（如 IDM、迅雷）
- 使用代理加速

### Q2: 如何确认模型是否正确安装？

**方法：**
1. 启动 ComfyUI
2. 添加对应的加载节点（如 Load Checkpoint）
3. 点击下拉框查看是否显示模型名称

### Q3: 节点包安装后报错怎么办？

**排查步骤：**
1. 检查 ComfyUI 版本是否满足最低要求
2. 检查依赖是否正确安装
3. 查看节点包的 GitHub Issues
4. 尝试更新到最新版本

### Q4: 如何更新 ComfyUI 和节点包？

**手动安装 / 便携版：**
```bash
# 更新 ComfyUI（手动安装）
cd ComfyUI
git pull

# 更新节点包
cd custom_nodes/节点包名
git pull
```

便携版用解压包 `update/` 目录里的 `update_comfyui.bat` / `update_comfyui_stable.bat`。

**Comfy Desktop：**
- 启动器顶部会出现 `Desktop Update Ready` 按钮；也可以 菜单 → `Desktop Settings` → `Updates`
- 更新通道在实例的 `Manage` → `Update` 里选（`Stable` / `Latest on GitHub`）

### Q5: 不同版本的模型可以混用吗？

**建议：**
- SD 1.5 模型与 SD 1.5 ControlNet 配合使用
- SDXL 模型与 SDXL ControlNet 配合使用
- 混用可能导致效果不佳或报错

### Q6: 如何确认我的路径是否正确？

**方法：**
1. 打开 ComfyUI 设置 → Directories
2. 查看显示的路径
3. 确保模型放在该路径下的子目录中

### Q7: 模型文件太大，磁盘空间不够怎么办？

**解决方案：**
- 使用符号链接将模型放在其他盘
- 使用 `extra_model_paths.yaml` 配置额外路径
- 删除不常用的模型

### Q8: 如何选择合适的模型？

**建议：**
- 写实风格：Realistic Vision、Juggernaut
- 动漫风格：Anything、MeinaMix
- 通用风格：DreamShaper、Deliberate
