# A3 提示词技巧速查

> **适合人群：** 已掌握提示词基础的进阶用户
> **阅读时长：** 约 20 分钟

## 功能描述（通俗易懂）

本文档介绍 ComfyUI 中**高级提示词技巧**，帮助你更精确地控制 AI 生成效果。这些技巧包括权重调整、交替提示词、Embedding 使用等。

### 核心价值

| 技巧 | 作用 | 效果 |
|------|------|------|
| **权重调整** | 控制词语重要性 | 精确控制画面元素 |
| **交替提示词** | 在生成过程中切换词语 | 创造独特效果 |
| **动态提示词** | 随机选择词语 | 批量生成变体 |
| **Embedding** | 使用预训练词语向量 | 稳定提升质量 |

---

## 使用场景

| 场景 | 适用技巧 | 效果 |
|------|----------|------|
| **强调特定元素** | 权重调整 | 让某个元素更突出 |
| **创造独特效果** | 交替提示词 | 混合不同风格 |
| **批量生成变体** | 动态提示词 | 一次生成多种版本 |
| **提升画面质量** | Embedding | 稳定高质量输出 |
| **避免特定问题** | 负向 Embedding | 减少画面错误 |

## 提示词结构

### 标准结构

```text
[主体] + [动作/状态] + [环境/背景] + [风格] + [质量词]
```

### 示例解析

```text
a beautiful woman          ← 主体：一个美丽的女人
reading a book             ← 动作：正在读书
in a cozy library          ← 环境：在温馨的图书馆
oil painting style         ← 风格：油画风格
masterpiece, best quality  ← 质量词：杰作，最佳质量
```

## 权重语法

### 基本权重语法

> ⚠️ **注意：** 以下语法为 ComfyUI 原生支持。

| 语法 | 效果 | 示例 |
|------|------|------|
| `(word)` | 增强约 1.1 倍 | `(blue sky)` |
| `((word))` | 增强约 1.21 倍 | `((blue sky))` |
| `(word:1.5)` | 自定义权重 1.5 倍 | `(blue sky:1.5)` |
| `[word]` | 减弱约 0.9 倍 | `[blue sky]` |

### 权重范围建议

| 权重范围 | 效果 | 建议 |
|----------|------|------|
| 0.5-0.9 | 减弱 | 减少某个元素的影响 |
| 1.0 | 默认 | 正常权重 |
| 1.1-1.3 | 轻微增强 | **推荐日常使用** |
| 1.4-1.5 | 明显增强 | 谨慎使用 |
| 1.5+ | 过度增强 | 可能导致失真 |

### 权重使用示例

```text
基础版：a woman in a garden
增强版：(beautiful woman:1.2) in a (flower garden:1.1)
减弱版：a woman in a [crowded] garden
组合版：(beautiful woman:1.2), (flower garden:1.1), [people:0.8]
```

## 交替与组合

### 交替提示词

在生成过程中切换不同的词语：

```text
[blue:red:0.5]
```

**解释：** 前 50% 的步数使用 "blue"，后 50% 使用 "red"

**效果：** 蓝色和红色混合过渡

### 交替提示词示例

| 语法 | 效果 |
|------|------|
| `[cat:dog:0.5]` | 前半程画猫，后半程画狗 |
| `[day:night:0.3]` | 前 30% 画白天，后 70% 画夜晚 |
| `[realistic:anime:0.6]` | 前 60% 写实风格，后 40% 动漫风格 |

### 动态提示词（随机选择）

每次队列时随机选择一个词语：

```text
{day|night}
```

**效果：** 每次生成随机选择 "day" 或 "night"

### 多选项动态提示词

```text
{wild|card|test}
```

**效果：** 每次随机选择 "wild"、"card" 或 "test"

### 动态提示词支持注释

```text
{day|night} // 这是注释
/* 多行注释 */
```

## Embedding 使用

### 什么是 Embedding？

Embedding（嵌入）是预训练的词语向量，可以帮助：
- 稳定提升画面质量
- 避免特定的画面问题
- 添加特定的风格效果

### 安装 Embedding

1. 下载 `.pt` 或 `.safetensors` 文件
2. 放入 `ComfyUI/models/embeddings/` 目录
3. 重启 ComfyUI

### 使用语法

```text
embedding:embedding_filename.pt
```

或省略扩展名：

```text
embedding:embedding_filename
```

### 常用 Embedding

| Embedding | 类型 | 作用 |
|-----------|------|------|
| `EasyNegative` | 负向 | 减少画面问题 |
| `badhandv4` | 负向 | 减少手部错误 |
| `ng_deepnegative_v1_75t` | 负向 | 通用负向优化 |
| `verybadimagenegative_v1.3` | 负向 | 减少画面问题 |

### Embedding 使用示例

**正向提示词：**
```text
a beautiful woman, embedding:easynegative
```

**负向提示词：**
```text
embedding:badhandv4, low quality, blurry
```

## 注意事项

### 权重使用

- 权重过高可能导致画面失真
- 建议权重范围：0.8-1.3
- 避免对多个词语使用高权重

### 交替提示词

- 交替点（如 0.5）影响最终效果
- 过早交替可能导致元素混合
- 建议从 0.5 开始尝试

### Embedding

- 确保 Embedding 文件格式正确
- 不同 Embedding 效果不同，需要测试
- 可以同时使用多个 Embedding

## 常见问题

### Q1：权重应该设置多少？

**建议：**
- 日常使用：1.1-1.2
- 强调效果：1.3-1.4
- 超过 1.5 可能导致失真

---

### Q2：交替提示词效果不明显？

**解决方案：**
1. 调整交替点（如从 0.5 改为 0.3 或 0.7）
2. 使用差异较大的词语
3. 增加 steps 数量

---

### Q3：Embedding 加载失败？

**解决方案：**
1. 检查文件是否在正确目录
2. 检查文件格式是否正确
3. 重启 ComfyUI

---

### Q4：动态提示词不生效？

**解决方案：**
1. 确保使用正确的语法 `{a|b|c}`
2. 检查是否有语法错误
3. 确保每次队列生成不同结果

---

### Q5：如何组合使用多种技巧？

**建议顺序：**
1. 先写基础提示词
2. 添加权重调整
3. 添加 Embedding
4. 最后添加动态/交替提示词
