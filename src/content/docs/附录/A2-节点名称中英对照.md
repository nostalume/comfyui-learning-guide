# A2 节点名称中英对照

> **相关官方文档：** [ComfyUI 官方文档](https://docs.comfy.org/) | [中文文档](https://docs.comfy.org/zh/)
> **适合人群：** 所有读者
> **体裁：** reference（查阅型）—— **本文不做推导**，只索引已推出的结论。推导见 [1.5-节点类型](../1-概述与安装部署/1.5-节点类型.md)
> **用途：** 在界面（英文）与文档（中文）之间建立名称对应

---

## 为什么需要这份表

ComfyUI 界面上的节点名是**英文**，而本套文档用**中文**称呼它们。这不是翻译偏好问题，而是两种必要之间的取舍：

- 如果文档直接用英文名：读文档时要在脑子里做一次映射，且不知道社区中文讨论里那个节点叫什么。
- 如果文档直接用中文名：在软件里**搜不到**那个节点（搜索框只认英文）。

因此本套文档的约定是 **`英文名（中文名）`** —— 首次出现时给出两者，之后可只用其一。

**这也是为什么这份表是「查阅型」而不是「教学型」：** 它记录的是已经推导出的命名结论。想理解「为什么 ComfyUI 要区分 Load Checkpoint 和 Load LoRA」，请读 [1.5-节点类型](../1-概述与安装部署/1.5-节点类型.md) 与 [2.6-LoRA与LyCORIS](../2-模型体系与管理/2.6-LoRA与LyCORIS.md)。

## A2.1 核心节点速查

按**在标准工作流中的出现顺序**排列 —— 这个顺序本身就是文生图的执行顺序：

| # | 英文名 | 中文名 | 类别 | 一句话作用 |
|---|--------|--------|------|-----------|
| 1 | `Load Checkpoint` | 加载模型 | 输入 | 把大模型读进内存，工作流的起点 |
| 2 | `CLIP Text Encode` | CLIP文本编码器 | 输入 | 把提示词文字变成 AI 能用的条件 |
| 3 | `CLIP Text Encoder` | CLIP文本编码器 | 输入 | 同上（部分版本/插件的写法差异） |
| 4 | `Empty Latent Image` | 空Latent图像 | 输入 | 生成一块空白潜空间作为画布 |
| 5 | `Load Image` | 加载图像 | 输入 | 读取一张图片（图生图/ControlNet 用） |
| 6 | `Load VAE` | 加载VAE | 输入 | 单独加载 VAE（不用 Checkpoint 自带的） |
| 7 | `Load LoRA` | 加载LoRA | 输入 | 给基础模型叠加风格/人物/概念 |
| 8 | `Load ControlNet Model` | 加载ControlNet模型 | 输入 | 加载控制模型 |
| 9 | `Apply ControlNet` | 应用ControlNet | 处理 | 把控制条件注入生成过程 |
| 10 | `KSampler` | K采样器 | 生成 | 核心节点：按条件与参数迭代出图 |
| 11 | `VAE Encode` | VAE编码 | 处理 | 把像素图压成潜空间（图生图用） |
| 12 | `VAE Decode` | VAE解码 | 处理 | 把潜空间还原成像素图 |
| 13 | `Upscale Image` | 放大图像 | 处理 | 放大图片尺寸 |
| 14 | `Preview Image` | 预览图像 | 输出 | 显示结果（不落盘） |
| 15 | `Save Image` | 保存图像 | 输出 | 保存结果到磁盘 |

### 一个必须注意的坑

`CLIP Text Encode` 与 `CLIP Text Encoder` 是**同一件事的两种写法**，都译作「CLIP文本编码器」。不同版本、不同插件里会出现其中任一个，界面搜索时两个都值得试。**这不是两个不同节点。**

## A2.2 按类别分组

同一张表，换个组织方式 —— 便于「我想找一个做某类事的节点」时查阅。

### 输入类（把外部资源读进来）

| 英文名 | 中文名 | 读什么 |
|--------|--------|--------|
| `Load Checkpoint` | 加载模型 | 大模型（决定整体风格） |
| `Load LoRA` | 加载LoRA | 小型风格/人物模型 |
| `Load VAE` | 加载VAE | 色彩解码器 |
| `Load ControlNet Model` | 加载ControlNet模型 | 控制模型 |
| `Load Image` | 加载图像 | 磁盘上的图片 |
| `CLIP Text Encode` | CLIP文本编码器 | 文字提示词 |
| `Empty Latent Image` | 空Latent图像 | 无（凭空造一块画布） |

### 处理/生成类

| 英文名 | 中文名 | 做什么 |
|--------|--------|--------|
| `KSampler` | K采样器 | 采样生成（工作流的引擎） |
| `Apply ControlNet` | 应用ControlNet | 注入控制条件 |
| `VAE Encode` | VAE编码 | 像素 → 潜空间 |
| `VAE Decode` | VAE解码 | 潜空间 → 像素 |
| `Upscale Image` | 放大图像 | 尺寸放大 |

### 输出类

| 英文名 | 中文名 | 区别 |
|--------|--------|------|
| `Preview Image` | 预览图像 | 只在界面显示，**不写磁盘** |
| `Save Image` | 保存图像 | 写入输出目录 |

> **`Preview Image` vs `Save Image` 的实用差别：** 调试阶段全用 Preview，避免输出目录堆满废图；定稿后才换成 Save。两者的输出接口一样，可以互换。

## A2.4 命名约定（供贡献者参考）

本套文档遵循以下约定，新增内容时请保持一致：

1. **首次出现**用 `英文名（中文名）` 完整形式。
2. **之后出现**可只用中文名或英文名，依上下文可读性而定。
3. **标题中**可用 `### Load Checkpoint（加载模型）`。
4. **代码块内不标注** —— 代码/workflow JSON 里的名字必须原样保留，否则无法运行。
5. 中文名**优先采用官方中文文档的译法**（参照 `https://docs.comfy.org/zh/`）。
6. 端口与参数名保留英文，必要时括号注释，如 `ckpt_name（模型文件名）`。
