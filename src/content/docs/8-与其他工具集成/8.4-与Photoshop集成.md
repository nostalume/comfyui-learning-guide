## 概述

### 什么是 Photoshop 集成？

**功能描述：**
Photoshop 集成是指将 ComfyUI 与 Adobe Photoshop 连接，实现图层互通、蒙版编辑、AI 增强、局部重绘等功能，将 AI 生成能力无缝融入传统设计工作流。

**核心价值：**
- 🎨 **图层互通**：PS 图层与 ComfyUI 双向传输
- 🎭 **蒙版编辑**：利用 PS 精确的蒙版功能
- ⚡ **AI 增强**：一键放大、风格化、重绘
- 🔄 **非破坏性**：AI 结果作为新图层，保留原始内容

**使用场景：**

| 场景 | 说明 | 效率提升 |
|------|------|----------|
| 局部重绘 | 精确修改图像局部 | ⭐⭐⭐⭐⭐ |
| 图像放大 | AI 超分辨率放大 | ⭐⭐⭐⭐ |
| 风格转换 | 将照片转为艺术风格 | ⭐⭐⭐⭐ |
| 背景替换 | 智能替换背景 | ⭐⭐⭐⭐ |

## 方式一：ComfyUI-Photoshop 插件（推荐）

### 插件简介

**功能描述：**
ComfyUI-Photoshop 插件是一个连接 Photoshop 和 ComfyUI 的桥梁，支持图层发送、结果接收、蒙版处理等功能。

**支持版本：**
- Photoshop CC 2019 及以上
- Photoshop 2020/2021/2022/2023/2024（推荐）

### 安装步骤详解

#### 第一步：下载插件

1. **访问 GitHub 仓库**
   - 网址：https://github.com/NimaNzrii/comfyui-photoshop
   - 或搜索「ComfyUI Photoshop Plugin」

2. **下载最新版本**
   - 点击「Releases」
   - 下载最新版本的 ZIP 文件
   - 文件名类似：`comfyui-photoshop-v1.x.x.zip`

#### 第二步：解压并安装

**Windows 安装步骤：**

1. **解压文件**
   - 右键 ZIP 文件 →「解压到当前文件夹」
   - 得到 `comfyui-photoshop` 文件夹

2. **复制到 Photoshop 插件目录**
   
   **默认路径：**
   ```text
   C:\Program Files\Adobe\Adobe Photoshop 2024\Plug-ins\
   ```
   
   **或用户插件目录：**
   ```text
   C:\Users\[用户名]\AppData\Roaming\Adobe\Plug-ins\CC\
   ```
   
   **操作方法：**
   - 将解压的文件夹复制到上述目录之一
   - 如果目录不存在，请手动创建

3. **设置插件权限**
   - 右键插件文件夹 →「属性」
   - 取消勾选「只读」（如有）
   - 点击「确定」

**Mac 安装步骤：**

1. **解压文件**
   - 双击 ZIP 文件解压

2. **复制到插件目录**
   ```text
   /Applications/Adobe Photoshop 2024/Plug-ins/
   ```
   
   或用户目录：
   ```text
   ~/Library/Application Support/Adobe/Plug-Ins/CC/
   ```

#### 第三步：启动 ComfyUI 服务

1. **打开命令提示符**
   - Win + R → 输入 `cmd` → 回车

2. **进入 ComfyUI 目录**
   ```bash
   cd C:\ComfyUI
   ```

3. **启动 ComfyUI**
   ```bash
   python main.py --listen 0.0.0.0 --port 8188
   ```

   **参数说明：**
   
   | 参数 | 功能描述 | 说明 |
   |------|----------|------|
   | --listen 0.0.0.0 | 监听所有网络接口 | 允许外部访问 |
   | --port 8188 | 端口号 | 默认 8188 |

4. **验证启动成功**
   - 看到 `Starting server` 字样
   - 访问 http://localhost:8188 确认可打开

#### 第四步：配置插件连接

1. **启动 Photoshop**
   - 打开 Photoshop
   - 如果提示「无法验证插件」，请在设置中允许

2. **打开插件面板**
   - 菜单：窗口 → 扩展功能 → ComfyUI
   - 或：窗口 → 扩展 → ComfyUI

3. **配置连接参数**
   
   在插件面板中设置：
   
   | 参数 | 设置值 | 说明 |
   |------|--------|------|
   | Host | localhost | ComfyUI 地址 |
   | Port | 8188 | ComfyUI 端口 |
   
   点击「Test Connection」测试连接

4. **连接成功提示**
   - 显示绿色「Connected」表示成功
   - 显示红色「Connection Failed」请检查：
     - ComfyUI 是否正在运行
     - 端口是否正确
     - 防火墙是否阻止

### 插件使用教程

#### 功能一：发送图层到 ComfyUI

**功能描述：**
将 Photoshop 中的图层发送到 ComfyUI 进行处理。

**详细步骤：**

1. **选择图层**
   - 在图层面板中选择要处理的图层
   - 支持普通图层、智能对象、调整图层

2. **打开插件面板**
   - 窗口 → 扩展功能 → ComfyUI

3. **点击发送按钮**
   - 点击「Send Layer」或「发送图层」
   - 等待传输完成（通常 1-3 秒）

4. **在 ComfyUI 中查看**
   - 图层会自动加载到 Load Image 节点
   - 可以开始设计工作流

#### 功能二：接收处理结果

**功能描述：**
将 ComfyUI 生成的图像导入到 Photoshop 作为新图层。

**详细步骤：**

1. **在 ComfyUI 中完成生成**
   - 运行工作流
   - 等待生成完成

2. **点击接收按钮**
   - 在插件面板点击「Receive Result」
   - 或「接收结果」

3. **结果导入**
   - 图像自动作为新图层导入
   - 位于当前选中图层上方

#### 功能三：发送蒙版

**功能描述：**
将 Photoshop 中的蒙版发送到 ComfyUI，用于局部重绘。

**详细步骤：**

1. **创建蒙版**
   - 选择图层
   - 点击图层面板下方的「添加蒙版」按钮
   - 使用画笔工具绘制蒙版
   - 白色 = 保留，黑色 = 处理

2. **发送蒙版**
   - 在插件面板点击「Send Mask」
   - 蒙版会作为单独图像发送

3. **在 ComfyUI 中使用**
   - 蒙版加载到 Load Image 节点
   - 连接到 Mask 输入端口

### 常用工作流示例

#### 局部重绘工作流

**功能描述：**
使用 Photoshop 蒙版精确控制重绘区域。

**详细步骤：**

1. **在 Photoshop 中准备**
   - 打开要处理的图像
   - 创建蒙版，标记要修改的区域
   - 黑色 = 需要重绘的区域

2. **发送图层和蒙版**
   - 点击「Send Layer」发送原图
   - 点击「Send Mask」发送蒙版

3. **在 ComfyUI 中配置**
   
   **节点连接：**
   ```text
   Load Image (原图) → VAEEncode
   Load Image (蒙版) → Mask Composite
       ↓
   KSampler (Inpainting) → VAE Decode
       ↓
   Save Image
   ```

4. **运行并接收结果**
   - 点击「Queue Prompt」运行
   - 在 Photoshop 插件中点击「Receive Result」

#### 图像放大工作流

**功能描述：**
使用 AI 模型放大低分辨率图像。

**详细步骤：**

1. **选择要放大的图层**
   - 在 Photoshop 中选择图层

2. **发送到 ComfyUI**
   - 点击「Send Layer」

3. **配置放大工作流**
   
   **推荐模型：**
   
   | 模型 | 放大倍数 | 特点 |
   |------|----------|------|
   | Real-ESRGAN | 4x | 通用，效果好 |
   | ESRGAN_4x | 4x | 高质量 |
   | SwinIR | 4x | 细节保留好 |
   | 4x-UltraSharp | 4x | 锐化效果好 |

   **节点连接：**
   ```text
   Load Image → Upscale Model → Save Image
   ```

4. **接收放大结果**
   - 高分辨率图像作为新图层导入

## Photoshop 脚本开发

### JSX 脚本基础

**功能描述：**
使用 Photoshop 的 JSX 脚本语言自动化操作。

**脚本示例：发送图层到 ComfyUI**

```javascript
/*
 * 发送当前图层到 ComfyUI
 * 
 * 功能描述：
 * 1. 导出当前图层为 PNG
 * 2. 通过 API 上传到 ComfyUI
 * 3. 返回图像名称
 */

function sendLayerToComfyUI() {
    var doc = app.activeDocument;
    var layer = doc.activeLayer;
    
    if (!layer.visible) {
        alert("请选择可见图层");
        return;
    }
    
    var tempFile = new File(Folder.temp + "/comfyui_layer_" + Date.now() + ".png");
    
    var saveOptions = new PNGSaveOptions();
    saveOptions.compression = 9;
    saveOptions.interlaced = false;
    
    doc.saveAs(tempFile, saveOptions, true, Extension.LOWERCASE);
    
    var serverUrl = "http://localhost:8188";
    var uploadUrl = serverUrl + "/upload/image";
    
    var result = uploadFile(tempFile, uploadUrl);
    
    tempFile.remove();
    
    if (result) {
        alert("图层已发送到 ComfyUI\n图像名称: " + result.name);
        return result.name;
    } else {
        alert("发送失败，请检查 ComfyUI 是否运行");
    }
}

function uploadFile(file, url) {
    var connection = new Socket();
    
    if (connection.open(url.replace("http://", ""), "binary")) {
        var boundary = "----ComfyUIBoundary" + Date.now();
        
        var header = "POST /upload/image HTTP/1.1\r\n";
        header += "Host: localhost:8188\r\n";
        header += "Content-Type: multipart/form-data; boundary=" + boundary + "\r\n";
        
        file.encoding = "BINARY";
        file.open("r");
        var fileData = file.read();
        file.close();
        
        var body = "--" + boundary + "\r\n";
        body += 'Content-Disposition: form-data; name="image"; filename="' + file.name + '"\r\n';
        body += "Content-Type: image/png\r\n\r\n";
        body += fileData;
        body += "\r\n--" + boundary + "--\r\n";
        
        header += "Content-Length: " + body.length + "\r\n\r\n";
        
        connection.write(header + body);
        
        var response = connection.read(999999);
        connection.close();
        
        var jsonStart = response.indexOf("{");
        if (jsonStart > -1) {
            var jsonStr = response.substring(jsonStart);
            return eval("(" + jsonStr + ")");
        }
    }
    
    return null;
}

sendLayerToComfyUI();
```

### 接收结果脚本

```javascript
/*
 * 从 ComfyUI 接收生成的图像
 * 
 * 功能描述：
 * 1. 从 ComfyUI output 目录获取图像
 * 2. 导入为新的图层
 */

function receiveFromComfyUI(filename) {
    var doc = app.activeDocument;
    
    var imageUrl = "http://localhost:8188/view?filename=" + filename + "&type=output";
    
    var tempFile = new File(Folder.temp + "/comfyui_result_" + Date.now() + ".png");
    
    if (downloadFile(imageUrl, tempFile)) {
        var placedLayer = doc.artLayers.add();
        placedLayer.name = "ComfyUI Result";
        
        var fileRef = new File(tempFile.fsName);
        var docRef = app.open(fileRef);
        
        docRef.activeLayer.duplicate(doc, ElementPlacement.PLACEATBEGINNING);
        docRef.close(SaveOptions.DONOTSAVECHANGES);
        
        tempFile.remove();
        
        return true;
    }
    
    return false;
}

function downloadFile(url, destFile) {
    var connection = new Socket();
    
    if (connection.open("localhost:8188", "binary")) {
        var request = "GET /view?filename=" + destFile.name + "&type=output HTTP/1.1\r\n";
        request += "Host: localhost:8188\r\n";
        request += "Connection: close\r\n\r\n";
        
        connection.write(request);
        
        var response = connection.read(99999999);
        connection.close();
        
        var headerEnd = response.indexOf("\r\n\r\n");
        if (headerEnd > -1) {
            var imageData = response.substring(headerEnd + 4);
            
            destFile.encoding = "BINARY";
            destFile.open("w");
            destFile.write(imageData);
            destFile.close();
            
            return true;
        }
    }
    
    return false;
}
```

## 实用技巧

### 非破坏性工作流

**功能描述：**
保持原始内容不被修改，AI 结果作为新图层。

**操作方法：**

1. **使用智能对象**
   - 右键图层 → 转换为智能对象
   - 处理后可随时修改

2. **保留原始图层**
   - 复制图层后再处理
   - 隐藏原始图层作为备份

3. **使用图层组**
   - 将 AI 处理结果放入图层组
   - 方便管理和对比

### 色彩管理

**功能描述：**
确保 PS 和 ComfyUI 之间色彩一致。

**设置方法：**

| 设置项 | 推荐值 | 说明 |
|--------|--------|------|
| 色彩空间 | sRGB | 最广泛兼容 |
| 位深度 | 8-bit | 通用格式 |
| 配置文件 | 嵌入 ICC | 确保色彩准确 |

**导出设置：**
- 文件 → 导出 → 导出为
- 勾选「嵌入颜色配置文件」

### 分辨率匹配

**功能描述：**
确保输入输出分辨率一致。

**注意事项：**
- 发送前检查图像尺寸
- ComfyUI 中设置正确的宽高
- 接收结果时检查分辨率

## 常见问题 FAQ

<details>
<summary>❓ 插件无法连接 ComfyUI 怎么办？</summary>

**排查步骤：**

1. **检查 ComfyUI 是否运行**
   - 访问 http://localhost:8188
   - 确认可以打开 ComfyUI 界面

2. **检查端口是否正确**
   - 默认端口：8188
   - 如果修改了端口，需在插件中同步修改

3. **检查防火墙设置**
   - Windows：控制面板 → 防火墙 → 允许应用
   - 添加 Python 和 Photoshop 到允许列表

4. **检查启动参数**
   - 确保 ComfyUI 使用 `--listen 0.0.0.0` 启动
   - 或使用 `--listen 127.0.0.1`

</details>

<details>
<summary>❓ 图像质量有损失怎么办？</summary>

**解决方法：**

1. **使用 PNG 格式传输**
   - PNG 无损压缩
   - 避免使用 JPEG

2. **避免多次压缩**
   - 一次性导出
   - 不要反复导出导入

3. **保持色彩空间一致**
   - 使用 sRGB
   - 嵌入 ICC 配置文件

4. **检查位深度**
   - 使用 8-bit 或 16-bit
   - 避免转换时降质

</details>

<summary>❓ 处理速度慢怎么办？</summary>

**优化方法：**

| 优化项 | 方法 | 效果 |
|--------|------|------|
| 降低分辨率 | 发送前缩小图像 | 显著提升 |
| 减少采样步数 | steps: 20-25 | 中等提升 |
| 使用更快采样器 | dpmpp_2m | 中等提升 |
| 启用 GPU 加速 | 确保使用 GPU | 显著提升 |

</details>

<details>
<summary>❓ 如何在 Photoshop 中找到插件？</summary>

**查找方法：**

1. **检查安装位置**
   - 插件应在 Plug-ins 目录下

2. **重新启动 Photoshop**
   - 安装后需重启

3. **检查扩展面板**
   - 窗口 → 扩展功能（或扩展）
   - 查找「ComfyUI」

4. **检查插件管理器**
   - 帮助 → 关于插件
   - 查看是否列出

</details>
