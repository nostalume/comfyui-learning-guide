## 功能描述

工作流复用是指将设计好的 ComfyUI 工作流保存为模板，方便日后重复使用或分享给他人。这就像保存了一个"配方"，下次只需要换一下"食材"（参数），就能快速得到想要的结果。

### 工作流复用原理

ComfyUI 的工作流以 JSON 格式存储，包含以下信息：

1. **节点定义**：工作流中使用的所有节点及其类型
2. **连接关系**：节点之间的数据流向
3. **参数值**：每个节点的具体参数设置
4. **布局信息**：节点在画布上的位置

当加载工作流时，ComfyUI 会根据 JSON 文件重建整个工作流图。

## 使用场景

| 场景 | 说明 |
|------|------|
| 日常生成 | 保存常用的基础工作流，快速开始新任务 |

| 团队协作 | 分享工作流给团队成员使用 |
| 学习交流 | 分享工作流帮助他人学习 |

## 5.3.1 模板化工作流

### 功能描述

将工作流按用途分类存储，形成个人或团队的模板库。良好的分类结构可以大大提高工作效率。

### 分类建议

```text
workflows/
├── portrait/                    # 人像生成
│   ├── basic_portrait.json      # 基础人像
│   ├── portrait_with_lora.json  # LoRA 风格人像
│   └── portrait_hires.json      # 高清放大人像
│
├── landscape/                   # 风景生成
│   ├── basic_landscape.json     # 基础风景
│   └── landscape_wide.json      # 宽屏风景
│
├── product/                     # 产品图
│   ├── product_photo.json       # 产品摄影
│   └── product_white_bg.json    # 白底产品图
│
├── img2img/                     # 图生图
│   ├── basic_img2img.json       # 基础图生图
│   └── style_transfer.json      # 风格迁移
│
└── api/                         # API 工作流
    ├── batch_generation.json    # 批量生成
    └── automated_pipeline.json  # 自动化流水线
```

### 操作步骤

1. 在 ComfyUI 中设计好工作流
2. 按 `Ctrl + S` 或点击菜单 **Save**
3. 选择保存位置，按分类命名（如 `portrait/basic_portrait.json`）
4. 下次使用时，按 `Ctrl + O` 加载该工作流

## 5.3.2 保存与加载工作流

### 功能描述

ComfyUI 提供多种方式保存和加载工作流，支持本地文件和图片嵌入两种形式。

### 保存操作

| 操作 | 方法 | 快捷键 | 说明 |
|------|------|--------|------|
| 保存工作流 | 菜单 → Save | `Ctrl + S` | 保存为 JSON 文件 |
| 另存为 | 菜单 → Save As | - | 指定新名称保存 |
| 保存为 API 格式 | 菜单 → Save (API Format) | - | 用于 API 调用 |
| 保存为图片 | 菜单 → Save as Image | - | 嵌入 JSON 到 PNG |

### 加载操作

| 操作 | 方法 | 快捷键 | 说明 |
|------|------|--------|------|
| 加载工作流 | 菜单 → Load | `Ctrl + O` | 从 JSON 文件加载 |
| 加载默认工作流 | 菜单 → Load Default | `Ctrl + D` | 加载默认模板 |
| 从图片加载 | 拖拽 PNG 到浏览器 | - | 从嵌入 JSON 的图片加载 |

### 操作步骤

#### 保存工作流

1. 设计完成工作流后，点击右上角菜单按钮
2. 选择 **Save** 或按 `Ctrl + S`
3. 在弹出的对话框中选择保存位置
4. 输入文件名，点击保存

#### 加载工作流

1. 点击右上角菜单按钮
2. 选择 **Load** 或按 `Ctrl + O`
3. 选择要加载的 JSON 文件
4. 工作流会在画布中重建

#### 从图片加载工作流

1. 找到之前导出的工作流图片（PNG 格式）
2. 直接将图片拖拽到浏览器窗口
3. ComfyUI 会自动提取嵌入的 JSON 并加载工作流

## 5.3.3 工作流分享

### 功能描述

将设计好的工作流分享给他人，支持 JSON 文件和图片两种方式。

### 方式一：JSON 文件分享

#### 操作步骤

1. 保存工作流为 JSON 文件
2. 将 JSON 文件发送给对方（邮件、网盘等）
3. 对方在 ComfyUI 中选择 **Load** 加载该文件
4. 如有自定义节点，需要安装相应插件

#### 注意事项

- 💡 接收方需要安装工作流中使用的所有自定义节点
- 💡 可以在 JSON 中添加注释说明用途和参数

### 方式二：截图分享

#### 功能描述

将工作流导出为 PNG 图片，图片中嵌入完整的 JSON 数据。这种方式直观且方便传播。

#### 操作步骤

1. 在菜单中选择 **Save as Image**
2. 选择保存位置
3. 将生成的 PNG 图片分享给对方
4. 对方直接将图片拖入 ComfyUI 即可加载

#### 示例

```text
分享流程：
├── 发送方：Save as Image → 得到 workflow.png
├── 传输：通过微信/邮件/网盘发送
└── 接收方：拖拽 PNG 到 ComfyUI → 自动加载工作流
```

#### 注意事项

- 💡 图片看起来是工作流的截图，但内部包含完整 JSON
- 💡 不要用图片编辑软件修改该图片，否则可能损坏嵌入数据
- 💡 适合在社交媒体分享，接收方无需额外工具

## 5.3.4 模板管理建议

### 命名规范

| 规范 | 示例 | 说明 |
|------|------|------|
| 功能描述 | `portrait_realistic.json` | 清晰表达用途 |
| 版本号 | `portrait_v2.json` | 区分不同版本 |
| 日期标记 | `portrait_20240428.json` | 按时间管理 |
| 作者标记 | `portrait_by_john.json` | 多人协作时区分 |

### 版本管理

```text
建议使用 Git 管理工作流：

workflows/
├── .git/
├── portrait/
│   ├── basic.json
│   └── README.md  # 说明文档
└── .gitignore
```

### 模板文档化

为重要模板添加说明文档：

```markdown
# basic_portrait.json

## 用途
生成写实风格人像

## 推荐参数
- 模型：realistic_vision_v5
- 尺寸：512x768
- 步数：25-30

## 依赖节点
- 无自定义节点

## 作者
John Doe
```

## 5.3.5 工作流优化建议

### 提高复用性的技巧

| 技巧 | 说明 |
|------|------|
| 参数外部化 | 使用 Primitive 节点提取关键参数 |
| 模块化设计 | 将常用组合封装为独立模块 |
| 添加注释 | 在关键节点添加说明 |
| 清理冗余 | 删除未使用的节点和连接 |

### 示例：参数外部化后的工作流

| 外部参数（Primitive 节点） | 目标节点 |
|---|---|
| 正向提示词 | CLIP文本编码器（CLIP Text Encoder） |
| 负向提示词 | CLIP文本编码器（CLIP Text Encoder） |
| 图片宽度 | 空Latent图像（Empty Latent Image） |
| 图片高度 | 空Latent图像（Empty Latent Image） |
| 种子 | K采样器（KSampler） |
| 采样步数 | K采样器（KSampler） |
| CFG 强度 | K采样器（KSampler） |

## 常见问题

### Q1：加载工作流时提示缺少节点怎么办？

**A：** 这说明工作流使用了你未安装的自定义节点。解决方法：
1. 查看错误提示中的节点名称
2. 在 ComfyUI Manager 中搜索并安装该节点
3. 重启 ComfyUI 后重新加载工作流

---

### Q2：如何将工作流设为默认启动模板？

**A：**
1. 设计好工作流后保存
2. 将文件命名为 `default.json`
3. 放置在 ComfyUI 的用户目录下
4. 重启 ComfyUI，按 `Ctrl + D` 即可加载

---

### Q3：工作流太大，加载很慢怎么办？

**A：** 优化建议：
- 删除未使用的节点
- 减少不必要的预览节点
- 将大型工作流拆分为多个小工作流

---

### Q4：如何批量管理工作流模板？

**A：** 建议：
- 使用文件夹按类别分类
- 使用 Git 进行版本控制
- 定期清理过时的模板
- 为模板添加说明文档

---

### Q5：分享的工作流对方打开后参数不对？

**A：** 可能原因：
- 模型文件名称不同，需要重新选择模型
- 自定义节点版本不同
- ComfyUI 版本差异

解决方法：在分享时附带说明文档，列出所需模型和节点。
