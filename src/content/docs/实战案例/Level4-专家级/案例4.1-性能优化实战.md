#### 1.1 检查 GPU 信息

打开命令行（Windows 按 `Win+R`，输入 `cmd`），执行以下命令：

```bash
nvidia-smi
```

**预期输出示例：**

```text
+-----------------------------------------------------------------------------+
| NVIDIA-SMI 535.154.05   Driver Version: 535.154.05   CUDA Version: 12.2     |
|-------------------------------+----------------------+----------------------+

+-------------------------------+----------------------+----------------------+
```

**关键信息解读：**

| 信息项 | 位置 | 含义 |
|-------|------|------|
| Driver Version | 第一行 | 显卡驱动版本 |
| CUDA Version | 第一行 | 支持的 CUDA 最高版本 |
| GPU Name | 第二行开始 | 显卡型号 |

#### 5.3 使用监控脚本（可选）

创建文件 `monitor_gpu.py`：

```python
import torch
import time

def monitor_vram(interval=1, duration=60):
    print("="*60)
    print("显存监控")
    print("="*60)
    print(f"{'时间(s)':<10} {'已分配(GB)':<15} {'已缓存(GB)':<15} {'空闲(GB)':<15}")
    print("-"*60)
    
    start = time.time()
    while time.time() - start < duration:
        allocated = torch.cuda.memory_allocated() / 1024**3
        reserved = torch.cuda.memory_reserved() / 1024**3
        total = torch.cuda.get_device_properties(0).total_memory / 1024**3
        free = total - allocated
        
        elapsed = time.time() - start
        print(f"{elapsed:<10.1f} {allocated:<15.2f} {reserved:<15.2f} {free:<15.2f}")
        time.sleep(interval)
    
    print("="*60)

if __name__ == "__main__":
    monitor_vram(interval=1, duration=30)
```

运行监控：

```bash
python monitor_gpu.py
```

## 常见问题

### Q1: 安装 xFormers 时报错 "No matching distribution found"

**原因分析：**
- Python 版本不兼容
- CUDA 版本与 PyTorch 不匹配
- pip 版本过旧

**解决方案：**

```bash
# 步骤1：更新 pip
python -m pip install --upgrade pip

# 步骤2：检查 Python 版本（需要 3.10+）
python --version

# 步骤3：检查 PyTorch CUDA 版本
python -c "import torch; print(torch.version.cuda)"

# 步骤4：按显卡重新安装 PyTorch 的 CUDA 版
# RTX 20 系及以上的 NVIDIA 卡：CUDA 13.0
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu130
# 10 系及更早的老卡：用旧的 CUDA 12.6 包
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu126

# 步骤5：重新安装 xFormers（版本跟着上一步的 torch 走）
pip install -U xformers
```

### Q2: 启动时提示 "xFormers not available" 或没有加速效果

**原因分析：**
- xFormers 未正确安装
- 启动参数未生效
- 与其他优化冲突

**解决方案：**

```bash
# 步骤1：验证 xFormers 安装
python -c "import xformers; print(xformers.__version__)"

# 步骤2：检查启动命令是否正确
python main.py

# 步骤3：查看控制台输出，确认包含
# "Using xformers cross attention"

# 步骤4：如果仍然无效，尝试重新安装
pip uninstall xformers
pip cache purge
pip install xformers
```

### Q3: 使用 BF16 后生成图像质量下降或出现异常

**原因分析：**
- 显卡不支持 BF16
- 模型与精度不兼容

**解决方案：**

```bash
# 步骤1：检查显卡是否支持 BF16
python -c "import torch; print(f'支持BF16: {torch.cuda.is_bf16_supported()}')"

# 如果输出 False，改用 FP16
python main.py --fp16-unet

# 步骤2：如果支持但仍有问题，尝试混合精度
python main.py --fp16-unet --bf16-vae
```

### Q4: Flash Attention 安装失败或编译错误

**原因分析：**
- 缺少编译工具
- CUDA 版本不兼容
- Windows 环境编译问题

**解决方案：**

```bash
# 方案1：使用预编译版本（如果有）
pip install flash-attn --no-build-isolation
```

### Q5: 优化后显存反而增加了

**原因分析：**
- 同时启用了多个优化选项
- 缓存未清理

**解决方案：**

```bash
# 步骤1：只使用必要的优化参数
python main.py

# 步骤2：不要同时指定多个注意力实现（它们互斥）
# 错误示例：
# python main.py --use-pytorch-cross-attention --use-flash-attention  # 不要这样

# 步骤3：定期重启 ComfyUI 清理缓存
```

### Q6: 如何确认优化是否真正生效？

**验证方法：**

1. **查看启动日志**

   启动时控制台应显示：
   ```text
   Using xformers cross attention
   ```
   或
   ```text
   Using flash attention
   ```

2. **对比生成时间**

   使用相同参数、相同种子，对比优化前后的生成时间

3. **监控显存使用**

   ```bash
   nvidia-smi -l 1
   ```
   观察生成过程中的显存峰值是否降低
