### 三条安装路径的差异

ComfyUI 的程序本体是同一份源码，但**装法有三条**（不是「两个版本」）—— 能力对照与迁移见 [A4 版本差异指南](../../附录/A4-版本差异指南.md)：

- **Comfy Desktop**：适合新手，一键安装、多实例管理。模型放在它统一管理的共享库里，**脚本里的路径要跟着改**（见 [2.1 模型放在哪](../../2-模型体系与管理/2.1-项目结构与模型存放.md)）。
- **Windows 便携版**：解压即用，自带 Python，启动用包里的 `run_nvidia_gpu.bat` —— **这个文件只有便携版有**，手动安装里没有它。
- **手动安装**：适合开发者，完全可控，启动用 `python main.py`，便于与脚本、API 集成。

**视频转绘比出图更吃环境，有两点与出图案例不同：**

1. **FFmpeg 与装法无关** —— 它是系统级工具，三条路径都要另装（见下文 [FFmpeg 安装说明](#ffmpeg-安装说明)）。
2. **这是长时任务**（逐帧处理，一批跑很久），所以「跑到一半才发现配置不对」的代价比出图大得多：桌面端改完实例设置要**重启实例**才生效，手动安装 / 便携版则是停掉进程重跑。开始前先把参数试对，见 [减少闪烁技巧详解](#减少闪烁技巧详解)。

#### 第三部分：帧编码与采样

```text
Load Video ──IMAGE──► VAE Encode ──LATENT──► KSampler
                            ▲                    ▲
Load Checkpoint ──VAE───────┘                    │
                                                 │
正向提示词 ──CONDITIONING─────────────────────────┤
                                                 │

```

**连接步骤：**
1. 拖入 `VAE Encode` 节点
2. **连接 IMAGE**：`Load Video` 的 IMAGE 输出 → `VAE Encode` 的 IMAGE 输入
3. **连接 VAE**：`Load Checkpoint` 的 VAE 输出 → `VAE Encode` 的 VAE 输入
4. 拖入 `KSampler` 节点
5. **连接 LATENT**：`VAE Encode` 的 LATENT 输出 → `KSampler` 的 LATENT 输入
6. **连接 MODEL**：`Load Checkpoint` 的 MODEL 输出 → `KSampler` 的 MODEL 输入
7. **连接 CONDITIONING**：正向/负向提示词连接到 KSampler

#### 第四部分：解码与合成

```text
KSampler ──LATENT──► VAE Decode ──IMAGE──► Video Combine
                            ▲
Load Checkpoint ──VAE───────┘
```

**连接步骤：**
1. 拖入 `VAE Decode` 节点
2. **连接 LATENT**：`KSampler` 的 LATENT 输出 → `VAE Decode` 的 LATENT 输入
3. **连接 VAE**：`Load Checkpoint` 的 VAE 输出 → `VAE Decode` 的 VAE 输入
4. 拖入 `Video Combine` 节点
5. **连接 IMAGE**：`VAE Decode` 的 IMAGE 输出 → `Video Combine` 的 IMAGE 输入

### 步骤 5: 详细参数配置

#### 5.1 Load Video 参数

| 参数 | 说明 | 推荐值 | 范围 |
|-----|------|-------|------|
| video | 选择视频文件 | - | - |
| force_rate | 强制帧率 | 0 或 10 | 0-30 |
| frame_load_cap | 最大加载帧数 | 0 或 30 | 0-100 |
| skip_first_frames | 跳过开头帧数 | 0 | 0+ |
| select_every_nth | 每隔几帧取一帧 | 1 | 1-5 |

> 💡 **技巧：** `frame_load_cap` 设为 0 表示加载全部帧，测试时建议限制帧数。

#### 5.2 KSampler 参数（关键！）

| 参数 | 推荐值 | 说明 | 重要程度 |
|-----|-------|------|---------|
| seed | **固定值**（如 12345） | **必须固定！** | ⭐⭐⭐⭐⭐ |
| steps | 20-30 | 采样步数 | ⭐⭐⭐ |
| cfg | 7-10 | 分类器指导系数 | ⭐⭐⭐ |
| sampler_name | euler_ancestral | 推荐采样器 | ⭐⭐ |
| scheduler | normal | 默认调度器 | ⭐⭐ |
| **denoise** | **0.3-0.5** | **最关键参数！** | ⭐⭐⭐⭐⭐ |

> 💡 **核心技巧：** `denoise` 值越低，输出越接近原图；值越高，风格变化越大但闪烁越严重。

#### 5.3 Video Combine 参数

| 参数 | 说明 | 推荐值 |
|-----|------|-------|
| frame_rate | 输出帧率 | 与输入相同或稍低 |
| format | 输出格式 | video/h264-mp4 |
| loop_count | 循环次数 | 0（不循环） |
| pingpong | 往返播放 | false |

## 参数详解

### denoise 参数影响详解

| denoise 值 | 闪烁程度 | 风格变化程度 | 适用场景 | 推荐使用 |
|-----------|---------|-------------|---------|---------|
| 0.2-0.3 | 极低 | 非常轻微 | 保持原图结构 | 细节修复 |
| 0.3-0.4 | 低 | 轻微 | 轻微风格化 | **人物视频** |
| 0.4-0.5 | 中低 | 中等 | 平衡效果 | **通用推荐** |
| 0.5-0.6 | 中等 | 明显 | 风格转换 | 艺术风格化 |
| 0.6-0.7 | 中高 | 强烈 | 大幅修改 | 需要 ControlNet |
| 0.7+ | 高 | 非常强烈 | 创意效果 | 实验性 |

> 💡 **经验法则：** 人物视频使用较低 denoise（0.3-0.4），风景视频可适当提高（0.5-0.6）。

## 减少闪烁技巧详解

### 方法一：调整 denoise 参数（最有效）

| denoise 值 | 效果 | 适用场景 |
|-----------|------|---------|
| 0.3-0.4 | 闪烁极低，风格变化小 | 人物视频、需要保持细节 |
| 0.4-0.5 | 平衡效果 | 通用场景 |
| 0.5-0.6 | 风格明显，有轻微闪烁 | 风景、艺术风格化 |

### 方法二：固定 seed（必须）

```text
KSampler → seed: 12345（固定值而非 -1）
```

固定 seed 确保每帧使用相同的随机种子，保持帧间一致性。

### 方法三：使用 ControlNet（强烈推荐）

**推荐 ControlNet 模型：**

| 模型 | 功能 | 适用场景 |
|-----|------|---------|
| depth | 保持深度结构 | 所有场景 |
| openpose | 保持人物姿态 | 人物视频 |
| normal | 保持法线方向 | 物体视频 |
| canny | 保持边缘 | 保持轮廓 |

**ControlNet 工作流：**
```text
Load Video → Depth Estimation → ControlNet Loader → KSampler
```

### 方法四：帧间混合（高级）

使用 `Frame Interpolation` 节点或后期处理工具进行帧间混合：

```bash
# FFmpeg 帧混合命令
ffmpeg -i input.mp4 -vf "tmix=frames=3:weights=1 2 1" output.mp4
```

### 方法五：降低帧率

减少处理帧数可以间接减少闪烁：
- 原帧率 30fps → 处理为 10-15fps
- 使用 `Load Video` 的 `select_every_nth` 参数

## 常见问题与解决方案

### 问题 1: 视频闪烁严重

**症状：** 生成的视频帧与帧之间差异很大，看起来在闪烁

**可能原因：**
- denoise 值过高
- seed 未固定
- 缺少 ControlNet

**解决方案：**

| 解决方法 | 具体操作 |
|---------|---------|
| 降低 denoise | 从 0.7 降到 0.4-0.5 |
| 固定 seed | 设置固定值如 12345，不要用 -1 |
| 添加 ControlNet | 使用 Depth ControlNet 保持结构 |

### 问题 2: 人物面部扭曲

**症状：** 人物面部变形、不自然

**可能原因：**
- denoise 值过高
- 风格变化过大
- 提示词不适合

**解决方案：**
1. 降低 denoise 到 0.3-0.4
2. 使用更适合人物的提示词
3. 添加 ControlNet OpenPose 保持姿态

### 问题 3: 视频无法加载

**症状：** Load Video 节点无法加载视频文件

**可能原因：**
- FFmpeg 未安装
- 视频格式不支持
- 文件路径错误

**解决方案：**

1. **检查 FFmpeg 安装：**
   ```bash
   ffmpeg -version
   ```
   如果未找到命令，需要安装 FFmpeg

2. **检查视频格式：**
   - 推荐使用 MP4 (H.264) 格式
   - 避免使用特殊编码格式

3. **检查文件路径：**
   - 确保视频在 `ComfyUI/input/` 目录
   - 文件名避免中文和特殊字符

### 问题 4: 处理速度慢

**症状：** 视频处理时间过长

**可能原因：**
- 分辨率过高
- 帧数过多
- 显存不足

**解决方案：**

| 优化方法 | 具体操作 |
|---------|---------|
| 降低分辨率 | 从 1080p 降到 720p |
| 减少帧数 | 使用 frame_load_cap 限制 |
| 降低采样步数 | 从 30 步降到 20 步 |

### 问题 5: 输出视频无声音

**症状：** 生成的视频没有原视频的音频

**原因：** VideoHelperSuite 不处理音频

**解决方案：**

使用 FFmpeg 合并音频：

```bash
ffmpeg -i output_video.mp4 -i input_audio.mp4 -c:v copy -c:a aac final_output.mp4
```
