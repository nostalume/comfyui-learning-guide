## 案例概述

### 案例目标

本案例将帮助你将 ComfyUI 完整集成到业务系统中，实现：

1. **电商产品图生成**：自动生成产品展示图
2. **内容创作平台**：批量生成营销素材
3. **设计辅助系统**：快速生成设计草图
4. **完整工作流**：从需求到交付的完整流程

| 知识点 | 重要程度 | 说明 |

- 电商平台产品图生成

### 步骤 2: 数据库设计（25分钟）

#### 2.1 创建数据库表结构

```sql
-- 用户表
CREATE TABLE users (
    id SERIAL PRIMARY KEY,
    username VARCHAR(50) UNIQUE NOT NULL,
    email VARCHAR(100) UNIQUE NOT NULL,
    password_hash VARCHAR(255) NOT NULL,
    role VARCHAR(20) DEFAULT 'user',
    credits INTEGER DEFAULT 100,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 任务表
CREATE TABLE tasks (
    id SERIAL PRIMARY KEY,
    task_id VARCHAR(36) UNIQUE NOT NULL,
    user_id INTEGER REFERENCES users(id),
    task_type VARCHAR(50) NOT NULL,
    status VARCHAR(20) DEFAULT 'pending',
    workflow JSONB NOT NULL,
    params JSONB,
    result JSONB,
    error_message TEXT,
    priority INTEGER DEFAULT 0,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    started_at TIMESTAMP,
    completed_at TIMESTAMP
);

-- 生成结果表
CREATE TABLE generation_results (
    id SERIAL PRIMARY KEY,
    task_id VARCHAR(36) REFERENCES tasks(task_id),
    image_url VARCHAR(500),
    thumbnail_url VARCHAR(500),
    width INTEGER,
    height INTEGER,
    seed BIGINT,
    model_name VARCHAR(100),
    generation_params JSONB,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 模板表
CREATE TABLE templates (
    id SERIAL PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    description TEXT,
    category VARCHAR(50),
    workflow JSONB NOT NULL,
    preview_image VARCHAR(500),
    is_public BOOLEAN DEFAULT false,
    created_by INTEGER REFERENCES users(id),
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 创建索引
CREATE INDEX idx_tasks_user_id ON tasks(user_id);
CREATE INDEX idx_tasks_status ON tasks(status);
CREATE INDEX idx_tasks_created_at ON tasks(created_at);
CREATE INDEX idx_generation_results_task_id ON generation_results(task_id);
```

```bash
from sqlalchemy import create_engine
from sqlalchemy.ext.declarative import declarative_base
from sqlalchemy.orm import sessionmaker
import os

DATABASE_URL = os.getenv(
    "DATABASE_URL",
    "postgresql://postgres:password@localhost:5432/comfyui_business"
)

engine = create_engine(DATABASE_URL)
SessionLocal = sessionmaker(autocommit=False, autoflush=False, bind=engine)
Base = declarative_base()


def get_db():
    """获取数据库会话"""
    db = SessionLocal()
    try:
        yield db
    finally:
        db.close()
```

```bash
"""
数据模型定义
"""
from pydantic import BaseModel, Field
from typing import Optional, List, Dict, Any
from datetime import datetime
from enum import Enum


class TaskStatus(str, Enum):
    PENDING = "pending"
    QUEUED = "queued"
    PROCESSING = "processing"
    COMPLETED = "completed"
    FAILED = "failed"


class TaskType(str, Enum):
    TEXT_TO_IMAGE = "text_to_image"
    IMAGE_TO_IMAGE = "image_to_image"
    PRODUCT_IMAGE = "product_image"
    BATCH_GENERATION = "batch_generation"


class GenerateRequest(BaseModel):
    """图像生成请求"""
    prompt: str = Field(..., description="正向提示词")
    negative_prompt: str = Field(default="low quality, blurry", description="负向提示词")
    width: int = Field(default=512, ge=64, le=2048)
    height: int = Field(default=512, ge=64, le=2048)
    steps: int = Field(default=20, ge=1, le=100)
    cfg: float = Field(default=7.0, ge=1.0, le=20.0)
    seed: Optional[int] = Field(default=None)
    model_name: str = Field(default="realisticVisionV51_v51VAE.safetensors")
    task_type: TaskType = Field(default=TaskType.TEXT_TO_IMAGE)


class ProductImageRequest(BaseModel):
    """产品图生成请求"""

    background: str = Field(default="white", description="背景")

class TaskResponse(BaseModel):

class TaskResultResponse(BaseModel):
```

#### 3.3 创建 ComfyUI 服务

```bash
cat > app/services/comfyui_service.py << 'EOF'
"""
ComfyUI 服务封装
"""
import requests
import json
import uuid
from typing import Dict, Any, Optional, List
import logging
from datetime import datetime

logger = logging.getLogger(__name__)


class ComfyUIService:
    """ComfyUI 服务客户端"""
    
    def __init__(self, base_url: str = "http://localhost:8188"):
        self.base_url = base_url
        self.client_id = str(uuid.uuid4())
    
    def queue_prompt(self, workflow: Dict[str, Any]) -> Dict[str, Any]:
        """提交工作流"""
        url = f"{self.base_url}/prompt"
        payload = {
            "prompt": workflow,
            "client_id": self.client_id
        }
        
        response = requests.post(url, json=payload, timeout=60)
        response.raise_for_status()
        return response.json()
    
    def get_history(self, prompt_id: str) -> Dict[str, Any]:
        """获取任务历史"""
        url = f"{self.base_url}/history/{prompt_id}"
        response = requests.get(url, timeout=30)
        response.raise_for_status()
        return response.json()
    
    def get_image(self, filename: str, subfolder: str = "", img_type: str = "output") -> bytes:
        """获取图像"""
        url = f"{self.base_url}/view"
        params = {
            "filename": filename,
            "subfolder": subfolder,
            "type": img_type
        }
        response = requests.get(url, params=params, timeout=30)
        response.raise_for_status()
        return response.content
    
    def get_system_stats(self) -> Dict[str, Any]:
        """获取系统状态"""
        url = f"{self.base_url}/system_stats"
        response = requests.get(url, timeout=10)
        response.raise_for_status()
        return response.json()
    
    def build_text2img_workflow(
        self,
        prompt: str,
        negative_prompt: str = "",
        width: int = 512,
        height: int = 512,
        steps: int = 20,
        cfg: float = 7.0,
        seed: Optional[int] = None,
        model_name: str = "realisticVisionV51_v51VAE.safetensors"
    ) -> Dict[str, Any]:
        """构建文生图工作流"""
        if seed is None:
            seed = int(uuid.uuid4().int % 2**32)
        
        return {
            "3": {
                "class_type": "KSampler",
                "inputs": {
                    "seed": seed,
                    "steps": steps,

class ComfyUICluster:
    """ComfyUI 集群管理"""
    
    def __init__(self, servers: List[str]):
        self.servers = [ComfyUIService(url) for url in servers]
        self.current_index = 0
    
    def get_next_server(self) -> ComfyUIService:
        """轮询获取下一个服务器"""
        server = self.servers[self.current_index]
        self.current_index = (self.current_index + 1) % len(self.servers)
        return server
    
    def get_healthy_servers(self) -> List[ComfyUIService]:
        """获取健康的服务器"""
        healthy = []
        for server in self.servers:
            try:
                server.get_system_stats()
                healthy.append(server)
            except Exception:
                logger.warning(f"Server {server.base_url} is unhealthy")
        return healthy
```

## 常见问题

### Q1: API 服务启动失败

**问题描述：** 启动 main.py 时报错。

**解决方案：**

```bash
# 检查依赖是否安装
pip install -r requirements.txt

# 检查端口是否被占用
lsof -i :8000

# 检查 ComfyUI 是否运行
curl http://localhost:8188/system_stats
```

### Q2: 图像生成任务一直处于 processing 状态

**问题描述：** 任务提交后状态一直是 processing。

**解决方案：**

```bash
# 检查 ComfyUI 日志
docker logs comfyui-instance-1

# 检查模型是否正确加载
curl http://localhost:8188/object_info

# 检查 GPU 状态
nvidia-smi
```

### Q3: 前端无法访问 API

**问题描述：** 前端页面报 CORS 错误。

**解决方案：**

- 确保 FastAPI 的 CORS 配置正确
- 检查 API URL 是否正确
- 确认 API 服务正在运行

### Q4: 数据库连接失败

**问题描述：** 启动时报数据库连接错误。

**解决方案：**

```bash
# 检查 PostgreSQL 是否运行
sudo systemctl status postgresql

# 测试数据库连接
psql -U postgres -d comfyui_business

# 检查连接字符串
echo $DATABASE_URL
```

### Q5: 如何添加用户认证？

**问题描述：** 需要为 API 添加用户认证。

**解决方案：**

参考案例 5.3 的 JWT 认证实现，添加用户登录和 Token 验证。

### Q6: 如何扩展到多个 GPU 服务器？

**问题描述：** 需要支持多台 GPU 服务器。

**解决方案：**

1. 在 ComfyUICluster 中添加更多服务器 URL
2. 配置负载均衡策略
3. 实现健康检查和故障转移
