## 实战步骤

### 步骤 1: 理解模型目录结构

#### 完整目录结构

```text
📁 ComfyUI/models/
├── 📁 checkpoints/          # 大模型（Checkpoint）
│   ├── sd15/                # SD 1.5 模型（可创建子目录分类）
│   └── sdxl/                # SDXL 模型
├── 📁 lora/                 # LoRA 模型
│   ├── style/               # 风格 LoRA
│   ├── character/           # 角色 LoRA
│   └── concept/             # 概念 LoRA
├── 📁 vae/                  # VAE 模型
├── 📁 controlnet/           # ControlNet 模型
├── 📁 embeddings/           # Textual Inversion
└── 📁 upscale_models/       # 放大模型
```

#### 各类模型说明

| 模型类型 | 目录 | 文件格式 | 作用 | 文件大小 |
|---------|------|---------|------|---------|
| Checkpoint | checkpoints/ | .safetensors, .ckpt | 基础大模型 | 2-6GB |
| LoRA | lora/ | .safetensors | 风格/角色微调 | 50-200MB |
| VAE | vae/ | .safetensors, .pt | 颜色/解码优化 | 300-400MB |
| ControlNet | controlnet/ | .safetensors | 控制生成 | 1-2GB |
| Embedding | embeddings/ | .pt, .bin | 提示词优化 | 5-50MB |
| Upscale | upscale_models/ | .pth, .pt | 图像放大 | 50-100MB |

### 步骤 2: 从 Civitai 下载模型

#### Civitai 简介

Civitai 是最大的 AI 绘画模型分享平台，提供各类模型的下载和展示。

**访问地址：** [https://civitai.com/](https://civitai.com/)

#### 下载流程

1. **访问 Civitai 网站**
   - 打开浏览器，访问 [civitai.com](https://civitai.com/)

2. **搜索模型**
   - 使用搜索框搜索模型名称
   - 或通过分类筛选模型类型

3. **选择模型版本**
   - 点击模型卡片进入详情页
   - 查看模型说明和效果展示
   - 选择适合的版本（注意基础模型版本）

4. **下载模型**
   - 点击 Download 按钮下载
   - 注意选择正确的文件格式

#### 模型选择注意事项

| 注意项 | 说明 |
|-------|------|
| 基础模型 | 确认模型基于 SD1.5 还是 SDXL |
| 文件格式 | 优先选择 .safetensors 格式 |
| 文件大小 | 注意磁盘空间 |
| 版本选择 | 选择最新稳定版本 |

### 步骤 3: 模型文件放置

#### 放置规则

| 模型类型 | 放置目录 | 文件格式 |
|---------|---------|---------|
| Checkpoint | `models/checkpoints/` | .safetensors, .ckpt |
| LoRA | `models/lora/` | .safetensors |

#### 放置步骤

1. **确认模型类型**
   - 查看模型说明，确认是 Checkpoint、LoRA 还是其他类型

2. **选择目标目录**
   - 根据模型类型选择对应的目录

3. **复制或移动文件**
   - 将下载的模型文件复制到目标目录

4. **刷新或重启**
   - 在 ComfyUI 中点击 Refresh
   - 或重启 ComfyUI

### 步骤 4: 使用 Checkpoint 模型

#### 加载 Checkpoint

1. **添加 加载模型（Load Checkpoint） 节点**
   - 双击空白处
   - 搜索 `Load Checkpoint`
   - 添加节点

2. **选择模型**
   - 点击 `ckpt_name` 下拉框
   - 选择已安装的模型

3. **连接节点**
   - MODEL → K采样器（KSampler）.model
   - CLIP → CLIP文本编码器（CLIP Text Encode）.clip
   - VAE → VAE解码（VAE Decode）.vae

#### 推荐入门 Checkpoint

| 模型名称 | 风格 | 说明 | 下载地址 |
|---------|------|------|---------|
| Realistic Vision V5 | 写实 | 人像、风景 | [Civitai](https://civitai.com/models/4201/realistic-vision-v50) |
| DreamShaper V8 | 通用 | 多风格 | [Civitai](https://civitai.com/models/4384/dreamshaper) |
| Juggernaut XL | 写实 | SDXL 模型 | [Civitai](https://civitai.com/models/133005/juggernaut-xl) |

### 步骤 5: 使用 LoRA 模型

#### 什么是 LoRA？

LoRA（Low-Rank Adaptation）是一种轻量级的模型微调技术，可以在不改变基础模型的情况下，添加特定风格或角色。

#### LoRA 的优势

| 优势 | 说明 |
|-----|------|
| 文件小 | 通常 50-200MB |
| 灵活 | 可叠加多个 LoRA |
| 快速 | 加载速度快 |
| 多样 | 风格、角色、概念丰富 |

#### 添加 LoRA Loader 节点

1. **添加节点**
   - 双击空白处
   - 搜索 `LoraLoader`
   - 添加节点

2. **连接节点**
   ```text
   Load Checkpoint → LoraLoader → KSampler
                         ↓
                    (model, clip)
   ```

3. **配置参数**
   - lora_name: 选择 LoRA 文件
   - strength_model: 模型强度（推荐 0.5-1.0）
   - strength_clip: CLIP 强度（推荐 0.5-1.0）

#### LoRA 参数详解

| 参数 | 范围 | 推荐值 | 说明 |
|-----|-----|-------|------|
| strength_model | 0-2 | 0.5-1.0 | 影响模型输出 |
| strength_clip | 0-2 | 0.5-1.0 | 影响提示词理解 |

#### 推荐入门 LoRA

| LoRA 名称 | 用途 | 下载地址 |
|----------|------|---------|
| Detail Tweaker | 细节增强 | [Civitai](https://civitai.com/models/58390/detail-tweaker-lora-lies) |
| Film Grain | 胶片质感 | [Civitai](https://civitai.com/models/4077/film-grain) |

### 步骤 6: 使用 VAE 模型

#### 什么是 VAE？

VAE（Variational Autoencoder）负责图像的编码和解码，影响图像的颜色和细节。

#### VAE 的作用

| 作用 | 说明 |
|-----|------|
| 颜色优化 | 改善图像颜色饱和度 |
| 细节增强 | 提升图像清晰度 |
| 解码质量 | 影响最终输出质量 |

#### 使用 VAE 的三种方法

**方法一：使用 Checkpoint 内置 VAE**

默认使用模型内置 VAE，无需额外配置。

**方法二：加载外部 VAE**

1. 添加 **Load VAE（加载VAE）** 节点
2. 选择 VAE 文件
3. 连接到 VAE Decode 节点

```text
Load Checkpoint
Load VAE → VAE Decode.vae
```

**方法三：使用 VAELoader 节点**

```text
CheckpointLoader (with VAE) → VAELoader → VAE Decode
```

#### 推荐入门 VAE

| VAE 名称 | 适用模型 | 说明 |
|---------|---------|------|
| sd-vae-ft-mse | SD 1.5 | 颜色鲜艳，通用 |
| vae-ft-mse-840000 | SD 1.5 | 平衡效果 |
| sdxl_vae | SDXL | SDXL 官方 VAE |

### 步骤 7: 模型命名规范

#### 推荐命名格式

```text
[基础模型]_[风格/用途]_[版本]_[作者].safetensors
```

#### 命名示例

| 类型 | 示例命名 |
|-----|---------|
| Checkpoint | `sd15_realistic_vision_v5_sg.safetensors` |
| Checkpoint | `sdxl_juggernaut_xl_v9.safetensors` |
| LoRA | `lora_detail_tweaker_v1.safetensors` |
| VAE | `vae_sd_ft_mse.safetensors` |

#### 命名建议

| 建议 | 说明 |
|-----|------|
| 使用英文 | 避免中文和特殊字符 |
| 包含版本号 | 便于区分不同版本 |
| 标注基础模型 | SD15 或 SDXL |
| 简洁明了 | 避免过长的文件名 |

## 参数配置详解

### LoRA 强度建议

| 强度 | 效果 | 适用场景 | 注意事项 |
|-----|------|---------|---------|
| 0.3-0.5 | 轻微影响 | 细节调整 | 效果不明显 |
| 0.5-0.8 | 中等影响 | 风格融合 | 推荐范围 |
| 0.8-1.0 | 强烈影响 | 主导风格 | 可能过拟合 |
| 1.0+ | 非常强烈 | 特殊效果 | 谨慎使用 |

### 多 LoRA 叠加

**连接方式：**

```text
Load Checkpoint → LoraLoader (1) → LoraLoader (2) → KSampler
```

**强度分配建议：**

| LoRA 数量 | 单个强度 | 总强度 |
|----------|---------|-------|
| 1 个 | 0.7-1.0 | ≤ 1.0 |
| 2 个 | 0.5-0.7 | ≤ 1.4 |
| 3 个 | 0.3-0.5 | ≤ 1.5 |

### 常用 VAE 对比

| VAE | 特点 | 适用模型 | 效果 |
|-----|------|---------|------|
| sd-vae-ft-mse | 颜色鲜艳 | SD 1.5 | 饱和度高 |
| vae-ft-mse-840000 | 平衡 | SD 1.5 | 自然 |
| sdxl_vae | 官方 | SDXL | 标准 |

## 常见问题（FAQ）

### Q1: 模型不显示在下拉框中怎么办？

**问题描述：** 已放置模型文件，但在节点下拉框中看不到模型。

**可能原因：**
1. 模型文件放置位置错误
2. 文件格式不正确
3. ComfyUI 未刷新
4. 文件名包含特殊字符

**解决方案：**

| 步骤 | 操作 | 说明 |
|-----|------|------|
| 1 | 检查文件位置 | 确认在正确的 models 子目录 |
| 2 | 检查文件格式 | 必须是 .safetensors 或 .ckpt |
| 3 | 刷新模型列表 | 点击界面上的 Refresh 按钮 |
| 4 | 重启 ComfyUI | 添加新模型后重启 |
| 5 | 检查文件名 | 避免中文和特殊字符 |

**目录检查清单：**
- Checkpoint → `models/checkpoints/`
- LoRA → `models/lora/`
- VAE → `models/vae/`
- Embedding → `models/embeddings/`

### Q2: LoRA 无效果或效果不明显怎么办？

**问题描述：** 加载了 LoRA 但生成的图像没有明显变化。

**可能原因：**
1. LoRA 强度过低
2. LoRA 与模型不兼容
3. 提示词与 LoRA 风格冲突
4. 连接方式错误

**解决方案：**

| 方案 | 操作 | 说明 |
|-----|------|------|
| 方案1 | 提高强度值 | 从 0.5 提高到 0.8-1.0 |
| 方案2 | 检查基础模型 | 确认 LoRA 兼容 SD1.5 或 SDXL |
| 方案3 | 调整提示词 | 添加与 LoRA 风格相关的提示词 |
| 方案4 | 检查连接 | 确认 LoRA 正确连接到 KSampler |

**LoRA 兼容性检查：**
- SD 1.5 LoRA → 只能用于 SD 1.5 模型
- SDXL LoRA → 只能用于 SDXL 模型

### Q3: 图像颜色发灰怎么办？

**问题描述：** 生成的图像颜色偏灰，不够鲜艳。

**可能原因：**
1. 模型内置 VAE 效果不佳
2. 未加载外部 VAE
3. 模型本身颜色倾向

**解决方案：**

| 方案 | 操作 | 效果 |
|-----|------|------|
| 方案1 | 加载外部 VAE | 使用 sd-vae-ft-mse |
| 方案2 | 更换模型 | 选择颜色更好的模型 |
| 方案3 | 后期调整 | 使用图像编辑软件调整 |

**推荐 VAE：**
- SD 1.5: sd-vae-ft-mse
- SDXL: sdxl_vae

### Q4: 模型加载失败或报错怎么办？

**问题描述：** 加载模型时出现错误或无法加载。

**可能原因：**
1. 模型文件损坏
2. 文件格式不支持
3. 显存不足
4. 版本不兼容

**解决方案：**

| 步骤 | 操作 | 说明 |
|-----|------|------|
| 1 | 检查文件完整性 | 重新下载模型 |
| 2 | 检查文件格式 | 使用 .safetensors 格式 |
| 3 | 检查显存 | 关闭其他程序释放显存 |
| 4 | 检查版本 | 确认模型与 ComfyUI 版本兼容 |

**文件完整性检查：**
- 对比文件大小是否与下载页面一致
- 使用 MD5 校验（如果提供）

### Q5: 如何管理和组织大量模型？

**问题描述：** 模型越来越多，难以管理和选择。

**解决方案：**

| 方法 | 操作 | 效果 |
|-----|------|------|
| 方法1 | 创建子目录 | 按类型/风格分类存放 |
| 方法2 | 统一命名 | 使用规范的命名格式 |
| 方法3 | 记录模型信息 | 建立模型清单文档 |
| 方法4 | 定期清理 | 删除不常用的模型 |

**目录分类建议：**

```text
models/
├── checkpoints/
│   ├── realistic/        # 写实风格
│   ├── anime/           # 动漫风格
```
