> ⚠️ **路径约定：** `<ComfyUI 目录>` 指你安装 ComfyUI 的那个文件夹。下文的路径都按这个约定写，执行前请替换为你自己的实际路径。

### 如何查找你的 ComfyUI 安装路径？

**方法1：看启动日志（最可靠）**
1. 启动 ComfyUI
2. 在控制台里找 `Loaded X models from ...` 那一行 —— 它打印的就是模型目录
3. 桌面端也可以走界面：左上角菜单 → `Desktop Settings` → `Storage` → `Shared Models`

**方法2：搜索模型文件**
1. 打开文件资源管理器
2. 搜索 `v1-5-pruned-emaonly.safetensors`
3. 找到后，上一级目录就是 `models\checkpoints`

### 一键下载脚本

> ⚠️ **脚本里的路径：** 把 `<ComfyUI 目录>` 换成你实际的安装路径再运行。若分不清自己的路径是什么，见 [2.1 模型放在哪](../../2-模型体系与管理/2.1-项目结构与模型存放.md)。

#### 手动安装 / 便携版

**Windows 用户（PowerShell）：**
```powershell
# 你的 ComfyUI 安装路径
$ComfyUI路径 = "<ComfyUI 目录>"

# 创建模型目录
mkdir -p "$ComfyUI路径\models\checkpoints"
mkdir -p "$ComfyUI路径\models\vae"

# 下载 SD 1.5 模型
Invoke-WebRequest -Uri "https://huggingface.co/runwayml/stable-diffusion-v1-5/resolve/main/v1-5-pruned-emaonly.safetensors" -OutFile "$ComfyUI路径\models\checkpoints\v1-5-pruned-emaonly.safetensors"

# 下载 VAE
Invoke-WebRequest -Uri "https://huggingface.co/stabilityai/sd-vae-ft-mse-original/resolve/main/vae-ft-mse-840000-ema-pruned.safetensors" -OutFile "$ComfyUI路径\models\vae\vae-ft-mse-840000-ema-pruned.safetensors"
```

**Linux/Mac 用户（终端）：**
```bash
# 你的 ComfyUI 安装路径
ComfyUI路径="/path/to/your/ComfyUI_SDK"

mkdir -p "$ComfyUI路径/models/checkpoints"
mkdir -p "$ComfyUI路径/models/vae"

wget -O "$ComfyUI路径/models/checkpoints/v1-5-pruned-emaonly.safetensors" "https://huggingface.co/runwayml/stable-diffusion-v1-5/resolve/main/v1-5-pruned-emaonly.safetensors"

wget -O "$ComfyUI路径/models/vae/vae-ft-mse-840000-ema-pruned.safetensors" "https://huggingface.co/stabilityai/sd-vae-ft-mse-original/resolve/main/vae-ft-mse-840000-ema-pruned.safetensors"
```

#### Comfy Desktop

桌面端**别把模型放进程序目录** —— 它默认从「共享模型库」里找模型。把上面的脚本里的 `$ComfyUI路径\models` 换成共享库的 `models` 路径即可：

```powershell
# 共享模型库（Windows 默认位置）
$models = "$env:LOCALAPPDATA\Comfy-Desktop\ComfyUI-Shared\models"

mkdir -p "$models\checkpoints"
mkdir -p "$models\vae"

Invoke-WebRequest -Uri "https://huggingface.co/runwayml/stable-diffusion-v1-5/resolve/main/v1-5-pruned-emaonly.safetensors" -OutFile "$models\checkpoints\v1-5-pruned-emaonly.safetensors"
Invoke-WebRequest -Uri "https://huggingface.co/stabilityai/sd-vae-ft-mse-original/resolve/main/vae-ft-mse-840000-ema-pruned.safetensors" -OutFile "$models\vae\vae-ft-mse-840000-ema-pruned.safetensors"
```

> ⚠️ 位置可能被改过（`Desktop Settings` → `Storage` → `Shared Models` 里以 **Primary** 那个为准），也见过老版本装在 `%USERPROFILE%\ComfyUI-Shared`。见 [2.1 模型放在哪](../../2-模型体系与管理/2.1-项目结构与模型存放.md)。

### 完整目录结构说明

你的 ComfyUI 安装路径结构应该是这样的：

```text
📁 <ComfyUI 目录>\          ← 你的 ComfyUI 安装目录
├── 📁 models\                                 ← 模型文件放在这里
│   ├── 📁 checkpoints\                        ← 大模型
│   │   └── v1-5-pruned-emaonly.safetensors    ← SD 1.5 模型
│   └── 📁 vae\                               ← VAE 模型
│       └── vae-ft-mse-840000-ema-pruned.safetensors
├── 📁 custom_nodes\                           ← 自定义节点包
├── 📁 output\                                 ← 生成结果输出

```

> 💡 **提示：** 桌面端的结构不一样 —— 实例目录里虽然也有 `ComfyUI\models\`，但**默认扫描的是共享库** `ComfyUI-Shared\models\`。别按上面这棵树去找。

### 验证模型安装

#### 步骤 1：确认你的模型路径是否正确

**方法 1：查看 ComfyUI 设置（推荐）**
1. 打开 ComfyUI
2. **桌面端：** 左上角菜单 → `Desktop Settings` → `Storage` → `Shared Models`，看列出的模型目录
3. **手动安装 / 便携版：** 启动日志里那一行 `Loaded X models from …` 就是答案
4. 确保你的模型文件放在这个路径下的对应子目录（大模型放 `checkpoints/`）

**方法 2：检查启动日志**
1. 启动 ComfyUI
2. 查看控制台输出
3. 找到类似这样的日志：
   ```text
   Loaded X models from <ComfyUI 目录>\models\checkpoints
   ```
4. 确认模型文件在这个目录下

#### 步骤 2：验证模型是否加载成功

1. 添加 `Load Checkpoint（加载模型）` 节点
2. 点击 `ckpt_name` 下拉框
3. 如果能看到 `v1-5-pruned-emaonly.safetensors`，说明安装成功

#### 如果模型没加载出来怎么办？

| 问题 | 解决方案 |
|-----|---------|
| 模型文件放错目录 | 确认路径是否与 ComfyUI 设置中的 Models 路径一致 |
| 文件名错误 | 确保文件名是 `.safetensors` 或 `.ckpt` 后缀 |
| ComfyUI 没重启 | 添加新模型后需要重启 ComfyUI |
| 权限问题 | 确保对模型目录有读取权限 |

> 💡 **提示：** 如果你不确定自己的路径，可以搜索电脑上的 `v1-5-pruned-emaonly.safetensors` 文件，找到后确认它的所在目录是否与 ComfyUI 设置中的路径一致。

## 实战步骤

### 步骤 1: 启动 ComfyUI

#### Windows 便携版

**双击解压包里的启动脚本**（弹出来的命令行窗口别关，它就是服务进程）：

```bash
# 在便携包目录下

```

NVIDIA 显卡用 `run_nvidia_gpu.bat`；AMD / Intel / 无独显的包分别对应 `run_amd_gpu.bat` / `run_intel_gpu.bat` / `run_cpu.bat`。

#### 手动安装（Linux / macOS / Windows）

```bash
# 进入 ComfyUI 目录（含 main.py 的那一层）
cd ComfyUI

# 启动
python main.py --listen 127.0.0.1 --port 8188
```

**启动成功标志：**
```text
To see the GUI go to: http://127.0.0.1:8188
```

#### Comfy Desktop

1. 打开 **Comfy Desktop**，在实例卡片列表里找到你的实例
2. 点卡片上的启动按钮
3. 程序会自己拉起界面（App 窗口内嵌，或自动打开浏览器）

> 💡 **提示：** 桌面端启动后会自动打开界面，无需手动输入网址。

### 步骤 2: 加载默认工作流

1. 打开浏览器，访问 `http://127.0.0.1:8188`（桌面端会自动打开）
2. 点击右侧面板的 **Load Default** 按钮
3. 或使用快捷键 `Ctrl + D`

> 📝 **说明：** 默认工作流包含文生图所需的所有基本节点，非常适合新手学习。

### 步骤 3: 选择模型

1. 找到 **加载模型（Load Checkpoint）** 节点（通常在左上角）
2. 点击 `ckpt_name` 下拉框
3. 选择已下载的模型（如 `v1-5-pruned-emaonly.safetensors`）

> ⚠️ **注意：** 如果下拉框为空，说明模型未正确放置，请返回"前置条件"部分检查。

### 步骤 4: 输入提示词

**正向提示词节点（第一个 CLIP Text Encode（CLIP文本编码器））：**

```text
a beautiful landscape with mountains and a lake, sunset, golden hour, 
masterpiece, best quality, highly detailed, 8k
```

**负向提示词节点（第二个 CLIP Text Encode）：**

```text
low quality, blurry, distorted, ugly, bad anatomy, 
worst quality, low resolution
```

> 💡 **提示：** 正向提示词描述你想要的画面，负向提示词描述你不想要的效果。

### 步骤 5: 设置图像尺寸

在 **空Latent图像（Empty Latent Image）** 节点设置：

| 参数 | 值 | 说明 |
|-----|---|------|
| width | 512 | 宽度（像素） |
| height | 512 | 高度（像素） |
| batch_size | 1 | 批量大小（一次生成几张图） |

> ⚠️ **注意：** SD 1.5 模型推荐使用 512x512 尺寸，过大可能导致图像质量下降。

### 步骤 6: 调整采样参数

在 **KSampler** 节点设置：

| 参数 | 推荐值 | 说明 |
|-----|-------|------|
| seed | 随机 | 或固定值便于复现 |
| steps | 20-25 | 采样步数 |
| cfg | 7.0 | 提示词引导强度 |
| sampler_name | euler_ancestral | 采样器 |
| scheduler | normal | 调度器 |
| denoise | 1.0 | 文生图固定为 1.0 |

### 步骤 7: 生成图像

1. 点击右侧面板的 **Queue Prompt** 按钮
2. 或使用快捷键 `Ctrl + Enter`
3. 等待生成完成（约 5-15 秒）

> 📊 **进度查看：** 右侧面板会显示当前进度，节点上也会显示进度条。

### 步骤 8: 查看和保存结果

- 生成完成后，图像会显示在 **Save Image（保存图像）** 节点
- 右键点击图像可保存
- 图像自动保存到 `ComfyUI/output/` 目录

## 参数配置详解

### KSampler 参数说明

| 参数 | 范围 | 推荐值 | 影响 |
|-----|------|-------|------|
| seed | 0-2147483647 | 随机 | 相同 seed + 参数 = 相同结果 |
| steps | 1-100 | 20-30 | 越高越精细，但耗时增加 |
| cfg | 1-20 | 5-12 | 越高越遵循提示词，但可能过饱和 |
| denoise | 0-1 | 1.0 | 文生图固定 1.0，图生图 0.3-0.8 |

#### seed（随机种子）

- **作用：** 控制图像生成的随机性
- **特点：** 相同的 seed 值 + 相同的参数 = 完全相同的图像
- **使用场景：**
  - 想要复现某张图像时，使用相同的 seed
  - 想要探索不同效果时，使用随机 seed

#### steps（采样步数）

- **作用：** 控制图像生成的精细程度
- **影响：**
  - 步数太少（<15）：图像可能模糊、细节不足
  - 步数适中（20-30）：质量与速度的最佳平衡
  - 步数太多（>40）：提升有限，但耗时明显增加

#### cfg（提示词引导强度）

- **作用：** 控制图像与提示词的匹配程度
- **影响：**
  - cfg 太低（<5）：图像可能偏离提示词
  - cfg 适中（7-10）：平衡创意与控制
  - cfg 太高（>15）：图像可能过饱和、不自然

#### denoise（重绘强度）

- **作用：** 控制新生成内容的比例
- **文生图：** 固定为 1.0（完全新生成）
- **图生图：** 0.3-0.8（保留部分原图特征）

### 采样器选择

| 采样器 | 速度 | 质量 | 推荐步数 | 适用场景 |
|-------|------|------|---------|---------|
| euler | ⭐⭐⭐ | ⭐⭐ | 15-20 | 快速预览 |
| euler_ancestral | ⭐⭐⭐ | ⭐⭐⭐ | 20-25 | 通用推荐 |
| dpmpp_2m | ⭐⭐ | ⭐⭐⭐⭐ | 20-30 | 高质量生成 |
| dpmpp_2m_sde | ⭐ | ⭐⭐⭐⭐⭐ | 25-35 | 最高质量 |

> 💡 **新手推荐：** 使用 `euler_ancestral` 采样器，步数设置为 20-25，这是最稳定可靠的组合。

## 常见问题（FAQ）

### Q1: 模型列表为空，无法选择模型怎么办？

**问题描述：** 在 加载模型（Load Checkpoint） 节点的下拉框中看不到任何模型。

**可能原因：**
1. 模型文件未放置到正确目录
2. 模型文件格式不正确
3. ComfyUI 未重启

**解决方案：**

| 步骤 | 操作 | 说明 |
|-----|------|------|
| 1 | 检查模型文件位置 | 确保在 `models/checkpoints/` 目录下 |
| 2 | 检查文件格式 | 必须是 `.safetensors` 或 `.ckpt` 后缀 |
| 3 | 重启 ComfyUI | 添加新模型后必须重启 |
| 4 | 检查文件完整性 | 确保文件大小正确（SD1.5 约 4GB） |

### Q2: 提示"显存不足"（Out of Memory）怎么办？

**问题描述：** 生成图像时出现 CUDA out of memory 错误。

**可能原因：**
1. 显存太小（<4GB）
2. 图像尺寸设置过大
3. 其他程序占用显存

**解决方案：**

| 方案 | 操作 | 适用情况 |
|-----|------|---------|
| 方案1 | 降低图像尺寸 | 尝试 512x512 或更小 |
| 方案2 | 使用低显存模式启动 | `python main.py --lowvram` |
| 方案3 | 关闭其他程序 | 关闭浏览器、游戏等 |
| 方案4 | 使用 CPU 模式 | `python main.py --cpu`（速度很慢） |

### Q3: 生成的图像全黑或全白怎么办？

**问题描述：** 生成的图像是纯黑色或纯白色，没有任何内容。

**可能原因：**
1. 模型文件损坏
2. VAE 加载失败
3. 提示词格式错误

**解决方案：**

| 步骤 | 操作 | 说明 |
|-----|------|------|
| 1 | 重新下载模型 | 文件可能下载不完整 |
| 2 | 检查模型文件大小 | SD1.5 应该约 4.2GB |
| 3 | 尝试其他模型 | 排除模型本身问题 |
| 4 | 检查提示词 | 确保没有特殊字符或格式错误 |

### Q4: 生成速度很慢怎么办？

**问题描述：** 生成一张图像需要很长时间（超过 1 分钟）。

**可能原因：**
1. 未启用 xFormers 优化
2. 使用 CPU 模式
3. 硬件性能不足

**解决方案：**

| 方案 | 操作 | 效果 |
|-----|------|------|
| 方案1 | 安装 xFormers | 可提升 20-30% 速度 |
| 方案2 | 降低采样步数 | 从 25 降到 20 |
| 方案3 | 使用更快的采样器 | 如 euler |
| 方案4 | 升级硬件 | 更好的 GPU |

### Q5: 如何保存工作流以便下次使用？

**问题描述：** 想保存当前的工作流配置，下次直接加载。

**解决方案：**

| 操作 | 快捷键 | 说明 |
|-----|-------|------|
| 保存工作流 | `Ctrl + S` | 保存为 .json 文件 |
| 加载工作流 | `Ctrl + O` | 打开已保存的工作流 |
| 导出为图片 | 右键菜单 | 导出包含工作流的图片 |
