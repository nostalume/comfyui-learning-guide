## 核心概念：什么是 OpenPose？

### OpenPose 简介

**OpenPose** 是一种姿态检测技术，可以识别图像中人物的关节点位置，生成骨架图。

**通俗理解：**
- OpenPose 会"看"图片中的人，找出他们的关节位置
- 然后用点和线画出骨架结构
- AI 根据这个骨架生成新的人物图像，保持相同的姿态

### 关节点说明

OpenPose 可以检测以下类型的关节点：

| 检测类型 | 关节点数量 | 说明 |
|---------|-----------|------|
| 身体（Body） | 18 个 | 头、肩、肘、腕、髋、膝、踝等 |
| 手部（Hand） | 21×2 个 | 每只手 21 个关键点 |
| 面部（Face） | 70 个 | 眼睛、眉毛、鼻子、嘴巴等 |

**骨架图颜色含义：**
- 🔴 红色点：头部相关
- 🟢 绿色线：身体连接
- 🔵 蓝色点：手部关节
- 🟡 黄色点：面部特征

### 应用场景

| 场景 | 说明 | 效果 |
|-----|------|------|
| 姿态复刻 | 保持人物姿态，改变服装/风格 | 同姿势不同造型 |
| 角色换装 | 保持姿态，更换服装和背景 | 换装效果 |
| 手部控制 | 精确控制手部姿势 | 手势复刻 |
| 多人场景 | 控制多人的姿态关系 | 多人姿态同步 |

## 实战步骤

### 步骤 1: 准备人物参考图

**操作步骤：**

1. **选择合适的人物照片**
   - 推荐类型：全身照、半身照、舞蹈动作
   - 图片要求：人物清晰、姿态明确、背景简洁
   - 图片尺寸：建议 512x512 或 768x768

2. **参考图选择标准**

| ✅ 好的参考图 | ❌ 不推荐的参考图 |
|-------------|-----------------|
| 人物清晰可见 | 人物被遮挡严重 |
| 姿态明确 | 姿态模糊不清 |
| 光线均匀 | 光线过暗或过曝 |
| 背景简洁 | 背景复杂干扰 |

> 💡 **小贴士：** 初学者建议使用背景简洁的全身照，效果更容易看到。

### 步骤 2: 添加所需节点

**操作步骤：**

1. **清空工作区**
   - 点击菜单 `Edit` → `Clear` 或按 `Ctrl+Delete`

2. **逐个添加以下节点**（双击空白处搜索节点名称）：

| 序号 | 节点名称 | 搜索关键词 | 数量 |
|-----|---------|-----------|------|
| 1 | Load Checkpoint（加载模型） | checkpoint | 1 |
| 2 | Load Image（加载图像） | image | 1 |
| 3 | Load ControlNet Model | controlnet | 1 |
| 4 | Apply ControlNet（应用ControlNet） | apply controlnet | 1 |
| 5 | CLIP Text Encode（CLIP文本编码器） (Positive) | clip text | 1 |
| 6 | CLIP Text Encode (Negative) | clip text | 1 |
| 7 | Empty Latent Image（空Latent图像） | empty latent | 1 |
| 8 | KSampler（K采样器） | ksampler | 1 |
| 9 | VAE Decode（VAE解码） | vae decode | 1 |
| 10 | Save Image（保存图像） | save image | 1 |

### 步骤 3: 配置节点参数

**Load Checkpoint 节点：**
```text
ckpt_name: v1-5-pruned-emaonly.safetensors
```

**Load ControlNet Model 节点：**
```text
control_net_name: control_v11p_sd15_openpose.pth
```

**Load Image 节点：**
```text
点击 "choose file to upload" 上传你的人物参考图
```

**Apply ControlNet 节点：**

| 参数 | 值 | 说明 |
|---|---|---|
| strength | 0.9 | 姿态控制需要较强强度 |
| start_percent | 0.0 | 开始影响时间 |
| end_percent | 1.0 | 结束影响时间 |

**CLIP Text Encode (Positive) 节点：**
```text
text: a person in elegant dress, studio lighting, masterpiece, best quality
```

**CLIP Text Encode (Negative) 节点：**
```text
text: (worst quality:1.4), (low quality:1.4), bad anatomy, bad hands, missing fingers, extra limbs
```

**Empty Latent Image 节点：**

| 参数 | 值 | 说明 |
|---|---|---|
| width | 512 | 输出宽度 |
| height | 768 | 人物图建议竖版 |
| batch_size | 1 | 每次生成的张数 |

**KSampler 节点：**
```text

steps: 20
cfg: 7.0
sampler_name: euler_ancestral
scheduler: normal
denoise: 1.0
```

### 步骤 4: 连接节点

**连接顺序（按输出端口 → 输入端口）：**

| 类别 | 源节点 | 输出 | 目标节点 | 输入槽 |
|---|---|---|---|---|
| 模型 | Load Checkpoint | MODEL | KSampler | model |
| 模型 | Load Checkpoint | CLIP | CLIP Text Encode (Positive) | clip |
| 模型 | Load Checkpoint | CLIP | CLIP Text Encode (Negative) | clip |
| 模型 | Load Checkpoint | VAE | VAE Decode | vae |
| ControlNet | Load ControlNet Model | control_net | Apply ControlNet | control_net |
| ControlNet | Load Image | IMAGE | Apply ControlNet | image |
| ControlNet | Apply ControlNet | MODEL | KSampler | model（替换原连接） |
| 提示词 | CLIP Text Encode (Positive) | CONDITIONING | KSampler | positive |
| 提示词 | CLIP Text Encode (Negative) | CONDITIONING | KSampler | negative |
| 潜空间 | Empty Latent Image | LATENT | KSampler | latent_image |
| 输出 | KSampler | LATENT | VAE Decode | samples |

### 步骤 5: 运行生成

**操作步骤：**

3. 等待生成完成（约 10-30 秒）
4. 在 Save Image 节点查看结果

## 参数详解

### 核心参数：strength（控制强度）

**参数含义：**
- 控制 OpenPose 对生成结果的影响程度
- 值越大，AI 越会按照骨架图生成姿态

**参数对照表：**

| strength 值 | 效果描述 | 适用场景 | 推荐指数 |
|------------|---------|---------|---------|
| 0.5 - 0.7 | 轻微影响，姿态可能变化 | 风格化处理 | ⭐⭐⭐ |
| 0.7 - 0.9 | 中等影响，姿态基本保持 | 标准使用 | ⭐⭐⭐⭐ |
| 0.9 - 1.0 | 强烈影响，姿态精确控制 | 精确姿态复刻 | ⭐⭐⭐⭐⭐ |
| 1.0+ | 可能过拟合，细节可能变形 | 特殊需求 | ⭐⭐ |

**调整建议：**
- 初学者从 **0.9** 开始尝试
- 姿态控制通常需要较高的 strength 值
- 如果手部变形，可尝试降低到 0.8

### OpenPose 预处理器选择

| 预处理器 | 检测内容 | 适用场景 | 推荐指数 |
|---------|---------|---------|---------|
| Openpose | 身体 18 点 | 单人全身 | ⭐⭐⭐⭐⭐ |
| Openpose_Full | 身体+手部+面部 | 需要完整控制 | ⭐⭐⭐⭐⭐ |
| Openpose_Hand | 仅手部 42 点 | 手部特写 | ⭐⭐⭐⭐ |
| Openpose_Face | 仅面部 70 点 | 面部表情控制 | ⭐⭐⭐⭐ |
| Openpose_FaceOnly | 仅面部关键点 | 表情复刻 | ⭐⭐⭐ |

### 辅助参数：start_percent / end_percent

**使用场景：**

| 设置 | 效果 | 适用场景 |
|-----|------|---------|
| start=0.0, end=1.0 | 全程影响 | 标准使用 |
| start=0.0, end=0.6 | 前期影响 | 姿态确定后自由发挥 |
| start=0.4, end=1.0 | 后期影响 | 前期自由，后期固定姿态 |

## 常见问题（FAQ）

### Q1: 为什么生成的姿态和参考图不一样？

**可能原因：**
1. **strength 值过低**：OpenPose 影响不够
2. **参考图姿态不清晰**：检测器无法正确识别
3. **人物被遮挡**：关节点检测失败

**解决方案：**
```text
1. 提高 strength 值到 0.9-1.0
2. 选择姿态清晰、人物完整的参考图
3. 确保人物关键部位没有被遮挡
```

### Q2: 生成的手部变形严重怎么办？

**可能原因：**
1. 未使用手部预处理器
2. 手部在参考图中不清晰
3. strength 值过高导致过拟合

**解决方案：**
```text
方案1：使用 Openpose_Full 预处理器（包含手部检测）
方案2：选择手部清晰的参考图
方案3：适当降低 strength 值到 0.8-0.9
方案4：在负向提示词中添加：bad hands, deformed fingers
```

### Q3: 多人场景姿态控制混乱怎么办？

**可能原因：**
1. 多人检测精度有限
2. 人物重叠导致检测错误
3. 背景复杂干扰检测

**解决方案：**
```text
方案1：使用背景简洁的参考图
方案2：确保人物之间有足够间距
方案3：分步处理：先生成单人，再合成
方案4：使用更高分辨率的参考图
```

### Q4: 面部表情和参考图不一致怎么办？

**可能原因：**
1. 未启用面部检测
2. 面部在参考图中太小
3. 提示词与表情冲突

**解决方案：**
```text
方案1：使用 Openpose_Full 预处理器（包含面部检测）
方案2：使用面部占比较大的参考图
方案3：在提示词中描述目标表情
```

### Q5: 如何创建自定义姿态图？

**方法：**
```text
方法1：手绘骨架图
- 使用绘图软件绘制彩色点和线
- 按照标准颜色绘制关节点
- 保存为 PNG 格式使用

方法2：使用在线工具
- 搜索 "OpenPose editor online"
- 使用在线编辑器创建姿态
- 导出骨架图使用

方法3：使用 3D 模型
- 在 3D 软件中摆好姿势
- 渲染骨架图
- 导入 ComfyUI 使用
```
