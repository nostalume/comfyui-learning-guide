## 概述

图像处理节点是 ComfyUI 工作流中不可或缺的组成部分，用于对生成的图像进行后处理、变换、合成等操作。本节详细介绍常用的图像处理节点及其使用方法。

> 💡 **提示：** 大多数图像处理节点来自 WAS Node Suite，建议先安装此节点包。

## 6.2.1 图像变换节点

### Image Scale（图像缩放）

> **来源：** ComfyUI 内置
> **分类：** image/upscaling

调整图像的尺寸大小，支持多种缩放算法和尺寸指定方式。这是最基础也是最常用的图像处理节点之一。

**参数：**

| 参数 | 类型 | 说明 | 可选值/范围 |
|------|------|------|-------------|
| image | IMAGE | 输入图像 | - |
| upscale_method | COMBO | 缩放算法 | nearest-exact, bilinear, area, bicubic, lanczos |
| width | INT | 目标宽度 | 64-16384 |
| height | INT | 目标高度 | 64-16384 |
| crop | COMBO | 裁剪方式 | disabled, center |

#### 缩放算法对比

| 算法 | 特点 | 适用场景 |
|------|------|----------|
| nearest-exact | 最近邻插值，保持锐利边缘 | 像素艺术、图标 |
| bilinear | 双线性插值，平滑 | 一般缩放 |
| bicubic | 双三次插值，更平滑 | 照片、高质量缩放 |
| lanczos | Lanczos 插值，高质量 | 高质量放大 |
| area | 区域插值 | 缩小图像 |

**适用场景：**

| 场景 | 推荐配置 |
|------|----------|
| 放大生成图像 | lanczos 或 bicubic |
| 缩小图像 | area |
| 保持像素风格 | nearest-exact |
| 批量处理 | 固定宽高比 |

**示例：**

```text
KSampler → VAE Decode → Image Scale (width=1024, height=1024) → Save Image
```

**使用注意：**

- 放大图像不会增加细节，可能导致模糊
- 缩小图像可能丢失细节
- 保持宽高比需要手动计算

### Image Crop（图像裁剪）

> **来源：** WAS Node Suite
> **分类：** WAS Suite/Image/Transform

从图像中裁剪出指定区域，支持多种裁剪模式和自定义坐标。

**参数：**

| 参数 | 类型 | 说明 |
|------|------|------|
| image | IMAGE | 输入图像 |
| crop_mode | COMBO | 裁剪模式（center, custom, percentage） |
| x | INT | 起始 X 坐标（custom 模式） |
| y | INT | 起始 Y 坐标（custom 模式） |
| width | INT | 裁剪宽度 |
| height | INT | 裁剪高度 |
| percentage_x | FLOAT | X 位置百分比 |
| percentage_y | FLOAT | Y 位置百分比 |
| percentage_width | FLOAT | 宽度百分比 |
| percentage_height | FLOAT | 高度百分比 |

**适用场景：**

| 场景 | 推荐模式 |
|------|----------|
| 裁剪中心区域 | center |
| 精确位置裁剪 | custom |
| 按比例裁剪 | percentage |

**使用注意：**

- 确保裁剪区域不超出图像边界
- percentage 模式更适合批量处理不同尺寸图像

## 6.2.2 图像滤镜节点

### Image Adjust（图像调整）

> **来源：** WAS Node Suite
> **分类：** WAS Suite/Image/Adjustment

调整图像的亮度、对比度、饱和度等基本属性，是最常用的图像调整节点。

**参数：**

| 参数 | 类型 | 说明 | 范围 | 默认值 |
|------|------|------|------|--------|
| image | IMAGE | 输入图像 | - | - |
| brightness | FLOAT | 亮度 | 0.0-2.0 | 1.0 |
| contrast | FLOAT | 对比度 | 0.0-2.0 | 1.0 |
| saturation | FLOAT | 饱和度 | 0.0-2.0 | 1.0 |
| gamma | FLOAT | 伽马值 | 0.1-5.0 | 1.0 |

#### 参数效果说明

| 参数 | 值 < 1.0 | 值 = 1.0 | 值 > 1.0 |
|------|----------|----------|----------|
| brightness | 变暗 | 原始 | 变亮 |
| contrast | 降低对比 | 原始 | 增强对比 |
| saturation | 降低饱和 | 原始 | 增强饱和 |
| gamma | 变亮 | 原始 | 变暗 |

**适用场景：**

| 场景 | 推荐配置 |
|------|----------|
| 提亮暗图 | brightness=1.2, gamma=0.9 |
| 增强色彩 | saturation=1.3, contrast=1.1 |
| 复古效果 | saturation=0.7, contrast=1.2 |
| 高对比风格 | contrast=1.4, saturation=1.2 |

**示例：**

```text
VAE Decode → Image Adjust (brightness=1.1, contrast=1.2, saturation=1.3) → Save Image
```

## 6.2.3 图像合成节点

### Image Blend（图像混合）

> **来源：** WAS Node Suite
> **分类：** WAS Suite/Image/Composite

将两张图像按照指定的混合模式进行合成，是实现图像叠加效果的核心节点。

**参数：**

| 参数 | 类型 | 说明 | 可选值 |
|------|------|------|--------|
| image_a | IMAGE | 底层图像 | - |
| image_b | IMAGE | 上层图像 | - |
| blend_factor | FLOAT | 混合强度 | 0.0-1.0 |
| blend_mode | COMBO | 混合模式 | 见下表 |

#### 混合模式详解

| 模式 | 效果描述 | 适用场景 |
|------|----------|----------|
| **normal** | 标准透明度混合 | 通用叠加 |
| **multiply** | 正片叠底，结果变暗 | 阴影、纹理叠加 |
| **screen** | 滤色，结果变亮 | 光效、高光 |
| **overlay** | 叠加，暗部变暗亮部变亮 | 纹理增强 |
| **soft_light** | 柔光，柔和的叠加效果 | 柔和效果 |
| **hard_light** | 强光，强烈的叠加效果 | 强烈对比 |
| **color dodge** | 颜色减淡，变亮 | 发光效果 |
| **color burn** | 颜色加深，变暗 | 烧灼效果 |
| **difference** | 差值，反转效果 | 特殊效果 |
| **exclusion** | 排除，柔和的差值 | 特殊效果 |
| **add** | 相加，变亮 | 光效叠加 |
| **subtract** | 相减，变暗 | 特殊效果 |

**适用场景：**

| 场景 | 推荐配置 |
|------|----------|
| 添加纹理 | multiply, blend_factor=0.3-0.5 |
| 添加光效 | screen, blend_factor=0.5-0.8 |
| 增强对比 | overlay, blend_factor=0.3-0.6 |
| 柔和叠加 | soft_light, blend_factor=0.4-0.7 |

**示例：**

```text
Image A (底图) ─┐
                 ├→ Image Blend (overlay, 0.5) → Output
Image B (纹理) ─┘
```

## 6.2.4 抠图与背景处理节点

### RemBG（AI 抠图）

> **来源：** ComfyUI-RemBG 插件
> **仓库：** https://github.com/Jcd1230/rembg-comfyui-node

使用 AI 模型自动去除图像背景，实现智能抠图。

**参数：**

| 参数 | 类型 | 说明 | 可选值 |
|------|------|------|--------|
| image | IMAGE | 输入图像 | - |
| model | COMBO | 抠图模型 | u2net, u2netp, isnet-general-use 等 |
| post_process | BOOLEAN | 后处理 | True/False |
| only_mask | BOOLEAN | 仅输出遮罩 | True/False |

#### 模型对比

| 模型 | 特点 | 适用场景 |
|------|------|----------|
| u2net | 通用模型，效果好 | 大多数场景 |
| u2netp | 轻量版，速度快 | 简单背景 |
| isnet-general-use | 高精度 | 复杂场景 |
| silueta | 人像专用 | 人像抠图 |

**适用场景：**

| 场景 | 推荐模型 |
|------|----------|
| 人像抠图 | silueta 或 u2net |
| 商品抠图 | u2net |
| 复杂背景 | isnet-general-use |
| 快速处理 | u2netp |

**示例：**

```text
Load Image → RemBG (model=u2net) → Save Image
```

**使用注意：**

- 首次使用需要下载模型
- 复杂背景可能需要后处理
- 边缘细节可能不够完美

### SAM Segment（SAM 分割）

> **来源：** Impact Pack
> **分类：** ImpactPack/Detection

使用 Segment Anything Model (SAM) 进行精确的目标分割，支持点选和框选分割。

**参数：**

| 参数 | 类型 | 说明 |
|------|------|------|
| image | IMAGE | 输入图像 |
| sam_model | SAM_MODEL | SAM 模型 |
| points | STRING | 分割点坐标 |
| labels | STRING | 点标签（前/背景） |
| threshold | FLOAT | 分割阈值 |

#### SAM 模型对比

| 模型 | 大小 | 速度 | 精度 |
|------|------|------|------|
| sam_vit_b | 375MB | 快 | 一般 |
| sam_vit_l | 1.2GB | 中 | 好 |
| sam_vit_h | 2.4GB | 慢 | 最好 |

**适用场景：**

- 精确目标分割
- 局部重绘准备
- 遮罩生成

**使用注意：**

- SAM 模型较大，首次使用需要下载
- 需要正确设置分割点
- 与 FaceDetailer 配合使用效果更佳

## 常见问题

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 图像处理后变模糊 | 缩放算法不当 | 使用 lanczos 或 bicubic |
| 混合效果不理想 | 混合模式选择错误 | 尝试不同混合模式 |
| 抠图边缘粗糙 | 模型精度不足 | 使用更高精度模型或后处理 |
| 处理速度慢 | 图像尺寸过大 | 先缩小再处理 |
| 显存不足 | 批量处理过多 | 减小 batch_size |
