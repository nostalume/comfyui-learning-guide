# 6.5 自定义节点安装

> **本文承接：**
> [6.1](./6.1-常用节点包.md) 到 [6.4](./6.4-条件节点.md) 讲的都是「用别人的节点」。本文先解决把它们装进来这件事，以及装坏了怎么救回来。
>
> **本文引出：**
> 装别人的节点是第一步；当现成节点都不够用时，就该自己写了 —— 见 [6.6 节点开发基础](./6.6-节点开发基础.md)。

> **相关官方文档：** [ComfyUI 官方文档](https://docs.comfy.org/) | [中文文档](https://docs.comfy.org/zh/)

---

## 概述

ComfyUI 支持通过多种方式安装自定义节点，包括 **ComfyUI Manager**（推荐）、**Git 克隆** 和 **手动安装**。本节详细介绍各种安装方法、常见问题排查及故障排除指南。

> 💡 **提示：** 强烈建议使用 ComfyUI Manager 管理节点，它提供了最便捷的安装和更新体验。

---

## 6.5.1 方法一：ComfyUI Manager（推荐）

### 为什么推荐 ComfyUI Manager？

| 优势 | 说明 |
|------|------|
| 图形化界面 | 无需命令行操作 |
| 一键安装 | 自动处理依赖 |
| 自动更新 | 一键更新所有节点 |
| 缺失节点修复 | 自动检测并安装工作流缺失节点 |
| 版本管理 | 查看和管理已安装节点 |

### 安装 ComfyUI Manager

#### 步骤1：进入 custom_nodes 目录

```bash
cd ComfyUI/custom_nodes
```

#### 步骤2：克隆仓库

```bash
git clone https://github.com/ltdrdata/ComfyUI-Manager.git
```

#### 步骤3：重启 ComfyUI

重启后，界面右侧会出现 "Manager" 按钮。

### 使用 ComfyUI Manager 安装节点

#### 通过界面安装

1. 点击右侧菜单的 **Manager** 按钮
2. 选择 **Install Custom Nodes**
3. 搜索或浏览需要的节点
4. 点击 **Install** 安装
5. 重启 ComfyUI

#### 通过 URL 安装

1. 点击 **Manager** → **Install via Git URL**
2. 输入节点的 Git 仓库地址
3. 点击 **Install**
4. 重启 ComfyUI

### ComfyUI Manager 功能详解

| 功能 | 说明 | 使用场景 |
|------|------|----------|
| Install Custom Nodes | 浏览和安装节点 | 安装新节点 |
| Install Missing Nodes | 自动安装工作流缺失的节点 | 导入他人工作流时 |
| Install via Git URL | 通过 Git URL 安装 | 安装未收录的节点 |
| Update All | 更新所有已安装节点 | 批量更新 |
| Fetch Updates | 检查更新 | 查看可用更新 |
| Alternatives of A1111 | WebUI 插件的 ComfyUI 替代方案 | 从 WebUI 迁移 |

## 6.5.2 方法二：Git 克隆安装

### 适用场景

- 网络环境无法访问 ComfyUI Manager
- 需要安装特定版本的节点
- 开发者需要克隆仓库进行修改

### 基本步骤

#### 步骤1：进入 custom_nodes 目录

```bash
cd ComfyUI/custom_nodes
```

#### 步骤2：克隆节点仓库

```bash
git clone https://github.com/作者/节点名称.git
```

#### 步骤3：安装依赖（如有）

```bash
cd 节点名称
pip install -r requirements.txt
```

#### 步骤4：重启 ComfyUI

### 常用节点 Git 地址

| 节点名称 | Git 地址 |
|---------|---------|
| ComfyUI-Manager | https://github.com/ltdrdata/ComfyUI-Manager |
| ComfyUI-Impact-Pack | https://github.com/ltdrdata/ComfyUI-Impact-Pack |
| ComfyUI-AnimateDiff-Evolved | https://github.com/Kosinkadink/ComfyUI-AnimateDiff-Evolved |
| ComfyUI-IPAdapter-plus | https://github.com/cubiq/ComfyUI_IPAdapter_plus |
| ComfyUI-VideoHelperSuite | https://github.com/Kosinkadink/ComfyUI-VideoHelperSuite |
| WAS Node Suite | https://github.com/WASasquatch/was-node-suite-comfyui |
| Comfyroll Studio | https://github.com/RockOfFire/ComfyUI_Comfyroll_CustomNodes |
| Efficiency Nodes | https://github.com/jags111/efficiency-nodes-comfyui |

### 安装特定版本

```bash
git clone https://github.com/作者/节点名称.git
cd 节点名称
git checkout v1.0.0
```

## 6.5.3 方法三：手动安装

### 适用场景

- 无法使用 Git
- 需要安装修改过的节点
- 网络受限环境

### 安装步骤

#### 步骤1：下载节点 ZIP 文件

从 GitHub 或其他来源下载节点的 ZIP 压缩包。

#### 步骤2：解压到 custom_nodes 目录

```text
ComfyUI/custom_nodes/节点名称/
```

**注意：** 确保文件夹结构正确，`__init__.py` 文件应该在根目录。

#### 步骤3：安装依赖

```bash
cd ComfyUI/custom_nodes/节点名称
pip install -r requirements.txt
```

#### 步骤4：重启 ComfyUI

**使用注意：**

- 确保文件夹名称正确（避免 `-main` 或 `-master` 后缀）
- 检查 Python 版本兼容性
- 检查依赖版本要求
- 手动安装的节点无法通过 Manager 更新

## 6.5.4 安装后验证

### 检查节点是否加载

#### 方法1：查看控制台输出

启动 ComfyUI 时，控制台会显示加载的节点：

```text
[ComfyUI] Loading custom nodes...
[ComfyUI] Loaded: ComfyUI-Impact-Pack
[ComfyUI] Loaded: ComfyUI-AnimateDiff-Evolved
```

#### 方法2：在界面中搜索

1. 双击画布空白处
2. 输入节点名称
3. 检查节点是否出现在搜索结果中

#### 方法3：检查节点分类

在节点菜单中查找对应的分类，确认节点是否出现。

### 常见加载信息

| 信息 | 说明 |
|------|------|
| `Loaded: 节点名` | 节点加载成功 |
| `Failed to load: 节点名` | 节点加载失败 |
| `ImportError: No module named 'xxx'` | 缺少依赖 |

## 6.5.5 常见问题解答（FAQ）

### Q1：节点不显示在菜单中

**可能原因：**

| 原因 | 检查方法 |
|------|----------|
| 安装路径错误 | 确认 `__init__.py` 在 `custom_nodes/节点名/` 下 |
| Python 依赖缺失 | 查看控制台错误信息 |
| 节点与 ComfyUI 版本不兼容 | 尝试更新 ComfyUI 或节点 |
| 节点名称冲突 | 检查是否有同名节点 |

**解决方案：**

```bash
cd ComfyUI/custom_nodes/节点名称
pip install -r requirements.txt
```

---

### Q2：导入错误（ImportError）

**错误示例：**

```text
ImportError: No module named 'xxx'
```

**解决方案：**

```bash
pip install xxx

./python_embeded/python.exe -m pip install xxx
```

**Windows 便携版：**

```bash
cd ComfyUI
.\python_embeded\python.exe -m pip install xxx
```

---

### Q3：节点加载失败

**错误示例：**

```text
Failed to load custom node: xxx
```

**排查步骤：**

1. 检查 Python 版本兼容性
2. 检查依赖版本
3. 查看详细错误信息
4. 尝试更新节点到最新版本
5. 检查是否有冲突的节点

---

### Q4：Git 命令不可用

**解决方案：**

| 系统 | 安装方法 |
|------|----------|
| Windows | 安装 [Git for Windows](https://git-scm.com/download/win) |
| Linux | `sudo apt install git` |
| macOS | `brew install git` |

---

### Q5：依赖冲突

**问题：** 不同节点依赖版本冲突

**解决方案：**

```bash
python -m venv comfyui_env
source comfyui_env/bin/activate
pip install -r requirements.txt
```

**Windows：**

```bash
python -m venv comfyui_env
comfyui_env\Scripts\activate
pip install -r requirements.txt
```

---

### Q6：网络连接问题

**问题：** 无法连接 GitHub 或 PyPI

**解决方案：**

1. 使用代理
2. 使用国内镜像源：

```bash
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

3. 手动下载节点 ZIP 文件

---

### Q7：显存不足

**问题：** 安装节点后显存占用增加

**解决方案：**

- 禁用不常用的节点
- 使用 `--lowvram` 参数启动
- 减少同时加载的模型数量

## 6.5.6 故障排除指南

### 故障排除流程图

| 层级 | 检查项 | 结论与处置 |
|---|---|---|
| 1 | 检查控制台错误信息 | 见下三行，按错误类型分支 |
| 1.1 | └ `ImportError` | 安装缺失依赖 |
| 1.2 | └ `FileNotFoundError` | 检查文件路径 |
| 1.3 | └ 其他错误 | 搜索解决方案 |
| 2 | 检查节点是否加载 | 见下两行 |
| 2.1 | └ 未加载 | 检查安装路径 |
| 2.2 | └ 已加载 | 检查节点配置 |
| 3 | 检查依赖版本 | 见下两行 |
| 3.1 | └ 版本冲突 | 创建虚拟环境 |
| 3.2 | └ 版本过低 | 更新依赖 |

### 详细排查步骤

#### 步骤1：查看错误日志

启动 ComfyUI 时注意控制台输出，记录所有错误信息。

#### 步骤2：检查安装路径

```text
正确的路径：
ComfyUI/custom_nodes/节点名称/__init__.py

错误的路径：
ComfyUI/custom_nodes/节点名称-main/__init__.py
ComfyUI/custom_nodes/节点名称/节点名称/__init__.py
```

#### 步骤3：检查依赖

```bash
pip list | grep 节点名
```

#### 步骤4：尝试重新安装

```bash
rm -rf ComfyUI/custom_nodes/节点名称
git clone https://github.com/作者/节点名称.git
pip install -r requirements.txt
```

#### 步骤5：检查版本兼容性

- 查看节点的 README 文件
- 检查 ComfyUI 版本要求
- 检查 Python 版本要求

## 6.5.7 节点更新

### 使用 ComfyUI Manager 更新

1. 点击 **Manager** → **Fetch Updates**
2. 查看可用更新
3. 点击 **Update All** 或单独更新

### 使用 Git 更新

```bash
cd ComfyUI/custom_nodes/节点名称
git pull
pip install -r requirements.txt
```

### 更新所有节点（Linux/macOS）

```bash
cd ComfyUI/custom_nodes
for d in */; do
    cd "$d"
    git pull
    cd ..
done
```

## 6.5.8 节点卸载

### 方法一：删除文件夹

直接删除 custom_nodes 目录下的节点文件夹：

```bash
rm -rf ComfyUI/custom_nodes/节点名称
```

**Windows：**

```powershell
Remove-Item -Recurse -Force "ComfyUI\custom_nodes\节点名称"
```

### 方法二：通过 ComfyUI Manager

1. 点击 **Manager** → **Install Custom Nodes**
2. 找到已安装的节点
3. 点击 **Uninstall**

## 6.5.9 高级技巧

### 批量安装节点

创建一个脚本批量安装多个节点：

```bash
#!/bin/bash
cd ComfyUI/custom_nodes

nodes=(
    "https://github.com/ltdrdata/ComfyUI-Impact-Pack"
    "https://github.com/Kosinkadink/ComfyUI-AnimateDiff-Evolved"
    "https://github.com/cubiq/ComfyUI_IPAdapter_plus"
)

for node in "${nodes[@]}"; do
    git clone "$node"
done
```

### 备份已安装节点列表

```bash
cd ComfyUI/custom_nodes
ls -d */ > installed_nodes.txt
```

### 检查节点更新状态

```bash
cd ComfyUI/custom_nodes
for d in */; do
    cd "$d"
    echo "=== $d ==="
    git status
    cd ..
done
```

## 6.5.10 时效性说明

| 项目 | 说明 |
|-----|------|
| ComfyUI Manager | 持续更新，功能可能增加 |
| 节点仓库地址 | 可能迁移或变更 |

- 定期更新 ComfyUI Manager
- 关注节点作者的更新公告
- 使用虚拟环境隔离依赖
- 备份重要的工作流
