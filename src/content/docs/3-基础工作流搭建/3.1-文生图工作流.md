## 功能描述（通俗易懂）

**文生图（Text-to-Image）** 是 ComfyUI 最基础、最核心的功能。简单来说，就是**你用文字描述想要的内容，AI 帮你画出来**。

想象一下，你告诉画家："请画一幅夕阳下的海边风景，有金色的阳光、平静的海面、远处的山脉。"画家就会根据你的描述创作一幅画。文生图就是让 AI 来扮演这个画家的角色。

**简单来说：你打字描述 → AI 生成图片**

### 为什么学习文生图？

| 优势 | 说明 |
|------|------|
| **门槛低** | 只需要会打字就能使用 |
| **创意无限** | 可以生成任何你能描述的内容 |
| **效率高** | 几秒钟就能生成一张图片 |
| **成本低** | 不需要任何绘画技能 |

### 核心概念解释

| 概念 | 通俗解释 |
|------|----------|
| **Checkpoint（大模型）** | AI 的"大脑"，决定了画画的风格和能力 |
| **CLIP** | AI 的"耳朵"，负责理解你说的文字 |
| **Prompt（提示词）** | 你给 AI 的"指令"，告诉它画什么 |
| **Latent（潜空间）** | AI 的"草稿纸"，在生成过程中存储图像信息 |
| **KSampler（采样器）** | AI 的"画笔"，一步步把草稿变成成品 |
| **VAE** | AI 的"翻译器"，把内部数据转换成我们能看到的图片 |

## 使用场景

| 场景 | 说明 | 示例 |
|------|------|------|
| **创意创作** | 从零开始创作艺术作品、插画、概念图 | 游戏概念图、小说插图 |

| **学习研究** | 了解 AI 绘画的基本原理和流程 | 测试不同模型效果 |
| **娱乐休闲** | 创作有趣的图片 | 生成头像、表情包 |

## 必需节点清单

| 序号 | 节点名称 | 功能 | 通俗解释 |
|------|----------|------|----------|
| 1 | 加载模型（Load Checkpoint） | 加载大模型 | 选择 AI 的"大脑" |
| 2 | CLIP文本编码器（CLIP Text Encoder，正向） | 正向提示词编码 | 告诉 AI 你**想要**什么 |
| 3 | CLIP文本编码器（CLIP Text Encoder，负向） | 负向提示词编码 | 告诉 AI 你**不想要**什么 |
| 4 | 空Latent图像（Empty Latent Image） | 创建空白画布 | 设置图片的大小 |
| 5 | K采样器（KSampler） | 采样器 | AI 开始画画 |
| 6 | VAE解码（VAE Decode） | 解码图像 | 把内部数据变成图片 |
| 7 | 保存图像（Save Image） | 保存图像 | 把图片保存到电脑 |

## 节点连接步骤

### 步骤 1：加载模型

**操作方法：**
1. 在空白处右键 → Add Node → loaders → Load Checkpoint
2. 点击 `ckpt_name` 下拉框，选择你下载的模型

**模型选择建议：**

| 想要的效果 | 推荐模型类型 |
|------------|--------------|
| 真实照片 | Realistic Vision, Deliberate |
| 动漫风格 | Anything, Counterfeit |
| 艺术风格 | DreamShaper, RevAnimated |
| 通用场景 | SDXL Base, Juggernaut |

**官方推荐入门模型：** [v1-5-pruned-emaonly-fp16.safetensors](https://huggingface.co/Comfy-Org/stable-diffusion-v1-5-archive/blob/main/v1-5-pruned-emaonly-fp16.safetensors)（SD1.5 基础模型，约 4GB，消费级显卡即可运行）

**小贴士：**
- 模型文件放在 `ComfyUI/models/checkpoints/` 文件夹
- 不同模型有不同的风格，比如写实、动漫、油画等

---

### 步骤 2：添加提示词节点

**操作方法：**
1. 右键 → Add Node → conditioning → CLIP文本编码器（CLIP Text Encode）（添加两次）
2. 将 加载模型（Load Checkpoint） 的 `CLIP` 输出连接到两个 CLIP文本编码器 的 `clip` 输入
3. 第一个节点输入**正向提示词**（你想要的内容）
4. 第二个节点输入**负向提示词**（你不想要的内容）

**示例提示词：**

| 类型 | 示例 |
|------|------|
| 正向提示词 | `a beautiful landscape, mountains, lake, sunset, golden hour, masterpiece, best quality` |
| 负向提示词 | `low quality, blurry, ugly, text, watermark` |

**提示词技巧：**

| 技巧 | 说明 | 示例 |
|------|------|------|
| 使用逗号分隔 | 让 AI 更容易理解 | `cat, cute, fluffy` |
| 添加形容词 | 增加细节描述 | `beautiful, dramatic, peaceful` |
| 指定风格 | 控制画面风格 | `oil painting, photorealistic, anime` |
| 添加质量词 | 提升图片质量 | `masterpiece, best quality, 4k` |

**常用负向提示词清单：**

| 类别 | 常用词 |
|------|--------|
| 质量问题 | `low quality, blurry, pixelated, noisy` |
| 画面问题 | `ugly, deformed, disfigured, bad anatomy` |
| 多余元素 | `text, watermark, signature, logo` |
| 光线问题 | `overexposed, underexposed, bad lighting` |

---

### 步骤 3：创建空白画布

**操作方法：**
1. 右键 → Add Node → latent → 空Latent图像（Empty Latent Image）
2. 设置 `width`（宽度）和 `height`（高度）
3. 设置 `batch_size`（批量大小，默认 1）

**推荐尺寸：**

| 用途 | 推荐尺寸 | 说明 |
|------|----------|------|
| 正方形图片 | 512×512 / 1024×1024 | 适合人像、特写 |
| 竖版图片 | 512×768 / 768×1024 | 适合全身照、海报 |
| 横版图片 | 768×512 / 1024×768 | 适合风景、场景 |
| 16:9 宽屏 | 912×512 / 1024×576 | 适合视频封面、横幅 |

**注意事项：**
- 尺寸越大，需要的显存越多
- SD 1.5 模型推荐 512-768 范围
- SDXL 模型推荐 1024 起步

---

### 步骤 4：添加采样器（核心）

**操作方法：**
1. 右键 → Add Node → sampling → KSampler
2. 按以下顺序连接：

| 连接来源 | 连接目标 |
|----------|----------|
| Load Checkpoint 的 `MODEL` | KSampler 的 `model` |
| 正向 CLIP Text Encode 的 `CONDITIONING` | KSampler 的 `positive` |
| 负向 CLIP Text Encode 的 `CONDITIONING` | KSampler 的 `negative` |
| Empty Latent Image 的 `LATENT` | KSampler 的 `latent_image` |

---

### 步骤 5：解码图像

**操作方法：**
1. 右键 → Add Node → latent → VAE Decode
2. 连接：

| 连接来源 | 连接目标 |
|----------|----------|
| KSampler 的 `LATENT` | VAE Decode 的 `samples` |
| Load Checkpoint 的 `VAE` | VAE Decode 的 `vae` |

---

### 步骤 6：保存图像

**操作方法：**
1. 右键 → Add Node → image → 保存图像（Save Image）
2. 连接：VAE解码（VAE Decode） 的 `IMAGE` → 保存图像（Save Image） 的 `images`

**自动保存：**
- 图片会自动保存到 `ComfyUI/output/` 文件夹
- 文件名包含时间戳和参数信息

---

### 步骤 7：运行工作流

**操作方法：**
1. 点击右上角的 **"Queue Prompt"** 按钮
2. 右侧队列会显示进度
3. 等待生成完成（可能需要几十秒到几分钟）
4. 生成的图片会出现在右侧历史记录中

**进度说明：**

| 显示状态 | 含义 |
|----------|------|
| `Pending` | 排队等待中 |
| `Running` | 正在生成 |
| `Complete` | 生成完成 |

## K采样器（KSampler）参数详解

K采样器（KSampler）是整个工作流的核心节点，参数设置直接影响生成效果。

| 参数 | 说明 | 推荐值 | 详细解释 |
|------|------|--------|----------|
| **seed** | 随机种子 | 随机或固定 | 相同种子 + 相同参数 = 相同图片 |
| **control_after_generate** | 种子生成后控制模式 | fixed / increment / decrement / randomize | 决定多批次生成时种子的变化规律 |
| **steps** | 采样步数 | 20-30 | 步数越多越精细，但速度越慢 |
| **cfg** | 提示词引导强度 | 7-8 | 数值越高，AI 越严格遵守提示词 |
| **sampler_name** | 采样器名称 | euler_ancestral / dpmpp_2m | 不同的算法，效果略有不同 |
| **scheduler** | 调度器 | normal / karras | 控制采样过程的节奏 |
| **denoise** | 去噪强度 | 1.0 | 文生图固定为 1.0 |

### 参数调整建议

| 参数 | 调低效果 | 调高效果 |
|------|----------|----------|
| steps | 生成快，细节少 | 生成慢，细节丰富 |
| cfg | AI 更自由发挥 | AI 更严格遵循提示词 |
| denoise | - | 文生图固定为 1.0 |

### Steps（步数）

| 步数范围 | 效果 | 适用场景 |
|----------|------|----------|
| 10-15 | 快速生成，细节较少 | 快速预览、测试 |
| 20-30 | 平衡速度和质量 | **日常使用推荐** |
| 40+ | 细节丰富，速度慢 | 高质量输出 |

### CFG Scale（提示词强度）

| CFG 范围 | 效果 | 适用场景 |
|----------|------|----------|
| 5-7 | AI 发挥空间大，可能偏离提示词 | 创意探索 |
| 7-10 | 平衡提示词遵守和创意 | **日常使用推荐** |
| 10+ | 严格遵守提示词，可能生硬 | 精确控制 |

### Seed（随机种子）

| 设置方式 | 效果 |
|----------|------|
| 随机（🎲图标） | 每次生成不同的图片 |
| 固定数值 | 相同参数生成相同图片 |

## 采样器选择指南

| 采样器 | 特点 | 适用场景 | 推荐步数 |
|--------|------|----------|----------|
| **euler** | 快速，简单 | 快速预览、测试 | 15-20 |
| **euler_ancestral** | 增加随机性，效果自然 | 通用场景 | 20-25 |
| **dpmpp_2m** | 高效，质量好 | **推荐日常使用** | 20-30 |
| **dpmpp_2m_sde** | 更细腻，细节丰富 | 高质量生成 | 25-35 |

**新手建议：** 直接使用 `dpmpp_2m` + `karras` 组合，效果稳定。

## 注意事项

### 显存相关

| 问题 | 解决方案 |
|------|----------|
| 显存不足（OOM） | 减小图片尺寸，如 512×512 |
| 生成速度慢 | 降低 steps 数量，使用更快的采样器 |
| 图片质量差 | 检查模型是否适合当前风格 |
| 电脑卡顿 | 关闭其他占用显存的程序 |

### 模型相关

- 确保模型与提示词风格匹配（写实模型不适合动漫提示词）
- SD 1.5 模型推荐尺寸：512×512 到 768×768
- SDXL 模型推荐尺寸：1024×1024
- 不同模型有不同的风格倾向

### 提示词相关

- 提示词建议使用英文（大部分模型对英文支持更好）
- 使用逗号分隔不同的描述
- 避免矛盾的描述（如 "realistic cartoon"）
- 多用具体词汇，少用抽象词汇

## 常见问题

### Q1：点击 Queue Prompt 后没有反应？

**可能原因及解决：**
1. 模型未正确加载 → 检查模型文件是否存在
2. 节点连接错误 → 检查所有连线是否正确
3. 显存不足 → 减小图片尺寸或关闭其他程序

---

### Q2：生成的图片全是噪点或模糊？

**可能原因及解决：**
1. steps 太少 → 增加到 20-30
2. 模型损坏或不兼容 → 重新下载模型
3. 提示词质量差 → 添加质量词如 "masterpiece, best quality"

---

### Q3：图片内容与提示词不符？

**可能原因及解决：**
1. 提示词不够具体 → 添加更多细节描述
2. CFG 太低 → 增加到 7-10
3. 模型风格不匹配 → 更换适合的模型

---

### Q4：生成速度太慢？

**优化建议：**
1. 减小图片尺寸（如从 1024×1024 改为 512×512）
2. 减少 steps（如从 40 改为 20）
3. 使用更快的采样器（如 euler）
4. 确保使用 GPU 加速（检查控制台是否显示 CUDA）

---

### Q5：如何生成相同内容的图片？

**方法：**
1. 固定 seed 值（点击 seed 旁边的🎲图标切换为固定模式）
2. 保持所有参数不变
3. 点击 Queue Prompt

---

### Q6：生成的图片有奇怪的问题？

**常见问题及解决：**

| 问题 | 解决方案 |
|------|----------|
| 人物手指异常 | 添加负向提示词：`bad hands, extra fingers` |
| 画面模糊 | 增加 steps，添加 `sharp, detailed` |
| 色彩异常 | 添加 `vibrant colors` 或调整模型 |
| 构图奇怪 | 添加构图词：`centered, rule of thirds` |
