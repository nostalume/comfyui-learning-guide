## 功能描述（通俗易懂）

**面部修复** 是专门用于优化人物面部细节的功能。在 AI 生成的人物图片中，面部经常会出现模糊、变形或细节不足的问题，面部修复可以自动检测并修复这些问题。

### 为什么需要面部修复？

| 问题 | 原因 | 面部修复的作用 |
|------|------|----------------|
| 面部模糊 | 生成尺寸小，细节不足 | 增强面部细节 |
| 面部变形 | AI 生成不稳定 | 修复面部结构 |
| 眼睛/嘴巴问题 | 细节生成困难 | 优化五官细节 |
| 远景人物模糊 | 面部占比小 | 放大并修复面部 |

### 生活中的类比

想象你拍了一张照片，但人物的脸有点模糊：
- 普通放大 → 脸还是模糊的
- 面部修复 → 自动识别面部，放大并增强细节，让脸变得清晰

## 方案一：使用 Impact Pack 的 FaceDetailer

### 功能描述

FaceDetailer 是 Impact Pack 插件提供的面部修复节点，功能强大且可自定义，是面部修复的推荐方案。

### 安装方法

**方法 1：使用 ComfyUI Manager（推荐）**
1. 打开 ComfyUI Manager
2. 搜索 "Impact Pack"
3. 点击安装

**方法 2：手动安装**

```bash
cd ComfyUI/custom_nodes
git clone https://github.com/ltdrdata/ComfyUI-Impact-Pack.git
```

### FaceDetailer 节点

**节点名称：** `FaceDetailer`

**节点输入：**

| 输入 | 说明 | 连接来源 |
|------|------|----------|
| `image` | 输入图像 | VAE解码（VAE Decode）的输出 |
| `model` | 模型 | 加载模型（Load Checkpoint）的 MODEL |
| `clip` | CLIP | 加载模型（Load Checkpoint）的 CLIP |
| `vae` | VAE | 加载模型（Load Checkpoint）的 VAE |
| `positive` | 正向条件 | CLIP文本编码器（CLIP Text Encoder） |
| `negative` | 负向条件 | CLIP文本编码器（CLIP Text Encoder） |

**节点输出：**

| 输出 | 说明 |
|------|------|
| `IMAGE` | 修复后的图像 |

### 关键参数

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| `guide_size` | 512 | 面部放大尺寸 |
| `guide_size_for` | True | 是否启用 guide_size |
| `max_size` | 1024 | 最大处理尺寸 |
| `steps` | 20-30 | 重绘步数 |
| `denoise` | 0.4-0.6 | 重绘强度 |

### 参数详解

#### guide_size（面部放大尺寸）

| 值 | 效果 | 建议 |
|----|------|------|
| 256 | 较小，速度快 | 远景人物 |
| 512 | 中等，平衡 | **推荐日常使用** |
| 768+ | 较大，细节丰富 | 特写人物 |

#### denoise（重绘强度）

| 值 | 效果 | 建议 |
|----|------|------|
| 0.3-0.4 | 轻微修复 | 保持原貌 |
| 0.4-0.6 | 中等修复 | **推荐日常使用** |
| 0.6-0.8 | 较大改变 | 可能改变面部特征 |

## 方案二：使用 ReActor

### 功能描述

ReActor 是一个简单易用的面部修复插件，适合快速修复场景。

### 安装方法

**方法 1：使用 ComfyUI Manager（推荐）**
1. 打开 ComfyUI Manager
2. 搜索 "ReActor"
3. 点击安装

**方法 2：手动安装**

```bash
cd ComfyUI/custom_nodes
git clone https://github.com/Gourieff/ComfyUI-ReActor.git
```

### ReActor Face Restore 节点

**节点输入：**

| 输入 | 说明 |
|------|------|
| `image` | 输入图像 |

**关键参数：**

| 参数 | 说明 | 推荐值 |
|------|------|--------|
| `model` | 修复模型 | CodeFormer / GFPGAN |
| `fidelity` | 保真度 | 0.5-0.8 |

### 修复模型选择

| 模型 | 特点 | 适用场景 |
|------|------|----------|
| `CodeFormer` | 细节丰富，效果自然 | **推荐日常使用** |
| `GFPGAN` | 修复力度大 | 严重损坏的面部 |

### fidelity 参数

| 值 | 效果 |
|----|------|
| 0.0-0.3 | 强力修复，可能改变面部 |
| 0.5-0.8 | 平衡修复 | **推荐** |
| 0.8-1.0 | 轻微修复，保持原貌 |

## 细节增强工作流

### 完整流程

```text
原图 → 放大（可选）→ 面部修复 → 细节重绘（可选）→ 输出
```

### 推荐节点顺序

| 步骤 | 节点 | 说明 |
|------|------|------|
| 1 | VAE解码（VAE Decode） | 输出原图 |
| 2 | Image Upscale With Model | 放大（可选） |
| 3 | FaceDetailer | 面部修复 |
| 4 | 保存图像（Save Image） | 保存 |

## 注意事项

### 处理时间

- 面部修复会增加处理时间
- 每个面部需要单独处理
- 多人图片处理时间更长

### denoise 设置

- denoise 过高可能改变面部特征
- denoise 过低修复效果不明显
- 建议从 0.5 开始尝试

### 多人图片

- 确保检测到所有面部
- 不同面部可能需要不同参数
- 可以分批处理

### 风格化图片

- 某些风格化图片可能不适合面部修复
- 动漫风格建议使用专用模型
- 修复后可能失去原有风格

## 常见问题

### Q1：面部修复后特征变了怎么办？

**解决方案：**
1. 降低 denoise 参数（如从 0.6 降到 0.4）
2. 使用与原图相同的提示词
3. 尝试不同的修复模型

---

### Q2：面部没有被检测到？

**解决方案：**
1. 检查面部是否清晰可见
2. 调整检测参数
3. 尝试先放大图片再修复

---

### Q3：修复效果不明显？

**解决方案：**
1. 提高 denoise 参数
2. 增加 guide_size
3. 增加 steps 数量
4. 使用更好的模型

---

### Q4：处理速度太慢？

**解决方案：**
1. 减小 guide_size
2. 降低 steps 数量
3. 使用 ReActor 快速修复

---

### Q5：如何选择修复方案？

| 需求 | 推荐方案 |
|------|----------|
| 高质量修复 | FaceDetailer |
| 快速修复 | ReActor |
| 自定义控制 | FaceDetailer |
| 简单易用 | ReActor |
