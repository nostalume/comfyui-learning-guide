## 1.2.1 装之前：先确认三件事

### 一、芯片与系统版本

| 你的机器 | 官方支持情况 |
|---|---|
| **Apple Silicon（M1 及以后）** | ✅ 官方支持，用 Metal（MPS）加速 |
| Intel 芯片的 Mac | ⚠️ 官方不支持。理论上能靠 CPU 跑，但很慢，不建议作为主力 |

**一个常见误解要先澄清：** ComfyUI 在 Apple Silicon 上用的是 **PyTorch + MPS（Metal Performance Shaders）**，而不是苹果自家的 MLX 框架 —— MLX 是另一套东西，ComfyUI 并没有用它。

系统版本：**macOS 13（Ventura）或更高**。

### 二、磁盘

- 程序本身：桌面端官方建议每个实例预留 **4.85 GB** 以上
- **模型另算** —— 一个 SD 1.5 大模型约 2-4 GB，SDXL 约 6-7 GB。长期使用建议留出 100 GB 以上

### 三、浏览器

官方建议 **Chrome 143 或更高版本**；更早的 Chrome 在 ComfyUI 上会有画面错乱与性能问题。Safari 与 Firefox 也能正常使用。

## 1.2.2 两条路，先选一条

| 方式 | 是什么 | 适合谁 |
|---|---|---|
| **Comfy Desktop** | 一个启动器，帮你创建、管理、更新实例 | **绝大多数人（官方推荐）** |
| **手动安装** | 自己装 Python 与 Git，克隆源码 | 要写脚本调 API、要读源码、要管理多个环境 |

> ⚠️ **Windows 上的「便携版」在 macOS 上没有。** 官方的便携包目前只面向 Windows；Mac 用户走上面两条路即可。

模型目录同样因装法而异，见 [2.1 项目结构与模型存放](../2-模型体系与管理/2.1-项目结构与模型存放.md)。

## 1.2.3 方式一：Comfy Desktop（推荐）

它是一个**多实例管理器**：装一次启动器，由它创建和管理若干个彼此独立的 ComfyUI，升级也在它内部完成 —— 你不必手动碰 `git` 或 `pip`。

### 步骤

1. 从官方文档页 [Comfy Desktop for macOS](https://docs.comfy.org/installation/desktop/macos) 给出的链接下载安装包（`.dmg`）
2. 打开 `.dmg`，把 **Comfy Desktop** 拖进「应用程序」文件夹
3. 从启动台或 Spotlight 启动它
4. 第一次打开可能出现**安全提示** —— 去「系统设置 → 隐私与安全性」，点 **仍要打开**（Open Anyway）即可放行
5. 进入 **Welcome** 页，在这里**创建你的第一个实例**；这一步才真正把 ComfyUI 装到磁盘上，会花几分钟
6. 实例创建完成后启动它，浏览器界面会自动打开

### 关于更新

有新版本时窗口顶部会出现 `Desktop Update Ready` 按钮，点一下自动重启并升级。

也可以手动来：左上角菜单 → `Desktop Settings` → `Updates`，那里能检查更新、执行 `Restart & Update`，还带一个「自动安装桌面端更新」的开关。

### 关于卸载（它不是一删就干净）

把「应用程序」里的 Comfy Desktop 拖进废纸篓，删掉的只是**启动器本身**。你的实例、模型、产出都还在磁盘上 —— 要彻底清理，得手动删这几处：

| 数据 | macOS 默认位置 |
|---|---|
| 各个实例 | `~/ComfyUI-Installs` |
| 共享的模型与输入/输出 | `~/ComfyUI-Shared` |
| 设置与安装记录 | `~/Library/Application Support/Comfy Desktop` |
| 运行日志 | `~/Library/Logs/Comfy Desktop` |

装好之后 → [1.3 启动、界面与第一张图](./1.3-启动界面与第一张图.md)。

## 1.2.4 方式二：手动安装（开发者路线）

这条路你得到的是**一个可以直接读、直接改的源码目录**，也是后面接 API、写脚本时唯一顺手的形态。

### 一、先建一个独立的 Python 环境

**这一步不能省。** ComfyUI 依赖一大堆特定版本的库，直接装进系统 Python 会污染它、并和你机器上的其他项目打架。官方的手动安装指南也把它排在最前。

用 Conda（官方示例）：

```bash
conda create -n comfyenv
conda activate comfyenv
```

或者用 Python 自带的 `venv`：

```bash
python3 -m venv comfyenv
source comfyenv/bin/activate
```

**Python 版本选择：** 官方推荐 **3.13**；**3.14** 可用，但部分自定义扩展会出问题；**3.12** 是在 3.13 上碰到依赖冲突时的退路。

### 二、装 Git，再克隆源码

macOS 一般自带 `git`；没有的话用 Homebrew 装：

```bash
brew install git
```

然后克隆源码：

```bash
git clone https://github.com/Comfy-Org/ComfyUI.git
cd ComfyUI
```

### 三、装 PyTorch

官方给 Apple Silicon 的命令是：

```bash
conda install pytorch-nightly::pytorch torchvision torchaudio -c pytorch-nightly
```

不用 Conda 的话，直接 pip 装到的就是带有 Metal 加速的官方 macOS 版：

```bash
pip3 install torch torchvision torchaudio
```

装完可以验证 Metal 加速是否可用：

```bash
python3 -c "import torch; print(torch.backends.mps.is_available())"
```

输出 `True` 就说明能走 GPU。

### 四、装其余依赖

```bash
pip3 install -r requirements.txt
```

### 五、启动

```bash
python3 main.py
```

### 更新

在同一个目录里拉取新代码，然后重跑一次依赖安装（依赖清单会变）：

```bash
git pull
pip3 install -r requirements.txt
```

> ⚠️ 每次操作前先确认你仍在第一步建的那个虚拟环境里，否则依赖会被装到系统 Python 上去。

## 1.2.6 常见问题

### Q1：提示 `No module named 'torch'` 或 torch 相关报错

1. 确认你用的是 `python3` 而不是 `python`
2. 确认当前处在第一步建的那个虚拟环境里
3. 按 1.2.4 第三步重装一次 PyTorch

### Q2：生成时提示内存不足

1. 调小画面尺寸（比如从 1024 改到 512）
2. 关掉其他吃内存的应用
3. 用 `--lowvram` 参数启动

### Q3：打开桌面端时被系统拦住

去「系统设置 → 隐私与安全性」，在底部找到被拦截的提示，点 **仍要打开**。

### Q4：都装好了，但界面里没有模型可选

模型还没下载，或者没放进 ComfyUI 认的目录 —— 见 [2.1 项目结构与模型存放](../2-模型体系与管理/2.1-项目结构与模型存放.md)。

> 启动之后的界面与出图问题（地址打不开、出图太慢等），集中在 [1.3 启动、界面与第一张图](./1.3-启动界面与第一张图.md) 的排错一节。

## 1.2.7 关闭与卸载

### 关闭

- 桌面端：直接退出应用
- 手动安装：切回终端窗口按 `Ctrl + C`，或直接关掉该窗口

### 卸载

| 装法 | 怎么卸 |
|---|---|
| Comfy Desktop | 把应用拖进废纸篓（**只删启动器**）；实例与模型另见 1.2.3 的数据目录表 |
| 手动安装 | 删掉克隆下来的文件夹与虚拟环境 |
