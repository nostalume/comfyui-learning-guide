## 1.3.1 启动 ComfyUI

ComfyUI 不是一个双击就出窗口的普通软件。它由两部分构成：后台是一个**本地服务器**，前台是你的**浏览器**。所以启动动作的本质，是「把一个服务挂到你自己的机器上」，而浏览器只是碰巧成了它的界面。

**启动方式取决你用哪种装法**（见 [1.1.2 三条路](./1.1-Windows安装.md)）：

### 如果你用的是 Comfy Desktop

打开启动器，点一下你建好的那个实例就行 —— 界面会自动在浏览器里打开。**桌面端没有「命令行窗口」**，服务由启动器在后台托管。

### 如果你用的是便携版（Windows）

1. 进入解压出来的那个文件夹
2. 双击 `run_nvidia_gpu.bat`（NVIDIA 显卡）或 `run_cpu.bat`（无独显）
3. 会弹出一个命令行窗口 —— **这个窗口不要关**，它就是那个服务器

### 如果你是手动安装

打开终端，进入源码目录启动：

```bash
python main.py
```

### 启动成功的标志

命令行窗口出现类似这样一行，就说明服务已经挂上了：

```text
To see the GUI go to: http://127.0.0.1:8188
```

（`127.0.0.1` 与后面要讲的 `localhost` 是同一个意思。）

**注意：** 便携版与手动安装都有一个必须一直开着的进程 —— 前者是那个命令行窗口，后者是终端。它一关，服务就停了，浏览器里的界面也随即失效。后面遇到的所有「突然连不上」，第一件要检查的事就是它还在不在。桌面端由启动器托管，不用操心这件事。

## 1.3.2 访问界面

1. 打开浏览器（推荐 Chrome 或 Firefox）
2. 在地址栏输入 `http://localhost:8188`，回车
3. 看到 ComfyUI 的界面，就说明前后台已经接上了

`localhost` 的意思就是「这台机器自己」，`8188` 是 ComfyUI 默认占用的端口号。所以这个地址翻译过来是：**访问我本机上 8188 端口那个服务**。这也解释了后面两个常见现象：

- 服务没启动时，这个地址会打不开 —— 因为那里根本没有东西在应答
- 装了多个版本、或多个实例同时跑时，要改端口，否则第二个起不来（见 [1.3.7](#137-启动与运行的六个常见问题)）

## 1.3.3 先认清屏幕：四个区域各管什么

第一次打开时界面是**空白的**，这是正常的 —— 它还没有加载任何工作流。

趁界面空着，先把屏幕分工记住。之后无论工作流多复杂，你都能立刻知道该往哪里看：

| 区域 | 名称 | 用途 |
|---|---|---|
| 左侧面板 | 节点菜单 | 所有可用节点的清单，拖拽取用 |
| 中间区域 | 工作区 | 放置节点、连线的画布 |
| 右侧上方 | 属性面板 | 显示所选节点的参数 |
| 右侧下方 | 队列与历史 | 正在排队/执行的任务，以及生成过的结果 |
| 顶部工具栏 | 菜单与运行 | 保存、加载、运行等按钮 |

其中**右侧下方**是新手最容易忽略、却最常要看的地方：工作流跑没跑、跑到哪一步、出图了没有，答案都在那里。

## 1.3.4 加载一个现成的工作流

既然界面是空白的，最快的起步方式不是自己连线，而是先借一份别人的：

1. 点击顶部工具栏的 `Load`（或菜单 → Load）
2. 在弹出的菜单里选择一个示例，例如 `txt2img.json`
3. 工作区会出现若干已经连接好的节点

如果你手上有别人的工作流文件，也可以直接把它**拖进浏览器窗口**，效果一样。

到这一步，你已经有了一个「能跑的图」——但还不理解它。**接下来这一步才是本文的重点。**

---

## 1.3.5 让这张图真的出来：四项设置

一份现成工作流加载进来后，通常有四个地方必须由你决定。四步都做对，图才会出来。

### 一、选模型

在工作区找到 `CheckpointLoaderSimple` 节点，点开它上面的下拉菜单，选中你安装时下载的模型（例如 `Realistic Vision V5.safetensors`）。

下拉框是空的时候只有两种可能：模型没下载，或者放错了目录 —— 两种情况都在 [1.3.7](#137-启动与运行的六个常见问题) 里有排查步骤。

### 二、填提示词

找到两个 `CLIPTextEncode` 节点：一个接正向提示词，一个接负向提示词。

正向提示词写你想要的画面，例如：

```text
a beautiful sunset over the ocean, golden hour, peaceful, serene, professional photography
```

负向提示词写你不想要的，例如：

```text
low quality, blurry, ugly, distorted, text, watermark
```

**为什么这两行字能控制画面，而不仅仅是在「描述」？** 这个问题本文不展开 —— 它是 [3.3 提示词入门](../3-基础工作流搭建/3.3-提示词入门.md) 的主题。现在你只需要知道：**先能出图，再回头懂原理**，顺序比反过来更省力。

### 三、调参数

找到 `KSampler` 节点，先只关心三个值：

| 参数 | 建议值 | 作用 |
|---|---|---|
| `steps` | 20–30 | 迭代步数，越高越细、越慢 |
| `cfg` | 7 | 提示词的「话语权」，越高越贴提示词、越高越僵硬 |
| `seed` | 任意整数 | 随机种子，**相同种子 + 相同参数 = 相同图片** |

再找到 `EmptyLatentImage` 节点，设置画面尺寸：`width` / `height` 用 512 或 1024。

### 四、运行

点击顶部工具栏的 `Queue Prompt`。

- 右侧下方的队列会显示进度
- 生成完成后，结果缩略图出现在右侧下方的历史里，点开即可看大图

跑起来之后如果没出图，跳到 [1.3.7](#137-启动与运行的六个常见问题) 按现象对照；那里覆盖了新手阶段的绝大多数情况。

## 1.3.6 把图存下来

1. 点击右侧历史里的图片缩略图
2. 在弹出的窗口中右键图片
3. 选择「保存图片」，选定保存位置

**一个值得记住的细节：** ComfyUI 生成的图片里**自带完整的工作流数据**。也就是说，这张图的文件本身就是一份可复现的配方 —— 拖回界面就能还原出生成它的整套节点与参数（包括种子）。这一点在 [1.4 工作流保存、加载与分享](./1.4-工作流保存加载分享.md) 里会正式用到。

## 1.3.7 启动与运行的六个常见问题

### Q1：命令行窗口一闪而过（便携版）

**原因：** 启动脚本执行到一半就失败了，窗口来不及停留。

**解决：** 不要双击 `.bat`。打开命令提示符，进入 ComfyUI 目录，手动运行 `run_nvidia_gpu.bat`，这样错误信息会留在屏幕上。

### Q2：提示 `CUDA out of memory`

**原因：** 显存不够。

**解决：** 依次尝试 —— 关掉其他占用显存的程序 → 用 `--lowvram` 参数启动 → 调小画面尺寸。系统性的显存优化见 [7.3 推理加速](../7-性能优化与显存管理/7.3-推理加速.md)。

### Q3：打不开 `http://localhost:8188`

**原因：** 服务没有成功启动，或者端口被占用。

**解决：**

1. 回头看命令行窗口有没有报错
2. 确认 8188 没有被别的程序占用
3. 换一个端口启动

### Q4：提示「找不到模型」/ 模型下拉框是空的

**原因：** 没有下载模型，或模型没放在 ComfyUI 认的目录里。

**解决：** 把模型文件放进 `ComfyUI/models/checkpoints/`，然后重启 ComfyUI（它会扫描该目录）。目录规则与扫描机制见 [2.1 模型放在哪](../2-模型体系与管理/2.1-项目结构与模型存放.md)。

### Q5：生成速度很慢

**原因：** 这通常是正常现象 —— 出图本身要算。

**解决：** 减少 `steps`、调小尺寸，或换更好的显卡。各档显卡的参考速度见 [7.1 生成速度 Benchmark](../7-性能优化与显存管理/7.1-生成速度benchmark.md)。

### Q6：图出来了，但质量不好

**解决：** 三个方向 —— 优化提示词、增加 `steps`、换一个模型。提示词的方向见 [3.3 提示词入门](../3-基础工作流搭建/3.3-提示词入门.md)。

## 1.3.8 关闭与开机自启（可选）

### 关闭

- **桌面端：** 退出应用即可（也可以在启动器里单独停止某个实例）
- **便携版 / 手动安装：** 切回那个命令行窗口或终端，按 `Ctrl + C`；也可以直接关掉窗口

### 开机自启

- **桌面端：** 通常不需要 —— 它是个应用，想用时打开即可
- **便携版（Windows）：** 右键 `run_nvidia_gpu.bat` → 创建快捷方式 → 把快捷方式放进「开始菜单 → 启动」文件夹
- **手动安装：** 把启动命令写成脚本（Windows 用 `.bat`，macOS 用 `.sh`），再让系统开机时运行它 —— macOS 走「系统设置 → 通用 → 登录项」

> 启动参数（`--lowvram`、`--port`、`--reserve-vram` 等）与编辑器快捷键的完整清单，见 [附录 A6 安装部署参考](../附录/A6-安装部署参考.md)。

## 练习

1. 启动 ComfyUI，访问 `http://localhost:8188`
2. 加载 `txt2img.json` 示例
3. 选中 `CheckpointLoaderSimple`，确认模型下拉框里有你下载的模型
4. 修改正向提示词，加两个形容词
5. 固定 `seed` 为同一个数，把 `steps` 从 10 改成 30，比较两张图
6. 把 `cfg` 从 5 改成 10，再比较一次
7. 保存你最满意的那一张

第 3–7 步的每一次对照，都在让你亲眼看到「参数 → 画面」的因果关系。它们的具体原理，正是 [3.1 文生图工作流](../3-基础工作流搭建/3.1-文生图工作流.md) 与 [3.3 提示词入门](../3-基础工作流搭建/3.3-提示词入门.md) 要讲的内容。
