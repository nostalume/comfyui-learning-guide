## 1.1.1 装之前：先确认三件事

### 一、你的显卡决定用哪个安装包

| 显卡 | 该用哪个包 | 说明 |
|---|---|---|
| NVIDIA RTX 20 系及以上 | **官方默认包**（CUDA 13.0） | 开箱即用，本文默认假设这种情况 |
| NVIDIA GTX 10 系及更早 | 需要旧的 CUDA 12.6 包 | 官方默认包基于 CUDA 13.0，只支持 20 系及以上 |
| AMD 显卡（RDNA 2 及以上） | 便携版 AMD 专用包 | 需要较新的 AMD 驱动 |
| Intel Arc 显卡 | 便携版 Intel 专用包 | 实验性支持 |
| 没有独立显卡 | `run_cpu.bat` 或 `--cpu` | 能跑，但慢到只适合验证流程 |

> ⚠️ **时效性提示：** 显卡与 CUDA 版本的对应关系变得很快，请以官方[系统要求](https://docs.comfy.org/installation/system_requirements)页为准。

### 二、系统与磁盘

- **系统：** Windows 10 或 Windows 11（64 位）
- **磁盘：** 程序本身不大（桌面端官方建议每个实例预留 4.85 GB 以上），但**模型要另算** —— 一个 SD 1.5 大模型约 2-4 GB，SDXL 约 6-7 GB。长期使用建议留出 100 GB 以上
- **内存：** 16 GB 起步（社区经验值，非官方硬性要求）

### 三、浏览器

官方建议用 **Chrome 143 或更高版本** —— 更早的 Chrome 在 ComfyUI 上会有画面错乱和性能问题。Firefox、Edge 也能正常使用。

## 1.1.2 三条路，先选一条

同一套 ComfyUI，官方提供了三种装法。**它们装出来的目录结构不一样**，选错了会在后面反复困惑「为什么我的文件夹和教程里对不上」。所以先花一分钟选路：

| 方式 | 是什么 | 适合谁 | 代价 |
|---|---|---|---|
| **Comfy Desktop** | 一个启动器，帮你创建、管理、更新实例 | **绝大多数人（官方推荐）** | 目录由它统一管理，想手动改路径要多绕一步 |
| **Windows 便携版** | 解压即用，自带 Python 环境 | 不想碰命令行；想随时用最新提交 | 更新要手动双击脚本；程序与模型混在一起 |
| **手动安装** | 自己装 Python 与 Git，克隆源码 | 要写脚本调 API、要读源码、要管理多个环境 | 步骤最多，出问题要自己查 |

**一句话判据：**

- **只是想出图** → 桌面端（[1.1.3](#113-方式一comfy-desktop推荐)）
- **想让程序来调它**（脚本、API、自动化）→ 手动安装（[1.1.5](#115-方式三手动安装开发者路线)）
- **两者之间**，或没有管理员权限 → 便携版（[1.1.4](#114-方式二windows-便携版)）

> 💡 三条路不是互斥的，可以同时装。但**模型目录各在一处**，这是三个世界里最容易踩的坑，见 [2.1 项目结构与模型存放](../2-模型体系与管理/2.1-项目结构与模型存放.md)。

## 1.1.3 方式一：Comfy Desktop（推荐）

官方现在主推的入口。它是一个**多实例管理器**：装一次启动器，就能由它创建和管理若干个彼此独立的 ComfyUI，升级也在它内部完成 —— 所以你不会去手动碰 `git` 或 `pip`。

### 步骤

1. 从官方文档页 [Comfy Desktop for Windows](https://docs.comfy.org/installation/desktop/windows) 给出的链接下载安装包（`.exe`）
2. 运行它，按提示走完安装（一路默认即可）
3. 从开始菜单或桌面快捷方式启动 **Comfy Desktop**
4. 第一次打开会出现 **Welcome** 页，在这里**创建你的第一个实例** —— 这一步才真正把 ComfyUI 装到磁盘上，所以会花几分钟
5. 实例创建完成后启动它，浏览器界面会自动打开

### 关于更新

有新版本时，窗口顶部会出现 `Desktop Update Ready` 按钮 —— 点一下，它会自动重启并完成升级。

也可以手动来：左上角菜单 → `Desktop Settings` → `Updates`，在那里检查更新、执行 `Restart & Update`，还有一个「自动安装桌面端更新」的开关。

### 关于卸载（它不是一删就干净）

在「设置 → 应用」里卸载，删掉的只是**启动器本身**。你的实例、模型、产出都还在磁盘上 —— 要彻底清理，得手动删这几处：

| 数据 | Windows 默认位置 |
|---|---|
| 各个实例 | `%LOCALAPPDATA%\Comfy-Desktop\ComfyUI-Installs` |
| 共享的模型与输入/输出 | `%LOCALAPPDATA%\Comfy-Desktop\ComfyUI-Shared` |
| 设置与安装记录 | `%APPDATA%\Comfy Desktop` |
| 运行日志 | `%APPDATA%\Comfy Desktop\logs` |

> 💡 早期版本的桌面端把实例装在 `%USERPROFILE%\ComfyUI-Installs`、共享模型在 `%USERPROFILE%\ComfyUI-Shared`。找不到时，两个位置都看一眼。

装好之后 → [1.3 启动、界面与第一张图](./1.3-启动界面与第一张图.md)。

## 1.1.4 方式二：Windows 便携版

一个压缩包，里面已经把 ComfyUI 要用的 Python 环境（`python_embeded`）一并打包了 —— 所以**你不需要另外装 Python**。

### 步骤

1. 从[便携版页面](https://docs.comfy.org/installation/comfyui_portable_windows)下载**与你显卡匹配**的那个包
2. 用 [7-Zip](https://7-zip.org/) 解压（Windows 自带的解压工具处理这类大包容易出错）
3. 进入解压出来的文件夹，**双击与显卡对应的那个 `.bat`**

解压后你会看到这样的结构：

```text
ComfyUI_windows_portable
├── ComfyUI/                   # 程序本体
├── python_embeded/            # 自带的 Python 环境
├── update/                    # 更新脚本
├── run_cpu.bat                # 无独显时用这个
└── run_nvidia_gpu.bat         # NVIDIA 显卡用这个
```

AMD 与 Intel 的包里，对应的启动脚本分别是 `run_amd_gpu.bat` 与 `run_intel_gpu.bat`。

> ⚠️ **弹出的那个命令行窗口不要关。** 它就是 ComfyUI 的服务进程；窗口一关，浏览器里的界面立刻失效。

### 更新

进 `update\` 文件夹，双击对应的脚本：

- `update_comfyui.bat` —— 升到最新提交
- `update_comfyui_stable.bat` —— 升到稳定版

### 想让局域网里其他设备访问

用记事本打开 `run_nvidia_gpu.bat`，在命令末尾加上 `--listen`：

```batch
.\python_embeded\python.exe -s ComfyUI\main.py --listen --windows-standalone-build
pause
```

保存后重启。启动日志里会出现 `http://0.0.0.0:8188`，其他设备用 `http://你的本机IP:8188` 即可访问。

### 想额外装 Python 包

某些扩展会要求你装额外的包。注意要用**它自带的那个 Python**，不是你系统里的：

```batch
.\python_embeded\python.exe -m pip install <包名>
```

启动参数的含义见 [附录 A6](../附录/A6-安装部署参考.md)。

## 1.1.5 方式三：手动安装（开发者路线）

这条路你得到的是**一个可以直接读、直接改的源码目录**，也是后面接 API、写脚本时唯一顺手的形态。

### 一、先建一个独立的 Python 环境

**这一步不能省。** ComfyUI 依赖一大堆特定版本的库，直接装进系统 Python 会污染它、并和你机器上的其他项目打架。官方的手动安装指南也把这一步排在最前。

用 Conda（官方示例）：

```bash
conda create -n comfyenv
conda activate comfyenv
```

或者用 Python 自带的 `venv`：

```bash
python -m venv comfyenv
comfyenv\Scripts\activate
```

**Python 版本选择：** 官方推荐 **3.13**；**3.14** 可用，但部分自定义扩展会出问题；**3.12** 是在 3.13 上碰到依赖冲突时的退路。

### 二、装 Git，再克隆源码

从 [git-scm.com](https://git-scm.com/download/win) 安装 Git（一路默认即可）。

```bash
git clone https://github.com/Comfy-Org/ComfyUI.git
cd ComfyUI
```

### 三、装 PyTorch

NVIDIA 显卡（CUDA 13.0，对应 RTX 20 系及以上）：

```bash
pip install torch torchvision torchaudio --extra-index-url https://download.pytorch.org/whl/cu130
```

### 四、装其余依赖

```bash
pip install -r requirements.txt
```

### 五、启动

```bash
python main.py
```

### 更新

在同一个目录里拉取新代码，然后重跑一次依赖安装（依赖清单会变）：

```bash
git pull
pip install -r requirements.txt
```

> ⚠️ 每次操作前先确认你仍在第一步建的那个虚拟环境里（命令行提示符前应显示 `comfyenv`），否则依赖会被装到系统 Python 上去。

## 1.1.7 常见问题

### Q1：报错「找不到 CUDA」或「Torch not compiled with CUDA enabled」

**CUDA** 是 NVIDIA 显卡做 AI 计算时要用的一套驱动与工具。这条报错几乎总是两件事之一：

1. 显卡驱动太旧 → 去 NVIDIA 官网更新驱动
2. 装错了包或用错了启动脚本 → NVIDIA 显卡必须用 `run_nvidia_gpu.bat`（便携版），或装带 `cu130` 的 PyTorch（手动安装）

### Q2：装依赖时下载慢或超时

换国内镜像：

```bash
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### Q3：生成时提示显存不足

依次尝试：关掉其他占显存的程序 → 调小画面尺寸 → 用 `--lowvram` 启动。系统性做法见 [7.5 显存优化](../7-性能优化与显存管理/7.5-显存优化.md)。

### Q4：都装好了，但界面里没有模型可选

模型还没下载，或者没放进 ComfyUI 认的目录 —— 见 [2.1 项目结构与模型存放](../2-模型体系与管理/2.1-项目结构与模型存放.md)。

> 启动之后的界面与出图问题（地址打不开、窗口一闪而过、出图太慢等），集中在 [1.3 启动、界面与第一张图](./1.3-启动界面与第一张图.md) 的排错一节。

## 1.1.8 卸载

| 装法 | 怎么卸 |
|---|---|
| Comfy Desktop | 设置 → 应用 → 卸载（**只删启动器**）；实例与模型另见 1.1.3 的数据目录表 |
| 便携版 | 直接把整个 `ComfyUI_windows_portable` 文件夹删掉 |
| 手动安装 | 删掉克隆下来的文件夹与虚拟环境；Python、Git 不再需要时再从「应用」里卸载 |
