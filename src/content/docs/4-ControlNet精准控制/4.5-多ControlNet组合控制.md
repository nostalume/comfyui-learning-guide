## 4.5.1 功能描述（通俗易懂）

### 什么是多 ControlNet 组合？

多 ControlNet 组合就是同时使用多个 ControlNet 来控制图像生成，每个 ControlNet 负责不同的控制维度，组合起来实现更精确的控制效果。

### 通俗类比

| 类比 | 说明 |
|------|------|
| 单个 ControlNet | 给画家一张草图，让他按草图作画 |
| 多个 ControlNet | 给画家一张草图 + 一张姿势参考 + 一张深度图，让他同时遵循所有参考 |

**就像给画家多份"施工图纸"**，每份图纸控制一个方面，最终效果更加精确可控。

### 核心价值

```text
单个 ControlNet：
只控制一个维度（如只控制轮廓）
结果：轮廓对了，但姿势、空间可能不对

多个 ControlNet：
同时控制多个维度（轮廓 + 姿势 + 空间）
结果：每个维度都符合预期
```

## 4.5.2 组合原理

### 条件叠加机制

多个 ControlNet 通过条件叠加的方式组合，每个 ControlNet 的输出都会影响最终的生成结果。

这里有一件最容易搞混的事：**接线是串联的，叠加才是效果。**

`Apply ControlNet` 节点只有**一个** conditioning 输入口，所以叠两个 ControlNet 时，只能把前一个的输出接进后一个的输入，一路串下去。节点源码里那句 `set_previous_controlnet()` 说的正是这件事——把新的 ControlNet 挂到上一个后面。既然只有一个入口，就不存在「同时接两路、各自算完再合并」这种接法。

但「串联」描述的是**接线形态**，不是**生效方式**。每串上一个节点，它的条件就被追加进同一份 conditioning，最后还是**一起**交给 UNet、在各层同时起作用——既不是后一个覆盖前一个，也不是轮流各改一遍。

### 条件融合方式

| 方式 | 在 ComfyUI 里怎么做 | 特点 |
|------|------|------|
| 串联叠加 | 把多个 `Apply ControlNet` 首尾相接——就是上一节那张图的接法，也是本文全程采用的方式 | 最常用，效果稳定 |
| 并行融合 | 手工搭两条链、各接一个 ControlNet，再用 `Conditioning (Combine)` 把结果并回来 | 更灵活，需要更多显存；ComfyUI 不提供现成入口 |
| 加权平均 | 调各节点的 `strength`（见 §4.5.5） | 可调节各控制的影响比例 |

## 4.5.3 使用场景

### 适用场景

| 场景 | 推荐组合 | 说明 |
|------|----------|------|
| 人物场景 | OpenPose + Depth | 控制姿势和空间 |
| 建筑设计 | Canny + Depth | 控制轮廓和深度 |
| 产品渲染 | Canny + Normal | 控制形状和光影 |
| 人物肖像 | InstantID + OpenPose | 保持人脸和控制姿势 |
| 室内设计 | Depth + Seg | 控制空间和区域 |
| 动漫角色 | Lineart + OpenPose | 控制线稿和姿势 |

### 不推荐组合

| 组合 | 原因 |
|------|------|
| Canny + Lineart | 功能重复，可能冲突 |
| Canny + SoftEdge | 都是边缘检测，效果重复 |
| 多个深度 ControlNet | 信息冗余 |

## 4.5.4 ControlNet 工作流搭建

### 必需节点清单

| 序号 | 节点名称 | 功能 | 说明 |
|------|----------|------|------|
| 1 | 加载模型（Load Checkpoint） | 加载大模型 | 基础模型 |
| 2 | 加载图像（Load Image） | 加载控制图像 | 可多个 |
| 3 | Preprocessor | 预处理控制图像 | 与 ControlNet 类型匹配 |
| 4 | 加载ControlNet模型（Load ControlNet Model） | 加载 ControlNet | 可多个 |
| 5 | 应用ControlNet（Apply ControlNet） | 应用 ControlNet | 可多个串联 |
| 6 | CLIP文本编码器（CLIP Text Encoder） | 提示词编码 | 正向和负向 |
| 7 | 空Latent图像（Empty Latent Image） | 创建空白画布 | 设置尺寸 |
| 8 | K采样器（KSampler） | 采样器 | 生成图像 |
| 9 | VAE解码（VAE Decode） | 解码 | Latent → 图像 |
| 10 | 保存图像（Save Image） | 保存 | 输出结果 |

### 节点连接步骤

#### 单个 ControlNet 连接

```text
步骤 1：加载模型和图片
        ↓
步骤 2：添加预处理器节点，连接图片
        ↓
步骤 3：添加 "加载ControlNet模型（Load ControlNet Model）" 节点
        ↓
步骤 4：添加 "应用ControlNet（Apply ControlNet）" 节点
        ↓
步骤 5：连接各节点
        - 预处理器输出 → 应用ControlNet（Apply ControlNet） 的 `image`
        - ControlNet 模型 → 应用ControlNet（Apply ControlNet） 的 `control_net`
        - 正向 CONDITIONING → 应用ControlNet（Apply ControlNet） 的 `positive`
        - 负向 CONDITIONING → 应用ControlNet（Apply ControlNet） 的 `negative`
        ↓
步骤 6：应用ControlNet（Apply ControlNet） 的输出连接到 K采样器（KSampler）
```

## 4.5.5 参数说明

### ControlNet 强度参数

| 参数 | 范围 | 默认值 | 说明 |
|------|------|--------|------|
| strength | 0.0-2.0 | 1.0 | ControlNet 影响强度 |
| start_percent | 0.0-1.0 | 0.0 | 开始应用的步数比例 |
| end_percent | 0.0-1.0 | 1.0 | 结束应用的步数比例 |

### 参数详解

#### strength（强度）

| 值范围 | 效果 | 使用场景 |
|--------|------|----------|
| 0.0-0.3 | 几乎无影响 | 轻微参考 |
| 0.3-0.7 | 轻微引导 | 辅助控制 |
| 0.7-1.0 | 平衡控制 | 常规使用 |
| 1.0-1.5 | 强控制 | 主要控制 |
| 1.5-2.0 | 非常强 | 严格遵循 |

#### start_percent / end_percent（时间控制）

| 设置 | 效果 | 使用场景 |
|------|------|----------|
| start=0.0, end=1.0 | 全程应用 | 默认设置 |
| start=0.0, end=0.5 | 前半程应用 | 先控制后自由 |
| start=0.3, end=1.0 | 后半程应用 | 先自由后控制 |
| start=0.2, end=0.8 | 中间应用 | 平滑过渡 |

## 4.5.6 常用组合方案

下面五种组合覆盖了绝大多数实际需求。表中的强度值是**起点**而不是定值，具体怎么微调见 §4.5.7。

| 组合 | 构成（strength） | 效果 | 适用场景 |
|------|------------------|------|----------|
| 一 · 姿态 + 深度 | OpenPose 1.0 + Depth 0.8 | 姿势正确，空间关系合理 | 人物在特定环境中的生成；需同时保持姿势与空间关系 |
| 二 · 边缘 + 姿态 | Canny 0.8 + OpenPose 1.0 | 轮廓清晰，姿势准确 | 需要精确轮廓与姿势的人物生成；线稿转图时保持姿势 |
| 三 · 线稿 + 深度 | Lineart 1.0 + Depth 0.7 | 线条风格保持，空间感强 | 动漫线稿上色；插画生成 |
| 四 · 人脸 + 姿势 | InstantID 1.0 + OpenPose 0.8 | 人脸保持，姿势可控 | 同一人物换不同姿势；人脸保持 + 姿势参考 |
| 五 · 三重控制 | Canny 0.7 + OpenPose 0.8 + Depth 0.6 | 全方位精确控制 | 轮廓、姿势、空间都要卡死的场景 |

组合五要多留一份心：三个 ControlNet 同时生效，**显存需求按 12 GB 以上准备**，生成速度明显变慢，三个强度之间还要来回调才能平衡——建议两两组合都过关之后，再上它。

> **这里为什么用表格而不是示意图**：这五行的结构完全相同，变的只是「挑了哪几个 ControlNet、各自多大强度」。图为表格补的是**形状**，不是**条目**——像这样同构、逐项取值的内容，横向比对反而比五张图更快。

## 4.5.7 组合强度调节

### 强度分配原则

| 原则 | 说明 |
|------|------|
| 主次分明 | 主要控制使用较高强度，辅助控制使用较低强度 |
| 避免冲突 | 同类型 ControlNet 不要叠加 |
| 总量控制 | 多个 ControlNet 的总影响不宜过强 |

### 推荐强度配置

| 组合数量 | 总强度建议 | 单个强度建议 |
|----------|------------|--------------|
| 2 个 | 1.5-2.0 | 0.75-1.0 |
| 3 个 | 2.0-2.5 | 0.6-0.8 |
| 4 个+ | 2.5-3.0 | 0.5-0.7 |

### 强度调节示例

#### 示例：OpenPose + Depth

| 场景 | OpenPose | Depth | 说明 |
|------|----------|-------|------|
| 姿势优先 | 1.0 | 0.6 | 姿势严格，空间参考 |
| 平衡控制 | 0.8 | 0.8 | 两者平衡 |
| 空间优先 | 0.6 | 1.0 | 空间严格，姿势参考 |

## 4.5.8 注意事项

### 避免冲突

| 冲突类型 | 示例 | 解决方案 |
|----------|------|----------|
| 同类型叠加 | Canny + Lineart | 只选一个 |
| 功能重复 | Canny + SoftEdge | 选择更适合的 |
| 信息矛盾 | 不同来源的控制图 | 确保控制图一致 |

### 显存管理

| ControlNet 数量 | 显存需求 | 建议 |
|------------------|----------|------|
| 1 个 | 6-8 GB | 基础配置 |
| 2 个 | 8-10 GB | 推荐配置 |
| 3 个 | 10-12 GB | 需要较好显卡 |
| 4 个+ | 12+ GB | 高端显卡 |

### 步数影响

| ControlNet 数量 | 推荐步数 | 说明 |
|------------------|----------|------|
| 1 个 | 20-25 | 基础步数 |
| 2 个 | 25-30 | 略微增加 |
| 3 个 | 30-35 | 需要更多步数 |
| 4 个+ | 35-40 | 确保效果 |

### 常见错误

| 错误 | 原因 | 解决方案 |
|------|------|----------|
| 控制冲突 | 同类型 ControlNet 叠加 | 移除重复类型 |
| 显存不足 | ControlNet 过多 | 减少数量或降低分辨率 |
| 效果不佳 | 强度参数不当 | 调整各 ControlNet 强度 |
| 生成缓慢 | 步数过少 | 增加采样步数 |

## 4.5.9 常见问题解答

### Q1: 多个 ControlNet 的顺序重要吗？

是的，顺序会影响结果：
- **串联连接时**：后面的 ControlNet 在前面的基础上叠加
- **建议顺序**：主要控制在前，辅助控制在后

### Q2: 为什么组合后效果变差？

可能原因：
1. **强度过高** - 降低各 ControlNet 的 strength
2. **类型冲突** - 检查是否有同类型 ControlNet
3. **控制图矛盾** - 确保各控制图信息一致
4. **步数不足** - 增加采样步数

### Q3: 如何判断哪个 ControlNet 应该用更高强度？

| 判断标准 | 说明 |
|----------|------|
| 主要目标 | 控制主要目标的 ControlNet 用更高强度 |
| 信息量 | 信息量大的控制图用更高强度 |
| 精确度要求 | 需要精确控制的用更高强度 |

### Q4: 最多可以同时使用多少个 ControlNet？

理论上没有限制，但实际建议：
- **推荐数量**：2-3 个
- **最大数量**：4-5 个（高端显卡）
- **注意**：数量越多，调节难度越大

### Q5: 不同分辨率的控制图可以组合吗？

可以，但建议：
- 统一控制图分辨率
- 或使用相同比例的分辨率
- 避免比例差异过大

### Q6: 如何快速调试多 ControlNet 组合？

调试步骤：
1. **单独测试** - 先单独测试每个 ControlNet
2. **逐步添加** - 确认单个有效后再添加下一个
3. **强度调节** - 从低强度开始逐步提高
4. **对比观察** - 保存中间结果对比
