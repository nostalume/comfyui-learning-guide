## 0.2.1 它是一个「搭出来」的出图工具

0.1 讲了 AI 怎么出图。现在问题变成：**你用什么去指挥它？**

常见的工具有两种做法。

一种是**填表格**：界面上摆好一排输入框 —— 这里写提示词、那里选模型、下面拉个滑块调步数，点生成。你把表格填对，它出图。

ComfyUI 是另一种。它把出图这件事拆成若干个**各管一件事的小方块**，由你自己把方块用线连起来：

```text
[加载模型] ──→ [写提示词] ──→ [采样] ──→ [解码] ──→ [保存]
                                  ↑
                            [噪声 / 空图]
```

这张「方块 + 连线」的图，就是你的出图流程。

| 名词 | 指什么 | 什么时候讲 |
|------|--------|-----------|
| **节点（node）** | 图里的一个方块，负责一件事 | [1.5 节点类型](../1-概述与安装部署/1.5-节点类型.md) 会推出它们为什么只能分成这几类 |
| **工作流（workflow）** | 整张方块与连线的图 | [1.4 工作流保存、加载与分享](../1-概述与安装部署/1.4-工作流保存加载分享.md) |

**这带来一个根本区别：** 填表格的工具里，能调什么由别人替你定好；在 ComfyUI 里，**你能改的是「流程本身」** —— 加一个方块、换一种连法，就换了一种做法。这既是它强的地方，也是它比填表工具难上手的原因。[0.3](./0.3-与WebUI的差异对比.md) 会把这件事讲透。

## 0.2.2 它能做哪几类事

ComfyUI 的功能看着杂，其实都能挂到上面那条链的某一环上 —— **哪一环做得不够好，就有一个功能来补它**。

| 你想要的 | 它解决什么问题 | 谁需要 | 在哪一章 |
|---------|--------------|--------|---------|
| **文生图** | 给文字，出一张图 | 所有人 | [3.1](../3-基础工作流搭建/3.1-文生图工作流.md) |
| **图生图** | 给一张图再加文字，改成另一张 | 要改风格、改细节的人 | [3.2](../3-基础工作流搭建/3.2-图生图工作流.md) |
| **提示词控制** | 让出的图更接近你描述的样子 | 所有人 | [3.3](../3-基础工作流搭建/3.3-提示词入门.md) |
| **高清修复 / 放大** | 小图放大后依然清晰 | 要交付成品图的人 | [3.4](../3-基础工作流搭建/3.4-高清修复工作流.md) |
| **面部修复** | 放大之后脸崩了 | 做人像的人 | [3.5](../3-基础工作流搭建/3.5-面部修复与细节增强.md) |
| **角色一致性** | 同一个人出现在不同场景里 | 做系列图、故事分镜的人 | [4.4](../4-ControlNet精准控制/4.4-InstantID与FaceID.md) |
| **精确控制构图** | 指定姿势、轮廓、景深 | 需要「就照这个来」的人 | [4.1](../4-ControlNet精准控制/4.1-ControlNet原理.md) |
| **批量生成** | 一次出几十张挑一张 | 做素材、做对比测试的人 | [5.1](../5-自动化与批量生成/5.1-批量生成.md) |
| **视频生成** | 让一张静态图动起来 | 做短视频的人 | [6.3](../6-高级节点与插件生态/6.3-视频相关节点.md) |
| **省显存 / 加速** | 显卡一般也能跑得动 | 配置有限的人 | [7.5](../7-性能优化与显存管理/7.5-显存优化.md) |
| **接进自己的系统** | 让别的程序自动调用它出图 | 要把它用进业务的人 | [5.4](../5-自动化与批量生成/5.4-API调用.md) |

有两点值得先说：

- **最上面五项是一条主线。** 从「出一张图」到「出一张能用的图」，第 3 章就是照这个顺序排的 —— 先跑通，再逐环做细。你不需要一次学完。
- **很多「不同的功能」，差别只在链条的一环。** 比如「图生图」与「文生图」最大的不同，只是起点从一片噪声换成了一张已有的图；「高清修复」是在链尾多加一段放大。**看懂链条，就不用逐个死记功能名。**

每类功能的具体参数（步数、重绘强度、放大倍数……）都写在上面那张表指到的那一章里；本文只回答「能做哪些事」。

## 0.2.3 那为什么是 ComfyUI

工具不止一个。0.1 已经列过常见选项（MidJourney、DALL·E、Stable Diffusion WebUI……）。ComfyUI 的取舍大致是这样：

| 好处 | 代价 |
|------|------|
| **完全免费、开源**，没有订阅和次数限制 | 要自己安装、自己配环境 |
| **本地运行**，图和提示词不出你的机器 | 需要一块像样的显卡（见 [0.1 需要什么条件](./0.1-什么是AI图像生成.md)） |
| **流程可改**，能长成别人做不出的样子 | 刚上手比填表式工具陡 |
| **社区生态大**，现成的工作流、模型、节点包拿来就能用 | 东西太多，得先知道去哪找 |

一句话：**它用「简单」换来了「可控」。**

如果你只想赶紧出几张图看效果，填表式工具更省事；如果你想把出图这件事**做成一整套自己的流程**、将来还要复用、还要批量跑，那多花的这些学习成本会还回来。

至于「和 WebUI 比究竟差在哪、原来会用 WebUI 的人要改什么」，[0.3](./0.3-与WebUI的差异对比.md) 整篇在讲。
