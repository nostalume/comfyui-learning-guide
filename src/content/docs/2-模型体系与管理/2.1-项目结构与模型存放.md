# 2.1 模型放在哪：项目结构与扫描机制

> **本文承接：**
> 在 [1.3 启动、界面与第一张图](../1-概述与安装部署/1.3-启动界面与第一张图.md) 里你亲手选过一次模型；当时若下拉框是空的，本文就是那道题的完整答案 —— 模型该放在哪、ComfyUI 又是怎么找到它们的。
>
> **本文引出：**
> 知道「放哪」之后，下一个问题是「从哪来」，见 [2.2 模型下载渠道](./2.2-模型下载渠道.md)；模型本身分几类、各管什么，从 [2.3 Checkpoint 大模型](./2.3-Checkpoint大模型.md) 开始。

> **适用版本：** 三条安装路径（Comfy Desktop / Windows 便携版 / 手动安装）通用
> **路径约定：** 本文用 `<ComfyUI 目录>` 代表「你安装 ComfyUI 的那个文件夹」。**它不是固定名字** —— 你的可能叫 `ComfyUI`、`ComfyUI_SDK`，或者别的什么。凡是看到它，都换成你自己的实际路径。

---

## 2.1.1 从一个现象说起

你按教程把模型文件丢进了一个叫 `models\checkpoints` 的文件夹，重启 ComfyUI，下拉框里**还是空的**。

更让人困惑的是，网上有些路径能用，有些看起来差不多的就是不行：

| 路径 | 结果 |
|---------|---------|
| `<便携包目录>\ComfyUI\models\checkpoints\` | ✅ 能找到模型 |
| `<便携包目录>\models\checkpoints\`（漏了中间的 `ComfyUI\`） | ❌ 找不到模型 |

（`<便携包目录>` = 你解压便携包得到的那个文件夹，见 [1.1.4](../1-概述与安装部署/1.1-Windows安装.md#114-方式二windows-便携版)。其实两条路径只差中间一层，`models\` 就在 `ComfyUI\` 里面。）

文件名一样、文件夹名一样，结果却相反。差别不在模型上，而在于**整条路径是不是 ComfyUI 启动时真正扫描的那一条**。

## 2.1.2 根源：它只扫一个根

ComfyUI 启动时，只把**一个**目录当作模型根，默认是：

```text
<ComfyUI 目录>/models/
```

规则只有一条：**只有放在这个 `models/` 下的子文件夹里的模型，才会被加载。**

它不猜、不去别处找，也不会提示你「你可能想放的是另一个文件夹」—— 找不到就是找不到。于是问题从「模型该放哪」变成了更具体的一句：

> **我这台机器上的那个 `models/` 到底在哪？**

而它之所以不固定，是因为 ComfyUI 有三条安装路径，三条路的目录深度不一样：

| 安装路径 | 你的 `<ComfyUI 目录>` 是什么 |
|---------|---------|
| **手动安装** | 你 `git clone` 下来的那个文件夹 —— 位置随便、名字随便 |
| **Windows 便携版** | 解压出来的包里面那层 `ComfyUI\`（不是包的根目录） |
| **Comfy Desktop** | 由启动器创建、放在 `ComfyUI-Installs` 下的某个实例目录（见 [2.1.5](#215-桌面端为什么路径不一样)） |

再加上你安装时可能自定义了路径 —— 教程里写的是作者的路径，你的不是。三条路径的完整对照见 [A4 版本差异指南](../附录/A4-版本差异指南.md)。

## 2.1.3 找到你的模型根：四种方法，按可靠性排序

**① 看启动日志（最可靠）**

启动 ComfyUI 后，控制台里会有这样一行：

```text
Loaded 3 models from <ComfyUI 目录>\models\checkpoints
```

**它打印的就是答案**，不用猜。日志窗口在哪，见 [附录 A6 安装部署参考](../附录/A6-安装部署参考.md)。

**② 看设置里的目录（桌面端）**

左上角菜单 → `Desktop Settings` → `Storage` → **`Shared Models`**，列出的每个目录都会被扫描，标着 **Primary** 的那个是新模型的默认落点。具体到某个实例，再看它的 `Manage` → `Storage`。

**③ 从 `main.py` 反推（手动安装 / 便携版）**

`main.py` 所在的那一层就是 `<ComfyUI 目录>`，模型根是它的 `models` 子文件夹。

```text
<ComfyUI 目录>\
└── models\          <- 模型放在这里
```

**④ 反着搜模型文件**

在文件管理器里搜一个你确定已下载的模型文件名（比如 `v1-5-pruned-emaonly.safetensors`），找到文件后往上退：`checkpoints` 的上一级就是 `models`。

## 2.1.4 找到了根，再看往里放什么

`models/` 下面按模型用途分成若干子文件夹。你已经下好的模型属于哪一类，就放哪一类 —— **先按「用途」和「后缀」对号入座就行，这些类型的名字此刻不必都懂**：

| 模型类型 | 文件后缀 | 放进这个子文件夹 | 典型大小 |
|---------|---------|---------|---------|
| 大模型（SD 1.5 / SDXL / Flux） | `.safetensors`、`.ckpt` | `models\checkpoints\` | 2-10 GB |
| VAE | `.safetensors` | `models\vae\` | 300 MB-2 GB |
| LoRA | `.safetensors` | `models\lora\` | 50-500 MB |
| ControlNet | `.pth`、`.safetensors` | `models\controlnet\` | 1-2 GB |
| CLIP Vision | `.safetensors` | `models\clip_vision\` | 1-2 GB |
| IP-Adapter | `.safetensors` | `models\ipadapter\` | 1-2 GB |
| InstantID | `.bin` | `models\instantid\` | 1-2 GB |
| InsightFace | 整个文件夹 | `models\insightface\antelopev2\` | 300 MB |
| AnimateDiff 运动模型 | `.ckpt` | `models\animatediff\` | 2-4 GB |
| 放大模型 | `.pth` | `models\upscale_models\` | 50-100 MB |

> 💡 **先认识两种文件后缀：** `.safetensors` 是一种模型文件格式，`.ckpt` 也是一种 —— 用法上没区别，ComfyUI 两种都认。`.safetensors` 是较新的格式，也更容易确保文件里只有权重、没有夹带别的东西，所以现在下载到的基本都是它；`.ckpt` 多见于早期模型。**你需要做的只是认后缀、把它放进对应目录。**
>
> 这些类型各是什么、什么时候用，从 [2.3 Checkpoint 大模型](./2.3-Checkpoint大模型.md) 起逐个讲；下载链接见 [附录 A5](../附录/A5-模型与工具清单.md)。

## 2.1.5 桌面端为什么路径不一样

手动安装和便携版都是「**程序目录 = 模型根所在的那一层**」，桌面端不是 —— 它是个**多实例管理器**：启动器只管创建和管理，每个实例各是一套完整的 ComfyUI，模型则默认放在**所有实例共用的共享库**里：

```text
%LOCALAPPDATA%\Comfy-Desktop\
├── ComfyUI-Installs\               <- 每个实例一个子文件夹
│   └── <实例名>\
│       ├── ComfyUI\                <- 程序本体（含 main.py 与它自己的 models\）
│       ├── standalone-env\         <- 该实例自带的 Python 环境
│       └── ...
└── ComfyUI-Shared\                 <- 实例之间共用的库
    ├── models\                     <- 模型默认放这里
    │   ├── checkpoints\
    │   ├── vae\
    │   └── ...
    └── output\                     <- 生成结果
```

手动安装 / 便携版没有这层包装，`models\` 就在程序目录下：

```text
<ComfyUI 目录>\
├── models\                         <- 模型放这里
│   ├── checkpoints\
│   ├── vae\
│   └── ...
├── custom_nodes\                   <- 自定义节点包
├── output\                         <- 生成结果
└── main.py                         <- 启动文件
```

前面两张树看下来，其实只有一件事要记住 —— **三条安装路径长得不一样，但你要找的那一层永远是「本级目录里的 `models\`」**：

> 💡 **一句话记法：** 谁旁边有 `models\`，谁就是你要找的那一层。桌面端上看到多个 `ComfyUI` 名字的目录时，**先看共享库 `ComfyUI-Shared\models\`** —— 默认情况下模型都在那儿。
>
> 💡 位置也能改：桌面端 `Desktop Settings` → `Storage` 里可以增删共享模型目录，标为 **Primary** 的那个负责接收新模型；单个实例要不要用共享目录，在它的 `Manage` → `Storage` 里设。完整路径表见 [A4.4](../附录/A4-版本差异指南.md#a44-目录结构差异)。

三个目录各管什么，先有个印象就够：

| 目录 | 管什么 |
|---------|---------|
| `models/` | 所有模型文件 —— 本文的主角 |
| `custom_nodes/` | 第三方节点包（装扩展时用） |
| `output/` | 生成出来的图片默认存这里 |

更细的版本差异（更新方式、命令行参数、配置方式）见 [附录 A4 版本差异指南](../附录/A4-版本差异指南.md)。

## 2.1.6 排错

**放错了文件夹会怎样？**
模型加载不出来，但**文件不会损坏**。移到正确位置、重启 ComfyUI 即可。

**文件名看着对，还是加载不出来？**
按这个顺序查：

1. 后缀写全了吗？`.safetensors` 不是 `.safetensor`。
2. 放进对应的**子**文件夹了吗？（大模型放进 `checkpoints\`，不是直接扔在 `models\` 里）
3. 重启 ComfyUI 了吗？（**改完目录必须重启**，它只在启动时扫描）
4. 文件下完整了吗？（半途中断的下载文件常常是坏的，重下一次）
5. 磁盘空间够吗？

**怎么验证装对了？**
加一个 `Load Checkpoint` 节点，点开 `ckpt_name` 下拉框 —— 能看到模型名就是成功了。看不到就回到 2.1.3。

**模型太大，想放别的盘怎么办？**
两种做法，都不需要复制文件：

```powershell
# 做法一：符号链接 —— 把 D 盘的真实目录挂到 ComfyUI 的模型目录下
mklink /D "<ComfyUI 目录>\models\checkpoints" "D:\Models\checkpoints"
```

需要以管理员身份运行。`<...>` 这种写法是什么意思，见 [附录 A7 约定表](../附录/A7-如何读本文档.md)。

做法二：编辑 `extra_model_paths.yaml`，直接把额外的模型目录告诉 ComfyUI。这个文件的位置与写法见 [附录 A6](../附录/A6-安装部署参考.md)。

**换电脑了，怎么搬？**
把整个 `models` 文件夹复制过去即可；如果装过扩展，`custom_nodes` 也一起搬。`output` 是你的产出，可选。

**怎么清理不要的模型？**
进对应子目录删掉 `.safetensors` / `.pth` 文件，然后重启。删之前确认那个模型确实不再需要 —— 重下要占流量和时间。
