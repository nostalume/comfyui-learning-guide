## 2.3.4 Load Checkpoint 节点使用

```text
节点输入：无
节点输出：
  - MODEL: UNet 模型
  - CLIP: 文本编码器
  - VAE: 变分自编码器

参数：
  - ckpt_name: 选择模型文件
```

**使用方法：**

1. 双击画布，搜索 "Load Checkpoint"
2. 点击节点中的 `ckpt_name` 下拉框
3. 选择已放置在 `models/checkpoints/` 目录下的模型
