## 2.6.1 概念说明

### 什么是 LoRA？

**LoRA**（Low-Rank Adaptation，低秩自适应）是一种轻量级的模型微调技术。

#### 功能描述（通俗易懂）

想象一下，大模型（Checkpoint）就像一个"全能画家"，它什么都会画，但可能画得不够专业。LoRA 就像是给这位画家一本"专项训练手册"，让他快速学会某个特定技能：

- 想画动漫风格？加载一个"动漫风格 LoRA"
- 想画某个特定角色？加载一个"角色 LoRA"
- 想画某种服装？加载一个"服装 LoRA"

**核心优势：**

- 文件小（通常只有 50-200MB），而完整模型通常有 2-7GB
- 可以叠加使用，一个模型可以同时加载多个 LoRA
- 不修改原模型，随时可以切换或移除

#### 类比理解

| 概念              | 类比     | 说明         |
| --------------- | ------ | ---------- |
| Checkpoint（大模型） | 手机系统   | 基础功能，体积大   |
| LoRA            | APP 插件 | 增强特定功能，体积小 |
| LoRA 强度         | APP 设置 | 控制功能影响程度   |

### 什么是 LyCORIS？

**LyCORIS**（LoRA for Beyond Conventional Methods）是 LoRA 的升级版本。

#### 功能描述（通俗易懂）

LyCORIS 是 LoRA 的"增强版"，它采用了更先进的数学方法，可以在相同文件大小下实现更好的效果：

- **更灵活**：支持更多微调方式
- **效果更好**：在细节表现上更出色
- **兼容性好**：使用方式和 LoRA 完全一样

#### LoRA 与 LyCORIS 对比

| 类型      | 全称                  | 特点        | 文件大小     | 推荐场景      |
| ------- | ------------------- | --------- | -------- | --------- |
| LoRA    | Low-Rank Adaptation | 轻量微调，通用性强 | 50-200MB | 通用场景，新手入门 |
| LyCORIS | LoRA for Beyond     | 更灵活，效果更好  | 类似 LoRA  | 追求更高质量的效果 |

## 2.6.2 LoRA 分类

### 按用途分类

| 类型      | 文件大小     | 用途      | 使用场景                |
| ------- | -------- | ------- | ------------------- |
| 风格 LoRA | 50-200MB | 艺术风格迁移  | 想让图片变成油画、水彩、动漫等特定风格 |
| 角色 LoRA | 50-150MB | 特定人物/角色 | 想生成某个动漫角色、游戏角色或真人   |
| 概念 LoRA | 20-100MB | 特定概念/元素 | 想生成某种特定物品、场景或概念     |
| 服装 LoRA | 30-100MB | 特定服装风格  | 想让人物穿上特定风格的服装       |

### 使用场景详解

#### 场景一：风格迁移

**需求：** 想让生成的图片具有某种艺术风格（如油画、水彩、赛博朋克）

**解决方案：** 使用风格 LoRA

**示例：**

```text
提示词：a beautiful landscape, mountains, river
加载 LoRA：oil_painting_style.safetensors
强度设置：strength_model = 0.7
```

**效果：** 生成的风景图片会呈现油画风格

#### 场景二：角色生成

**需求：** 想生成某个特定动漫角色或游戏角色

**解决方案：** 使用角色 LoRA

**示例：**

```text
提示词：1girl, standing in a park, smiling
加载 LoRA：character_xxx.safetensors
强度设置：strength_model = 0.9
```

**效果：** 生成的角色会具有 LoRA 训练的角色特征

#### 场景三：服装设计

**需求：** 想让人物穿上特定风格的服装

**解决方案：** 使用服装 LoRA

**示例：**

```text
提示词：1girl, full body, fashion pose
加载 LoRA：hanfu_style.safetensors
强度设置：strength_model = 0.8
```

**效果：** 人物会穿着汉服风格的服装

## 2.6.3 LoRA 加载节点

### Load LoRA 节点

#### 功能描述

将 LoRA 文件加载到模型中，使模型获得 LoRA 训练的特定能力。

#### 节点结构

```text
节点输入：
  - model: MODEL 类型（来自 Checkpoint）
  - clip: CLIP 类型（来自 Checkpoint）

节点输出：
  - MODEL: 加载 LoRA 后的模型
  - CLIP: 加载 LoRA 后的 CLIP
```

#### 参数说明

| 参数名            | 类型  | 说明             | 推荐值     |
| -------------- | --- | -------------- | ------- |
| lora_name      | 选择框 | 选择要加载的 LoRA 文件 | 根据需求选择  |
| strength_model | 浮点数 | 对模型的影响强度       | 0.6-1.0 |
| strength_clip  | 浮点数 | 对 CLIP 的影响强度   | 0.6-1.0 |

#### 参数详解

**strength_model（模型强度）：**

- 控制 LoRA 对图像生成的影响程度
- 数值越高，LoRA 特征越明显
- 过高可能导致"过拟合"，图片变得不自然

**strength_clip（CLIP 强度）：**

- 控制 LoRA 对提示词理解的影响
- 通常与 strength_model 设置相同值
- 某些情况下可以设为 0（仅影响图像，不影响提示词理解）

#### 使用示例

**基础用法：**

```text
步骤：
1. 将 LoRA 文件放入 models/lora/ 目录
2. 添加 "Load LoRA" 节点
3. 连接：Load Checkpoint → Load LoRA → KSampler
4. 设置强度参数
```

**工作流连接图：**

```text
Load Checkpoint
      │
      ├── model ──→ Load LoRA ──→ model ──→ KSampler
      │                  ↑
      └── clip ──────────┴──→ clip ──→ CLIP Text Encode
```

## 2.6.4 LoRA 强度参数建议

### 通用建议

| 参数                  | 推荐范围    | 说明             |
| ------------------- | ------- | -------------- |
| strength_model      | 0.6-1.0 | 过高可能过拟合        |
| strength_model (风格) | 0.6-0.8 | 避免风格过强，影响图片自然度 |
| strength_model (角色) | 0.8-1.0 | 确保角色特征明显       |

### 不同类型 LoRA 的强度建议

| LoRA 类型 | 推荐强度    | 原因              |
| ------- | ------- | --------------- |
| 风格 LoRA | 0.5-0.8 | 风格太强会使图片失去原模型特色 |
| 角色 LoRA | 0.8-1.0 | 需要保证角色特征清晰可辨    |
| 概念 LoRA | 0.6-0.9 | 根据概念复杂度调整       |
| 服装 LoRA | 0.7-0.9 | 需要服装细节清晰        |

### 强度调整技巧

| 现象         | 调整方向                                    |
| ---------- | --------------------------------------- |
| LoRA 特征不明显 | 提高强度（+0.1）                              |
| 图片变得奇怪/失真  | 降低强度（-0.1）                              |
| 颜色变得奇怪     | 尝试只调整 strength_model，strength_clip 设为 0 |
| 风格太强烈      | 降低 strength_model 到 0.5-0.6             |

## 2.6.5 多 LoRA 叠加

### 叠加原则

1. **控制总强度**：所有 LoRA 强度之和不超过 1.5
2. **优先级排序**：角色 LoRA > 概念 LoRA > 风格 LoRA
3. **注意兼容性**：某些 LoRA 组合可能产生冲突
4. **逐步添加**：先测试单个 LoRA，再逐步叠加

### 叠加示例

**示例：角色 + 风格组合**

```text
Load Checkpoint
      │
      ▼
  LoRA Loader 1 (角色 LoRA, strength=0.9)
      │
      ▼
  LoRA Loader 2 (风格 LoRA, strength=0.6)
      │
      ▼
   KSampler

总强度 = 0.9 + 0.6 = 1.5 ✓（刚好在推荐范围内）
```

### 多 LoRA 强度分配建议

| 组合类型    | LoRA 1 强度 | LoRA 2 强度 | 总强度  |
| ------- | --------- | --------- | ---- |
| 角色 + 风格 | 0.9 (角色)  | 0.5 (风格)  | 1.4  |
| 角色 + 服装 | 0.8 (角色)  | 0.6 (服装)  | 1.4  |
| 风格 + 风格 | 0.5 (风格1) | 0.5 (风格2) | 1.0  |
| 角色 + 角色 | 不推荐       | 不推荐       | 可能冲突 |

### 叠加连接方式

```text
Load Checkpoint
      │
      ▼
  LoRA Loader 1 (角色)
      │
      ▼
  LoRA Loader 2 (风格)
      │
      ▼
   KSampler
```

## 2.6.6 注意事项

### 文件管理

| 注意点  | 说明                           |
| ---- | ---------------------------- |
| 文件位置 | 必须放在 `models/lora/` 目录下      |
| 文件格式 | 支持 `.safetensors` 和 `.pt` 格式 |
| 命名规范 | 建议用英文命名，避免特殊字符               |

### 使用建议

| 注意点  | 说明                          |
| ---- | --------------------------- |
| 刷新列表 | 添加新 LoRA 后需要点击 "Refresh" 刷新 |
| 版本匹配 | 注意 LoRA 适用的模型版本（SD1.5/SDXL） |
| 强度调试 | 从低强度开始，逐步调整到满意效果            |
| 保存设置 | 满意的 LoRA 设置可以保存为工作流模板       |

### 常见问题

| 问题       | 原因             | 解决方案                   |
| -------- | -------------- | ---------------------- |
| LoRA 不生效 | 强度太低或文件位置错误    | 检查文件位置，提高强度            |
| 图片变奇怪    | 强度过高或 LoRA 不兼容 | 降低强度，尝试单独使用            |
| 找不到 LoRA | 未刷新列表          | 点击 Refresh 或重启 ComfyUI |
| 颜色异常     | LoRA 与模型不匹配    | 更换匹配的 LoRA 或调整强度       |
