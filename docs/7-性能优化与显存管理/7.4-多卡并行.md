## 概述

### 什么是多卡并行？

多卡并行是指利用多张 GPU 显卡协同工作，以提高生成吞吐量或支持更大模型的运行方式。

### 为什么需要多卡并行？

| 场景 | 说明 |
|-----|------|
| **提高吞吐量** | 多张 GPU 同时处理多个任务 |
| **运行大模型** | 单卡显存不足时，多卡分担 |
| **批量处理** | 大规模图像生成任务 |
| **服务部署** | 高并发 API 服务 |

### 多卡并行的优势

| 优势 | 说明 |
|-----|------|
| **线性扩展** | 2 张卡约 2 倍吞吐量 |
| **灵活配置** | 可根据需求选择模式 |
| **成本优化** | 利用现有硬件资源 |

## 多 GPU 使用模式

### 模式对比

| 模式 | 原理 | 优点 | 缺点 | 适用场景 |
|-----|------|------|------|---------|
| **多实例并行** | 每张卡独立运行 | 配置简单、完全隔离 | 无法共享显存 | 批量任务 |
| **模型并行** | 模型拆分到多卡 | 支持大模型 | 通信开销 | 显存不足 |
| **负载均衡** | 外部调度分发 | 高效利用 | 需要额外组件 | 服务部署 |

## 模式一：多实例并行（推荐）

### 什么是多实例并行？

在每张 GPU 上运行独立的 ComfyUI 实例，每个实例处理不同的任务。这是最简单、最稳定的多 GPU 使用方式。

### 工作原理

```
任务队列
    ├── 任务1 → ComfyUI (GPU 0) → 结果1
    ├── 任务2 → ComfyUI (GPU 1) → 结果2
    └── 任务3 → ComfyUI (GPU 2) → 结果3
```

### 优点与缺点

**优点：**
- 配置简单，易于理解
- 完全隔离，互不影响
- 适合批量任务处理
- 故障不会相互影响

**缺点：**
- 无法共享模型显存
- 需要多个端口
- 每个实例独立加载模型

### 详细配置步骤

#### 步骤 1：检查 GPU 信息

**Windows PowerShell：**
```powershell
nvidia-smi --query-gpu=index,name,memory.total --format=csv
```

**输出示例：**
```
index, name, memory.total [MiB]
0, NVIDIA GeForce RTX 3080, 10240 MiB
1, NVIDIA GeForce RTX 3080, 10240 MiB
```

#### 步骤 2：启动第一个实例

**Windows PowerShell：**
```powershell
$env:CUDA_VISIBLE_DEVICES="0"

```

**Linux/macOS：**
```bash
CUDA_VISIBLE_DEVICES=0 python main.py --port 8188
```

#### 步骤 3：启动第二个实例（新终端）

**Windows PowerShell：**
```powershell
$env:CUDA_VISIBLE_DEVICES="1"
python main.py --port 8189
```

**Linux/macOS：**
```bash
CUDA_VISIBLE_DEVICES=1 python main.py --port 8189
```

#### 步骤 4：验证运行

打开浏览器访问：
- GPU 0：`http://localhost:8188`
- GPU 1：`http://localhost:8189`

### 一键启动脚本

#### Windows PowerShell 脚本

创建文件 `start_multi_gpu.ps1`：

```powershell
$comfyuiPath = "E:\ComfyUI"
$ports = @(8188, 8189, 8190, 8191)

Write-Host "启动多 GPU ComfyUI 实例..." -ForegroundColor Green

for ($i = 0; $i -lt $ports.Count; $i++) {
    $port = $ports[$i]
    Write-Host "启动 GPU $i 在端口 $port..." -ForegroundColor Yellow
    
    Start-Process powershell -ArgumentList @"
        -NoExit
        -Command "cd $comfyuiPath; `$env:CUDA_VISIBLE_DEVICES='$i'; python main.py --port $port"
"@
}

Write-Host "所有实例已启动！" -ForegroundColor Green
Write-Host "访问地址：" -ForegroundColor Cyan
for ($i = 0; $i -lt $ports.Count; $i++) {
    Write-Host "  GPU $i: http://localhost:$($ports[$i])" -ForegroundColor White
}
```

**运行方式：**
```powershell
powershell -ExecutionPolicy Bypass -File start_multi_gpu.ps1
```

#### Linux/macOS Bash 脚本

创建文件 `start_multi_gpu.sh`：

```bash
#!/bin/bash

COMFYUI_PATH="/path/to/ComfyUI"
PORTS=(8188 8189 8190 8191)

echo "启动多 GPU ComfyUI 实例..."

for i in "${!PORTS[@]}"; do
    port=${PORTS[$i]}
    echo "启动 GPU $i 在端口 $port..."
    
    CUDA_VISIBLE_DEVICES=$i python main.py --port $port &
done

echo "所有实例已启动！"
echo "访问地址："
for i in "${!PORTS[@]}"; do
    echo "  GPU $i: http://localhost:${PORTS[$i]}"
done

wait
```

**运行方式：**
```bash
chmod +x start_multi_gpu.sh
./start_multi_gpu.sh
```

### 配置参数说明

| 参数 | 说明 | 示例 |
|-----|------|------|
| `CUDA_VISIBLE_DEVICES` | 指定使用的 GPU | `"0"` 或 `"0,1"` |
| `--port` | 指定服务端口 | `8188` |
| `--listen` | 允许外部访问 | `0.0.0.0` |
| `--cuda-device` | 指定 CUDA 设备 | `0` |

## 模式二：模型并行

### 什么是模型并行？

将大模型的参数拆分到多张 GPU 上，每张 GPU 只存储和处理模型的一部分。

### 工作原理

```
完整模型 (24GB)
    ↓ 模型拆分
GPU 0: Encoder + 前半部分 U-Net (~12GB)
GPU 1: 后半部分 U-Net + Decoder (~12GB)
    ↓ 数据流
输入 → GPU 0 → GPU 1 → 输出
```

### 适用场景

| 场景 | 说明 |
|-----|------|
| 单卡显存不足 | 需要运行超大模型 |
| Flux 等大模型 | 12B 参数模型 |
| 高分辨率生成 | 需要大量显存 |

### 配置方法

#### 启用模型并行

```bash
python main.py --split-memory --gpu-only
```

#### 参数说明

| 参数 | 说明 |
|-----|------|
| `--split-memory` | 启用模型分块 |
| `--gpu-only` | 强制所有计算在 GPU |

### 显存分配示例

| GPU | 分配内容 | 显存占用 |
|-----|---------|---------|
| GPU 0 | 模型前半部分 | ~50% |
| GPU 1 | 模型后半部分 | ~50% |

### 注意事项

- 模型并行会增加 GPU 间通信开销
- 单张图生成速度可能下降 20-30%
- 需要高速 PCIe 或 NVLink 连接
- 适合显存不足但需要运行大模型的场景

## 模式三：负载均衡

### 什么是负载均衡？

通过外部调度器将任务分发到不同的 ComfyUI 实例，实现任务的均衡分配。

### 架构图

```
                    负载均衡器
                        │
        ┌───────────────┼───────────────┐
        ↓               ↓               ↓
   ComfyUI          ComfyUI         ComfyUI
   (GPU 0)          (GPU 1)         (GPU 2)
   :8188            :8189           :8190
```

### 方案一：Nginx 反向代理

#### 安装 Nginx

**Windows：**
下载地址：http://nginx.org/en/download.html

**Linux：**
```bash
sudo apt install nginx
```

#### 配置文件

编辑 `nginx.conf`：

```nginx
upstream comfyui_backend {
    least_conn;
    server 127.0.0.1:8188;
    server 127.0.0.1:8189;
    server 127.0.0.1:8190;
}

server {
    listen 80;
    server_name localhost;

    location / {
        proxy_pass http://comfyui_backend;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_read_timeout 300s;
        proxy_connect_timeout 75s;
    }

    location /ws {
        proxy_pass http://comfyui_backend;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
    }
}
```

#### 启动 Nginx

```bash
nginx
```

### 方案二：Python 轮询调度

```python
import requests
import itertools
import time
from typing import Dict, Any

class ComfyUILoadBalancer:
    def __init__(self, servers):
        self.servers = itertools.cycle(servers)
        self.server_status = {s: {"busy": False, "last_used": 0} for s in servers}
    
    def get_available_server(self):
        """获取可用的服务器"""
        for _ in range(len(self.server_status)):
            server = next(self.servers)
            if not self.server_status[server]["busy"]:
                return server
        return None
    
    def queue_prompt(self, workflow: Dict[str, Any]) -> Dict:
        """提交工作流到队列"""
        server = self.get_available_server()
        if not server:
            raise Exception("所有服务器都忙")
        
        self.server_status[server]["busy"] = True
        try:
            response = requests.post(
                f"{server}/prompt",
                json={"prompt": workflow},
                timeout=30
            )
            return response.json()
        finally:
            self.server_status[server]["busy"] = False
            self.server_status[server]["last_used"] = time.time()
    
    def get_history(self, prompt_id: str) -> Dict:
        """获取执行历史"""
        for server in self.server_status:
            try:
                response = requests.get(f"{server}/history/{prompt_id}")
                if response.status_code == 200 and response.json():
                    return response.json()
            except:
                continue
        return {}

servers = [
    "http://localhost:8188",
    "http://localhost:8189",
    "http://localhost:8190"
]

lb = ComfyUILoadBalancer(servers)
```

### 方案三：使用任务队列

```python
import queue
import threading
import requests

class TaskDispatcher:
    def __init__(self, servers):
        self.servers = servers
        self.task_queue = queue.Queue()
        self.results = {}
        
        for server in servers:
            thread = threading.Thread(
                target=self.worker,
                args=(server,),
                daemon=True
            )
            thread.start()
    
    def worker(self, server):
        while True:
            task_id, workflow = self.task_queue.get()
            try:
                response = requests.post(
                    f"{server}/prompt",
                    json={"prompt": workflow}
                )
                self.results[task_id] = response.json()
            except Exception as e:
                self.results[task_id] = {"error": str(e)}
            self.task_queue.task_done()
    
    def submit(self, task_id, workflow):
        self.task_queue.put((task_id, workflow))
    
    def get_result(self, task_id):
        return self.results.get(task_id)

servers = ["http://localhost:8188", "http://localhost:8189"]
dispatcher = TaskDispatcher(servers)
```

### Python 监控脚本

```python
import pynvml
import time

def init_nvml():
    pynvml.nvmlInit()

def get_gpu_info(gpu_index=0):
    handle = pynvml.nvmlDeviceGetHandleByIndex(gpu_index)
    
    name = pynvml.nvmlDeviceGetName(handle)
    mem_info = pynvml.nvmlDeviceGetMemoryInfo(handle)
    util = pynvml.nvmlDeviceGetUtilizationRates(handle)
    temp = pynvml.nvmlDeviceGetTemperature(handle, pynvml.NVML_TEMPERATURE_GPU)
    
    return {
        "name": name.decode() if isinstance(name, bytes) else name,
        "memory_used": mem_info.used / 1024**3,
        "memory_total": mem_info.total / 1024**3,
        "memory_percent": mem_info.used / mem_info.total * 100,
        "gpu_util": util.gpu,
        "memory_util": util.memory,
        "temperature": temp
    }

def monitor_all_gpus(interval=1):
    init_nvml()
    device_count = pynvml.nvmlDeviceGetCount()
    
    print(f"监控 {device_count} 个 GPU...")
    print("-" * 80)
    
    try:
        while True:
            print(f"\n{'='*80}")
            for i in range(device_count):
                info = get_gpu_info(i)
                print(f"GPU {i}: {info['name']}")
                print(f"  显存: {info['memory_used']:.1f}/{info['memory_total']:.1f} GB ({info['memory_percent']:.1f}%)")
                print(f"  利用率: GPU {info['gpu_util']}%, 显存 {info['memory_util']}%")
                print(f"  温度: {info['temperature']}°C")
            time.sleep(interval)
    except KeyboardInterrupt:
        print("\n监控已停止")

monitor_all_gpus()
```

## 常见问题 FAQ

### Q1: GPU 间负载不均怎么办？

**原因：** 任务分配不均匀

**解决方案：**

1. 使用负载均衡器动态分配
2. 实现智能调度算法
3. 监控各 GPU 负载状态

```python
def smart_dispatch(workflow, servers):
    """智能调度：选择负载最低的服务器"""
    min_load = float('inf')
    best_server = None
    
    for server in servers:
        load = get_gpu_load(server)
        if load < min_load:
            min_load = load
            best_server = server
    
    return submit_to_server(best_server, workflow)
```

### Q2: 模型加载到错误的 GPU 怎么办？

**原因：** CUDA_VISIBLE_DEVICES 设置问题

**解决方案：**

1. 检查环境变量设置
   ```bash
   echo $CUDA_VISIBLE_DEVICES
   ```

2. 确保在启动 Python 前设置
   ```bash
   CUDA_VISIBLE_DEVICES=0 python main.py
   ```

3. 使用 --cuda-device 参数
   ```bash
   python main.py --cuda-device 0
   ```

### Q3: 通信延迟高怎么办？

**原因：** PCIe 带宽限制

**解决方案：**

1. 使用 NVLink 连接（如支持）
2. 确保使用 PCIe 3.0/4.0 x16 插槽
3. 避免模型并行，改用多实例

### Q4: 如何判断多 GPU 是否正常工作？

**检查方法：**

1. 查看 nvidia-smi 输出
   ```bash
   nvidia-smi
   ```
   确认多张 GPU 都有显存占用

2. 检查端口监听
   ```bash
   netstat -an | grep 8188
   netstat -an | grep 8189
   ```

3. 访问各实例的 Web 界面
   - http://localhost:8188
   - http://localhost:8189

### Q5: Windows 下启动多实例失败怎么办？

**常见原因及解决方案：**

| 原因 | 解决方案 |
|-----|---------|
| 端口被占用 | 更换端口或关闭占用进程 |
| 环境变量未生效 | 在同一终端设置和启动 |
| 权限问题 | 以管理员身份运行 |

**正确的启动顺序：**

```powershell
# 终端 1
$env:CUDA_VISIBLE_DEVICES="0"
python main.py --port 8188

# 终端 2（新开一个 PowerShell）
$env:CUDA_VISIBLE_DEVICES="1"
python main.py --port 8189
```

### Q6: 如何实现跨机器的分布式部署？

**方案：**

1. 每台机器运行 ComfyUI 实例
2. 使用统一的负载均衡器
3. 配置网络访问

```nginx
upstream comfyui_distributed {
    server 192.168.1.10:8188;
    server 192.168.1.11:8188;
    server 192.168.1.12:8188;
}
```
