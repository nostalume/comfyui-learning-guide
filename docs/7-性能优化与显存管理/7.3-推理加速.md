## 概述

### 什么是推理加速？

推理加速是指通过各种技术手段，提高 AI 模型生成图像的速度。在保证生成质量的前提下，减少每张图片的生成时间。

### 为什么需要推理加速？

| 原因 | 说明 |
|-----|------|
| **提高效率** | 减少等待时间，提高工作流效率 |
| **降低成本** | 云端 GPU 按时间计费，加速等于省钱 |
| **改善体验** | 快速反馈，便于调试和迭代 |
| **批量处理** | 加速后可以处理更多任务 |

### 主要加速方案

| 方案 | 加速效果 | 难度 | 推荐度 |
|-----|---------|------|-------|
| xFormers | 20-30% | 低 | ⭐⭐⭐⭐⭐ |
| SDPA | 20-30% | 低 | ⭐⭐⭐⭐⭐ |
| Flash Attention 2 | 20-35% | 中 | ⭐⭐⭐⭐ |
| TensorRT | 30-40% | 高 | ⭐⭐⭐ |
| torch.compile | 10-20% | 低 | ⭐⭐⭐⭐ |
| FP8 量化 | 20-30% | 低 | ⭐⭐⭐ |

## xFormers 加速

### 什么是 xFormers？

xFormers 是 Facebook Research（Meta）开发的高效 Transformer 组件库。它通过优化的注意力机制实现加速和显存优化。

**核心原理：**
- 优化 Self-Attention 计算
- 减少显存访问次数
- 支持稀疏注意力

### xFormers 的优势

| 优势 | 说明 |
|-----|------|
| **速度提升** | 20-30% 加速 |
| **显存节省** | 减少约 10-20% 显存 |
| **兼容性好** | 支持大多数模型 |
| **易于使用** | 安装后自动生效 |

### 安装前准备

#### 检查当前环境

```bash
python -c "import torch; print(f'PyTorch: {torch.__version__}'); print(f'CUDA: {torch.version.cuda}')"
```

输出示例：
```
PyTorch: 2.4.0
CUDA: 12.1
```

#### 确认 GPU 支持

```bash
nvidia-smi --query-gpu=name,driver_version,memory.total --format=csv
```

### 安装方法详解

#### 方法一：自动安装（推荐）

最简单的方式，让 pip 自动匹配版本：

```bash
pip install xformers
```

#### 方法二：指定版本安装

如果自动安装失败，需要手动匹配版本：

```bash
pip install xformers==0.0.28 --index-url https://download.pytorch.org/whl/cu121
```

#### 方法三：从源码编译（高级）

如果预编译版本不兼容，可以从源码编译：

```bash
pip install ninja
pip install git+https://github.com/facebookresearch/xformers.git@main
```

**错误信息：**
```
ModuleNotFoundError: No module named 'xformers'
```

**解决方案：**
```bash
pip install xformers
```

## SDPA（Scaled Dot Product Attention）

### 什么是 SDPA？

SDPA 是 PyTorch 2.0+ 内置的优化注意力机制，全称 Scaled Dot Product Attention。它支持多种后端优化，包括 Flash Attention 和 Memory-Efficient Attention。

### SDPA 的优势

| 优势 | 说明 |
|-----|------|
| **内置支持** | PyTorch 2.0+ 自带，无需安装 |
| **兼容性好** | 与 PyTorch 版本自动匹配 |
| **自动优化** | 根据硬件自动选择最佳后端 |
| **支持 Flash Attention 2** | RTX 30/40 系列可启用 |

### 启用方式

#### 自动启用

ComfyUI 在 PyTorch 2.0+ 上默认启用 SDPA。

#### 手动启用

```bash
python main.py --use-pytorch-cross-attention
```

### SDPA vs xFormers

| 特性 | SDPA | xFormers |
|-----|------|----------|
| 安装难度 | 内置，无需安装 | 需单独安装 |
| 兼容性 | 更好 | 需版本匹配 |
| 速度 | 相近 | 相近 |
| 显存 | 相近 | 相近 |
| Flash Attention 2 | 支持 | 不支持 |
| 维护状态 | 活跃 | 活跃 |

**推荐选择：**
- **RTX 40 系列**：优先使用 SDPA + Flash Attention 2
- **RTX 30 系列**：SDPA 或 xFormers 均可
- **RTX 20 系列**：推荐 xFormers
- **GTX 系列**：推荐 xFormers

## Flash Attention 2

### 什么是 Flash Attention 2？

Flash Attention 2 是一种高效的注意力计算算法，通过优化内存访问模式大幅提升速度。它是目前最快的注意力实现之一。

### 支持的 GPU

| GPU 系列 | Flash Attention 2 支持 | 说明 |
|---------|----------------------|------|
| RTX 40 系列 | ✅ 完全支持 | 最佳性能 |
| RTX 30 系列 | ✅ 完全支持 | 性能良好 |
| RTX 20 系列 | ⚠️ 部分支持 | 可能需要特定配置 |
| GTX 16/10 系列 | ❌ 不支持 | 架构不支持 |

### 安装 Flash Attention 2

#### 前置要求

- PyTorch 2.0+
- CUDA 11.6+
- 支持的 GPU（RTX 30/40 系列）

#### 安装步骤

**步骤 1：安装编译工具**

Windows：
```bash
pip install ninja packaging
```

Linux：
```bash
pip install ninja packaging
sudo apt-get install build-essential
```

**步骤 2：安装 Flash Attention**

```bash
pip install flash-attn --no-build-isolation
```

**步骤 3：验证安装**

```bash
python -c "import flash_attn; print(f'Flash Attention version: {flash_attn.__version__}')"
```

### 启用 Flash Attention 2

在 ComfyUI 中，Flash Attention 2 通过 SDPA 自动启用：


## TensorRT 加速

### 什么是 TensorRT？

TensorRT 是 NVIDIA 开发的高性能深度学习推理优化器。它可以将模型转换为优化后的引擎，显著提升推理速度。

### TensorRT 的优势

| 优势 | 说明 |
|-----|------|
| **极致速度** | 30-40% 加速 |
| **显存优化** | 减少显存占用 |
| **精度控制** | 支持 FP16/INT8 量化 |
| **NVIDIA 官方** | 持续更新优化 |

### TensorRT 的限制

| 限制 | 说明 |
|-----|------|
| 固定分辨率 | 需为特定分辨率优化 |
| 编译时间长 | 首次转换耗时较长 |
| GPU 限制 | 仅支持 NVIDIA GPU |
| 动态特性有限 | 动态 LoRA 支持有限 |

### 安装 TensorRT

#### 步骤 1：安装依赖

```bash
pip install tensorrt
pip install onnx onnx-graphsurgeon
pip install polygraphy
```

#### 步骤 2：验证安装

```bash
python -c "import tensorrt; print(f'TensorRT version: {tensorrt.__version__}')"
```

### 使用 TensorRT 加速 ComfyUI

#### 方法一：使用 ComfyUI-TensorRT 插件

1. **安装插件**
   ```bash
   cd ComfyUI/custom_nodes
   git clone https://github.com/comfyanonymous/ComfyUI_TensorRT
   ```

2. **安装依赖**
   ```bash
   cd ComfyUI_TensorRT
   pip install -r requirements.txt
   ```

3. **重启 ComfyUI**

4. **转换模型**
   - 在 ComfyUI 中使用 TensorRT 节点
   - 首次运行会自动编译 TensorRT 引擎

#### 方法二：手动转换模型

```python
import torch
import tensorrt as trt
import onnx

def export_to_onnx(model, output_path, input_shape=(1, 4, 64, 64)):
    dummy_input = torch.randn(input_shape)
    torch.onnx.export(
        model,
        dummy_input,
        output_path,
        opset_version=17,
        input_names=['input'],
        output_names=['output'],
        dynamic_axes={'input': {0: 'batch'}, 'output': {0: 'batch'}}
    )

def onnx_to_tensorrt(onnx_path, engine_path, fp16=True):
    logger = trt.Logger(trt.Logger.WARNING)
    builder = trt.Builder(logger)
    network = builder.create_network(1 << int(trt.NetworkDefinitionCreationFlag.EXPLICIT_BATCH))
    parser = trt.OnnxParser(network, logger)
    
    with open(onnx_path, 'rb') as f:
        parser.parse(f.read())
    
    config = builder.create_builder_config()
    if fp16:
        config.set_flag(trt.BuilderFlag.FP16)
    
    engine = builder.build_engine(network, config)
    with open(engine_path, 'wb') as f:
        f.write(engine.serialize())
```

### TensorRT 加速效果

| 模型 | 标准推理 | TensorRT | 提升 |
|-----|---------|----------|------|
| SD 1.5 (512x512) | 2.8s | 1.8s | ~35% |
| SDXL (1024x1024) | 5.5s | 3.5s | ~36% |

## 其他加速方案

### torch.compile

#### 什么是 torch.compile？

torch.compile 是 PyTorch 2.0+ 引入的即时编译优化，可以将模型编译为优化的机器码。

#### 启用方式

```bash
python main.py --torch-compile
```

#### 效果

- 速度提升：10-20%
- 首次运行需要编译时间
- 后续运行会使用缓存

#### 注意事项

- 首次编译可能需要几分钟
- 更改模型后需要重新编译
- 某些自定义节点可能不兼容

### FP8 量化

#### 什么是 FP8？

FP8（8-bit Floating Point）是一种新的数值格式，可以将模型从 FP16 进一步量化到 8 位。

#### 支持的 GPU

| GPU | FP8 支持 |
|-----|---------|
| RTX 40 系列 | ✅ 支持 |
| H100 | ✅ 支持 |
| RTX 30 系列 | ❌ 不支持 |
| RTX 20 系列 | ❌ 不支持 |

#### 启用方式

```bash
python main.py --fp8_e4m3fn-unet
```

或同时量化文本编码器：

```bash
python main.py --fp8_e4m3fn-unet --fp8_e4m3fn-text-encoder
```

#### 效果

- 显存减少：约 50%
- 速度提升：约 20%
- 质量影响：轻微

### BF16 精度

#### 什么是 BF16？

BF16（Brain Float 16）是一种 16 位浮点格式，相比 FP16 有更好的数值稳定性。

#### 支持的 GPU

| GPU | BF16 支持 |
|-----|---------|
| RTX 40 系列 | ✅ 支持 |
| RTX 30 系列 | ✅ 支持 |
| A100/H100 | ✅ 支持 |
| RTX 20 系列 | ❌ 不支持 |
| GTX 系列 | ❌ 不支持 |

#### 启用方式

```bash
python main.py --bf16-unet
```

#### 效果

- 更稳定的数值精度
- 轻微加速（5-10%）
- 避免某些情况下的 NaN 错误

## 性能测试方法

### 基准测试脚本

```python
import time
import torch

def benchmark(func, iterations=10, warmup=3):
    """
    执行基准测试
    
    参数：
    - func: 要测试的函数
    - iterations: 测试次数
    - warmup: 预热次数
    """
    for _ in range(warmup):
        func()
        torch.cuda.synchronize()
    
    times = []
    for _ in range(iterations):
        torch.cuda.synchronize()
        start = time.time()
        func()
        torch.cuda.synchronize()
        end = time.time()
        times.append(end - start)
    
    avg = sum(times) / len(times)
    min_t = min(times)
    max_t = max(times)
    
    print(f"平均: {avg:.3f}s")
    print(f"最快: {min_t:.3f}s")
    print(f"最慢: {max_t:.3f}s")
    
    return avg

def print_gpu_memory():
    allocated = torch.cuda.memory_allocated() / 1024**3
    reserved = torch.cuda.memory_reserved() / 1024**3
    print(f"显存: {allocated:.2f}GB / {reserved:.2f}GB")
```

### 对比测试步骤

1. **记录基准配置**
   ```bash
   python main.py
   # 运行测试，记录时间
   ```

2. **启用加速方案**
   ```bash
   python main.py --use-xformers
   # 运行相同测试，记录时间
   ```

3. **对比结果**
   - 比较生成时间
   - 检查输出质量
   - 监控显存占用

## 常见问题 FAQ

### Q1: xFormers 和 SDPA 可以同时使用吗？

**答：** 不可以。两者是互斥的，只能选择其一。

**推荐选择：**
- RTX 40 系列：使用 SDPA
- RTX 30 系列：两者皆可
- RTX 20 系列：使用 xFormers

### Q2: 如何判断加速是否生效？

**检查方法：**

1. 查看启动日志
   ```
   Using xformers cross attention
   # 或
   Using pytorch cross attention
   ```

2. 对比生成速度
   - 运行相同工作流
   - 比较生成时间

### Q3: 加速后图像质量会下降吗？

**答：** 通常不会。

- xFormers/SDPA：几乎无影响
- FP8：轻微影响，通常不可察觉
- TensorRT：取决于量化设置

### Q4: 为什么安装 xFormers 总是失败？

**常见原因：**

| 原因 | 解决方案 |
|-----|---------|
| 版本不匹配 | 按兼容表安装正确版本 |
| 缺少编译工具 | 安装 Visual Studio Build Tools |
| CUDA 版本不对 | 检查并匹配 CUDA 版本 |
| 网络问题 | 使用国内镜像源 |

### Q5: Flash Attention 2 安装失败怎么办？

**解决方案：**

1. 确认 GPU 支持（RTX 30/40 系列）
2. 安装编译工具：
   ```bash
   pip install ninja packaging
   ```
3. 使用预编译版本（如果有）
4. 改用 xFormers 或 SDPA
