# 6.1 常用节点包

> 📌 **版本信息**
> - 文档版本：v2.0
> - 更新日期：2026-04-28
> **相关官方文档：** [ComfyUI 官方文档](https://docs.comfy.org/) | [中文文档](https://docs.comfy.org/zh/)

## 概述

ComfyUI 的强大之处在于其丰富的插件生态。本节介绍最常用、最稳定的节点包，帮助您快速扩展 ComfyUI 的功能。每个节点包都经过社区广泛验证，是构建复杂工作流的基础。

> 💡 **提示：** 建议优先安装 ComfyUI-Manager，它可以帮助您管理其他所有节点包。

## 6.1.1 ComfyUI-Manager

> **推荐指数：** ⭐⭐⭐⭐⭐（必装）
> **状态：** 活跃维护
> **仓库：** https://github.com/ltdrdata/ComfyUI-Manager

### 功能描述

ComfyUI-Manager 是 ComfyUI 生态中最重要的插件管理工具，可以理解为 ComfyUI 的"应用商店"。它提供了图形化界面来搜索、安装、更新和管理所有自定义节点，大大降低了插件管理的门槛。

### 核心功能

| 功能 | 说明 | 使用频率 |
|------|------|----------|
| 插件搜索 | 搜索并浏览社区插件库 | 高 |
| 一键安装 | 点击即可安装插件，自动处理依赖 | 高 |
| 插件更新 | 一键更新所有或单个插件 | 中 |
| 工作流修复 | 自动检测并安装工作流中缺失的节点 | 高 |
| 模型管理 | 浏览和下载常用模型 | 中 |
| 版本控制 | 查看插件版本，支持回滚 | 低 |

### 安装方法

**方法一：Git 克隆（推荐）**

```bash
cd ComfyUI/custom_nodes
git clone https://github.com/ltdrdata/ComfyUI-Manager.git
```

**方法二：手动下载**

1. 访问 [GitHub 仓库](https://github.com/ltdrdata/ComfyUI-Manager)
2. 点击 "Code" → "Download ZIP"
3. 解压到 `ComfyUI/custom_nodes/ComfyUI-Manager/`

### 使用方法

安装完成后重启 ComfyUI，在界面右侧会出现 "Manager" 按钮：

1. **安装新节点：** Manager → Install Custom Nodes → 搜索/浏览 → Install
2. **安装缺失节点：** Manager → Install Missing Nodes（自动检测工作流缺失节点）
3. **更新所有节点：** Manager → Fetch Updates → Update All
4. **通过 URL 安装：** Manager → Install via Git URL → 输入仓库地址

### 使用场景

| 场景 | 操作 |
|------|------|
| 新手入门 | 使用 Manager 安装所有需要的节点 |
| 工作流分享 | 自动安装他人分享的工作流中缺失的节点 |
| 批量更新 | 一键更新所有已安装的节点 |
| 故障排查 | 查看节点加载状态和错误信息 |

### 注意事项

- 首次使用需要联网下载插件列表
- 部分节点可能需要额外的 Python 依赖
- 更新节点前建议备份重要工作流
- 如果 Manager 无法启动，检查网络连接和 Python 环境

### 常见问题

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| Manager 按钮不显示 | 安装路径错误 | 确保安装在 `custom_nodes/ComfyUI-Manager/` |
| 无法连接网络 | 网络限制 | 使用代理或手动下载节点 |
| 节点安装失败 | 依赖缺失 | 查看控制台错误，手动安装依赖 |

## 6.1.2 Comfyroll Studio

> **推荐指数：** ⭐⭐⭐⭐⭐（强烈推荐）
> **状态：** 活跃维护
> **仓库：** https://github.com/RockOfFire/ComfyUI_Comfyroll_CustomNodes

### 功能描述

Comfyroll Studio 是一个功能全面的节点包，提供了大量实用节点，涵盖图像生成、文本处理、逻辑控制等多个领域。它的节点设计注重易用性和实用性，特别适合需要构建复杂工作流的用户。

### 主要节点分类

| 分类 | 节点示例 | 功能说明 |
|------|----------|----------|
| **采样控制** | CR Seed, CR Random Multiline | 种子控制和随机化 |
| **图像输出** | CR Image Output, CR Image Grid | 图像保存和网格排列 |
| **文本处理** | CR Prompt Text, CR Text Concatenate | 提示词组合和处理 |
| **逻辑控制** | CR Switch, CR Conditional | 条件判断和分支选择 |
| **数值运算** | CR Integer Math, CR Float Math | 数学运算 |
| **颜色处理** | CR Color Tint, CR Halftone | 颜色调整和特效 |

### 安装方法

**通过 ComfyUI-Manager：**

1. Manager → Install Custom Nodes
2. 搜索 "Comfyroll"
3. 点击 Install

**通过 Git：**

```bash
cd ComfyUI/custom_nodes
git clone https://github.com/RockOfFire/ComfyUI_Comfyroll_CustomNodes.git
```

### 使用场景

| 场景 | 推荐节点 | 说明 |
|------|----------|------|
| 批量生成不同种子图像 | CR Seed + CR Random Multiline | 自动遍历多个种子 |
| 创建图像对比网格 | CR Image Grid | 将多张图像排列成网格 |
| 动态切换提示词 | CR Switch | 根据条件选择不同提示词 |
| 图像特效处理 | CR Halftone, CR Vignette | 添加艺术效果 |

### 核心节点详解

#### CR Seed 节点

**功能：** 提供可控的随机种子输入

**参数说明：**

| 参数 | 类型 | 说明 | 默认值 |
|------|------|------|--------|
| seed | INT | 随机种子值 | 0 |
| mode | COMBO | 固定/随机/增量/递减 | fixed |

**使用示例：**

```
CR Seed (mode=random) → KSampler (seed 输入)
```

#### CR Switch 节点

**功能：** 多路选择器，根据索引选择不同的输入

**参数说明：**

| 参数 | 类型 | 说明 |
|------|------|------|
| input1 - input5 | * | 多个输入选项 |
| switch_mode | COMBO | 选择模式 |

### 注意事项

- 节点数量较多，建议按需学习
- 部分节点与其他节点包功能重叠，选择最适合的即可
- 更新后可能需要重启 ComfyUI

### 常见问题

| 问题 | 解决方案 |
|------|----------|
| 节点不显示在菜单中 | 检查安装路径，确保 `__init__.py` 存在 |
| 找不到特定节点 | 使用搜索功能，节点名称可能略有不同 |

## 6.1.3 WAS Node Suite

> **推荐指数：** ⭐⭐⭐⭐⭐（强烈推荐）
> **状态：** 活跃维护
> **仓库：** https://github.com/WASasquatch/was-node-suite-comfyui

### 功能描述

WAS Node Suite 是一个功能极其丰富的节点包，专注于图像处理和文本操作。它提供了数百个实用节点，从基础的图像变换到高级的滤镜效果，几乎涵盖了图像处理的所有需求。

### 主要节点分类

| 分类 | 节点示例 | 功能说明 |
|------|----------|----------|
| **图像变换** | Image Scale, Image Crop, Image Flip | 缩放、裁剪、翻转 |
| **图像滤镜** | Image Filter, Image Bloom, Image Glitch | 各种滤镜效果 |
| **图像合成** | Image Blend, Image Overlay, Image Stack | 图像混合和叠加 |
| **文本处理** | Text Concatenate, Text Parse, Text Random | 文本操作 |
| **数值生成** | Random Number, Number Operation | 数值运算 |
| **调试工具** | Debug Print, Image Info | 调试和信息查看 |

### 安装方法

**通过 ComfyUI-Manager：**

1. Manager → Install Custom Nodes
2. 搜索 "WAS"
3. 点击 Install

**通过 Git：**

```bash
cd ComfyUI/custom_nodes
git clone https://github.com/WASasquatch/was-node-suite-comfyui.git
```

### 使用场景

| 场景 | 推荐节点 | 说明 |
|------|----------|------|
| 图像后处理 | Image Bloom, Image Bloom Filter | 添加光晕效果 |
| 图像混合 | Image Blend (多种混合模式) | 专业级图像合成 |
| 提示词组合 | Text Concatenate | 组合多个文本片段 |
| 图像信息查看 | Image Info | 查看图像尺寸、格式等信息 |

### 核心节点详解

#### Image Blend 节点

**功能：** 将两张图像按指定混合模式合成

**参数说明：**

| 参数 | 类型 | 说明 | 可选值 |
|------|------|------|--------|
| image_a | IMAGE | 底层图像 | - |
| image_b | IMAGE | 上层图像 | - |
| blend_factor | FLOAT | 混合强度 | 0.0 - 1.0 |
| blend_mode | COMBO | 混合模式 | normal, multiply, screen, overlay 等 |

**混合模式说明：**

| 模式 | 效果 | 适用场景 |
|------|------|----------|
| normal | 正常混合 | 通用 |
| multiply | 正片叠底（变暗） | 阴影、纹理叠加 |
| screen | 滤色（变亮） | 光效、高光叠加 |
| overlay | 叠加（对比增强） | 纹理增强 |
| soft_light | 柔光 | 柔和效果 |
| hard_light | 强光 | 强烈对比 |

#### Image Filter 节点

**功能：** 应用各种图像滤镜

**支持滤镜：**

| 滤镜 | 效果 |
|------|------|
| blur | 模糊 |
| sharpen | 锐化 |
| emboss | 浮雕 |
| edge_enhance | 边缘增强 |
| find_edges | 边缘检测 |

### 注意事项

- 节点数量众多，建议先熟悉常用节点
- 部分滤镜效果可能需要较长处理时间
- WAS 节点会创建配置文件 `was_suite_config.json`

### 常见问题

| 问题 | 解决方案 |
|------|----------|
| 配置文件错误 | 删除 `was_suite_config.json` 后重启 |
| 图像处理慢 | 减小图像尺寸或使用更简单的滤镜 |

## 6.1.4 Efficiency Nodes

> **推荐指数：** ⭐⭐⭐⭐（推荐）
> **状态：** 活跃维护
> **仓库：** https://github.com/jags111/efficiency-nodes-comfyui

### 功能描述

Efficiency Nodes 专注于提高工作流效率，提供批量处理、参数对比、LoRA 管理等实用功能。特别适合需要进行大量实验和参数调优的用户。

### 主要节点

| 节点 | 功能 | 使用场景 |
|------|------|----------|
| **XY Plot** | XY 参数对比图生成 | 参数对比实验 |
| **LoRA Stacker** | LoRA 批量管理 | 同时使用多个 LoRA |
| **Efficient Loader** | 高效模型加载器 | 简化加载流程 |
| **Simple Eval** | 简单表达式求值 | 数值计算 |

### 安装方法

```bash
cd ComfyUI/custom_nodes
git clone https://github.com/jags111/efficiency-nodes-comfyui.git
```

### 使用场景

#### XY Plot 参数对比

**功能：** 自动生成参数对比图，一次运行测试多个参数组合

**典型应用：**

| X 轴参数 | Y 轴参数 | 对比目的 |
|----------|----------|----------|
| steps | cfg | 采样步数与 CFG 对比 |
| sampler_name | scheduler | 采样器对比 |
| denoise | seed | 重绘强度对比 |

**使用示例：**

```
XY Plot:
  - X: steps [10, 20, 30, 40]
  - Y: cfg [5, 7, 9, 11]
  → 生成 4x4 = 16 张对比图
```

#### LoRA Stacker

**功能：** 同时加载和管理多个 LoRA

**参数说明：**

| 参数 | 说明 |
|------|------|
| lora_name | LoRA 模型名称 |
| strength_model | 模型强度 |
| strength_clip | CLIP 强度 |

### 注意事项

- XY Plot 会生成大量图像，注意存储空间
- LoRA Stacker 加载多个 LoRA 可能增加显存占用
- 部分功能与 Comfyroll 重叠，选择适合的即可

## 6.1.5 Impact Pack

> **推荐指数：** ⭐⭐⭐⭐⭐（强烈推荐）
> **状态：** 活跃维护
> **仓库：** https://github.com/ltdrdata/ComfyUI-Impact-Pack

### 功能描述

Impact Pack 是一个功能强大的节点包，专注于图像增强、分割检测和局部重绘。其核心功能 FaceDetailer（面部细节增强）是处理人像生成的必备工具。

### 主要节点

| 节点 | 功能 | 使用场景 |
|------|------|----------|
| **FaceDetailer** | 面部细节增强 | 人像生成、面部修复 |
| **SAM Detector** | SAM 分割检测 | 目标分割、抠图 |
| **ImpactIf** | 条件判断 | 工作流逻辑控制 |
| **ImpactSwitch** | 多路选择 | 动态路由 |
| **ImpactKSampler** | 增强采样器 | 局部重绘 |

### 安装方法

```bash
cd ComfyUI/custom_nodes
git clone https://github.com/ltdrdata/ComfyUI-Impact-Pack.git
cd ComfyUI-Impact-Pack
pip install -r requirements.txt
```

### 核心节点详解

#### FaceDetailer 节点

**功能：** 自动检测并增强图像中的人脸区域，大幅提升面部细节质量

**参数说明：**

| 参数 | 类型 | 说明 | 推荐值 |
|------|------|------|--------|
| guide_size | FLOAT | 面部放大尺寸 | 512 |
| guide_size_for | BOOLEAN | 是否按 bbox 放大 | True |
| max_size | FLOAT | 最大处理尺寸 | 1024 |
| seed | INT | 随机种子 | - |
| steps | INT | 重绘步数 | 20-30 |
| cfg | FLOAT | CFG 强度 | 7-8 |
| denoise | FLOAT | 重绘强度 | 0.4-0.6 |

**使用场景：**

| 场景 | 推荐配置 |
|------|----------|
| 全身人像 | guide_size=512, denoise=0.5 |
| 大头照 | guide_size=768, denoise=0.4 |
| 多人照片 | 增加 max_size |

**工作流示例：**

```
KSampler → VAE Decode → FaceDetailer → Save Image
```

#### SAM Detector 节点

**功能：** 使用 SAM 模型进行目标分割

**参数说明：**

| 参数 | 说明 |
|------|------|
| sam_model | SAM 模型选择 |
| points | 分割点位置 |
| threshold | 分割阈值 |

### 注意事项

- FaceDetailer 需要额外的面部检测模型
- SAM 模型较大，首次使用需要下载
- 处理多人图像时可能需要调整参数

### 常见问题

| 问题 | 解决方案 |
|------|----------|
| 面部检测失败 | 确保面部检测模型已下载 |
| SAM 模型加载失败 | 检查模型路径 `models/sams/` |
| 处理速度慢 | 减小 guide_size 或使用更小的 SAM 模型 |

## 6.1.6 IPAdapter Plus

> **推荐指数：** ⭐⭐⭐⭐⭐（强烈推荐）
> **状态：** 活跃维护
> **仓库：** https://github.com/cubiq/ComfyUI_IPAdapter_plus

### 功能描述

IPAdapter Plus 提供强大的图像到图像迁移能力，可以将参考图像的风格、内容迁移到生成图像中。这是实现风格迁移、角色一致性等高级功能的核心工具。

### 主要节点

| 节点 | 功能 |
|------|------|
| **IPAdapter Model Loader** | 加载 IPAdapter 模型 |
| **IPAdapter Apply** | 应用 IPAdapter 到模型 |
| **IPAdapter Style Composition** | 风格组合 |
| **IPAdapter FaceID** | 人脸 ID 保持 |

### 安装方法

```bash
cd ComfyUI/custom_nodes
git clone https://github.com/cubiq/ComfyUI_IPAdapter_plus.git
```

### 使用场景

| 场景 | 说明 |
|------|------|
| 风格迁移 | 将参考图风格应用到生成图 |
| 角色一致性 | 保持生成角色的外观一致 |
| 图像变体 | 基于参考图生成变体 |

### 注意事项

- 需要下载 IPAdapter 模型文件
- 不同模型适用于不同场景
- 与 ControlNet 配合效果更佳
