## 概述

ComfyUI 支持用户开发自定义节点来扩展功能。自定义节点使用 Python 编写，遵循特定的类结构和接口规范。本节将详细介绍如何从零开始开发自己的 ComfyUI 节点。

> 💡 **提示：** 开发自定义节点需要一定的 Python 编程基础。如果您是新手，建议先从修改现有节点开始学习。

## 6.5.2 节点基本结构

### 文件组织

一个基本的自定义节点包结构如下：

```
custom_nodes/
└── my_custom_nodes/
    ├── __init__.py          # 入口文件，注册节点
    ├── my_nodes.py          # 节点实现
    ├── requirements.txt     # 依赖列表（可选）
    └── README.md            # 说明文档（可选）
```

### 节点类结构

每个节点需要定义以下核心属性和方法：

```python
class MyCustomNode:
    @classmethod
    def INPUT_TYPES(cls):
        return {
            "required": {
                "input_name": ("TYPE", {"参数": "值"}),
            },
            "optional": {
                "optional_input": ("TYPE", {"default": "值"}),
            }
        }
    
    RETURN_TYPES = ("IMAGE", "STRING")
    RETURN_NAMES = ("output_image", "output_text")
    FUNCTION = "execute"
    CATEGORY = "my_category"
    
    def execute(self, input_name, optional_input=None):
        result = process(input_name)
        return (result, "done")
```

### 核心属性说明

| 属性 | 类型 | 说明 | 必需 |
|------|------|------|------|
| INPUT_TYPES | 方法 | 定义输入参数 | 是 |
| RETURN_TYPES | 元组 | 定义输出类型 | 是 |
| RETURN_NAMES | 元组 | 定义输出名称 | 否 |
| FUNCTION | 字符串 | 执行函数名 | 是 |
| CATEGORY | 字符串 | 节点分类 | 是 |
| OUTPUT_NODE | 布尔 | 是否为输出节点 | 否 |

## 6.5.3 INPUT_TYPES 详解

### 必需参数（required）

定义节点必须接收的输入：

```python
"required": {
    "image": ("IMAGE",),
    "prompt": ("STRING", {"default": ""}),
    "steps": ("INT", {
        "default": 20,
        "min": 1,
        "max": 100,
        "step": 1,
        "display": "number"
    }),
    "scale": ("FLOAT", {
        "default": 1.0,
        "min": 0.1,
        "max": 10.0,
        "step": 0.1,
        "round": 0.01
    }),
    "enabled": ("BOOLEAN", {"default": True}),
}
```

### 参数配置选项

| 选项 | 适用类型 | 说明 |
|------|----------|------|
| default | 所有 | 默认值 |
| min | INT, FLOAT | 最小值 |
| max | INT, FLOAT | 最大值 |
| step | INT, FLOAT | 步长 |
| round | FLOAT | 四舍五入精度 |
| display | INT, FLOAT | 显示方式（number/slider） |
| multiline | STRING | 是否多行文本 |
| dynamicPrompts | STRING | 是否支持动态提示词 |

### 可选参数（optional）

定义可选输入：

```python
"optional": {
    "optional_image": ("IMAGE", {"default": None}),
    "seed": ("INT", {"default": 0, "min": 0, "max": 0xffffffffffffffff}),
}
```

### 隐藏参数（hidden）

定义不显示在界面上的参数：

```python
"hidden": {
    "prompt": "PROMPT",
    "extra_pnginfo": "EXTRA_PNGINFO",
}
```

## 6.5.5 COMBO 类型（下拉选择）

### 静态选项

创建固定的下拉选择框：

```python
"model_type": (["SD1.5", "SDXL", "SD3"], {"default": "SD1.5"}),
```

### 动态选项

动态生成选项列表：

```python
@classmethod
def INPUT_TYPES(cls):
    import os
    models = os.listdir("models/checkpoints")
    models = [m for m in models if m.endswith(('.safetensors', '.ckpt'))]
    return {
        "required": {
            "model": (models,),
        }
    }
```

### 带标签的选项

```python
"quality": (["low:快速", "medium:平衡", "high:高质量"], {"default": "medium:平衡"}),
```

## 6.5.6 FUNCTION 执行函数

### 函数签名

执行函数接收 INPUT_TYPES 中定义的所有参数：

```python
def execute(self, image, prompt, steps, scale, optional_image=None, seed=0):
    result = process(image)
    return (result,)
```

### 返回值

返回值必须与 RETURN_TYPES 定义的类型数量一致：

```python
RETURN_TYPES = ("IMAGE", "STRING")

def execute(self, ...):
    return (output_image, output_text)
```

### 错误处理

```python
def execute(self, image):
    if image is None:
        raise ValueError("输入图像不能为空")
    try:
        result = process(image)
        return (result,)
    except Exception as e:
        raise RuntimeError(f"处理失败: {str(e)}")
```

## 6.5.7 INPUT_IS_LIST 和 OUTPUT_IS_LIST

### 处理批量数据

当需要处理批量输入时，使用 INPUT_IS_LIST：

```python
class BatchProcessNode:
    INPUT_IS_LIST = True
    OUTPUT_IS_LIST = True
    RETURN_TYPES = ("IMAGE",)
    FUNCTION = "execute"
    CATEGORY = "image/batch"
    
    @classmethod
    def INPUT_TYPES(cls):
        return {
            "required": {
                "images": ("IMAGE",),
            }
        }
    
    def execute(self, images):
        results = [process(img) for img in images]
        return (results,)
```

### 区别说明

| 属性 | 说明 |
|------|------|
| INPUT_IS_LIST = True | 输入参数以列表形式传入 |
| OUTPUT_IS_LIST = True | 输出结果为列表 |

## 6.5.9 完整示例节点

### 示例1：简单图像处理节点

```python
import torch

class SimpleBrightnessNode:
    @classmethod
    def INPUT_TYPES(cls):
        return {
            "required": {
                "image": ("IMAGE",),
                "brightness": ("FLOAT", {
                    "default": 1.0,
                    "min": 0.0,
                    "max": 2.0,
                    "step": 0.1
                }),
            }
        }
    
    RETURN_TYPES = ("IMAGE",)
    FUNCTION = "adjust_brightness"
    CATEGORY = "image/adjust"
    
    def adjust_brightness(self, image, brightness):
        result = image * brightness
        result = torch.clamp(result, 0, 1)
        return (result,)
```

### 示例2：带条件输出的节点

```python
class ConditionalOutputNode:
    @classmethod
    def INPUT_TYPES(cls):
        return {
            "required": {
                "image_a": ("IMAGE",),
                "image_b": ("IMAGE",),
                "use_a": ("BOOLEAN", {"default": True}),
            }
        }
    
    RETURN_TYPES = ("IMAGE",)
    FUNCTION = "select_image"
    CATEGORY = "utility"
    
    def select_image(self, image_a, image_b, use_a):
        return (image_a if use_a else image_b,)
```

### 示例3：文本处理节点

```python
class TextConcatNode:
    @classmethod
    def INPUT_TYPES(cls):
        return {
            "required": {
                "text_a": ("STRING", {"default": "", "multiline": True}),
                "text_b": ("STRING", {"default": "", "multiline": True}),
                "separator": ("STRING", {"default": ", "}),
            }
        }
    
    RETURN_TYPES = ("STRING",)
    FUNCTION = "concat"
    CATEGORY = "text"
    
    def concat(self, text_a, text_b, separator):
        result = separator.join([text_a, text_b])
        return (result,)
```

### 示例4：输出节点

```python
class SaveImageCustom:
    @classmethod
    def INPUT_TYPES(cls):
        return {
            "required": {
                "images": ("IMAGE",),
                "filename_prefix": ("STRING", {"default": "ComfyUI"}),
            },
            "hidden": {
                "prompt": "PROMPT",
                "extra_pnginfo": "EXTRA_PNGINFO",
            }
        }
    
    RETURN_TYPES = ()
    OUTPUT_NODE = True
    FUNCTION = "save_images"
    CATEGORY = "image"
    
    def save_images(self, images, filename_prefix, prompt=None, extra_pnginfo=None):
        import os
        from PIL import Image
        import numpy as np
        
        output_dir = "output"
        os.makedirs(output_dir, exist_ok=True)
        
        results = []
        for i, img in enumerate(images):
            img_np = (img.cpu().numpy() * 255).astype(np.uint8)
            pil_img = Image.fromarray(img_np)
            filename = f"{filename_prefix}_{i:05d}.png"
            filepath = os.path.join(output_dir, filename)
            pil_img.save(filepath)
            results.append({"filename": filename, "type": "output"})
        
        return {"ui": {"images": results}}
```

## 6.5.10 常用工具函数

### 图像格式转换

```python
from PIL import Image
import numpy as np
import torch

def tensor_to_pil(image_tensor):
    return [Image.fromarray((img.cpu().numpy() * 255).astype(np.uint8)) 
            for img in image_tensor]

def pil_to_tensor(pil_images):
    return torch.stack([torch.from_numpy(np.array(img) / 255.0) 
                        for img in pil_images])
```

### Latent 操作

```python
import comfy.utils

def encode_image(image, vae):
    return {"samples": vae.encode(image[:, :, :, :3])}

def decode_latent(latent, vae):
    return vae.decode(latent["samples"])
```

### 模型加载

```python
import comfy.sd

def load_checkpoint(checkpoint_path):
    return comfy.sd.load_checkpoint(checkpoint_path)
```

## 6.5.11 最佳实践

### 代码规范

| 规范 | 说明 |
|------|------|
| 命名规范 | 节点类名使用 PascalCase，函数名使用 snake_case |
| 类型提示 | 使用 Python 类型提示提高代码可读性 |
| 文档字符串 | 为复杂函数添加文档说明 |
| 错误处理 | 使用 try-except 捕获异常，提供有意义的错误信息 |

### 性能优化

```python
import torch

class OptimizedNode:
    @torch.no_grad()
    def execute(self, image):
        with torch.inference_mode():
            result = self._process(image)
        return (result,)
    
    def _process(self, image):
        return image * 1.5
```

### 内存管理

```python
import gc
import torch

def clear_memory():
    gc.collect()
    torch.cuda.empty_cache()
```

### 日志记录

```python
import logging

logger = logging.getLogger(__name__)

class MyNode:
    def execute(self, image):
        logger.info("开始处理图像")
        result = self._process(image)
        logger.info("处理完成")
        return (result,)
```

## 6.5.13 常见问题

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 节点不显示 | 注册错误 | 检查 NODE_CLASS_MAPPINGS |
| 参数类型错误 | 类型不匹配 | 检查 INPUT_TYPES 定义 |
| 内存溢出 | 未释放显存 | 使用 torch.no_grad() |
| 导入错误 | 依赖缺失 | 添加 requirements.txt |
| 节点崩溃 | 未处理异常 | 添加 try-except |
