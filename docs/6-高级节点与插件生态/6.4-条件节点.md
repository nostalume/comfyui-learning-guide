# 6.4 条件节点

> - 文档版本：v2.0

> **相关官方文档：** [ComfyUI 官方文档](https://docs.comfy.org/) | [中文文档](https://docs.comfy.org/zh/)

## 概述

条件节点用于在工作流中实现逻辑判断、分支选择和动态路由功能。这些节点主要来自 **Impact Pack** 和 **Inspire Pack**，能够大幅提升工作流的灵活性和自动化程度，是实现智能工作流的关键组件。

> 💡 **提示：** 条件节点可以让您的工作流"思考"，根据不同情况执行不同的操作，非常适合批量处理和自动化场景。

---

## 6.4.1 Impact Pack 条件节点

### 概述

Impact Pack 提供了一套完整的条件判断节点，支持布尔运算、比较运算和多路选择，是实现复杂工作流逻辑的基础。

### 核心节点列表

| 节点名称 | 功能说明 | 使用频率 |
|---------|---------|----------|
| **ImpactIf** | 条件判断节点 | 高 |
| **ImpactSwitch** | 多分支选择节点 | 高 |
| **ImpactValueRouter** | 数值路由节点 | 中 |
| **ImpactBoolean** | 布尔值节点 | 高 |
| **ImpactCompare** | 比较运算节点 | 中 |

---

### ImpactIf 节点

> **分类：** ImpactPack/Logic

#### 功能描述

根据布尔条件选择不同的输出路径，相当于编程中的 `if-else` 语句。当条件为 True 时输出第一个值，为 False 时输出第二个值。

#### 参数说明

| 参数名 | 类型 | 说明 | 必需 |
|-------|------|------|------|
| cond | BOOLEAN | 条件值（True/False） | 是 |
| tt_value | * | 条件为 True 时的输出值 | 是 |
| ff_value | * | 条件为 False 时的输出值 | 是 |

#### 输出

| 输出名 | 类型 | 说明 |
|-------|------|------|
| output | * | 根据条件选择的值 |

#### 使用场景

| 场景 | 说明 |
|------|------|
| 模型切换 | 根据条件选择不同的模型 |
| 提示词切换 | 根据条件选择不同的提示词 |
| 参数动态调整 | 根据条件选择不同的参数值 |

#### 使用示例

**示例1：条件模型选择**

```
ImpactBoolean(True) → ImpactIf(cond, tt_value=SDXL模型, ff_value=SD1.5模型) → KSampler
```

**示例2：提示词切换**

```
ImpactBoolean(条件) → ImpactIf(cond, tt_value="风景提示词", ff_value="人像提示词") → CLIPTextEncode
```

#### 注意事项

- tt_value 和 ff_value 的类型必须相同
- 支持任意数据类型（MODEL, IMAGE, STRING 等）

---

### ImpactSwitch 节点

> **分类：** ImpactPack/Logic

#### 功能描述

多分支选择器，支持多个输入端口，根据索引值选择对应的输入输出。相当于编程中的 `switch-case` 语句。

#### 参数说明

| 参数名 | 类型 | 说明 | 默认值 |
|-------|------|------|--------|
| select | INT | 选择索引（从1开始） | 1 |
| input1 | * | 第一个输入选项 | - |
| input2 | * | 第二个输入选项 | - |
| ... | * | 更多输入选项 | - |

#### 特点

- 支持任意数量的输入
- 可动态添加/删除输入端口
- 支持多种数据类型
- 索引从 1 开始

#### 使用场景

| 场景 | 说明 |
|------|------|
| 多模型切换 | 根据索引选择不同的模型 |
| 多风格切换 | 根据索引选择不同的风格 LoRA |
| 批量处理 | 循环遍历多个输入 |

#### 使用示例

**示例1：多模型切换**

```
ImpactSwitch(select=2, input1=模型A, input2=模型B, input3=模型C) → 输出模型B
```

**示例2：动态 LoRA 切换**

```
RandInt(min=1, max=5) → ImpactSwitch → 选择不同风格 LoRA
```

---

### ImpactCompare 节点

> **分类：** ImpactPack/Logic

#### 功能描述

执行数值比较运算，返回布尔结果。常用于构建复杂的条件判断逻辑。

#### 参数说明

| 参数名 | 类型 | 说明 |
|-------|------|------|
| a | FLOAT/INT | 第一个数值 |
| b | FLOAT/INT | 第二个数值 |
| op | COMBO | 比较运算符 |

#### 支持运算符

| 运算符 | 说明 | 示例 |
|-------|------|------|
| == | 等于 | a == b |
| != | 不等于 | a != b |
| > | 大于 | a > b |
| < | 小于 | a < b |
| >= | 大于等于 | a >= b |
| <= | 小于等于 | a <= b |

#### 使用场景

| 场景 | 说明 |
|------|------|
| 数值比较 | 判断数值大小关系 |
| 条件组合 | 与其他条件节点配合使用 |
| 循环控制 | 判断循环是否结束 |

#### 使用示例

```
ImpactCompare(value_a=10, value_b=5, op=">") → 返回 True
ImpactCompare(value_a=3, value_b=3, op="==") → 返回 True
```

---

### ImpactBoolean 节点

> **分类：** ImpactPack/Logic

#### 功能描述

创建布尔值（True/False），作为条件判断的输入源。

#### 参数说明

| 参数名 | 类型 | 说明 |
|-------|------|------|
| value | BOOLEAN | 布尔值 |

#### 使用场景

- 作为 ImpactIf 的条件输入
- 与 Primitive 节点配合使用
- 调试和测试工作流

## 6.4.2 Inspire Pack 条件节点

### 概述

Inspire Pack 提供了另一套条件节点，语法更简洁，同时提供了数值生成节点，适合批量处理场景。

### 核心节点列表

| 节点名称 | 功能说明 | 使用频率 |
|---------|---------|----------|
| **If** | 基础条件判断 | 高 |
| **Switch** | 多路选择器 | 高 |
| **FloatRange** | 浮点数范围生成 | 中 |
| **IntRange** | 整数范围生成 | 中 |
| **RandInt** | 随机整数生成 | 高 |
| **RandFloat** | 随机浮点数生成 | 中 |

---

### If 节点

> **分类：** InspirePack/Logic

#### 功能描述

基础条件判断节点，语法简洁，与 ImpactIf 功能类似。

#### 参数说明

| 参数名 | 类型 | 说明 |
|-------|------|------|
| condition | BOOLEAN | 条件表达式 |
| on_true | * | True 时返回值 |
| on_false | * | False 时返回值 |

#### 与 ImpactIf 的区别

| 特性 | Inspire If | ImpactIf |
|------|------------|----------|
| 参数命名 | condition, on_true, on_false | cond, tt_value, ff_value |
| 可读性 | 更直观 | 略显简写 |

---

### RandInt / RandFloat 节点

> **分类：** InspirePack/Util

#### 功能描述

生成随机数值，可用于批量生成中的随机参数选择。

#### RandInt 参数说明

| 参数名 | 类型 | 说明 | 默认值 |
|-------|------|------|--------|
| min_value | INT | 最小值 | 0 |
| max_value | INT | 最大值 | 100 |
| seed | INT | 随机种子 | 0 |

#### 使用场景

| 场景 | 说明 |
|------|------|
| 随机种子生成 | 为 KSampler 提供随机种子 |
| 随机参数选择 | 随机选择不同的参数组合 |
| 随机风格切换 | 随机选择不同的风格 |

#### 使用示例

```
RandInt(min=0, max=2147483647, seed=固定值) → KSampler (seed 输入)
```

---

### FloatRange / IntRange 节点

> **分类：** InspirePack/Util

#### 功能描述

生成数值范围序列，用于批量遍历参数。

#### 参数说明

| 参数名 | 类型 | 说明 |
|-------|------|------|
| start | FLOAT/INT | 起始值 |
| stop | FLOAT/INT | 结束值 |
| step | FLOAT/INT | 步长 |

#### 使用场景

- 批量参数遍历
- 参数矩阵生成
- 循环控制

#### 使用示例

```
FloatRange(start=0, end=10, step=1) → ImpactSwitch → 选择不同的参数组合
```

## 6.4.3 批量处理控制

### 使用条件节点控制批量生成

结合循环和条件节点实现智能批量处理：

```
FloatRange(start=0, end=10, step=1) 
  → ImpactSwitch(select=当前索引) 
  → 选择不同的参数组合
```

### 种子遍历示例

使用随机种子实现批量生成：

```
RandInt(min=0, max=2147483647, seed=固定值) 
  → 作为 KSampler 的 seed 输入
```

### LoRA 动态切换

根据条件动态切换 LoRA：

```
ImpactSwitch(select=索引) 
  → 输入多个 LoRA Loader 
  → 根据索引切换 LoRA
```

## 6.4.4 实用工作流示例

## 6.4.5 高级用法

### 嵌套条件

可以嵌套多个条件节点实现复杂逻辑：

```
ImpactIf(条件1,
  tt_value=ImpactIf(条件2, tt_value=A, ff_value=B),
  ff_value=C
)
```

**逻辑说明：**
- 如果条件1为 True，再判断条件2
- 条件2为 True 输出 A，否则输出 B
- 条件1为 False 直接输出 C

---

### 与 Primitive 节点配合

使用 Primitive 节点创建可复用的条件输入：

```
Primitive (Boolean) → 多个 ImpactIf 节点
```

**优点：**
- 一个 Primitive 可以控制多个条件节点
- 方便统一修改条件值

---

### 动态批量大小

根据条件选择不同的 batch_size：

```
ImpactSwitch → 根据条件选择不同的 batch_size
  → Empty Latent Image
```

**应用场景：** 根据显存情况动态调整批量大小

## 6.4.6 常见问题

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 类型不匹配 | tt_value 和 ff_value 类型不同 | 确保两个值类型相同 |
| Switch 索引越界 | select 值超出输入数量 | 检查索引值是否在有效范围内 |
| 条件不生效 | 布尔值传递错误 | 检查条件节点的连接 |
| 随机值不变 | seed 固定 | 使用不同的 seed 或时间戳 |
| 性能下降 | 条件逻辑过于复杂 | 简化逻辑或拆分工作流 |

## 6.4.7 ⚠️ 时效性说明

| 项目 | 说明 |
|-----|------|
| Impact Pack 版本 | 节点名称和参数可能随版本更新变化 |
| Inspire Pack | 部分节点功能与 Impact Pack 重叠，建议选择其一 |
| 性能影响 | 复杂条件逻辑可能增加工作流执行时间 |
| 类型兼容性 | 某些类型转换可能需要额外节点 |
