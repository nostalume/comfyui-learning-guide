# 6.3 视频相关节点

> 📌 **版本信息**
> - 文档版本：v2.0
> - 更新日期：2026-04-28
> **相关官方文档：** [ComfyUI 官方文档](https://docs.comfy.org/) | [中文文档](https://docs.comfy.org/zh/)

---

## 概述

视频相关节点主要用于在 ComfyUI 中实现 AI 视频生成和视频转绘功能。核心插件包括 **AnimateDiff**（动画生成）和 **VideoHelperSuite**（视频处理工具集）。通过这些节点，您可以将静态图像转换为动态视频，或对现有视频进行 AI 风格转换。

> ⚠️ **时效性说明：** AnimateDiff 版本迭代频繁，v3 版本参数与 v2 有差异。本文档基于最新版本编写，建议定期检查官方更新。

---

## 6.3.1 AnimateDiff 节点

### 概述

AnimateDiff 是目前最流行的 AI 动画生成方案，通过加载运动模型为静态图像生成添加运动信息，实现从文本/图像到动画的转换。

### 核心节点列表

| 节点名称 | 功能说明 | 使用频率 |
|---------|---------|----------|
| **AnimateDiff Loader** | 加载 AnimateDiff 运动模型 | 必用 |
| **AnimateDiff Sampler** | 动画采样器（Evolved Sampling） | 必用 |
| **AnimateDiff Combine** | 合成输出视频 | 必用 |
| **Context Options** | 上下文选项配置 | 高级 |
| **Sampling Settings** | 采样设置 | 高级 |

---

### AnimateDiff Loader

> **分类：** AnimateDiff/Loaders

#### 功能描述

加载 AnimateDiff 运动模型，为静态图像生成添加运动信息。这是使用 AnimateDiff 的第一步。

#### 参数说明

| 参数名 | 类型 | 说明 | 默认值 |
|-------|------|------|--------|
| model_name | STRING | 运动模型名称 | - |
| motion_scale | FLOAT | 运动强度 | 1.0 |
| min_motion_scale | FLOAT | 最小运动强度 | 1.0 |
| max_motion_scale | FLOAT | 最大运动强度 | 1.0 |
| motion_model_settings | MOTION_MODEL_SETTINGS | 高级模型设置 | - |

#### 可用运动模型

| 模型名称 | 适用版本 | 特点 | 推荐场景 |
|---------|---------|------|---------|
| mm_sd_v15_v2.ckpt | SD 1.5 | 标准版，兼容性好 | 通用动画 |
| mm_sd_v3.ckpt | SD 1.5 | v3 版本，更流畅 | 高质量动画 |
| mm_sdxl_v10_beta.ckpt | SDXL | SDXL 适配版本 | SDXL 动画 |
| mm_sd_v1.5_adapter.ckpt | SD 1.5 | 适配器版本 | 特定风格 |
| mm_StableAnimated_v3.ckpt | SD 1.5 | 高质量版本 | 专业动画 |

#### 使用场景

| 场景 | 推荐模型 | 说明 |
|------|----------|------|
| 新手入门 | mm_sd_v15_v2.ckpt | 兼容性最好 |
| 高质量动画 | mm_sd_v3.ckpt | 效果更流畅 |
| SDXL 用户 | mm_sdxl_v10_beta.ckpt | 配合 SDXL 模型 |

#### 注意事项

- 模型文件需放置在 `models/animatediff_models/` 目录
- 首次使用需要下载模型（约 2GB）
- v3 版本使用新的采样架构，部分参数与 v2 不兼容

---

### Context Options（上下文选项）

> **分类：** AnimateDiff/Context

#### 功能描述

控制动画帧的上下文窗口，用于长视频生成。通过滑动窗口机制，可以在有限显存下生成更长的视频。

#### 参数说明

| 参数名 | 类型 | 说明 | 推荐值 |
|-------|------|------|-------|
| context_length | INT | 上下文窗口大小（帧数） | 16-24 |
| context_stride | INT | 步长 | 1 |
| context_overlap | INT | 重叠帧数 | 4-8 |
| context_schedule | COMBO | 调度策略 | uniform |
| closed_loop | BOOLEAN | 是否循环 | True/False |

#### 调度策略说明

| 策略 | 说明 | 适用场景 |
|-----|------|---------|
| uniform | 均匀调度 | 通用场景 |
| sliding_window | 滑动窗口 | 长视频生成 |
| strided | 步进调度 | 特定效果 |

#### 使用场景

| 显存 | context_length | 最大帧数 |
|------|----------------|----------|
| 8GB | 8-12 | 16-24 |
| 12GB | 12-16 | 32-48 |
| 16GB | 16-24 | 48-72 |
| 24GB+ | 24-32 | 72-128 |

#### 注意事项

- Context Options 对于长视频生成至关重要
- 需要根据显存大小调整 context_length
- 显存不足时降低此值，否则会 OOM

### 基础工作流示例

#### 简单动画生成

```
CheckpointLoader → AnimateDiff Loader → CLIPTextEncode → KSampler → VAE Decode → AnimateDiff Combine
```

#### 完整节点连接图

```
┌─────────────────┐     ┌────────────────────┐     ┌──────────────────┐
│ CheckpointLoader│────→│ AnimateDiff Loader │────→│ CLIPTextEncode   │
└─────────────────┘     └────────────────────┘     └──────────────────┘
                                                            │
                                                            ↓
┌─────────────────┐     ┌────────────────────┐     ┌──────────────────┐
│ EmptyLatentImage│────→│     KSampler       │────→│    VAE Decode    │
│ (batch_size=N)  │     └────────────────────┘     └──────────────────┘
└─────────────────┘                                      │
                                                         ↓
                                                 ┌──────────────────┐
                                                 │ AnimateDiff      │
                                                 │ Combine          │
                                                 └──────────────────┘
```

## 6.3.2 VideoHelperSuite 节点

### 概述

VideoHelperSuite 提供完整的视频处理工具链，包括视频加载、帧提取、视频合成等功能，是视频转绘工作流的核心。

### 核心节点列表

| 节点名称 | 功能说明 | 使用频率 |
|---------|---------|----------|
| **Load Video (Upload)** | 上传并加载视频 | 必用 |
| **Load Video (Path)** | 从路径加载视频 | 必用 |
| **Video Info** | 获取视频信息 | 常用 |
| **Get Frame Count** | 获取帧数 | 常用 |
| **Split Video** | 拆分视频帧 | 常用 |
| **Merge Video** | 合并视频帧 | 常用 |
| **VHS Video Combine** | 视频合成输出 | 必用 |

---

### Load Video 节点

> **分类：** VideoHelperSuite/Load

#### 功能描述

从本地或上传加载视频文件，支持多种视频格式。

#### 支持格式

MP4, AVI, MOV, WEBM, GIF

#### 参数说明

| 参数名 | 类型 | 说明 | 默认值 |
|-------|------|------|--------|
| video | VIDEO | 视频文件 | - |
| force_rate | INT | 强制帧率（0为原帧率） | 0 |
| force_size | STRING | 强制尺寸 | Disabled |
| frame_load_cap | INT | 最大加载帧数（0为全部） | 0 |
| skip_first_frames | INT | 跳过前N帧 | 0 |
| select_every_nth | INT | 每N帧选择一帧 | 1 |

#### 使用场景

| 场景 | 推荐配置 |
|------|----------|
| 加载完整视频 | frame_load_cap=0 |
| 加载前N帧 | frame_load_cap=N |
| 降低帧率 | select_every_nth=2 或 3 |
| 跳过片头 | skip_first_frames=N |

#### 参数详解

| 参数 | 说明 | 示例 |
|------|------|------|
| force_rate | 强制改变帧率，可用于加速/减速 | force_rate=15（原30fps变15fps） |
| force_size | 调整视频尺寸 | 512x512, 768x768 |
| frame_load_cap | 限制加载帧数，节省显存 | 100（只加载前100帧） |
| skip_first_frames | 跳过视频开头 | 30（跳过前30帧） |
| select_every_nth | 抽帧，降低帧率 | 2（每2帧取1帧） |

---

### Video Combine 节点

> **分类：** VideoHelperSuite/Output

#### 功能描述

将生成的帧序列合成为视频，支持多种输出格式和编码选项。

#### 参数说明

| 参数名 | 类型 | 说明 | 默认值 |
|-------|------|------|--------|
| frame_rate | INT | 输出帧率 | 8 |
| loop_count | INT | 循环次数（0为无限） | 0 |
| filename_prefix | STRING | 文件名前缀 | AnimateDiff |
| format | STRING | 输出格式 | video/h264-mp4 |
| pingpong | BOOLEAN | 是否启用乒乓循环 | False |
| save_output | BOOLEAN | 是否保存到输出目录 | True |

#### 输出格式对比

| 格式 | 说明 | 优点 | 缺点 | 适用场景 |
|-----|------|------|------|---------|
| video/h264-mp4 | H.264 编码 MP4 | 兼容性好，体积适中 | 有损压缩 | 通用 |
| video/webm | WebM 格式 | 开源免费 | 兼容性一般 | 网页 |
| gif | GIF 动图 | 广泛支持 | 体积大，颜色少 | 简单动画 |
| image/png | PNG 序列 | 无损高质量 | 体积大 | 专业后期 |

#### 使用场景

| 场景 | 推荐配置 |
|------|----------|
| 通用分享 | format=video/h264-mp4, frame_rate=8-15 |
| 循环动画 | pingpong=True |
| 高质量输出 | format=image/png |
| 网页嵌入 | format=video/webm |

## 6.3.3 视频转绘工作流

### 基本流程

```
1. 加载视频 → Load Video 节点
2. 提取帧 → 自动处理
3. 逐帧处理 → 图生图工作流
4. 合成输出 → Video Combine 节点
```

### 推荐配置

| 参数 | 推荐值 | 说明 |
|-----|-------|------|
| denoise | 0.3-0.7 | 重绘强度，过高会导致闪烁 |
| frame_rate | 原视频帧率 | 保持一致性 |
| batch_size | 1-4 | 根据显存调整 |
| seed | 固定值 | 保持帧间一致性 |

### 减少闪烁技巧

| 方法 | 说明 | 效果 |
|-----|------|------|
| 降低 denoise 值 | 保留更多原始帧信息 | ⭐⭐⭐ 高 |
| 使用固定 seed | 确保生成一致性 | ⭐⭐⭐ 高 |
| 启用帧间混合 | 部分节点支持 | ⭐⭐ 中 |
| 使用 ControlNet | 保持结构稳定 | ⭐⭐⭐ 高 |
| 降低重绘强度 | 减少变化幅度 | ⭐⭐⭐ 高 |

---

### ControlNet 视频转绘

#### 推荐 ControlNet

| 类型 | 适用场景 | 强度建议 | 说明 |
|-----|---------|---------|------|
| **Depth** | 场景结构保持 | 0.7-1.0 | 保持深度和空间关系 |
| **Canny** | 边缘细节保持 | 0.5-0.8 | 保持轮廓线条 |
| **OpenPose** | 人物姿态保持 | 0.8-1.0 | 人物动作一致性 |
| **Tile** | 细节增强 | 0.5-0.7 | 增强细节，减少模糊 |

#### 工作流示例

```
Load Video → Depth ControlNet → KSampler (img2img) → Video Combine
```

## 6.3.4 AnimateDiff 高级用法

### 运动强度控制

通过 motion_scale 参数控制动画运动幅度：

| motion_scale | 效果 | 适用场景 |
|-------------|------|---------|
| 0.5-0.8 | 轻微运动 | 静态场景、微动画 |
| 1.0-1.2 | 标准运动 | 一般动画 |
| 1.3-1.5 | 明显运动 | 动作场景 |
| 1.5+ | 强烈运动 | 特殊效果 |

### 批量帧生成

```
Empty Latent Image (batch_size=16) → AnimateDiff Sampler → 输出16帧动画
```

#### batch_size 建议

| 显存 | 推荐 batch_size | 最大帧数 |
|-----|----------------|----------|
| 8GB | 4-8 | 8-16 |
| 12GB | 8-12 | 16-24 |
| 16GB | 12-16 | 24-32 |
| 24GB | 16-24 | 32-48 |

### 与 ControlNet 结合

AnimateDiff 可与 ControlNet 配合使用，实现可控动画：

```
ControlNet (OpenPose/Depth) → AnimateDiff Sampler → 结构化动画
```

#### 组合建议

| ControlNet | 效果 | 注意事项 |
|-----------|------|---------|
| OpenPose | 人物动作控制 | 需要逐帧姿态图 |
| Depth | 场景深度控制 | 保持深度一致性 |
| Canny | 边缘控制 | 适合线条动画 |

### 长视频生成

使用 Context Options 生成长视频：

#### 配置示例

```
Context Options:
  - context_length: 16
  - context_overlap: 4
  - context_schedule: sliding_window
```

#### 分段生成策略

1. 将长视频分成多个片段
2. 每个片段使用相同的 seed
3. 片段之间有重叠帧
4. 后期合成完整视频

## 6.3.5 常见问题

| 问题 | 原因 | 解决方案 |
|-----|------|---------|
| 视频闪烁 | 帧间不一致 | 降低 denoise，固定 seed |
| 显存不足 | batch_size 过大 | 减少 batch_size，启用低显存模式 |
| 运动不自然 | motion_scale 不当 | 调整 motion_scale 值 |
| 视频卡顿 | 帧率不匹配 | 统一输入输出帧率 |
| 模型加载失败 | 模型路径错误 | 检查 models/animatediff_models/ |
| 视频无法播放 | 编码格式问题 | 尝试不同输出格式 |
| 帧数过多 | frame_load_cap 未设置 | 设置 frame_load_cap 限制帧数 |
