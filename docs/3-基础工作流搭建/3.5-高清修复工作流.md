# 3.5 高清修复工作流

## 功能描述（通俗易懂）

**高清修复（Upscale）** 是将低分辨率图片放大并增强细节的功能。简单来说，就是**让小图变大图，让模糊图变清晰图**。

### 生活中的类比

想象你有一张小照片，想把它放大挂在墙上：
- 直接放大 → 图片变模糊、有马赛克
- 高清修复 → 图片变大但依然清晰，细节更丰富

### 为什么需要高清修复？

| 问题 | 原因 | 高清修复的作用 |
|------|------|----------------|
| 图片太小 | 生成时尺寸有限制 | 放大图片尺寸 |
| 细节不够 | 低分辨率限制 | 增强细节 |
| 放大模糊 | 直接放大会失真 | 智能补充细节 |

---

## 使用场景

| 场景 | 具体应用 | 效果 |
|------|----------|------|
| **图片放大** | 将小图放大用于打印或展示 | 512×512 → 2048×2048 |
| **细节增强** | 提升图片清晰度和细节 | 模糊 → 清晰 |
| **打印准备** | 为打印准备高分辨率图片 | 低清 → 高清 |
| **壁纸制作** | 制作高清壁纸 | 小尺寸 → 大尺寸 |
| **后期处理** | 对生成图片进行优化 | 基础质量 → 高质量 |

---

## 两种方案对比

ComfyUI 提供两种高清修复方案：

| 方案 | 原理 | 优点 | 缺点 | 适用场景 |
|------|------|------|------|----------|
| **直接放大** | 使用放大模型直接放大 | 简单快速，不改变内容 | 细节增加有限 | 快速放大、保持原图 |
| **放大 + 重绘** | 放大后用 AI 重绘细节 | 细节丰富，质量高 | 耗时较长 | 高质量输出 |

### 方案选择建议

| 需求 | 推荐方案 |
|------|----------|
| 快速放大，保持原图 | 方案一：直接放大 |
| 高质量输出，增加细节 | 方案二：放大 + 重绘 |
| 时间充裕，追求最佳效果 | 方案二：放大 + 重绘 |

---

## 方案一：直接放大

### 功能描述

使用专门的放大模型对图片进行放大，不改变图片内容，只是增加像素和细节。

### 所需节点

| 节点名称 | 功能 | 通俗解释 |
|----------|------|----------|
| `Load Upscale Model` | 加载放大模型 | 选择放大的算法 |
| `Image Upscale With Model` | 使用模型放大图片 | 执行放大操作 |

### 操作步骤

**步骤 1：添加放大模型节点**
1. 右键 → Add Node → loaders → Load Upscale Model
2. 选择放大模型

**步骤 2：添加放大节点**
1. 右键 → Add Node → image → Image Upscale With Model
2. 连接：

| 连接来源 | 连接目标 |
|----------|----------|
| Load Upscale Model 的输出 | Image Upscale With Model 的 `upscale_model` |
| VAE Decode 的 `IMAGE` | Image Upscale With Model 的 `image` |

### 推荐放大模型

| 模型名称 | 放大倍数 | 特点 | 适用场景 |
|----------|----------|------|----------|
| `Real-ESRGAN 4x+` | 4x | 通用，效果好 | 写实照片、通用 |
| `Real-ESRGAN 4x+ Anime6B` | 4x | 动漫专用 | 动漫图片 |
| `4x-UltraSharp` | 4x | 细节锐利 | 需要锐利细节 |
| `4x_NMKD-Siax_200k` | 4x | 平衡质量 | 通用场景 |

### 模型下载位置

放大模型放在：`ComfyUI/models/upscale_models/`

## 方案二：放大 + 重绘（推荐）

### 功能描述

先放大图片，然后用 AI 对放大后的图片进行重绘，补充更多细节。这是获得高质量图片的推荐方法。

### 工作流结构

```
原始生成图（如 512×512）
         │
         ▼
   Upscale Image（放大 1.5-2 倍）
         │
         ▼
    VAE编码（VAE Encode）（编码）
         │
         ▼
   K采样器（KSampler）（重绘，denoise: 0.3-0.5）
         │
         ▼
    VAE解码（VAE Decode）（解码）
         │
         ▼
    保存图像（Save Image）（保存）
```

### 操作步骤

**步骤 1：生成基础图像**
- 使用标准文生图工作流生成基础图片
- 建议尺寸：512×512 或 512×768

**步骤 2：添加放大节点**
1. 右键 → Add Node → image → Upscale Image
2. 设置 `upscale_method`：选择 `nearest-exact` 或 `lanczos`
3. 设置放大倍数：1.5 或 2

**步骤 3：编码放大后的图像**
1. 添加 VAE编码（VAE Encode）节点
2. 连接放大后的图像

**步骤 4：重绘**
1. 添加 K采样器（KSampler）节点
2. 设置 denoise：0.3-0.5（不要太高，否则会改变原图）
3. 连接编码后的 latent

**步骤 5：解码并保存**
1. 添加 VAE解码（VAE Decode）节点
2. 添加 保存图像（Save Image）节点

---

## 参数说明

### 放大倍数

| 倍数 | 效果 | 建议 |
|------|------|------|
| 1.5x | 轻度放大 | 适合细节增强 |
| 2x | 中度放大 | **推荐日常使用** |
| 3x-4x | 大幅放大 | 可能出现失真 |

### 重绘参数

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| denoise | 0.3-0.5 | 保留原图结构，补充细节 |
| steps | 15-20 | 重绘不需要太多步数 |
| sampler | dpmpp_2m | 高效稳定 |
| cfg | 7-10 | 与原图保持一致 |

### Denoise 选择建议

| denoise 值 | 效果 | 适用场景 |
|------------|------|----------|
| 0.2-0.3 | 轻微增强 | 保持原图，轻微优化 |
| 0.3-0.5 | 中等增强 | **推荐日常使用** |
| 0.5-0.7 | 较大改变 | 可能改变原图风格 |

## 示例

### 示例 1：基础高清修复

```
原图：512×512 生成的图片
放大倍数：2x
方法：放大 + 重绘
denoise：0.4
结果：1024×1024 高清图片
```

### 示例 2：大幅放大

```
原图：512×512 生成的图片
放大倍数：1.5x + 1.5x（两次放大）
方法：两次放大 + 重绘
denoise：每次 0.35
结果：约 1152×1152 高清图片
```

### 示例 3：快速放大

```
原图：512×512 生成的图片
放大倍数：4x
方法：直接放大（使用 Real-ESRGAN）
结果：2048×2048 图片
```

## 注意事项

### ⚠️ 显存管理

| 问题 | 解决方案 |
|------|----------|
| 显存不足 | 分多次放大，每次 1.5-2x |
| 生成速度慢 | 使用直接放大方案 |
| 图片太大 | 降低放大倍数 |

### ⚠️ 放大倍数

- 不要一次性放大太多（建议每次不超过 2x）
- 大幅放大建议分多次进行
- 过大倍数可能导致失真

### ⚠️ 重绘强度

- denoise 过高会改变原图风格
- denoise 过低细节增强不明显
- 建议从 0.35 开始尝试

## 常见问题

### Q1：放大后图片变模糊怎么办？

**解决方案：**
1. 使用放大 + 重绘方案
2. 提高重绘 denoise 值（0.4-0.5）
3. 使用更好的放大模型

---

### Q2：显存不足怎么办？

**解决方案：**
1. 分多次放大，每次 1.5x
2. 使用直接放大方案（不重绘）
3. 减小中间图片尺寸

---

### Q3：放大后图片风格变了？

**解决方案：**
1. 降低 denoise 值（0.2-0.3）
2. 使用与原图相同的提示词
3. 使用直接放大方案

---

### Q4：应该选择哪种放大模型？

**建议：**
- 写实照片：Real-ESRGAN 4x+
- 动漫图片：Real-ESRGAN 4x+ Anime6B
- 需要锐利细节：4x-UltraSharp

---

### Q5：高清修复需要多长时间？

| 方案 | 时间估计 |
|------|----------|
| 直接放大（4x） | 约 5-10 秒 |
| 放大 + 重绘（2x） | 约 30-60 秒 |
| 多次放大 + 重绘 | 约 1-3 分钟 |
