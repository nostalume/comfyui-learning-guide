## 功能描述（通俗易懂）

**图生图（Image-to-Image）** 是在文生图基础上的进阶功能。简单来说，就是**以一张现有图片为基础，让 AI 根据你的描述进行修改或再创作**。

### 生活中的类比

想象一下：
- 你有一张照片，想让画家把它改成油画风格 → 图生图可以做到
- 你有一张模糊的老照片，想让它变清晰 → 图生图可以做到
- 你有一张黑白线稿，想给它上色 → 图生图可以做到

### 与文生图的区别

| 对比项 | 文生图 | 图生图 |
|--------|--------|--------|
| **输入** | 仅文字描述 | 图片 + 文字描述 |
| **起点** | 空白画布 | 现有图片 |
| **创作方式** | 从零开始创作 | 基于原图修改 |
| **控制程度** | 较难精确控制 | 可以保留原图结构 |

### 核心概念：Denoise（重绘强度）

这是图生图最重要的参数，决定了 AI 修改原图的程度：

| Denoise 值 | 通俗解释 |
|------------|----------|
| 0.1-0.3 | 轻微调整，像给照片加滤镜 |
| 0.4-0.6 | 中等修改，保留大部分结构 |
| 0.7-0.9 | 大幅修改，只保留基本轮廓 |
| 1.0 | 完全重绘，等于文生图 |

**原理说明：** `denoise` 决定了参考图片转换为潜空间图像后，向潜在空间图像添加的噪声强度。如果 `denoise` 为 1，潜空间图像就会变成完全随机的噪声，与 `Empty Latent Image` 节点生成的潜在空间一样，从而丢失参考图片的所有特征。因此，图生图中 `denoise` 必须**小于 1** 才能保留原图信息。

### 核心优势

| 优势 | 说明 |
|------|------|
| **可控性强** | 可以保留原图的结构和构图 |
| **效率高** | 不需要从零开始创作 |
| **创意丰富** | 一张图可以生成多种风格变体 |
| **门槛低** | 只需要一张图片和简单的描述 |

## 使用场景

| 场景 | 具体应用 | 效果示例 |
|------|----------|----------|
| **风格迁移** | 将照片转换为艺术风格 | 照片 → 油画、水彩、动漫 |
| **局部修改** | 修改图片中的部分元素 | 换背景、换衣服、换发型 |
| **细节增强** | 提升图片清晰度和细节 | 模糊照片 → 清晰照片 |
| **草图上色** | 为线稿添加颜色 | 黑白线稿 → 彩色插画 |
| **图片修复** | 修复老照片或损坏图片 | 老照片 → 修复后照片 |
| **创意变体** | 基于同一图片生成不同版本 | 同一人物不同风格 |
| **概念设计** | 快速生成设计变体 | 同一场景不同风格 |

## 与文生图的区别

### 节点差异

| 差异点 | 文生图 | 图生图 |
|--------|--------|--------|
| **Latent 来源** | 空Latent图像（Empty Latent Image，空白） | VAE编码（VAE Encode，编码原图） |
| **denoise 值** | 固定为 1.0 | 0.3-0.8（根据需求调整） |
| **额外节点** | 无 | 加载图像（Load Image）+ VAE编码（VAE Encode） |

### 参数差异

| 参数 | 文生图 | 图生图 |
|------|--------|--------|
| denoise | 1.0（固定） | 0.1-1.0（灵活调整） |
| steps | 20-30 | 20-30 |
| cfg | 7-10 | 7-10 |

---

## 节点连接步骤

### 步骤 1：加载图片

**操作方法：**
1. 右键 → Add Node → image → Load Image
2. 点击 `image` 区域上传图片
3. 或将图片直接拖入节点

**支持的图片格式：** PNG、JPG、JPEG、WEBP

**图片建议：**
- 使用清晰、光线良好的图片效果更好
- 避免过于模糊或损坏的图片
- 图片尺寸建议与生成尺寸相近

---

### 步骤 2：编码图片

**操作方法：**
1. 右键 → Add Node → latent → VAE Encode（VAE编码）
2. 连接：

| 连接来源 | 连接目标 |
|----------|----------|
| Load Image 的 `IMAGE` | VAE Encode 的 `pixels` |
| Load Checkpoint（加载模型） 的 `VAE` | VAE Encode（VAE编码） 的 `vae` |

**通俗解释：** VAE Encode 把图片转换成 AI 能理解的内部格式。

---

### 步骤 3：修改 KSampler 连接

**操作方法：**
将 VAE编码（VAE Encode） 的 `LATENT` 输出连接到 K采样器（KSampler） 的 `latent_image` 输入

**注意：** 这会替换原来的空Latent图像（Empty Latent Image）连接。

---

### 步骤 4：输入提示词

**操作方法：**
1. 在正面提示词节点输入你想要的效果
2. 在负面提示词节点输入不想要的内容

**提示词示例：**

| 目标效果 | 正面提示词 | 负面提示词 |
|----------|------------|------------|
| 油画风格 | `oil painting style, Van Gogh style, artistic` | `photorealistic, modern, digital` |
| 动漫风格 | `anime style, cel shading, vibrant colors` | `photorealistic, realistic, 3d` |
| 清晰化 | `high quality, sharp, detailed, clear` | `blurry, low quality, noisy` |

---

### 步骤 5：调整参数

图生图最重要的参数是 **Denoising Strength（重绘强度）**。

| 参数 | 说明 | 推荐值 |
|------|------|--------|
| **denoise** | AI 修改图片的程度 | 0.3-0.7 |
| **steps** | 生成步数 | 20-30 |
| **cfg** | 提示词强度 | 7-10 |

---

### 步骤 6：运行工作流

**操作方法：**
1. 点击 **"Queue Prompt"** 按钮
2. 等待生成完成
3. 查看结果

---

## Denoise 参数详解

Denoise（重绘强度）是图生图最核心的参数，直接决定最终效果。

### 参数对照表

| denoise 值 | 修改程度 | 适用场景 | 示例 |
|------------|----------|----------|------|
| **0.1-0.3** | 轻微调整 | 色彩调整、细节增强 | 照片调色、清晰化 |
| **0.3-0.5** | 中等修改 | 风格迁移、局部修改 | 照片转油画 |
| **0.5-0.7** | 较大修改 | 创意变体、风格转换 | 真人转动漫 |
| **0.7-0.9** | 大幅修改 | 重绘、创意改造 | 完全改变风格 |
| **1.0** | 完全重绘 | 等同于文生图 | 忽略原图内容 |

### Denoise 选择建议

```
想要的效果                    推荐值
─────────────────────────────────────
只调整色彩/光线              → 0.2-0.3
保留结构，改变风格           → 0.4-0.5
保留轮廓，大幅修改           → 0.6-0.7
几乎完全重绘                 → 0.8-0.9
```

## 高级技巧

### 1. 使用 ControlNet

ControlNet 可以更好地控制图生图结果：

**优势：**
- 保持原图的结构和姿态
- 精确控制修改程度
- 适合人物和建筑

**使用方法：**
1. 添加 `应用ControlNet（ControlNetApply）` 节点
2. 选择合适的预处理器和模型
3. 连接到工作流中

---

### 2. 多次迭代

可以进行多次图生图迭代，逐步优化效果：

**流程：**
1. 先用中等 denoise 生成第一版
2. 把结果作为输入进行第二次图生图
3. 逐步调整，直到满意

**建议：**
- 每次 denoise 不要太高（0.3-0.5）
- 每次只调整一个方面

---

### 3. 分区域处理

对于复杂图片，可以分区域处理：

**方法：**
1. 使用遮罩指定修改区域
2. 不同区域使用不同的提示词
3. 最后合成完整图片

## 注意事项

### ⚠️ Denoise 设置

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 原图特征丢失太多 | denoise 过高 | 降低到 0.3-0.5 |
| 修改效果不明显 | denoise 过低 | 提高到 0.5-0.7 |
| 画面出现伪影 | denoise 与提示词冲突 | 调整提示词或 denoise |

### ⚠️ 图片尺寸

- 建议使用与原图相同或相近的尺寸
- 尺寸差异过大可能导致变形
- 可以先调整原图尺寸再进行图生图

### ⚠️ 模型选择

- 选择与目标风格匹配的模型
- 写实风格用写实模型
- 动漫风格用动漫模型
- 不同模型对 denoise 的敏感度不同
- 建议先用小图测试效果

### ⚠️ 图片质量

- 原图质量越好，效果越好
- 避免使用过于模糊或损坏的图片
- 图片尺寸建议与生成尺寸相近

## 常见问题

### Q1：原图特征丢失太多怎么办？

**解决方案：**
1. 降低 denoise 参数（如从 0.7 降到 0.4）
2. 使用 ControlNet 保持结构
3. 在提示词中强调要保留的特征

---

### Q2：图片出现奇怪的伪影怎么办？

**解决方案：**
1. 降低 denoise 参数
2. 更换更适合的模型
3. 调整提示词，避免矛盾描述
4. 增加 steps 数量

---

### Q3：生成速度比文生图慢？

**原因：** 图生图需要额外的图片编码步骤，这是正常的。

**优化建议：**
1. 减小图片尺寸
2. 降低 steps 数量
3. 使用更快的采样器

---

### Q4：如何精确控制修改区域？

**解决方案：**
1. 使用 Inpaint（局部重绘）功能
2. 使用 ControlNet 控制结构
3. 使用遮罩指定修改区域

---

### Q5：风格迁移效果不理想？

**解决方案：**
1. 调整 denoise 值（尝试 0.4-0.6）
2. 使用与目标风格匹配的模型
3. 在提示词中更明确地描述风格
