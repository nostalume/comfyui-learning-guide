# 提示词入门

> **适合人群：** 零基础初学者
> **目标：** 学会写有效的提示词
> **阅读时长：** 约 25 分钟
> **相关官方文档：** [ComfyUI 官方文档](https://docs.comfy.org/) | [中文文档](https://docs.comfy.org/zh/)

---

## 功能描述（通俗易懂）

**提示词（Prompt）** 就是你告诉 AI 的文字描述，用来指导它生成图片。可以把它理解为**你给 AI 的"指令"或"需求说明书"**。

### 生活中的类比

想象你在餐厅点菜：
- ❌ "我要吃的" → 服务员不知道你要什么
- ✅ "我要一份红烧牛肉面，多放辣椒，少放盐" → 服务员明确知道你要什么

提示词也是一样：
- ❌ "画一只猫" → AI 不知道要什么样的猫
- ✅ "一只可爱的橘猫，坐在窗台上，阳光照射，毛茸茸，高清照片" → AI 知道你要什么

### 核心原则

**好的提示词 = 详细描述 + 明确风格 + 具体要求**

---

## 使用场景

| 场景 | 提示词作用 | 示例 |
|------|------------|------|
| **文生图** | 描述想要生成的内容 | 生成风景、人物、动物等 |
| **图生图** | 描述想要修改的效果 | 风格转换、细节增强 |
| **风格控制** | 指定艺术风格 | 油画、水彩、动漫风格 |
| **质量控制** | 提升图片质量 | 高清、细节丰富 |
| **排除内容** | 避免不想要的元素 | 负面提示词 |

---

## 提示词结构

一个好的提示词通常包含以下几个部分：

```
[质量词] + [主体描述] + [环境/背景] + [风格/艺术风格] + [构图/视角] + [光线/色彩]
```

### 结构示例

```
masterpiece, best quality                          ← 质量词
a beautiful woman reading a book                   ← 主体描述
in a cozy library with warm lighting               ← 环境/背景
oil painting style                                 ← 风格
close-up portrait                                  ← 构图/视角
golden hour, warm colors                           ← 光线/色彩
```

---

## 参数说明

### 正面提示词（Positive Prompt）

告诉 AI 你**想要**什么。

| 类别 | 作用 | 示例 |
|------|------|------|
| 质量词 | 提升图片质量 | `masterpiece, best quality, 4k` |
| 主体词 | 描述主要内容 | `a beautiful woman, a cute cat` |
| 风格词 | 指定艺术风格 | `oil painting, anime, photorealistic` |
| 环境词 | 描述背景环境 | `in a forest, at sunset, indoors` |
| 光线词 | 描述光线效果 | `golden hour, soft lighting, dramatic` |

### 负面提示词（Negative Prompt）

告诉 AI 你**不想要**什么。

| 类别 | 作用 | 示例 |
|------|------|------|
| 质量排除 | 避免低质量 | `low quality, blurry, pixelated` |
| 内容排除 | 避免特定内容 | `text, watermark, logo` |
| 错误排除 | 避免常见错误 | `bad anatomy, extra fingers, deformed` |

## 常用提示词分类

### 1. 质量词

用于描述图片的质量，建议放在提示词开头：

| 词 | 说明 | 效果 |
|-----|------|------|
| `masterpiece` | 杰作级别 | 整体质量提升 |
| `best quality` | 最佳质量 | 细节更丰富 |
| `ultra detailed` | 超详细 | 细节更多 |
| `high resolution` | 高分辨率 | 图片更清晰 |
| `4K / 8K` | 高清 | 分辨率更高 |
| `sharp` | 清晰锐利 | 边缘更清晰 |
| `professional` | 专业级 | 整体更专业 |

**推荐组合：**
```
masterpiece, best quality, ultra detailed, 4k
```

---

### 2. 主体描述

描述图片的主要内容：

| 类别 | 示例提示词 |
|------|------------|
| **人物** | `a beautiful woman, young, smiling, elegant` |
| **动物** | `a cute puppy, golden retriever, fluffy` |
| **场景** | `a castle on a mountain, ancient, majestic` |
| **物体** | `a vintage car, red, classic, shiny` |
| **食物** | `a delicious cake, chocolate, decorated` |

---

### 3. 环境/背景

描述主体所处的环境：

| 词 | 说明 | 中文 |
|-----|------|------|
| `outdoors` | 户外 | 户外场景 |
| `indoors` | 室内 | 室内场景 |
| `forest` | 森林 | 森林环境 |
| `city` | 城市 | 城市背景 |
| `beach` | 海滩 | 海滩场景 |
| `night` | 夜晚 | 夜晚氛围 |
| `daytime` | 白天 | 白天场景 |
| `sunset` | 日落 | 日落时分 |
| `rainy` | 下雨 | 雨天氛围 |
| `snowy` | 下雪 | 雪天场景 |

---

### 4. 风格/艺术风格

描述图片的艺术风格：

| 风格 | 说明 | 适用场景 |
|-----|------|----------|
| `realistic` | 写实风格 | 真实照片效果 |
| `photorealistic` | 照片写实 | 超真实效果 |
| `oil painting` | 油画风格 | 艺术创作 |
| `watercolor` | 水彩风格 | 柔和艺术效果 |
| `cartoon` | 卡通风格 | 可爱风格 |
| `anime` | 动漫风格 | 日式动漫 |
| `cyberpunk` | 赛博朋克 | 科幻风格 |
| `minimalist` | 极简风格 | 简洁设计 |
| `vintage` | 复古风格 | 怀旧效果 |
| `sketch` | 素描风格 | 手绘效果 |
| `digital art` | 数字艺术 | 现代风格 |

---

### 5. 构图/视角

描述图片的构图方式：

| 词 | 说明 | 效果 |
|-----|------|------|
| `portrait` | 肖像 | 竖版构图，适合人像 |
| `landscape` | 风景 | 横版构图，适合风景 |
| `close-up` | 特写 | 放大主体细节 |
| `wide shot` | 全景 | 展示完整场景 |
| `from above` | 俯视 | 从上往下看 |
| `from below` | 仰视 | 从下往上看 |
| `side view` | 侧面 | 侧角度观察 |
| `front view` | 正面 | 正面观察 |
| `bird's eye view` | 鸟瞰 | 高空俯视 |

---

### 6. 光线/色彩

描述光线和色彩：

| 词 | 说明 | 效果 |
|-----|------|------|
| `golden hour` | 黄金时刻 | 温暖柔和的光线 |
| `soft lighting` | 柔和光线 | 温柔的光线效果 |
| `dramatic lighting` | 戏剧性光线 | 强烈对比的光线 |
| `natural light` | 自然光 | 自然的光线效果 |
| `backlight` | 逆光 | 从背后照射的光 |
| `warm colors` | 暖色 | 温暖的色彩 |
| `cool colors` | 冷色 | 冷色调的色彩 |
| `vibrant` | 鲜艳 | 鲜艳的色彩 |
| `muted` | 柔和 | 柔和的色彩 |
| `pastel colors` | 粉彩 | 柔和的粉彩色 |

## 负面提示词详解

### 常用负面提示词

| 类别 | 常用词 | 作用 |
|------|--------|------|
| **质量问题** | `low quality, blurry, pixelated, noisy` | 避免低质量图片 |
| **画面问题** | `ugly, deformed, disfigured, bad anatomy` | 避免画面错误 |
| **多余元素** | `text, watermark, signature, logo` | 避免多余文字/水印 |
| **光线问题** | `overexposed, underexposed, bad lighting` | 避免光线问题 |
| **人物问题** | `bad hands, extra fingers, missing fingers` | 避免人物错误 |

### 通用负面提示词模板

```
low quality, worst quality, blurry, pixelated, 
ugly, deformed, disfigured, bad anatomy, 
text, watermark, signature, logo
```

## 提示词技巧

### 技巧 1：使用逗号分隔

```
❌ 错误：a beautiful sunset golden hour peaceful
✅ 正确：a beautiful sunset, golden hour, peaceful
```

### 技巧 2：调整权重

可以调整某些词的重要性：

```
(beautiful landscape:1.2), mountains, lake
```

| 语法 | 效果 |
|------|------|
| `(word:1.2)` | 权重增加 20% |
| `(word:0.8)` | 权重减少 20% |
| `(word)` | 权重增加约 10% |
| `((word))` | 权重增加约 21% |

### 技巧 3：使用括号分组

```
(a beautiful woman, smiling):1.1, (in a garden, spring flowers):1.0
```

### 技巧 4：从简单到复杂

```
基础版：a cat
进阶版：a cute cat, fluffy, sitting on a windowsill
高级版：masterpiece, best quality, a cute fluffy cat sitting on a wooden 
        windowsill, warm morning light, soft focus background, professional 
        photography
```

### 技巧 5：参考优秀提示词

- 在 Civitai 上查看热门模型的提示词
- 学习其他人的描述方式
- 收藏并修改适合自己需求的提示词

## 注意事项

### ⚠️ 提示词长度

| 情况 | 建议 |
|------|------|
| 太短 | 添加更多细节描述 |
| 太长 | 可能被截断，保持精简 |
| 推荐 | 75-150 个 token（约 50-100 个英文单词） |

### ⚠️ 语言选择

- 大部分模型对**英文**支持最好
- 中文提示词效果可能不稳定
- 建议使用英文提示词

### ⚠️ 避免矛盾

```
❌ 错误：photorealistic cartoon cat
✅ 正确：photorealistic cat 或 cartoon cat
```

## 常见问题

### Q1：提示词应该写多长？

**建议：**
- 基础提示词：20-50 个单词
- 详细提示词：50-100 个单词
- 避免过长，可能被截断

---

### Q2：提示词的顺序重要吗？

**是的，顺序很重要：**
- 开头的词权重更高
- 建议把重要的词放在前面
- 质量词通常放在最前面

---

### Q3：为什么生成的图片和描述不符？

**可能原因：**
1. 提示词不够具体 → 添加更多细节
2. 提示词有矛盾 → 检查并修正
3. 模型不支持某些内容 → 更换模型
4. CFG 太低 → 提高到 7-10

---

### Q4：负面提示词必须写吗？

**建议：**
- 不是必须的，但强烈建议写
- 可以显著提升图片质量
- 使用通用模板即可

---

### Q5：如何学习写更好的提示词？

**方法：**
1. 多看优秀作品的提示词
2. 从简单开始，逐步添加细节
3. 记录有效的提示词组合
4. 多尝试，多练习
