### 二、开源项目时效性检查结果

#### 2.1 已检查的核心项目

| 项目 | 最新版本 | 更新状态 | 影响文档 |
|-----|---------|---------|---------|
| ComfyUI | v0.21.0 | 活跃更新（每周发布） | 全部文档 |
| ComfyUI 桌面端 | v2.0.0 | 活跃更新 | 安装部署、版本差异 |
| ComfyUI-Manager | v4.0.4+ | 活跃更新 | 安装部署、自定义节点 |
| AnimateDiff-Evolved | 持续更新 | 活跃更新 | 视频相关节点 |
| VideoHelperSuite | 持续更新 | 活跃更新 | 视频相关节点 |
| IPAdapter-Plus | 维护模式 | 仅维护，无新功能 | IP-Adapter |
| xFormers | v0.0.35/36 | 活跃更新 | 推理加速 |
| Flux | 多版本迭代 | 活跃开发 | Checkpoint大模型 |

#### 2.2 关键发现

1. **IPAdapter-Plus** 已于 2025.04 进入"仅维护"模式，不再计划新功能开发
2. **AnimateDiff** v3 版本参数与 v2 有差异，需注意兼容性
3. **xFormers** 版本需与 PyTorch 严格匹配，已更新兼容性表格
4. **Flux** 有多个社区优化版本（FP8、BNF NF4 等）
