# 5.2 队列管理

> **文档版本：** 2026.04
> **相关官方文档：** [ComfyUI 官方文档](https://docs.comfy.org/) | [中文文档](https://docs.comfy.org/zh/)

## 功能描述

队列管理是 ComfyUI 的核心功能之一，它允许你将多个生成任务排队等待执行。就像银行的叫号系统一样，你取了号（添加任务），然后等待叫号（执行任务），系统会按顺序处理每一个请求。

### 队列管理原理

ComfyUI 的队列系统基于以下机制运行：

1. **任务队列**：所有提交的生成任务都会进入队列，按先进先出（FIFO）顺序执行
2. **执行引擎**：后台持续监控队列，有任务时自动开始处理
3. **状态追踪**：记录每个任务的执行状态、历史和结果
4. **中断恢复**：支持暂停、中断和从断点继续执行

| 场景 | 说明 |
|------|------|

## 5.2.1 内置队列功能

### 功能描述

ComfyUI 内置了完整的队列管理系统，无需任何插件即可使用。通过界面右侧的面板可以查看和管理所有任务。

### 界面说明

| 功能 | 操作位置 | 说明 |
|------|----------|------|
| 添加任务 | Queue Prompt 按钮 | 将当前工作流加入队列 |
| 批量添加 | Queue Prompt 数字框 | 设置数量后批量添加相同任务 |
| 查看队列 | 右侧 Queue 面板 | 显示等待中和正在执行的任务 |
| 暂停队列 | Pause 按钮 | 暂停队列执行，当前任务继续 |
| 清空队列 | Clear 按钮 | 清除所有等待中的任务 |
| 查看历史 | History 面板 | 显示已完成任务的记录 |

### 操作步骤

#### 添加单个任务

1. 在画布中设计好工作流
2. 点击右侧菜单的 **Queue Prompt** 按钮
3. 任务自动加入队列并开始执行

#### 批量添加任务

1. 点击 **Queue Prompt** 按钮旁边的数字输入框
2. 输入想要添加的任务数量（如 10）
3. 点击确认，系统会添加指定数量的任务到队列

#### 查看和管理队列

1. 按键盘 **Q** 键打开队列面板
2. 查看当前正在执行和等待中的任务
3. 可以点击任务查看详情或取消

## 5.2.2 队列操作快捷键

### 快捷键列表

| 快捷键 | 功能 | 使用场景 |
|--------|------|----------|
| `Ctrl + Enter` | 将当前工作流加入队列 | 快速提交任务 |
| `Ctrl + Shift + Enter` | 将当前工作流优先加入队列 | 紧急任务插队 |
| `Ctrl + Alt + Enter` | 取消当前正在执行的任务 | 停止不满意的生成 |
| `Q` | 切换队列面板可见性 | 快速查看队列状态 |
| `H` | 切换历史面板可见性 | 查看已完成任务 |

### 操作步骤

1. **快速提交**：设计好工作流后，直接按 `Ctrl + Enter`
2. **紧急插队**：有重要任务时，按 `Ctrl + Shift + Enter` 优先执行
3. **停止生成**：对当前生成不满意时，按 `Ctrl + Alt + Enter` 中断

### 状态类型

| 状态 | 图标 | 说明 |
|------|------|------|

## 5.2.4 断点续跑

### 功能描述

当生成任务因意外中断（如崩溃、断电）时，可以通过记录的种子或历史记录从断点继续执行，避免重复已完成的工作。

### 方法一：记录种子

#### 操作步骤

1. 在开始批量生成前，记录起始种子编号
2. 任务执行过程中，定期检查已完成的数量
3. 发生中断后，计算剩余任务的起始种子
4. 修改种子参数，从断点继续

#### 示例

```
原计划：种子 1000-1099，共 100 张
中断时：已完成 1000-1045，共 46 张
续跑设置：种子从 1046 开始，再生成 54 张
```

### 方法二：使用历史记录

#### 操作步骤

1. 按键盘 **H** 键打开历史面板
2. 在历史列表中找到中断前的最后一个任务
3. 点击 **Load** 按钮重新加载该工作流
4. 查看其种子编号，设置新任务从下一个种子开始

#### 历史面板功能

| 操作 | 说明 |
|------|------|
| Load | 加载该任务的工作流 |
| Delete | 删除该历史记录 |
| Refresh | 刷新历史列表 |

## 5.2.5 最佳实践建议

### 队列管理建议

| 建议 | 说明 |
|------|------|
| 合理设置批量数量 | 避免一次添加过多任务，建议分批处理 |
| 定期清理历史 | 历史记录过多会影响界面响应 |
| 使用固定种子 | 便于追踪和复现结果 |
| 监控显存使用 | 避免因显存不足导致任务失败 |

### 效率优化建议

1. **预热模型**：第一次生成前先运行一个小任务预热
2. **合理分组**：相同模型的任务放在一起，减少模型切换
3. **错峰执行**：大批量任务安排在空闲时间执行

### 注意事项

- ⚠️ 清空队列会删除所有等待中的任务，但不会影响正在执行的任务
- ⚠️ 暂停队列后，当前任务会继续执行完成
- 💡 历史记录保存在本地，重启 ComfyUI 后仍然存在
- 💡 可以通过设置调整历史记录的保存数量

## 常见问题

### Q1：队列中的任务可以调整顺序吗？

**A：** 默认情况下队列按先进先出顺序执行。如果需要调整：
- 使用 `Ctrl + Shift + Enter` 将紧急任务优先加入队列
- 清空队列后重新按需要的顺序添加任务

---

### Q2：如何查看已完成任务的参数？

**A：**
1. 按 **H** 键打开历史面板
2. 找到目标任务
3. 点击 **Load** 加载该工作流
4. 查看各节点的参数设置

---

### Q3：队列执行速度很慢怎么办？

**A：** 可能原因和解决方案：

| 原因 | 解决方案 |
|------|----------|
| 采样步数过多 | 降低 steps 参数 |
| 图片分辨率过高 | 降低 width/height |
| 模型加载慢 | 使用更快的存储设备 |
| 显存不足 | 降低 batch_size 或使用 xformers |

---

### Q4：任务执行失败如何排查？

**A：** 排查步骤：
1. 查看控制台错误信息
2. 检查工作流中是否有红色标记的节点
3. 确认模型文件是否存在且完整
4. 检查显存是否充足
5. 尝试简化工作流逐步排查

---

### Q5：历史记录太多会影响性能吗？

**A：** 会有一定影响。建议：
- 定期清理不需要的历史记录
- 在设置中调整历史记录保留数量
- 重要工作流单独保存为 JSON 文件
