## 2.1.1 标准目录结构

```
ComfyUI/models/
├── checkpoints/              # 大模型 (Checkpoint)
│   ├── sd15/               # SD 1.5 模型（可选子目录）
│   ├── sdxl/               # SDXL 模型（可选子目录）
│   └── flux/               # Flux 模型（可选子目录）
├── lora/                    # LoRA 模型
│   ├── style/               # 风格 LoRA
│   ├── character/           # 角色 LoRA
│   └── concept/             # 概念 LoRA
├── controlnet/              # ControlNet 模型
│   ├── sd15/               # SD 1.5 ControlNet
│   └── sdxl/               # SDXL ControlNet
├── vae/                     # VAE 模型
├── clip/                    # CLIP 模型
├── t5/                      # T5 模型（Flux 等）
├── embeddings/               # 文本嵌入 (Textual Inversion)
├── ipadapter/               # IP-Adapter 模型
├── clip_vision/             # CLIP Vision 模型（IP-Adapter 需要）
├── animatediff_models/      # AnimateDiff 模型
├── upscale_models/          # 放大模型
├── insightface/             # InsightFace 模型（FaceID 需要）
└── vae_approx/              # VAE 近似模型（预览用）
```

## 2.1.2 命名规范建议

```
[基础模型]_[类型]_[风格/用途]_[版本].safetensors

示例：
sd15_realistic_vision_v5.safetensors
sdxl_juggernaut_xl_v9.safetensors
flux1-dev.safetensors
lora_anime_style_v2.safetensors
control_v11p_sd15_canny.safetensors
```

## 2.1.3 模型放置详细说明

### Checkpoint 大模型

**用途：** 决定图片的整体风格
**格式：** `.safetensors` 或 `.ckpt`
**位置：** `ComfyUI/models/checkpoints/`

**示例文件：**
- `Realistic Vision V5.safetensors`
- `DreamShaper_v8.safetensors`
- `Juggernaut_XL_v8.safetensors`

### ControlNet 模型

**用途：** 控制图片生成（姿态、深度等）
**格式：** `.safetensors`
**位置：** `ComfyUI/models/controlnet/`

**示例文件：**
- `control_v11f1p_sd15_depth.safetensors`
- `control_v11p_sd15_openpose.safetensors`
- `control_v11p_sd15_canny.safetensors`

### LoRA 模型

**用途：** 添加特定风格或特征
**格式：** `.safetensors` 或 `.pt`
**位置：** `ComfyUI/models/lora/`

**示例文件：**
- `Detail_Tweaker.safetensors`
- `Anime_Style.safetensors`

### VAE 模型

**用途：** 优化图片颜色和细节
**格式：** `.safetensors` 或 `.ckpt`
**位置：** `ComfyUI/models/vae/`

**示例文件：**
- `sd-vae-ft-mse.safetensors`
- `sdxl_vae.safetensors`

### 放大模型

**用途：** 放大图片并增强细节
**格式：** `.safetensors` 或 `.pt`
**位置：** `ComfyUI/models/upscale_models/`

**示例文件：**
- `4x-UltraSharp.pth`
- `RealESRGAN_x4plus.pth`

### Embedding 模型

**用途：** 添加或移除特定特征
**格式：** `.pt`
**位置：** `ComfyUI/models/embeddings/`

**示例文件：**
- `EasyNegative.pt`
- `badhandv4.pt`

## 2.1.4 模型放置操作步骤

### 步骤 1：找到模型文件夹

1. 打开文件资源管理器（Windows）或访达（macOS）
2. 找到你安装 ComfyUI 的文件夹
3. 进入 `models/` 文件夹

### 步骤 2：确认目录存在

确保以下目录都存在：
- `checkpoints/`
- `controlnet/`
- `lora/`
- `vae/`
- `upscale_models/`
- `embeddings/`

如果不存在，可以手动创建。

### 步骤 3：复制模型文件

1. 找到你下载的模型文件
2. 根据模型类型复制到对应的文件夹
3. 确保文件名没有特殊字符

### 步骤 4：验证安装

1. 启动 ComfyUI
2. 在对应的节点中选择模型
3. 如果能看到模型名称，说明安装成功

## 2.1.5 共享模型目录配置

如果需要在 ComfyUI 和其他 UI（如 WebUI）之间共享模型，可以配置 `extra_model_paths.yaml`：

1. 找到 ComfyUI 目录下的 `extra_model_paths.yaml.example`
2. 重命名为 `extra_model_paths.yaml`
3. 编辑配置：

```yaml
# 示例配置
webui_path:
  base_path: E:/stable-diffusion-webui/
  checkpoints: models/Stable-diffusion/
  lora: models/Lora/
  vae: models/VAE/
  embeddings: embeddings/
  controlnet: models/ControlNet/
  is_default: true
```

## 2.1.7 模型管理技巧

- **分类整理：** 按风格分类（写实、动漫、艺术），按用途分类（人物、风景、产品）
- **定期清理：** 删除不常用的模型，备份重要模型到外部存储
- **使用 ComfyUI-Manager：** 可以自动安装和管理模型，自动更新模型列表

## 2.1.8 常见问题

### Q1：模型不显示
**解决：**
- 确认模型放在正确的文件夹中
- 重新启动 ComfyUI
- 检查文件名是否正确（不要有中文或特殊字符）

### Q2：模型文件太大
**解决：**
- 确保有足够的存储空间
- 可以使用外部硬盘
- 选择更小的模型版本（如 FP16）

### Q3：模型版本不兼容
**解决：**
- 确认模型支持的 SD 版本
- 检查模型描述中的兼容性说明
- 尝试使用兼容的模型
