## 2.2.2 Civitai 使用指南

### 平台特点
- 最大的 AI 艺术模型社区
- 包含大量 Checkpoint、LoRA、ControlNet
- 用户评分和下载统计
- 社区工作流分享

### 注册与登录

1. 打开浏览器，访问 [Civitai](https://civitai.com/)
2. 点击右上角的"Sign Up"按钮
3. 填写注册信息：用户名、邮箱、密码
4. 点击"Sign Up"完成注册
5. 登录时点击"Sign In"，输入邮箱和密码

### 搜索与筛选模型

1. 在搜索框中输入关键词，如：
   - "Realistic Vision"（写实风格）
   - "DreamShaper"（通用风格）
   - "Anime"（动漫风格）
2. 按回车键搜索
3. 筛选建议：
   - 查看下载量和评分
   - 选择"Most Downloaded"或"Most Liked"排序
   - 阅读模型说明
   - 注意版本兼容性

### 下载模型

1. 在搜索结果中找到目标模型，点击进入详情页
2. 查看模型预览图和描述
3. 找到"Files"部分，选择下载文件：
   - 优先选择 `.safetensors` 格式（更安全）
   - 选择适合显存的版本（如 FP16 适合显存较小的设备）
4. 点击下载按钮，等待下载完成

### 安装模型

1. 找到下载的文件
2. 根据模型类型复制到对应文件夹：
   - Checkpoint → `ComfyUI/models/checkpoints/`
   - LoRA → `ComfyUI/models/lora/`
   - ControlNet → `ComfyUI/models/controlnet/`
   - VAE → `ComfyUI/models/vae/`
3. 重新启动 ComfyUI
4. 在对应节点中选择下载的模型

### 下载技巧

- **按热门程度排序：** 热门模型通常质量更高
- **查看模型版本：** 选择最新版本，查看更新日志
- **检查兼容性：** 确认模型支持的 SD 版本（SD 1.5 或 SDXL），确认所需显存大小
- **使用下载工具：** 大文件建议使用 IDM、迅雷等工具加速下载

### 推荐入门模型

| 风格 | 模型 | 说明 |
|------|------|------|
| 写实 | Realistic Vision V5 | 高质量写实 |
| 写实 | DreamShaper V8 | 通用写实 |
| 动漫 | MeinaMix | 动漫风格 |
| 动漫 | Anything V4 | 二次元风格 |
| SDXL | Juggernaut XL | SDXL 写实 |
| SDXL | Realistic Vision XL | SDXL 写实 |

## 2.2.3 HuggingFace 使用指南

### 平台特点
- 官方模型发布平台
- 稳定可靠，版本管理完善
- 包含图像生成、语言、音频等各类 AI 模型

### 主要模型仓库
- stabilityai（SD 官方模型）
- lllyasviel（ControlNet）
- comfyanonymous（ComfyUI 相关）

### 注册与登录

1. 打开浏览器，访问 [HuggingFace](https://huggingface.co/)
2. 点击右上角的"Sign Up"按钮
3. 填写注册信息：用户名、邮箱、密码
4. 点击"Sign Up"完成注册
5. 登录时点击"Sign In"，输入邮箱和密码

### 搜索与下载模型

1. 在搜索框中输入关键词，如"Stable Diffusion"、"ControlNet"、"VAE"
2. 按回车键搜索
3. 点击模型名称进入详情页，查看描述和文件列表
4. 找到"Files and versions"部分，选择下载文件
5. 点击文件右侧的下载按钮，等待下载完成

### 安装模型

1. 找到下载的文件
2. 根据文件类型放到对应的文件夹：
   - Checkpoint → `models/checkpoints/`
   - LoRA → `models/lora/`
   - ControlNet → `models/controlnet/`
   - VAE → `models/vae/`
3. 重新启动 ComfyUI

### 文件格式说明

| 格式 | 说明 | 推荐 |
|------|------|------|
| .safetensors | 安全的模型文件格式，不会执行恶意代码 | ✅ 推荐 |
| .ckpt | 旧版模型文件格式，可能存在安全风险 | ⚠️ 不推荐 |
| .bin | 二进制文件，通常是模型的一部分 | — |

### 下载技巧

- **使用 Git 克隆（大文件）：**
  ```bash
  git clone https://huggingface.co/模型名称
  ```
- **查看模型卡片：** 阅读模型描述、使用示例、许可证
- **使用 API（高级）：**
  ```python
  from huggingface_hub import hf_hub_download
  hf_hub_download(repo_id="模型名称", filename="文件名")
  ```

### 常用模型

| 类型 | 模型 | 说明 |
|------|------|------|
| 官方 | runwayml/stable-diffusion-v1-5 | SD 1.5 官方模型 |
| 官方 | stabilityai/stable-diffusion-xl-base-1.0 | SDXL 官方模型 |
| ControlNet | lllyasviel/ControlNet-v1-1 | ControlNet v1.1 |
| VAE | stabilityai/sd-vae-ft-mse | SD 1.5 VAE |
| VAE | stabilityai/sdxl-vae | SDXL VAE |

## 2.2.5 下载方式

### 浏览器下载
直接访问平台下载

### 命令行下载

```bash
# 使用 huggingface-cli
pip install huggingface-hub
huggingface-cli download <repo_id> --local-dir ./models/checkpoints/

# 使用 wget
wget -O model.safetensors "<download_url>"

# 使用 aria2（多线程，更快）
aria2c -x 16 -s 16 "<download_url>" -d ./models/checkpoints/ -o model.safetensors
```

## 2.2.7 常见问题

### Q1：下载速度很慢
**解决：**
- 耐心等待（国外网站通常较慢）
- 使用下载工具加速（IDM、迅雷）
- 尝试在网络畅通的时候下载
- HuggingFace 可尝试使用国内镜像或 Git 克隆

### Q2：下载的文件打不开或损坏
**解决：**
- 检查文件是否下载完整
- 尝试重新下载
- 确保文件格式正确（.safetensors 或 .ckpt）

### Q3：模型在 ComfyUI 中不显示
**解决：**
- 确认模型放在正确的文件夹中
- 重新启动 ComfyUI
- 检查文件名是否正确（不要有中文或特殊字符）

### Q4：找不到想要的模型
**解决：**
- 尝试不同的搜索关键词
- 浏览热门模型列表
- 查看模型分类

### Q5：模型文件太大
**解决：**
- 选择 FP16 版本（更小）
- 使用 Git 克隆（支持断点续传）
- 检查是否有分块下载
