## 2.7.1 CLIP 概念说明

### 什么是 CLIP？

**CLIP**（Contrastive Language-Image Pre-Training，对比语言-图像预训练）是 OpenAI 开发的一种多模态模型。

#### 功能描述（通俗易懂）

CLIP 是 AI 绘图系统的"翻译官"，它负责把你写的文字提示词"翻译"成 AI 模型能理解的语言。

**类比理解：**

| 角色 | 类比 | 功能 |
|------|------|------|
| 用户 | 客户 | 提出需求（写提示词） |
| CLIP | 翻译官 | 把客户需求翻译给画家 |
| 大模型 | 画家 | 根据翻译画画 |

**工作流程：**
```
用户输入提示词 → CLIP 编码 → 模型理解 → 生成图像
```

#### 为什么需要 CLIP？

AI 模型本身不直接理解文字，它只理解数字。CLIP 的作用就是：
1. 把你的文字描述转换成数字向量
2. 这些向量告诉模型你想要什么样的图像
3. 模型根据这些向量生成对应的图像

#### CLIP 的核心能力

| 能力 | 说明 | 示例 |
|------|------|------|
| 文本理解 | 理解提示词的含义 | "a cat" → 理解为"一只猫" |
| 语义关联 | 理解词语之间的关系 | "red apple" → 红色的苹果 |
| 概念组合 | 组合多个概念 | "a cat wearing a hat" → 戴帽子的猫 |

## 2.7.2 CLIP 版本详解

### 常用 CLIP 版本

| 版本 | 适用模型 | 说明 | 特点 |
|------|----------|------|------|
| CLIP ViT-L/14 | SD 1.5 | 默认版本 | 平衡性能与速度 |
| CLIP ViT-G/14 | SDXL | 更大更强 | 更好的理解能力 |
| CLIP ViT-H/14 | SD 2.1 | 高级版本 | 更精细的理解 |

### 版本命名解释

**ViT-L/14 的含义：**
- **ViT**：Vision Transformer（视觉变换器）
- **L**：Large（大型）
- **14**：patch size 为 14（图像分割块大小）

**版本大小对比：**
```
ViT-B < ViT-L < ViT-H < ViT-G
(小)                    (大)
```

### CLIP 模型位置

| 来源 | 位置 | 说明 |
|------|------|------|
| 内嵌在 Checkpoint 中 | 模型内部 | 大多数 SD 模型自带 CLIP |
| 独立 CLIP 模型 | `models/clip/` | 某些模型需要单独加载 |

## 2.7.3 CLIP 使用场景

### 场景一：正向提示词编码

#### 需求描述

告诉 AI 你想要什么样的图像。

#### 解决方案

使用 CLIP Text Encode (Positive) 节点。

#### 示例

```
提示词：a beautiful sunset over the ocean, golden hour, cinematic lighting
CLIP 编码后 → 模型理解 → 生成美丽的日落海景
```

### 场景二：负向提示词编码

#### 需求描述

告诉 AI 你不想要什么样的图像。

#### 解决方案

使用 CLIP Text Encode (Negative) 节点。

#### 示例

```
负向提示词：low quality, blurry, distorted, ugly
CLIP 编码后 → 模型避免这些特征 → 生成高质量图像
```

### 场景三：提示词权重调整

#### 需求描述

强调或弱化提示词中的某些部分。

#### 解决方案

使用 CLIP 特殊语法调整权重。

#### 语法说明

| 语法 | 效果 | 示例 |
|------|------|------|
| (word) | 增强 1.1 倍 | (cat) → 更像猫 |
| ((word)) | 增强 1.21 倍 | ((cat)) → 强调猫 |
| (word:1.5) | 增强 1.5 倍 | (cat:1.5) → 非常像猫 |
| [word] | 减弱 0.9 倍 | [cat] → 稍微不像猫 |

#### 示例

```
提示词：a (cat:1.3) sitting on a [chair]
效果：强调猫，弱化椅子
```

## 2.7.4 T5 概念说明

### 什么是 T5？

**T5**（Text-to-Text Transfer Transformer）是 Google 开发的大型语言模型，被 Flux 等新一代 AI 绘图模型采用作为文本编码器。

#### 功能描述（通俗易懂）

T5 是 CLIP 的"升级版翻译官"，它比 CLIP 更强大：

| 特性 | CLIP | T5 |
|------|------|-----|
| 文本长度 | 约 75 个 token | 支持超长文本 |
| 理解能力 | 基础语义 | 深度语义理解 |
| 复杂描述 | 可能理解偏差 | 精确理解 |

#### 为什么 Flux 使用 T5？

Flux 等新模型追求更高质量的图像生成，需要更精确的文字理解：
- CLIP 适合简单描述："a cat"
- T5 适合复杂描述："a fluffy orange cat sitting on a vintage leather armchair in a cozy library, warm afternoon sunlight streaming through tall windows, dust particles visible in the light rays"

### T5 的特点

| 特点 | 说明 | 优势 |
|------|------|------|
| 更长文本理解 | 支持更复杂的提示词 | 可以详细描述场景 |
| 更强的语义理解 | 理解更准确的描述 | 减少误解用户意图 |
| 文件较大 | 需要额外下载 | 换来更好的效果 |

### T5 模型位置

**放置目录：** `ComfyUI/models/t5/`

**常用 T5 模型：**

| 模型 | 大小 | 适用模型 |
|------|------|----------|
| t5xxl_fp16.safetensors | ~4.5GB | Flux |
| t5xxl_fp8_e4m3fn.safetensors | ~2.3GB | Flux（量化版） |

## 2.7.5 提示词编码节点

### CLIP Text Encode 节点

#### 功能描述

将文字提示词转换为模型可以理解的条件编码。

#### 节点结构

```
节点输入：
  - clip: CLIP 类型（来自 Checkpoint 或 Load CLIP）
  - text: 提示词文本

节点输出：
  - CONDITIONING: 条件编码（连接到 KSampler）
```

#### 参数说明

| 参数名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| clip | CLIP | CLIP 模型输入 | 来自 Load Checkpoint |
| text | 文本框 | 提示词内容 | "a beautiful landscape" |

#### 使用示例

**正向提示词节点：**
```
输入：
  clip: 来自 Checkpoint
  text: masterpiece, best quality, 1girl, long hair, smiling

输出：
  CONDITIONING → 连接到 KSampler 的 positive 输入
```

**负向提示词节点：**
```
输入：
  clip: 来自 Checkpoint
  text: low quality, blurry, distorted, ugly, bad anatomy

输出：
  CONDITIONING → 连接到 KSampler 的 negative 输入
```

### CLIP Text Encode (SDXL) 节点

#### 功能描述

SDXL 专用的文本编码节点，支持同时编码两个提示词（宽和窄）。

#### 参数说明

| 参数名 | 说明 |
|--------|------|
| text_g | 宽提示词（描述整体场景） |
| text_l | 窄提示词（描述细节） |

#### 使用示例

```
text_g: a beautiful woman in a garden
text_l: detailed face, jewelry, flowers

两个提示词会合并编码，产生更好的效果
```

## 2.7.6 提示词编写技巧

### 基本原则

| 原则 | 说明 | 示例 |
|------|------|------|
| 从重要到次要 | 重要的词放在前面 | "cat, sitting, garden" |
| 使用质量词 | 添加质量相关词 | "masterpiece, best quality" |
| 具体描述 | 越具体越好 | "fluffy orange cat" 而不是 "cat" |
| 使用负向提示词 | 排除不想要的元素 | "low quality, blurry" |

### 常用提示词模板

**人物生成：**
```
正向：masterpiece, best quality, 1girl, [详细描述], [服装], [姿势], [场景]
负向：low quality, worst quality, bad anatomy, bad hands, text, watermark
```

**风景生成：**
```
正向：masterpiece, best quality, landscape, [场景描述], [时间], [天气], [风格]
负向：low quality, blurry, text, watermark, people
```

**物品生成：**
```
正向：masterpiece, best quality, [物品], [材质], [颜色], [背景], [光照]
负向：low quality, blurry, text, watermark
```

## 2.7.7 注意事项

### CLIP 相关

| 注意点 | 说明 |
|--------|------|
| 模型匹配 | 不同模型需要匹配的 CLIP 版本 |
| 提示词长度 | CLIP 有 token 限制，过长会被截断 |
| 特殊字符 | 某些特殊字符可能导致编码错误 |

### T5 相关

| 注意点 | 说明 |
|--------|------|
| 显存需求 | T5 模型较大，需要足够显存 |
| 量化版本 | 显存不足时可使用 fp8 量化版本 |
| 下载位置 | 确保放在正确的目录 |

### 常见问题

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 提示词不生效 | CLIP 未正确连接 | 检查节点连接 |
| 生成结果与描述不符 | 提示词权重问题 | 调整提示词顺序或权重 |
| 找不到 CLIP | 模型未正确加载 | 检查 Checkpoint 是否包含 CLIP |
| T5 加载失败 | 文件位置错误或显存不足 | 检查文件位置，尝试量化版本 |
