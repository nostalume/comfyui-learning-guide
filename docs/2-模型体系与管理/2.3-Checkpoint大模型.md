## 2.3.3 模型选择指南

```
选择流程：

1. 确定风格需求
   ├── 写实/摄影 → Realistic Vision / Juggernaut
   ├── 动漫/二次元 → Anything / Animagine
   └── 艺术/插画 → DreamShaper

2. 确定硬件条件
   ├── 4-6GB 显存 → SD 1.5
   ├── 8-12GB 显存 → SDXL
   └── 16GB+ 显存 → Flux

3. 确定分辨率需求
   ├── 512-768 → SD 1.5
   └── 1024+ → SDXL / Flux
```

## 2.3.4 Load Checkpoint 节点使用

```
节点输入：无
节点输出：
  - MODEL: UNet 模型
  - CLIP: 文本编码器
  - VAE: 变分自编码器

参数：
  - ckpt_name: 选择模型文件
```

**使用方法：**

1. 双击画布，搜索 "Load Checkpoint"
2. 点击节点中的 `ckpt_name` 下拉框
3. 选择已放置在 `models/checkpoints/` 目录下的模型
