## 2.6.1 概念说明

### 什么是 IP-Adapter？

**IP-Adapter**（Image Prompt Adapter，图像提示适配器）是一种让 AI 模型"看图说话"的技术。

#### 功能描述（通俗易懂）

传统的 AI 绘图主要靠文字描述（提示词）来控制生成内容。但有时候：
- 用文字描述一张图片的风格很难
- 想让生成的人物长得像某张参考图
- 想要复制某张图的构图

IP-Adapter 解决了这个问题：**用图片作为提示词**！

**类比理解：**

| 传统方式 | IP-Adapter 方式 |
|----------|-----------------|
| 告诉画家"画一个穿红裙子的女孩" | 给画家一张参考照片说"画成这个风格" |
| 需要详细描述风格特征 | 直接展示风格参考图 |
| 可能描述不准确 | 图片即所见即所得 |

#### 核心优势

- **风格迁移**：一张图片就能复制风格
- **人物一致性**：保持人物特征不变
- **构图参考**：复制参考图的构图结构
- **无需训练**：不像 LoRA 需要训练，即插即用

#### "1-image LoRA" 的含义

IP-Adapter 有时被称为"单图 LoRA"，意思是：
- LoRA 需要多张图片训练才能学会某种风格/角色
- IP-Adapter 只需要一张参考图就能实现类似效果

> ⚠️ **时效性说明：** IP-Adapter Plus 仓库已于 2025.04 进入"仅维护"模式，不再计划新功能开发。现有功能稳定可用，但建议关注社区替代方案。

## 2.6.2 IP-Adapter 类型对比

### 四种主要类型

| 类型 | 特点 | 适用场景 | 权重建议 |
|------|------|----------|----------|
| IP-Adapter | 标准版本，通用性强 | 风格迁移、构图参考 | 0.5-1.0 |
| IP-Adapter Plus | 更强特征提取，细节保持 | 高质量风格迁移 | 0.6-1.0 |
| IP-Adapter Face | 人脸专用，五官特征保持 | 人脸风格化 | 0.8-1.2 |
| IP-Adapter FaceID | 身份保持，人物一致性 | 人物换装、多角度生成 | 0.8-1.0 |

### 类型详解

#### IP-Adapter（标准版）

**功能描述：**
最基础的版本，适合大多数场景。

**使用场景：**
- 风格迁移（让生成的图具有参考图的风格）
- 构图参考（复制参考图的构图结构）
- 色彩参考（复制参考图的色调）

**示例：**
```
参考图：一张赛博朋克风格的城市夜景
生成图：相同风格的另一个城市
```

#### IP-Adapter Plus

**功能描述：**
增强版本，特征提取能力更强，能保留更多细节。

**使用场景：**
- 需要高质量风格迁移
- 参考图细节很重要
- 标准 IP-Adapter 效果不够好时

**示例：**
```
参考图：一幅油画作品
生成图：相同油画风格的人物肖像
Plus 版本能更好地保留笔触质感
```

#### IP-Adapter Face

**功能描述：**
专门针对人脸优化的版本，能更好地保持五官特征。

**使用场景：**
- 人脸风格化
- 保持人物面部特征
- 人像生成

**示例：**
```
参考图：一张真人照片
生成图：动漫风格的同一人物
Face 版本能保持五官相似
```

#### IP-Adapter FaceID

**功能描述：**
最强的身份保持版本，能让不同角度、不同服装的人物保持身份一致。

**使用场景：**
- 人物换装（同一人物穿不同衣服）
- 多角度生成（同一人物不同姿势）
- 角色一致性要求高的场景

**示例：**
```
参考图：一张正面人物照
生成图：同一人物的侧面、背影、不同服装
FaceID 版本能确保是同一个人
```

## 2.6.3 模型文件要求

### CLIP Vision 模型（必需）

#### 功能描述

CLIP Vision 是 IP-Adapter 的"眼睛"，负责"看懂"参考图片。

#### 放置目录

`ComfyUI/models/clip_vision/`

#### 模型选择

| 模型文件 | 大小 | 用途 | 下载来源 |
|----------|------|------|----------|
| CLIP-ViT-H-14-laion2B-s32B-b79K.safetensors | ~2.5GB | SD 1.5 / SDXL 通用 | HuggingFace |
| CLIP-ViT-bigG-14-laion2B-39B-b160k.safetensors | ~3.5GB | SDXL 高质量 | HuggingFace |

**选择建议：**
- 新手入门：使用 H-14 版本（体积小，够用）
- 追求质量：使用 bigG-14 版本（效果更好）

### IP-Adapter 模型

#### 放置目录

`ComfyUI/models/ipadapter/`

#### SD 1.5 模型

| 模型文件 | 说明 | 特点 | 使用场景 |
|----------|------|------|----------|
| ip-adapter_sd15.safetensors | SD 1.5 基础模型 | 通用，速度快 | 一般风格迁移 |
| ip-adapter-plus_sd15.safetensors | SD 1.5 Plus 模型 | 细节更好 | 高质量风格迁移 |
| ip-adapter-plus-face_sd15.safetensors | SD 1.5 人脸模型 | 人脸专用 | 人脸风格化 |
| ip-adapter-faceid_sd15.bin | FaceID 模型 | 身份保持 | 人物一致性 |

#### SDXL 模型

| 模型文件 | 说明 | 使用场景 |
|----------|------|----------|
| ip-adapter_sdxl_vit-h.safetensors | SDXL 基础模型 | SDXL 风格迁移 |
| ip-adapter-plus_sdxl_vit-h.safetensors | SDXL Plus 模型 | SDXL 高质量迁移 |
| ip-adapter-faceid-plusv2_sdxl.bin | SDXL FaceID | SDXL 人物一致性 |

## 2.6.4 FaceID 模型配置

### 功能描述

FaceID 是 IP-Adapter 中最强大的身份保持功能，需要额外安装 InsightFace 库。

### 安装 InsightFace

```bash
pip install insightface onnxruntime
```

> ⚠️ **注意：** Windows 用户可能需要安装 Visual C++ Build Tools。

### InsightFace 模型

**放置目录：** `ComfyUI/models/insightface/antelopev2/`

**下载步骤：**
1. 从 HuggingFace 下载 `antelopev2` 模型
2. 解压后放置到指定目录

### FaceID LoRA 文件

FaceID 需要配合专用 LoRA 使用：

| FaceID 模型 | 对应 LoRA | 放置位置 |
|-------------|-----------|----------|
| ip-adapter-faceid_sd15.bin | ip-adapter-faceid_sd15_lora.safetensors | models/lora/ |
| ip-adapter-faceid-plusv2_sd15.bin | ip-adapter-faceid-plusv2_sd15_lora.safetensors | models/lora/ |

## 2.6.5 核心节点说明

### IPAdapter Apply 节点

#### 功能描述

将 IP-Adapter 应用到模型上，使模型能够"参考"输入的图片。

#### 输入参数详解

| 参数名 | 类型 | 说明 | 推荐值 |
|--------|------|------|--------|
| model | MODEL | 模型输入 | 来自 Checkpoint |
| ipadapter | IPADAPTER | IP-Adapter 模型 | 需要先加载 IP-Adapter |
| image | IMAGE | 参考图片 | Load Image 节点输出 |
| weight | FLOAT | 影响权重 | 0.5-1.0 |
| start_at | FLOAT | 开始影响步数 | 0.0 |
| end_at | FLOAT | 结束影响步数 | 1.0 |

#### 参数详解

**weight（权重）：**
- 控制参考图对生成结果的影响程度
- 0.5：轻微影响
- 0.8：中等影响
- 1.0：强烈影响
- 过高可能导致生成图与参考图过于相似

**start_at / end_at（影响范围）：**
- 控制参考图在采样过程中何时起作用
- start_at=0, end_at=1：全程影响
- start_at=0, end_at=0.5：前半程影响（主要影响构图）
- start_at=0.5, end_at=1：后半程影响（主要影响细节）

### IPAdapter Apply FaceID 节点

> ⚠️ **版本说明：** v2 版本使用专用 FaceID 节点，基础 IPAdapter Apply 节点不支持 FaceID 模型。

#### 额外参数

| 参数名 | 说明 | 推荐值 |
|--------|------|--------|
| weight_v2 | FaceID v2 权重 | 0.8-1.0 |
| mode | 模式选择 | 根据需求选择 |

#### mode 模式说明

| 模式 | 说明 | 使用场景 |
|------|------|----------|
| original | 原始模式 | 通用场景 |
| style | 风格模式 | 保持身份同时迁移风格 |
| composition | 构图模式 | 保持身份同时参考构图 |

## 2.6.6 使用场景与工作流

### 场景一：风格迁移

#### 需求描述

想让生成的图片具有某张参考图的风格（如油画、水彩、动漫等）。

#### 解决方案

使用 IP-Adapter 标准版或 Plus 版。

#### 工作流

```
Load Image (风格参考图) → IPAdapter Apply (weight=0.8)
                              ↓
Checkpoint Loader → KSampler → VAE Decode → Save Image
```

#### 参数建议

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| weight | 0.7-0.9 | 风格迁移建议值 |
| start_at | 0.0 | 从头开始影响 |
| end_at | 1.0 | 全程影响 |

#### 提示词建议

```
正向：in the style of [参考图风格], masterpiece, best quality
负向：low quality, blurry, distorted
```

#### 示例

```
参考图：梵高的《星空》
提示词：a peaceful village at night
结果：梵高风格的村庄夜景
```

### 场景二：人物一致性

#### 需求描述

想让多张生成的图片中的人物保持同一张脸（如换装、换场景）。

#### 解决方案

使用 IP-Adapter FaceID。

#### 工作流

```
Load Image (人物参考) → IPAdapter Apply FaceID
                              ↓
Checkpoint Loader → KSampler → VAE Decode → Save Image
```

#### 参数建议

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| weight | 0.8-1.0 | 人物一致性需要较高权重 |
| mode | original 或 style | 根据需求选择 |

#### 注意事项

- 参考图需包含清晰正面人脸
- 建议配合 ControlNet OpenPose 使用
- weight 建议设置 0.8-1.0

#### 示例

```
参考图：一张正面人物照
提示词：1girl, wearing red dress, standing in garden
结果：同一人物穿红裙子在花园
```

### 场景三：构图参考

#### 需求描述

想让生成的图片具有与参考图相似的构图结构。

#### 解决方案

使用 IP-Adapter 的 composition 模式或调整 start_at/end_at。

#### 工作流

```
Load Image (构图参考) → IPAdapter Apply (weight=0.6, mode=composition)
                              ↓
Checkpoint Loader → KSampler → VAE Decode → Save Image
```

#### 参数建议

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| weight | 0.5-0.7 | 构图参考不需要太高 |
| start_at | 0.0 | 从头开始 |
| end_at | 0.5 | 只影响前半程（构图阶段） |

#### 示例

```
参考图：一张三分法构图的照片
提示词：a cat sitting on a chair
结果：猫坐在椅子上，构图与参考图相似
```

## 2.6.7 高级技巧

### 多 IP-Adapter 组合

#### 功能描述

可以同时使用多个 IP-Adapter，分别控制不同方面。

#### 使用场景

- 同时控制风格和人物
- 同时参考多张图片

#### 工作流

```
参考图1 (风格) → IPAdapter Apply (weight=0.5)
参考图2 (人物) → IPAdapter Apply FaceID (weight=0.8)
                              ↓
                        KSampler
```

#### 示例

```
参考图1：梵高风格画作
参考图2：某人物照片
结果：该人物的梵高风格肖像
```

### 权重衰减控制

#### 功能描述

通过 start_at 和 end_at 控制参考图在不同采样阶段的影响程度。

#### 参数设置

| 设置 | 效果 | 使用场景 |
|------|------|----------|
| start_at=0.0, end_at=1.0 | 全程影响 | 通用场景 |
| start_at=0.0, end_at=0.5 | 前半程影响（构图） | 只想参考构图 |
| start_at=0.5, end_at=1.0 | 后半程影响（细节） | 只想参考细节风格 |

### 与 ControlNet 配合

#### 功能描述

IP-Adapter 与 ControlNet 可以同时使用，实现更精确的控制。

#### 工作流

```
参考图 → IPAdapter Apply
结构图 → ControlNet Apply
              ↓
        KSampler (双重控制)
```

#### 使用场景

| IP-Adapter 作用 | ControlNet 作用 | 结果 |
|-----------------|-----------------|------|
| 风格参考 | 姿势控制 | 特定姿势的风格化图片 |
| 人物参考 | 边缘控制 | 保持人物特征的精确轮廓 |
| 构图参考 | 深度控制 | 保持构图的空间深度 |

## 2.6.8 常见问题

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 找不到 CLIP Vision 模型 | 模型未下载或位置错误 | 检查 models/clip_vision/ 目录 |
| FaceID 效果差 | InsightFace 模型未正确安装 | 确保 InsightFace 模型正确安装 |
| 风格迁移不明显 | weight 值太低 | 提高 weight 值或使用 Plus 模型 |
| 人物变形 | weight 过高或参考图质量差 | 降低 weight 或配合 ControlNet |
| 参考图特征丢失 | 使用了错误的 IP-Adapter 类型 | 根据需求选择正确的类型 |
| 颜色偏差 | CLIP Vision 模型不匹配 | 尝试更换 CLIP Vision 模型 |
