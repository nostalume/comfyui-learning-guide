## 概述

### 什么是视频工具集成？

**功能描述：**
视频工具集成是指将 ComfyUI 与视频编辑工具结合，实现 AI 视频生成、视频转绘、帧序列处理等功能，将 AI 图像生成能力扩展到视频领域。

**核心价值：**
- 🎬 **视频转绘**：将现有视频转换为不同风格
- 🎨 **AI 动画**：使用 AnimateDiff 生成动画
- ⚡ **批量处理**：高效处理大量帧图像
- 🔗 **工作流整合**：与专业剪辑软件无缝配合

**使用场景：**
| 场景 | 说明 | 工具组合 |
|------|------|----------|
| 视频风格化 | 将视频转换为动漫/油画风格 | FFmpeg + ComfyUI |
| AI 动画创作 | 从静态图像生成动画 | AnimateDiff |
| 视频后期处理 | AI 增强视频质量 | DaVinci + ComfyUI |
| 短视频制作 | 快速生成创意视频 | Premiere + ComfyUI |

## FFmpeg 基础教程

### 什么是 FFmpeg？

**功能描述：**
FFmpeg 是一款强大的开源音视频处理工具，支持视频格式转换、压缩、剪辑、合并等操作，是与 ComfyUI 视频集成的核心工具。

**为什么需要 FFmpeg？**
- 将视频拆分为帧序列供 ComfyUI 处理
- 将处理后的帧序列合成为视频
- 视频格式转换和压缩
- 音视频同步处理

### FFmpeg 安装教程

#### Windows 安装步骤

**方法一：使用安装包（推荐新手）**

1. **下载 FFmpeg**
   - 访问：https://www.gyan.dev/ffmpeg/builds/
   - 下载「ffmpeg-release-essentials.zip」

2. **解压文件**
   - 解压到 `C:\ffmpeg`
   - 确保目录结构为：`C:\ffmpeg\bin\ffmpeg.exe`

3. **配置环境变量**
   - 右键「此电脑」→「属性」→「高级系统设置」
   - 点击「环境变量」
   - 在「系统变量」中找到「Path」，点击「编辑」
   - 点击「新建」，添加 `C:\ffmpeg\bin`
   - 点击「确定」保存

4. **验证安装**
   - 打开命令提示符（Win + R → 输入 cmd）
   - 输入：`ffmpeg -version`
   - 显示版本信息则安装成功

**方法二：使用包管理器（推荐开发者）**

```powershell
# 使用 Chocolatey
choco install ffmpeg

# 或使用 Scoop
scoop install ffmpeg
```

#### Mac 安装步骤

```bash
# 使用 Homebrew
brew install ffmpeg
```

#### Linux 安装步骤

```bash
# Ubuntu/Debian
sudo apt update
sudo apt install ffmpeg

# CentOS/RHEL
sudo yum install ffmpeg

# Arch Linux
sudo pacman -S ffmpeg
```

### FFmpeg 基础命令详解

#### 命令基本结构

```bash
ffmpeg [全局选项] [输入文件选项] -i 输入文件 [输出文件选项] 输出文件
```

**参数说明：**

| 参数 | 功能描述 | 示例 |
|------|----------|------|
| -i | 指定输入文件 | `-i input.mp4` |
| -c:v | 视频编码器 | `-c:v libx264` |
| -c:a | 音频编码器 | `-c:a aac` |
| -b:v | 视频比特率 | `-b:v 5M` |
| -b:a | 音频比特率 | `-b:a 128k` |
| -r | 帧率 | `-r 30` |
| -s | 分辨率 | `-s 1920x1080` |
| -t | 时长（秒） | `-t 10` |
| -ss | 起始时间 | `-ss 00:01:00` |

## 视频拆帧详细教程

### 什么是视频拆帧？

**功能描述：**
视频拆帧是将视频文件分解为单独的图像帧，以便 ComfyUI 逐帧处理。

**使用场景：**
- 视频风格化转绘
- 视频质量增强
- 特效处理

### 基础拆帧命令

#### 命令一：基本拆帧

```bash
ffmpeg -i input.mp4 frames/frame_%04d.png
```

**参数详解：**

| 参数 | 功能描述 | 说明 |
|------|----------|------|
| -i input.mp4 | 输入视频文件 | 支持所有常见格式 |
| frames/ | 输出目录 | 需提前创建 |
| frame_%04d.png | 输出文件名格式 | %04d 表示4位数字编号 |

**输出示例：**
```
frames/
├── frame_0001.png
├── frame_0002.png
├── frame_0003.png
└── ...
```

#### 命令二：指定帧率拆帧

```bash
ffmpeg -i input.mp4 -vf fps=24 frames/frame_%04d.png
```

**参数详解：**

| 参数 | 功能描述 | 推荐值 | 说明 |
|------|----------|--------|------|
| -vf fps=24 | 设置输出帧率 | 24/30/60 | 降低帧率可减少帧数 |

**使用场景：**
- 原视频帧率过高，需要降帧
- 只需要部分帧进行处理

#### 命令三：指定时间范围拆帧

```bash
ffmpeg -i input.mp4 -ss 00:00:10 -t 5 -vsync 0 frames/frame_%04d.png
```

**参数详解：**

| 参数 | 功能描述 | 示例 | 说明 |
|------|----------|------|------|
| -ss | 起始时间 | 00:00:10 | 从第10秒开始 |
| -t | 持续时间 | 5 | 处理5秒内容 |
| -vsync 0 | 保持原始时间戳 | - | 防止丢帧 |

#### 命令四：指定分辨率拆帧

```bash
ffmpeg -i input.mp4 -vf "scale=512:512" frames/frame_%04d.png
```

**参数详解：**

| 参数 | 功能描述 | 说明 |
|------|----------|------|
| scale=512:512 | 缩放到512x512 | 正方形输出 |
| scale=512:-1 | 宽度512，高度自动 | 保持宽高比 |
| scale=-1:512 | 高度512，宽度自动 | 保持宽高比 |

### 高级拆帧技巧

#### 按间隔拆帧（每N帧取1帧）

```bash
ffmpeg -i input.mp4 -vf "select=not(mod(n\,2))" -vsync vfr frames/frame_%04d.png
```

**参数说明：**
- `select=not(mod(n\,2))`：每2帧取1帧
- `select=not(mod(n\,5))`：每5帧取1帧
- `-vsync vfr`：可变帧率输出

#### 拆帧同时提取音频

```bash
ffmpeg -i input.mp4 -vn -acodec copy audio.aac
ffmpeg -i input.mp4 frames/frame_%04d.png
```

**参数说明：**
- `-vn`：不处理视频
- `-acodec copy`：直接复制音频流

## 帧合成视频详细教程

### 基础合成命令

#### 命令一：基本合成

```bash
ffmpeg -framerate 24 -i frames/frame_%04d.png -c:v libx264 output.mp4
```

**参数详解：**

| 参数 | 功能描述 | 推荐值 | 说明 |
|------|----------|--------|------|
| -framerate | 输入帧率 | 24 | 必须与拆帧时一致 |
| -i frames/frame_%04d.png | 输入帧序列 | - | 格式要与拆帧时一致 |
| -c:v libx264 | 视频编码器 | libx264 | H.264编码 |
| output.mp4 | 输出文件 | - | 支持mp4/mkv/mov等 |

#### 命令二：带音频合成

```bash
ffmpeg -framerate 24 -i frames/frame_%04d.png -i audio.aac -c:v libx264 -c:a aac -shortest output.mp4
```

**参数详解：**

| 参数 | 功能描述 | 说明 |
|------|----------|------|
| -i audio.aac | 输入音频文件 | 支持mp3/aac/wav等 |
| -c:a aac | 音频编码器 | AAC编码 |
| -shortest | 以最短的流为准 | 防止音视频不同步 |

#### 命令三：高质量合成

```bash
ffmpeg -framerate 24 -i frames/frame_%04d.png -c:v libx264 -preset slow -crf 18 -pix_fmt yuv420p output.mp4
```

**参数详解：**

| 参数 | 功能描述 | 推荐值 | 说明 |
|------|----------|--------|------|
| -preset | 编码速度预设 | slow/medium/fast | slow质量最高 |
| -crf | 质量因子 | 18-23 | 越小质量越高 |
| -pix_fmt | 像素格式 | yuv420p | 兼容性最好 |

**CRF 值参考：**

| CRF 值 | 质量 | 文件大小 | 使用场景 |
|--------|------|----------|----------|
| 0-17 | 无损/极高质量 | 极大 | 专业制作 |
| 18-23 | 高质量 | 大 | 推荐使用 |
| 24-28 | 中等质量 | 中 | 网络分享 |
| 29+ | 低质量 | 小 | 快速预览 |

### 视频压缩命令

#### 压缩视频文件

```bash
ffmpeg -i input.mp4 -c:v libx264 -crf 28 -preset medium output.mp4
```

**参数详解：**

| 参数 | 功能描述 | 推荐值 | 说明 |
|------|----------|--------|------|
| -crf | 压缩质量 | 23-28 | 值越大压缩率越高 |
| -preset | 编码速度 | medium | faster更快但质量略低 |

#### 调整视频分辨率

```bash
ffmpeg -i input.mp4 -vf "scale=1280:-1" -c:v libx264 -crf 23 output.mp4
```

#### 限制文件大小

```bash
ffmpeg -i input.mp4 -c:v libx264 -b:v 1M -c:a aac -b:a 128k output.mp4
```

**参数说明：**
- `-b:v 1M`：视频比特率 1Mbps
- `-b:a 128k`：音频比特率 128kbps

## 视频格式转换详解

### 常用格式转换命令

#### MP4 转 WebM

```bash
ffmpeg -i input.mp4 -c:v libvpx-vp9 -crf 30 -b:v 0 -c:a libopus output.webm
```

**参数详解：**

| 参数 | 功能描述 | 说明 |
|------|----------|------|
| libvpx-vp9 | VP9 编码器 | WebM 专用 |
| -crf 30 | 质量因子 | WebM 推荐值 |
| -b:v 0 | 无限比特率 | 配合 CRF 使用 |
| libopus | Opus 音频编码器 | 高质量音频 |

#### MP4 转 GIF

```bash
ffmpeg -i input.mp4 -vf "fps=10,scale=320:-1:flags=lanczos" -loop 0 output.gif
```

**参数详解：**

| 参数 | 功能描述 | 推荐值 | 说明 |
|------|----------|--------|------|
| fps=10 | 输出帧率 | 10-15 | GIF 帧率不宜过高 |
| scale=320:-1 | 宽度320，高度自适应 | 320-640 | 控制文件大小 |
| flags=lanczos | 缩放算法 | lanczos | 高质量缩放 |
| -loop 0 | 无限循环 | 0 | 0=无限循环 |

#### 视频提取音频

```bash
ffmpeg -i input.mp4 -vn -acodec copy output.aac
```

#### 音频添加到视频

```bash
ffmpeg -i video.mp4 -i audio.mp3 -c:v copy -c:a aac -map 0:v:0 -map 1:a:0 output.mp4
```

**参数说明：**
- `-map 0:v:0`：使用第一个输入的视频流
- `-map 1:a:0`：使用第二个输入的音频流

## AnimateDiff 视频生成

### 什么是 AnimateDiff？

**功能描述：**
AnimateDiff 是一种让 Stable Diffusion 模型生成连贯动画的技术，可以从静态图像或文本提示生成动画视频。

**核心优势：**
- 🎬 从文本生成动画
- 🎨 保持风格一致性
- ⚡ 支持多种运动效果
- 🔧 可控的运动参数

### AnimateDiff 插件安装

**安装步骤：**

1. **通过 ComfyUI Manager 安装**
   - 打开 Manager → Install Custom Nodes
   - 搜索「AnimateDiff Evolved」
   - 点击 Install

2. **下载模型文件**
   - 访问：https://huggingface.co/guoyww/animatediff
   - 下载 `mm_sd_v15_v2.ckpt`
   - 放置到：`ComfyUI/custom_nodes/ComfyUI-AnimateDiff-Evolved/models/`

### 基础 AnimateDiff 工作流

**节点连接图：**

```
┌─────────────────┐     ┌─────────────────┐     ┌─────────────────┐
│ Checkpoint      │────→│ AnimateDiff     │────→│   KSampler      │
│ Loader          │     │ Loader          │     │                 │
└─────────────────┘     └─────────────────┘     └────────┬────────┘
                                                         │
┌─────────────────┐     ┌─────────────────┐             │
│ CLIP Text       │────→│                 │             │
│ Encode (prompt) │     │                 │             │
└─────────────────┘     └─────────────────┘             │
                                                         │
                                              ┌──────────▼──────────┐
                                              │     VAE Decode      │
                                              └──────────┬──────────┘
                                                         │
                                              ┌──────────▼──────────┐
                                              │  AnimateDiff        │
                                              │  Combine            │
                                              └─────────────────────┘
```

### AnimateDiff 参数详解

#### AnimateDiff Loader 节点

| 参数 | 功能描述 | 推荐值 | 说明 |
|------|----------|--------|------|
| model_name | 模型名称 | mm_sd_v15_v2.ckpt | 动画模型文件 |
| motion_scale | 运动强度 | 1.0 | 值越大运动越剧烈 |
| min_context | 最小上下文 | 16 | 处理的最小帧数 |
| max_context | 最大上下文 | 16 | 处理的最大帧数 |

#### AnimateDiff Sampler 节点

| 参数 | 功能描述 | 推荐值 | 说明 |
|------|----------|--------|------|
| frame_count | 生成帧数 | 16-32 | 帧数越多视频越长 |
| context_length | 上下文长度 | 16-24 | 影响连贯性 |
| context_stride | 上下文步长 | 1 | 通常保持默认 |
| context_overlap | 上下文重叠 | 4-8 | 增加连贯性 |

### 长视频生成技巧

**使用 Context Options：**

```yaml
# 滑动窗口设置
context_length: 16
context_stride: 1
context_overlap: 4
```

**工作流配置：**

1. 添加「ADE_AnimateDiffUniformContextOptions」节点
2. 设置 context_length = 16
3. 设置 context_overlap = 4
4. 连接到 AnimateDiff Sampler

## 视频转绘完整流程

### 准备工作

1. **准备视频文件**
   - 建议时长：5-30秒
   - 建议分辨率：512x512 或 768x768
   - 建议帧率：24fps

2. **创建工作目录**
   ```
   video_project/
   ├── input_video.mp4
   ├── frames/
   ├── processed_frames/
   └── output_video.mp4
   ```

### 步骤一：拆帧

```bash
mkdir frames
ffmpeg -i input_video.mp4 -vf "fps=24,scale=512:-1" frames/frame_%04d.png
```

### 步骤二：ComfyUI 批量处理

**工作流配置：**

1. **Load Image 节点**
   - 设置为批量模式
   - 选择 frames 目录

2. **ControlNet 配置（可选）**
   - Depth ControlNet：保持场景结构
   - OpenPose ControlNet：保持人物姿态

3. **KSampler 设置**
   
   | 参数 | 推荐值 | 说明 |
   |------|--------|------|
   | seed | 固定值 | 保持一致性 |
   | denoise | 0.5-0.7 | 转绘强度 |
   | steps | 20-25 | 采样步数 |

### 步骤三：合成视频

```bash
ffmpeg -framerate 24 -i processed_frames/frame_%04d.png -c:v libx264 -crf 20 output_video.mp4
```

### 减少闪烁技巧

| 方法 | 功能描述 | 效果 |
|------|----------|------|
| 固定 seed | 使用相同的随机种子 | 保持一致性 |
| 降低 denoise | 减少重绘强度 | 保留更多原始帧 |
| 使用 ControlNet | 保持结构稳定 | 减少抖动 |
| 帧间混合 | 平滑过渡 | 减少闪烁 |

## 自动化脚本

### Python 完整自动化脚本

```python
import subprocess
import os
import json
import requests
import time
from pathlib import Path

class VideoProcessor:
    """
    视频处理自动化类
    
    功能描述：
    - 视频拆帧
    - ComfyUI 批量处理
    - 视频合成
    """
    
    def __init__(self, comfyui_url: str = "http://localhost:8188"):
        """
        初始化处理器
        
        参数详解：
        - comfyui_url: ComfyUI 服务地址
        """
        self.comfyui_url = comfyui_url
        self.frames_dir = "temp_frames"
        self.output_dir = "output_frames"
    
    def extract_frames(
        self,
        video_path: str,
        fps: int = 24,
        scale: str = "512:-1"
    ) -> list:
        """
        从视频提取帧
        
        参数详解：
        - video_path: 视频文件路径
        - fps: 输出帧率
        - scale: 缩放参数，格式 "宽:高"
        
        返回值：
        - 帧文件路径列表
        """
        os.makedirs(self.frames_dir, exist_ok=True)
        
        cmd = [
            "ffmpeg",
            "-i", video_path,
            "-vf", f"fps={fps},scale={scale}",
            "-vsync", "0",
            f"{self.frames_dir}/frame_%04d.png"
        ]
        
        print(f"执行命令: {' '.join(cmd)}")
        subprocess.run(cmd, check=True)
        
        frames = sorted([
            os.path.join(self.frames_dir, f)
            for f in os.listdir(self.frames_dir)
            if f.endswith('.png')
        ])
        
        print(f"已提取 {len(frames)} 帧")
        return frames
    
    def process_with_comfyui(
        self,
        workflow_path: str,
        input_dir: str = None,
        output_dir: str = None
    ) -> list:
        """
        使用 ComfyUI 处理帧
        
        参数详解：
        - workflow_path: 工作流 JSON 文件路径
        - input_dir: 输入目录（默认使用 frames_dir）
        - output_dir: 输出目录（默认使用 output_dir）
        
        返回值：
        - 处理后的帧路径列表
        """
        input_dir = input_dir or self.frames_dir
        output_dir = output_dir or self.output_dir
        os.makedirs(output_dir, exist_ok=True)
        
        with open(workflow_path, 'r', encoding='utf-8') as f:
            workflow = json.load(f)
        
        frames = sorted([
            f for f in os.listdir(input_dir)
            if f.endswith('.png')
        ])
        
        processed = []
        
        for i, frame in enumerate(frames):
            print(f"处理帧 {i+1}/{len(frames)}: {frame}")
            
            frame_path = os.path.join(input_dir, frame)
            
            with open(frame_path, 'rb') as f:
                response = requests.post(
                    f"{self.comfyui_url}/upload/image",
                    files={'image': f}
                )
            
            image_name = response.json()['name']
            
            for node_id, node in workflow.items():
                if node.get('class_type') == 'LoadImage':
                    node['inputs']['image'] = image_name
            
            response = requests.post(
                f"{self.comfyui_url}/prompt",
                json={"prompt": workflow}
            )
            
            prompt_id = response.json()['prompt_id']
            
            result = self._wait_for_completion(prompt_id)
            
            output_path = self._save_result(result, output_dir, frame)
            processed.append(output_path)
        
        return processed
    
    def _wait_for_completion(self, prompt_id: str, timeout: int = 120) -> dict:
        """
        等待任务完成
        
        参数详解：
        - prompt_id: 任务 ID
        - timeout: 超时时间（秒）
        
        返回值：
        - 任务结果
        """
        start_time = time.time()
        
        while time.time() - start_time < timeout:
            response = requests.get(
                f"{self.comfyui_url}/history/{prompt_id}"
            )
            history = response.json()
            
            if prompt_id in history:
                return history[prompt_id]
            
            time.sleep(1)
        
        raise TimeoutError(f"任务 {prompt_id} 超时")
    
    def _save_result(self, result: dict, output_dir: str, original_name: str) -> str:
        """
        保存处理结果
        
        参数详解：
        - result: 任务结果
        - output_dir: 输出目录
        - original_name: 原始文件名
        
        返回值：
        - 保存的文件路径
        """
        for node_id, output in result.get('outputs', {}).items():
            if 'images' in output:
                for image_info in output['images']:
                    response = requests.get(
                        f"{self.comfyui_url}/view",
                        params={
                            "filename": image_info['filename'],
                            "subfolder": image_info.get('subfolder', ''),
                            "type": "output"
                        }
                    )
                    
                    output_path = os.path.join(output_dir, original_name)
                    with open(output_path, 'wb') as f:
                        f.write(response.content)
                    
                    return output_path
        
        raise Exception("未找到输出图像")
    
    def combine_to_video(
        self,
        output_path: str,
        fps: int = 24,
        audio_path: str = None,
        crf: int = 20
    ) -> str:
        """
        将帧合成为视频
        
        参数详解：
        - output_path: 输出视频路径
        - fps: 帧率
        - audio_path: 音频文件路径（可选）
        - crf: 质量因子
        
        返回值：
        - 输出视频路径
        """
        cmd = [
            "ffmpeg",
            "-framerate", str(fps),
            "-i", f"{self.output_dir}/frame_%04d.png",
            "-c:v", "libx264",
            "-preset", "medium",
            "-crf", str(crf),
            "-pix_fmt", "yuv420p"
        ]
        
        if audio_path:
            cmd.extend(["-i", audio_path, "-c:a", "aac", "-shortest"])
        
        cmd.append(output_path)
        
        print(f"执行命令: {' '.join(cmd)}")
        subprocess.run(cmd, check=True)
        
        print(f"视频已保存: {output_path}")
        return output_path
    
    def cleanup(self):
        """
        清理临时文件
        """
        import shutil
        if os.path.exists(self.frames_dir):
            shutil.rmtree(self.frames_dir)
        if os.path.exists(self.output_dir):
            shutil.rmtree(self.output_dir)
        print("临时文件已清理")
    
    def process_video(
        self,
        video_path: str,
        workflow_path: str,
        output_path: str,
        fps: int = 24,
        scale: str = "512:-1",
        keep_temp: bool = False
    ) -> str:
        """
        完整视频处理流程
        
        参数详解：
        - video_path: 输入视频路径
        - workflow_path: 工作流 JSON 路径
        - output_path: 输出视频路径
        - fps: 帧率
        - scale: 缩放参数
        - keep_temp: 是否保留临时文件
        
        返回值：
        - 输出视频路径
        """
        try:
            print("=" * 50)
            print("步骤 1: 提取帧")
            print("=" * 50)
            self.extract_frames(video_path, fps, scale)
            
            print("\n" + "=" * 50)
            print("步骤 2: ComfyUI 处理")
            print("=" * 50)
            self.process_with_comfyui(workflow_path)
            
            print("\n" + "=" * 50)
            print("步骤 3: 合成视频")
            print("=" * 50)
            self.combine_to_video(output_path, fps)
            
            print("\n" + "=" * 50)
            print("处理完成!")
            print("=" * 50)
            
            return output_path
            
        finally:
            if not keep_temp:
                self.cleanup()


if __name__ == "__main__":
    processor = VideoProcessor()
    
    processor.process_video(
        video_path="input.mp4",
        workflow_path="workflow.json",
        output_path="output.mp4",
        fps=24,
        scale="512:-1"
    )
```

## 常见问题 FAQ

<details>
<summary>❓ FFmpeg 命令执行报错怎么办？</summary>

**常见错误及解决方法：**

| 错误信息 | 原因 | 解决方法 |
|----------|------|----------|
| "ffmpeg not found" | 未安装或未配置环境变量 | 重新安装并配置 PATH |
| "No such file or directory" | 输入文件不存在 | 检查文件路径 |
| "Invalid data found" | 视频文件损坏 | 尝试其他播放器验证 |
| "Output directory does not exist" | 输出目录不存在 | 创建目录后再执行 |

</details>

<details>
<summary>❓ 视频转绘后闪烁严重怎么办？</summary>

**解决方法：**

1. **固定随机种子**
   - 在 KSampler 中设置固定的 seed 值
   - 不要使用 -1（随机）

2. **降低 denoise 值**
   - 从 0.7 降到 0.5
   - 保留更多原始帧内容

3. **使用 ControlNet**
   - Depth ControlNet：保持场景结构
   - Tile ControlNet：保持细节

4. **帧间混合**
   - 使用帧混合节点
   - 设置适当的混合权重

</details>

<details>
<summary>❓ 如何处理长视频？</summary>

**建议方法：**

1. **分段处理**
   - 将视频分成 10-30 秒的片段
   - 分别处理后合并

2. **降低帧率**
   - 从 30fps 降到 24fps 或 15fps
   - 减少需要处理的帧数

3. **降低分辨率**
   - 使用 512x512 或更低分辨率
   - 加快处理速度

4. **使用云端资源**
   - LibLib 等平台的云端 GPU
   - 处理长视频更高效

</details>
