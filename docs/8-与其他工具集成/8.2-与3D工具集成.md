## 概述

### 什么是 3D 工具集成？

**功能描述：**
3D 工具集成是指将 Blender 等 3D 建模软件与 ComfyUI 结合，利用 ControlNet 的深度图、法线图等功能，实现精确的 3D 场景渲染和风格化。

**核心价值：**
- 🎯 **精确控制**：3D 模型提供精确的几何信息
- 🎨 **风格化渲染**：将 3D 场景转换为各种艺术风格
- ⚡ **快速迭代**：修改 3D 模型即可快速生成新图像
- 💡 **创意扩展**：突破传统渲染的限制

**使用场景：**
| 场景 | 说明 | 效果 |
|------|------|------|
| 室内设计 | 将 3D 室内模型渲染为水彩/油画风格 | 艺术化效果图 |
| 建筑可视化 | 将建筑模型转换为赛博朋克风格 | 概念设计图 |
| 游戏开发 | 快速生成游戏场景概念图 | 风格化场景 |
| 产品设计 | 产品渲染图风格化 | 营销素材 |

## Blender 深度图导出详细教程

### 什么是深度图？

**功能描述：**
深度图（Depth Map）是一张灰度图像，每个像素的灰度值代表该点到摄像机的距离。白色表示近，黑色表示远。

**使用场景：**
- 场景风格化：保持 3D 场景的空间结构
- 背景生成：基于简单 3D 模型生成复杂背景
- 室内设计：快速生成不同风格的室内效果图

### 方法一：使用 Compositor 导出深度图（推荐）

**功能描述：**
使用 Blender 内置的合成器（Compositor）导出深度图，无需安装额外插件。

#### 详细步骤：

**第一步：准备 3D 场景**

1. **创建或导入模型**
   - 新建场景：File → New → General
   - 或导入模型：File → Import → 选择格式（.obj/.fbx/.gltf）

2. **设置摄像机**
   - 按 `Numpad 0` 进入摄像机视图
   - 选择摄像机，按 `N` 打开属性面板
   - 在「视图锁定」中勾选「锁定摄像机到视图方位」
   - 用鼠标调整视角，摄像机跟随移动

3. **调整光照**
   - 添加光源：Shift + A → Light → Sun/Point/Area
   - 调整光源位置和强度
   - 在「渲染属性」中选择渲染引擎（Eevee/Cycles）

**第二步：设置深度图输出**

1. **切换到 Compositor 工作区**
   - 顶部菜单点击「Compositing」
   - 或使用快捷方式：顶部标签切换

2. **启用节点**
   - 勾选「使用节点」
   - 此时会出现 Render Layers 节点和 Composite 节点

3. **添加深度输出节点**
   
   **操作步骤：**
   - 按 `Shift + A` 打开添加菜单
   - 选择「输出」→「文件输出」
   - 将节点放置在右侧

4. **连接深度通道**
   
   **操作步骤：**
   - 在 Render Layers 节点找到「Depth」输出端口
   - 从 Depth 端口拖拽连线到 File Output 的 Image 输入端口
   - 连线会显示为绿色

5. **配置文件输出节点**
   
   **详细参数设置：**
   
   | 参数 | 设置值 | 说明 |
   |------|--------|------|
   | 基础路径 | `//depth_` | 输出文件路径，`//` 表示当前文件目录 |
   | 文件格式 | PNG | 输出格式 |
   | 色彩深度 | 16 | 位深度，越高精度越好 |
   | 编码 | Raw（或 sRGB） | 色彩编码 |

   **具体操作：**
   - 点击 File Output 节点上的「+」添加一个输出槽
   - 点击输出槽展开设置
   - 设置文件格式为 PNG
   - 设置色彩深度为 16

**第三步：渲染并保存**

1. **渲染场景**
   - 按 `F12` 开始渲染
   - 等待渲染完成

2. **查看输出**
   - 渲染完成后，深度图会自动保存
   - 文件位置：Blender 文件所在目录
   - 文件名：`depth_0001.png`

**注意事项：**
> ⚠️ **重要提醒**
> - 深度图可能看起来全黑或全白，这是正常的
> - 需要在 ComfyUI 中进行归一化处理
> - 16-bit 格式精度更高，推荐使用

### 方法二：使用插件导出深度图

**功能描述：**
使用专用插件可以更方便地导出深度图，适合频繁使用的用户。

#### 推荐插件：

直接在 Blender 中调用 ComfyUI API，实现一键渲染。

**安装步骤：**

**2. Depth Map Export 插件**

**安装步骤：**

   - 搜索「Blender depth map export addon」
   - 下载 `.py` 或 `.zip` 文件

2. **安装方法同上**

3. **使用方法**
   - 在渲染菜单中找到「Export Depth Map」
   - 设置输出路径和格式
   - 点击导出

### 深度图格式详解

| 格式 | 精度 | 文件大小 | 使用场景 | 推荐度 |
|------|------|----------|----------|--------|
| PNG 8-bit | 低（256级） | 小 | 简单场景、快速预览 | ⭐⭐ |
| PNG 16-bit | 中（65536级） | 中 | 一般场景、推荐使用 | ⭐⭐⭐⭐⭐ |
| EXR 32-bit | 高（浮点） | 大 | 专业场景、后期合成 | ⭐⭐⭐⭐ |

**如何选择：**
- 初学者：PNG 16-bit
- 专业用户：EXR 32-bit
- 快速测试：PNG 8-bit

## ComfyUI 深度图处理工作流

### 基础工作流配置

**节点连接图：**

```
┌─────────────────┐     ┌─────────────────┐     ┌─────────────────┐
│   Load Image    │────→│ ControlNet      │────→│    KSampler     │
│   (深度图)       │     │   Apply         │     │                 │
└─────────────────┘     └─────────────────┘     └────────┬────────┘
                                                         │
┌─────────────────┐     ┌─────────────────┐             │
│ ControlNet      │────→│                 │             │
│   Model Loader  │     └─────────────────┘             │
│   (Depth)       │                                     │
└─────────────────┘                                     ▼
                                              ┌─────────────────┐
                                              │   VAE Decode    │
                                              └────────┬────────┘
                                                       │
                                              ┌────────▼────────┐
                                              │   Save Image    │
                                              └─────────────────┘
```

### 详细节点配置

#### 1. Load Image 节点

**功能描述：**
加载从 Blender 导出的深度图。

**参数详解：**

| 参数 | 功能描述 | 推荐值 | 说明 |
|------|----------|--------|------|
| image | 选择图像文件 | - | 选择深度图文件 |
| upload | 上传新图像 | - | 点击上传按钮 |

**注意事项：**
- 确保图像方向正确
- 如果深度图看起来全黑，需要预处理

#### 2. ControlNet Model Loader 节点

**功能描述：**
加载 ControlNet 深度模型。

**模型选择：**

| 模型名称 | 适用版本 | 文件大小 | 推荐场景 |
|----------|----------|----------|----------|
| control_v11f1p_sd15_depth | SD 1.5 | 1.4GB | 通用场景 |
| control_depth-sdxl-1.0 | SDXL | 2.5GB | 高质量生成 |
| controlnet-zoe-depth | SD 1.5 | 1.5GB | 高精度深度 |
| control_v11p_sd15_mlsd | SD 1.5 | 1.4GB | 建筑线条 |

**下载地址：**
- Hugging Face: https://huggingface.co/lllyasviel/ControlNet-v1-1
- 放置路径：`ComfyUI/models/controlnet/`

#### 3. ControlNet Apply 节点

**功能描述：**
将 ControlNet 应用于生成过程。

**参数详解：**

| 参数 | 功能描述 | 推荐值 | 说明 |
|------|----------|--------|------|
| strength | 控制强度 | 0.8-1.0 | 值越高越遵循深度图 |
| start_percent | 开始百分比 | 0.0 | 从哪一步开始应用 |
| end_percent | 结束百分比 | 1.0 | 到哪一步结束应用 |

**参数调优建议：**

| 效果 | strength 设置 | 说明 |
|------|---------------|------|
| 严格遵循深度 | 1.0 | 完全按照深度图生成 |
| 适度变化 | 0.8-0.9 | 保持结构，允许细节变化 |
| 轻度参考 | 0.5-0.7 | 深度图作为参考 |

### 深度图预处理

**功能描述：**
如果从 Blender 导出的深度图需要调整，可以使用预处理器。

**可用预处理器：**

| 预处理器 | 功能描述 | 使用场景 |
|----------|----------|----------|
| DepthAnything | 通用深度估计 | 从普通图像生成深度图 |
| Zoe_DepthAnything | 高质量深度估计 | 需要高精度时使用 |
| MiDaS-DepthEstimation | 经典深度估计 | 兼容性好 |
| LeReS-DepthEstimation | 高精度深度估计 | 专业场景 |

**注意：** 如果深度图已经是标准格式，可以跳过预处理，直接使用。

## 完整工作流示例

### 场景：将 3D 室内模型渲染为水彩风格

#### Blender 端操作：

**第一步：准备场景**

1. **创建室内场景**
   - 添加地板：Shift + A → Mesh → Plane
   - 按 `S` 然后 `5` 放大
   - 添加墙壁：Shift + A → Mesh → Cube
   - 调整位置和大小

2. **添加家具**
   - Shift + A → Mesh → 选择形状
   - 或导入家具模型：File → Import

3. **设置摄像机**
   - 按 `Numpad 0` 进入摄像机视图
   - 调整角度，确保场景在画面中

**第二步：导出深度图**

1. **切换到 Compositor**
   - 顶部点击「Compositing」

2. **设置深度输出**
   - 启用「使用节点」
   - 添加 File Output 节点
   - 连接 Depth 输出到 File Output
   - 设置格式为 PNG 16-bit

3. **渲染**
   - 按 `F12` 渲染
   - 深度图自动保存

**第三步：导出彩色渲染图（可选）**

1. **添加另一个 File Output 节点**
2. **连接 Image 输出**
3. **再次渲染**

#### ComfyUI 端操作：

**第一步：加载深度图**

1. 添加 Load Image 节点
2. 点击「upload」上传深度图
3. 选择上传的图像

**第二步：配置 ControlNet**

1. 添加 Load ControlNet Model 节点
2. 选择 `control_v11f1p_sd15_depth`
3. 添加 Apply ControlNet 节点
4. 连接模型和图像
5. 设置 strength 为 0.9

**第三步：配置生成参数**

1. **添加 Checkpoint Loader**
   - 选择合适的模型，如 `dreamshaper_8.safetensors`

2. **添加 CLIP Text Encode（正向提示词）**
   ```
   watercolor painting, interior room, soft lighting, 
   artistic style, beautiful colors, masterpiece
   ```

3. **添加 CLIP Text Encode（负向提示词）**
   ```
   ugly, blurry, low quality, distorted, 
   bad anatomy, watermark
   ```

4. **添加 KSampler**
   
   | 参数 | 设置值 |
   |------|--------|
   | seed | 随机 |
   | steps | 25 |
   | cfg | 8 |
   | sampler_name | dpmpp_2m |
   | scheduler | normal |
   | denoise | 0.75 |

5. **添加 VAE Decode 和 Save Image**

**第四步：运行生成**

1. 点击「Queue Prompt」
2. 等待生成完成
3. 查看结果

### 参数调优指南

| 问题 | 解决方法 | 参数调整 |
|------|----------|----------|
| 结构不够准确 | 提高 ControlNet 强度 | strength: 0.9 → 1.0 |
| 风格不够明显 | 提高提示词权重 | CFG: 7 → 10 |
| 细节丢失 | 降低 denoise | denoise: 0.8 → 0.6 |
| 风格太强 | 降低 denoise | denoise: 0.7 → 0.5 |

## Normal Map 集成

### 什么是法线图？

**功能描述：**
法线图（Normal Map）记录了表面的法线方向，用于控制光照效果。在 ComfyUI 中可以用于保持 3D 模型的光影结构。

**使用场景：**
- 保持 3D 模型的光影效果
- 材质渲染
- 产品展示

### Blender 导出法线图

**方法一：使用材质节点**

1. **创建法线材质**
   - 切换到 Shading 工作区
   - 新建材质
   - 添加「Normal Map」节点
   - 连接到「Material Output」

2. **渲染输出**
   - 设置渲染引擎为 Cycles
   - 渲染并保存

**方法二：使用 Geometry Nodes**

1. **创建 Geometry Nodes**
   - 选择对象
   - 添加 Geometry Nodes 修改器
   - 创建法线输出节点

### ComfyUI 使用法线图

**节点连接：**

```
Load Image (法线图) → ControlNet Apply (Normal)
```

**推荐 ControlNet 模型：**

| 模型名称 | 说明 |
|----------|------|
| control_v11p_sd15_normalbae | SD 1.5 法线模型 |
| controlnet-normal-sdxl | SDXL 法线模型 |

## 自动化集成脚本

### Blender Python 自动渲染脚本

**功能描述：**
通过 Python 脚本自动渲染深度图并发送到 ComfyUI。

```python
import bpy
import os
import json
import requests
import time

def render_depth_map(output_path="//depth_output.png"):
    """
    渲染深度图
    
    参数详解：
    - output_path: 输出路径，// 表示 Blender 文件所在目录
    
    返回值：
    - 渲染完成后的完整文件路径
    """
    
    scene = bpy.context.scene
    
    scene.use_nodes = True
    tree = scene.node_tree
    
    for node in tree.nodes:
        tree.nodes.remove(node)
    
    render_layers = tree.nodes.new('CompositorNodeRLayers')
    
    file_output = tree.nodes.new('CompositorNodeOutputFile')
    file_output.base_path = os.path.dirname(bpy.data.filepath)
    file_output.format.file_format = 'PNG'
    file_output.format.color_depth = '16'
    file_output.file_slots[0].path = "depth_"
    
    tree.links.new(render_layers.outputs['Depth'], file_output.inputs[0])
    
    bpy.ops.render.render(write_still=True)
    
    output_file = os.path.join(
        os.path.dirname(bpy.data.filepath),
        "depth_0001.png"
    )
    
    return output_file

def send_to_comfyui(image_path, workflow_path, comfyui_url="http://localhost:8188"):
    """
    发送图像到 ComfyUI 进行处理
    
    参数详解：
    - image_path: 图像文件路径
    - workflow_path: 工作流 JSON 文件路径
    - comfyui_url: ComfyUI 服务地址
    
    返回值：
    - 任务 ID
    """
    
    with open(workflow_path, 'r', encoding='utf-8') as f:
        workflow = json.load(f)
    
    with open(image_path, 'rb') as f:
        files = {'image': f}
        response = requests.post(
            f"{comfyui_url}/upload/image",
            files=files
        )
    
    image_name = response.json()['name']
    
    for node_id, node in workflow.items():
        if node.get('class_type') == 'LoadImage':
            node['inputs']['image'] = image_name
    
    response = requests.post(
        f"{comfyui_url}/prompt",
        json={"prompt": workflow}
    )
    
    return response.json()['prompt_id']

def wait_for_result(prompt_id, comfyui_url="http://localhost:8188", timeout=300):
    """
    等待 ComfyUI 处理完成
    
    参数详解：
    - prompt_id: 任务 ID
    - comfyui_url: ComfyUI 服务地址
    - timeout: 超时时间（秒）
    
    返回值：
    - 输出图像信息
    """
    start_time = time.time()
    
    while time.time() - start_time < timeout:
        response = requests.get(f"{comfyui_url}/history/{prompt_id}")
        history = response.json()
        
        if prompt_id in history:
            return history[prompt_id]
        
        time.sleep(2)
    
    raise TimeoutError("ComfyUI 处理超时")

def automated_workflow():
    """
    完整自动化工作流示例
    
    功能描述：
    1. 渲染深度图
    2. 发送到 ComfyUI
    3. 等待处理完成
    4. 获取结果
    """
    print("步骤 1: 渲染深度图...")

    print("步骤 3: 等待处理完成...")
    result = wait_for_result(prompt_id)
    print("处理完成!")
    
    for node_id, output in result.get('outputs', {}).items():
        if 'images' in output:
            for image_info in output['images']:
                print(f"输出图像: {image_info['filename']}")

if __name__ == "__main__":
    automated_workflow()
```

### ComfyUI API 客户端类

```python
import requests
import json
import time
import uuid
from typing import Optional, Dict, Any

class ComfyUIBlenderClient:
    """
    ComfyUI Blender 集成客户端
    
    功能描述：
    - 上传图像到 ComfyUI
    - 提交工作流
    - 获取生成结果
    """
    
    def __init__(self, host: str = "localhost", port: int = 8188):
        """
        初始化客户端
        
        参数详解：
        - host: ComfyUI 服务地址
        - port: 端口号
        """
        self.base_url = f"http://{host}:{port}"
        self.client_id = str(uuid.uuid4())
    
    def upload_image(self, image_path: str, subfolder: str = "", overwrite: bool = True) -> str:
        """
        上传图像到 ComfyUI
        
        参数详解：
        - image_path: 本地图像路径
        - subfolder: 子文件夹名称
        - overwrite: 是否覆盖同名文件
        
        返回值：
        - 服务器上的图像名称
        """
        with open(image_path, 'rb') as f:
            files = {'image': (os.path.basename(image_path), f)}
            data = {
                'subfolder': subfolder,
                'overwrite': 'true' if overwrite else 'false'
            }
            response = requests.post(
                f"{self.base_url}/upload/image",
                files=files,
                data=data
            )
        
        if response.status_code != 200:
            raise Exception(f"上传失败: {response.text}")
        
        return response.json()['name']
    
    def queue_prompt(self, workflow: Dict[str, Any]) -> str:
        """
        提交工作流到队列
        
        参数详解：
        - workflow: 工作流 JSON 对象
        
        返回值：
        - 任务 ID
        """
        response = requests.post(
            f"{self.base_url}/prompt",
            json={
                "prompt": workflow,
                "client_id": self.client_id
            }
        )
        
        if response.status_code != 200:
            raise Exception(f"提交失败: {response.text}")
        
        return response.json()['prompt_id']
    
    def get_history(self, prompt_id: str) -> Dict[str, Any]:
        """
        获取任务历史
        
        参数详解：
        - prompt_id: 任务 ID
        
        返回值：
        - 任务历史信息
        """
        response = requests.get(f"{self.base_url}/history/{prompt_id}")
        return response.json()
    
    def get_image(self, filename: str, subfolder: str = "", folder_type: str = "output") -> bytes:
        """
        获取生成的图像
        
        参数详解：
        - filename: 文件名
        - subfolder: 子文件夹
        - folder_type: 文件夹类型 (output/input/temp)
        
        返回值：
        - 图像二进制数据
        """
        response = requests.get(
            f"{self.base_url}/view",
            params={
                "filename": filename,
                "subfolder": subfolder,
                "type": folder_type
            }
        )
        return response.content
    
    def process_depth_image(
        self,
        depth_image_path: str,
        workflow_path: str,
        output_path: str,
        timeout: int = 300
    ) -> str:
        """
        完整处理流程：上传深度图 → 运行工作流 → 保存结果
        
        参数详解：
        - depth_image_path: 深度图路径
        - workflow_path: 工作流 JSON 路径
        - output_path: 输出图像保存路径
        - timeout: 超时时间（秒）
        
        返回值：
        - 输出图像路径
        """
        
        print("上传深度图...")
        image_name = self.upload_image(depth_image_path)
        
        print("加载工作流...")
        with open(workflow_path, 'r', encoding='utf-8') as f:
            workflow = json.load(f)
        
        for node_id, node in workflow.items():
            if node.get('class_type') == 'LoadImage':
                node['inputs']['image'] = image_name
                break
        
        print("提交工作流...")
        prompt_id = self.queue_prompt(workflow)
        
        print(f"等待处理完成 (任务ID: {prompt_id})...")
        start_time = time.time()
        
        while time.time() - start_time < timeout:
            history = self.get_history(prompt_id)
            
            if prompt_id in history:
                result = history[prompt_id]
                
                for node_id, output in result.get('outputs', {}).items():
                    if 'images' in output:
                        for image_info in output['images']:
                            image_data = self.get_image(
                                image_info['filename'],
                                image_info.get('subfolder', '')
                            )
                            
                            with open(output_path, 'wb') as f:
                                f.write(image_data)
                            
                            print(f"结果已保存: {output_path}")
                            return output_path
                
                raise Exception("未找到输出图像")
            
            time.sleep(2)
        
        raise TimeoutError("处理超时")
```

## 常见问题 FAQ

<details>
<summary>❓ 深度图看起来全黑或全白怎么办？</summary>

**原因分析：**
深度值范围可能超出了 0-1 的显示范围。

**解决方法：**

1. **在 Blender 中调整**
   - 使用 Normalize 节点
   - 或调整摄像机远近裁剪平面

2. **在 ComfyUI 中处理**
   - 使用 DepthAnything 预处理器重新生成深度图
   - 或使用图像处理节点调整对比度

</details>

<details>
<summary>❓ 生成的图像结构不准确怎么办？</summary>

**排查步骤：**

1. **检查深度图质量**
   - 深度图是否清晰
   - 是否有明显的层次区分

2. **调整 ControlNet 参数**
   - 提高 strength 值（0.8 → 1.0）
   - 尝试不同的 ControlNet 模型

3. **检查提示词**
   - 确保提示词与深度图内容匹配
   - 避免矛盾的描述

</details>

<details>
<summary>❓ 如何同时使用多个 ControlNet？</summary>

**方法：**

使用多个 Apply ControlNet 节点串联：

```
Load Image 1 → ControlNet Apply 1 → ControlNet Apply 2 → KSampler
Load Image 2 ────────────────────────→
```

**推荐组合：**
- Depth + Canny：保持结构 + 细节
- Depth + OpenPose：场景 + 人物
- Normal + Depth：光影 + 结构

</details>
