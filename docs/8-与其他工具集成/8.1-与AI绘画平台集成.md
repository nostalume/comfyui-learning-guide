## 概述

### 什么是 AI 绘画平台集成？

**功能描述：**
AI 绘画平台集成是指将 ComfyUI 工作流导入到云端 AI 绘画平台，利用平台的 GPU 资源运行工作流，无需本地高性能显卡即可生成高质量图像。

**核心价值：**
- 💰 **节省硬件成本**：无需购买昂贵的显卡
- ☁️ **云端运行**：随时随地访问，不受本地设备限制
- 🔄 **工作流互通**：本地设计，云端运行，无缝衔接
- 📚 **资源共享**：使用平台提供的模型和素材

**使用场景：**
| 场景 | 说明 | 推荐平台 |
|------|------|----------|
| 学习测试 | 初学者体验 AI 绘画 | 吐司、SeaArt |
| 商业项目 | 需要稳定的服务保障 | LibLib、哩布哩布 |
| 模型测试 | 测试不同模型效果 | Tensor.art |
| 团队协作 | 多人共享工作流 | LibLib |

### 第二步：导入 ComfyUI 工作流

**功能描述：**
将本地 ComfyUI 设计的工作流导入到 LibLib 平台，利用云端资源运行。

**详细步骤：**

1. **导出本地工作流**
   
   在 ComfyUI 中导出工作流：
   - 点击菜单「Workflow」→「Export (API Format)」
   - 或使用快捷键：`Ctrl + S` 保存后选择 JSON 格式
   - 保存文件到本地（如：`my_workflow.json`）

2. **进入 LibLib 工作流页面**
   - 登录 LibLib
   - 点击顶部导航「工作流」
   - 点击「+ 创建工作流」

3. **上传工作流文件**
   - 选择「导入工作流」
   - 点击「上传文件」或拖拽 JSON 文件
   - 等待系统解析（通常需要 5-10 秒）

4. **检查兼容性**
   
   系统会自动检测：
   | 检测项 | 说明 | 处理方式 |
   |--------|------|----------|
   | 模型是否存在 | 检查所需模型是否在平台 | 选择替代模型或上传 |
   | 节点是否支持 | 检查自定义节点 | 查找替代节点 |
   | 版本兼容性 | ComfyUI 版本差异 | 更新工作流 |

### 第三步：云端运行工作流

**功能描述：**
在 LibLib 云端 GPU 上运行工作流，生成图像。

**详细步骤：**

1. **选择 GPU 类型**
   
   | GPU 类型 | 价格（参考） | 适用场景 | 推荐模型 |
   |---------|-------------|----------|----------|
   | RTX 3060 | ¥0.2/分钟 | SD 1.5、简单工作流 | sd-v1-5, dreamshaper |
   | RTX 3080 | ¥0.4/分钟 | SDXL、中等复杂度 | sdxl-base, dreamshaper-xl |
   | RTX 4090 | ¥0.8/分钟 | Flux、大模型、复杂工作流 | flux-dev, sd3-medium |

2. **配置运行参数**
   
   在工作流编辑器中：
   - 设置提示词（Prompt）
   - 调整采样参数（Steps、CFG）
   - 设置输出尺寸
   - 选择输出格式

3. **启动运行**
   - 点击「运行」按钮
   - 等待排队（高峰期可能需要等待）
   - 观察运行进度

4. **查看结果**
   - 运行完成后自动显示结果
   - 点击图像可放大查看
   - 支持下载高清原图

**参数详解：**

| 参数 | 功能描述 | 推荐值 | 说明 |
|------|----------|--------|------|
| Steps | 采样步数 | 20-30 | 步数越多细节越好，但耗时更长 |
| CFG Scale | 提示词遵循度 | 7-12 | 值越高越遵循提示词 |
| Seed | 随机种子 | -1（随机） | 固定值可复现结果 |
| Denoise | 重绘强度 | 0.6-0.9 | 图生图时使用 |

### 常见兼容性问题

| 问题 | 功能描述 | 原因分析 | 解决方法 |
|------|----------|----------|----------|
| 节点缺失 | 工作流中的节点在平台不存在 | 自定义节点未安装 | 查找替代节点或联系平台 |

| 版本不兼容 | 节点参数格式错误 | ComfyUI 版本差异 | 更新工作流或降级节点 |
| 路径错误 | 找不到模型文件 | 硬编码本地路径 | 使用相对路径或模型名称 |

### 兼容性检查清单

在导入工作流前，请逐一检查：

- [ ] **节点检查**：所有使用的节点在平台是否可用
- [ ] **模型检查**：模型是否已在平台上传或存在
- [ ] **版本检查**：节点参数是否与平台版本匹配
- [ ] **路径检查**：工作流是否有硬编码的本地路径
- [ ] **依赖检查**：ControlNet、LoRA 等是否可用

### 工作流适配建议

## API 集成详解

### 平台 API 调用

**功能描述：**
部分平台提供 API 接口，可通过代码调用工作流，实现自动化生成。

**完整示例代码：**

```python
import requests
import json
import time
import base64

class LibLibAPIClient:
    """
    LibLib API 客户端
    
    功能描述：
    - 提交工作流到云端运行
    - 查询运行状态
    - 获取生成结果
    """
    
    def __init__(self, api_key: str):
        """
        初始化客户端
        
        参数详解：
        - api_key: 平台 API 密钥，在个人设置中获取
        """
        self.base_url = "https://api.liblib.art"
        self.headers = {"Authorization": f"Bearer {api_key}"}
    
    def submit_workflow(self, workflow: dict, gpu_type: str = "RTX3080") -> dict:
        """
        提交工作流
        
        参数详解：
        - workflow: 工作流 JSON 对象
        - gpu_type: GPU 类型，可选 RTX3060/RTX3080/RTX4090
        
        返回值：
        - {"task_id": "xxx", "status": "pending"}
        """
        response = requests.post(
            f"{self.base_url}/v1/workflow/run",
            headers=self.headers,
            json={
                "workflow": workflow,
                "gpu_type": gpu_type
            }
        )
        
        if response.status_code != 200:
            raise Exception(f"提交失败: {response.text}")
        
        return response.json()
    
    def get_task_status(self, task_id: str) -> dict:
        """
        查询任务状态
        
        参数详解：
        - task_id: 任务 ID
        
        返回值：
        - {"status": "running/completed/failed", "progress": 50}
        """
        response = requests.get(
            f"{self.base_url}/v1/workflow/status/{task_id}",
            headers=self.headers
        )
        return response.json()
    
    def get_result(self, task_id: str) -> bytes:
        """
        获取生成结果
        
        参数详解：
        - task_id: 任务 ID
        
        返回值：
        - 图像二进制数据
        """
        response = requests.get(
            f"{self.base_url}/v1/workflow/result/{task_id}",
            headers=self.headers
        )
        return response.content
    
    def run_and_wait(self, workflow: dict, timeout: int = 300) -> bytes:
        """
        提交并等待结果（同步方式）
        
        参数详解：
        - workflow: 工作流 JSON
        - timeout: 超时时间（秒）
        
        返回值：
        - 图像二进制数据
        """
        task = self.submit_workflow(workflow)
        task_id = task["task_id"]
        
        start_time = time.time()
        while time.time() - start_time < timeout:
            status = self.get_task_status(task_id)
            
            if status["status"] == "completed":
                return self.get_result(task_id)
            elif status["status"] == "failed":
                raise Exception(f"任务失败: {status.get('error', '未知错误')}")
            
            print(f"进度: {status.get('progress', 0)}%")
            time.sleep(2)
        
        raise TimeoutError("任务超时")

# 使用示例
if __name__ == "__main__":
    client = LibLibAPIClient("your_api_key_here")
    
    with open("workflow.json", "r", encoding="utf-8") as f:
        workflow = json.load(f)
    
    image_data = client.run_and_wait(workflow)
    
    with open("output.png", "wb") as f:
        f.write(image_data)
    
    print("图像已保存到 output.png")
```

        headers={"Authorization": "Bearer YOUR_API_KEY"},
        json={
            "workflow": workflow,
            "callback_url": callback_url
        }
    )
    return response.json()

# 回调服务器示例（使用 Flask）
from flask import Flask, request

app = Flask(__name__)

@app.route("/callback", methods=["POST"])
def handle_callback():
    """
    处理平台回调
    
    回调数据格式：
    {
        "task_id": "xxx",
        "status": "completed",
        "images": ["url1", "url2"]
    }
    """
    data = request.json
    
    if data["status"] == "completed":
        print(f"任务 {data['task_id']} 完成")
        for image_url in data["images"]:
            print(f"图像地址: {image_url}")
    
    return {"received": True}

if __name__ == "__main__":
    app.run(port=8080)

## 常见问题 FAQ

<details>
<summary>❓ 哪个平台最适合初学者？</summary>

**推荐：吐司（Tusi.Art）**

原因：
1. 每日免费额度，无需付费即可体验
2. 界面简洁，操作友好
3. 社区活跃，有大量教程和分享
4. 支持中文，无语言障碍

入门步骤：
1. 注册账号
2. 浏览社区工作流
3. 一键使用他人分享的工作流
4. 逐步学习修改和创建自己的工作流

</details>

<details>
<summary>❓ 工作流导入后模型缺失怎么办？</summary>

**解决步骤：**

1. **检查平台模型库**
   - 在平台搜索模型名称
   - 查看是否有相似模型可替代

2. **上传自己的模型**
   - 进入「我的模型」
   - 上传模型文件
   - 等待处理完成

3. **修改工作流**
   - 在工作流编辑器中
   - 将模型节点改为平台已有模型
   - 重新运行

**注意事项：**
- 上传模型前请确认版权
- 大模型上传可能需要较长时间
- 部分平台对模型大小有限制

</details>

<details>
<summary>❓ 云端运行速度慢怎么办？</summary>

**优化建议：**

| 优化项 | 方法 | 效果 |
|--------|------|------|
| 降低分辨率 | 512x512 → 448x448 | 提升 30% |
| 减少步数 | 30 步 → 20 步 | 提升 33% |
| 使用更快的采样器 | euler → dpmpp_2m | 提升 20% |
| 选择合适的 GPU | RTX3060 → RTX4090 | 提升 200% |

**高峰期避让：**
- 工作日白天：排队时间长
- 深夜/凌晨：排队时间短
- 周末：中等

</details>

<details>
<summary>❓ 如何保护我的工作流不被他人复制？</summary>

**保护措施：**

1. **私有分享**
   - 部分平台支持私有工作流
   - 仅分享给指定用户

2. **加密关键参数**
   - 将关键参数通过 API 传入
   - 不在工作流中硬编码

3. **使用平台权限控制**
   - 设置工作流可见范围
   - 限制下载权限

**注意：** 完全防止复制较难，建议关注核心创意而非技术实现。

</details>
