## 概述

### 什么是快速上手手册？

**快速上手手册**是帮助新成员在最短时间内掌握 ComfyUI 基本操作的指导文档。它提供简洁明了的步骤说明、常用操作指南和问题解决方案。

**核心目标：**
- ⚡ **快速入门**：30分钟内完成首次生成
- 📚 **循序渐进**：从基础到进阶的学习路径
- 🎯 **实用导向**：聚焦最常用的功能和操作
- 🔧 **问题解决**：提供常见问题的解决方案

### 为什么需要快速上手手册？

| 场景 | 无上手手册 | 有上手手册 |
|-----|-----------|-----------|
| 新成员入职 | 需要老员工手把手教学，耗时1-2天 | 自学完成，仅需2-4小时 |
| 培训成本 | 每次培训都需要重复讲解 | 标准化培训，效率高 |
| 学习曲线 | 遇到问题无处询问，容易放弃 | 有据可查，学习顺畅 |
| 知识传承 | 依赖个人经验，难以复制 | 文档化知识，可复制 |

## 快速开始

### 安装步骤详解

#### Windows 便携版安装（推荐新手）

**功能描述：**
便携版是预配置好的 ComfyUI 版本，解压即用，无需配置环境。

**适用场景：**
- 首次接触 ComfyUI 的用户
- 不熟悉 Python 环境配置的用户
- 快速体验 ComfyUI 功能

**安装步骤：**

**步骤1：下载便携版**

1. 访问 ComfyUI 发布页面：
   ```
   https://github.com/comfyanonymous/ComfyUI/releases
   ```

2. 下载最新版本的便携包：
   - 文件名格式：`ComfyUI_windows_portable_nvidia_cu121_or_cpu.7z`
   - 选择适合你显卡的版本（NVIDIA 或 CPU）

**步骤2：解压文件**

1. 右键下载的 `.7z` 文件
2. 选择"解压到当前文件夹"或指定目录
3. 推荐解压到：`D:\ComfyUI`（路径不要包含中文）

**步骤3：运行程序**

1. 进入解压后的目录
2. 双击运行 `run_nvidia_gpu.bat`（NVIDIA 显卡）
   - 或 `run_cpu.bat`（仅 CPU 运行，速度较慢）

**步骤4：验证安装**

1. 等待命令行窗口显示：
   ```
   To see the GUI go to: http://127.0.0.1:8188
   ```
2. 浏览器自动打开或手动访问：http://127.0.0.1:8188
3. 看到 ComfyUI 界面即安装成功

**注意事项：**

1. **路径问题**
   - 不要使用中文路径
   - 不要使用带空格的路径
   - 推荐使用短路径如 `D:\ComfyUI`

2. **显卡驱动**
   - 确保显卡驱动为最新版本
   - NVIDIA 显卡需要 CUDA 支持

3. **端口占用**
   - 如果 8188 端口被占用，会自动使用其他端口
   - 查看命令行窗口显示的实际端口

#### Python 环境安装（适合开发者）

**功能描述：**
使用 Python 虚拟环境安装，适合需要自定义配置的用户。

**适用场景：**
- 需要自定义配置的用户
- 开发者或高级用户
- 需要与其他 Python 项目共存

**安装步骤：**

**步骤1：安装 Python**

1. 下载 Python 3.10 或 3.11：
   ```
   https://www.python.org/downloads/
   ```

2. 安装时勾选 "Add Python to PATH"

**步骤2：克隆仓库**

```bash
# 打开命令行，进入目标目录
cd D:\Dev

# 克隆 ComfyUI 仓库
git clone https://github.com/comfyanonymous/ComfyUI

# 进入目录
cd ComfyUI
```

**步骤3：创建虚拟环境**

```bash
# 创建虚拟环境
python -m venv venv

# 激活虚拟环境
# Windows:
venv\Scripts\activate
# Linux/macOS:
source venv/bin/activate
```

**步骤4：安装依赖**

```bash
# 升级 pip
python -m pip install --upgrade pip

# 安装 PyTorch（NVIDIA 显卡）
pip install torch torchvision torchaudio --extra-index-url https://download.pytorch.org/whl/cu121

# 安装 ComfyUI 依赖
pip install -r requirements.txt
```

**步骤5：启动程序**

```bash
# 启动 ComfyUI
python main.py
```

### 首次配置

#### 安装 ComfyUI Manager

**功能描述：**
ComfyUI Manager 是节点管理工具，可以方便地安装、更新自定义节点。

**为什么需要：**
- 一键安装缺失节点
- 自动更新节点包
- 管理已安装节点

**安装步骤：**

```bash
# 进入 custom_nodes 目录
cd ComfyUI\custom_nodes

# 克隆 Manager 仓库
git clone https://github.com/ltdrdata/ComfyUI-Manager.git

# 重启 ComfyUI
```

**验证安装：**

1. 重启 ComfyUI
2. 点击右侧面板的 "Manager" 按钮
3. 看到 Manager 界面即安装成功

#### 下载基础模型

**功能描述：**
模型是生成图像的核心，需要下载至少一个基础模型。

**推荐模型：**

| 模型名称 | 基础架构 | 风格 | 大小 | 下载链接 |
|---------|---------|------|------|---------|
| Realistic Vision V5 | SD 1.5 | 写实 | 4.2GB | [Civitai](https://civitai.com/models/4201) |
| DreamShaper | SD 1.5 | 通用 | 2.1GB | [Civitai](https://civitai.com/models/4384) |
| Juggernaut XL | SDXL | 写实 | 6.9GB | [Civitai](https://civitai.com/models/133005) |

**下载步骤：**

1. 访问模型下载页面
2. 点击 "Download" 按钮
3. 将下载的 `.safetensors` 文件放入：
   ```
   ComfyUI\models\checkpoints\
   ```

**注意事项：**

1. **文件格式**
   - 推荐使用 `.safetensors` 格式
   - `.ckpt` 格式也可以使用，但安全性较低

2. **存储位置**
   - 确保放入正确的目录
   - 文件名建议使用英文

3. **刷新模型列表**
   - 放入模型后需要刷新
   - 点击 "Refresh" 或重启 ComfyUI

### 常用操作详解

#### 添加节点

**方法一：双击添加**

1. 双击工作区空白处
2. 在搜索框输入节点名称
3. 点击或回车添加节点

**方法二：右键菜单**

1. 右键点击工作区空白处
2. 选择 "Add Node"
3. 在分类菜单中找到需要的节点

**方法三：搜索添加**

1. 点击侧边栏的 "Node Library"
2. 在搜索框输入关键词
3. 双击需要的节点

#### 连接节点

**操作步骤：**

1. 将鼠标移到节点的输出端口（右侧圆点）
2. 按住左键拖拽
3. 移动到目标节点的输入端口（左侧圆点）
4. 释放鼠标完成连接

**连接规则：**

| 规则 | 说明 |
|-----|------|
| 颜色匹配 | 相同颜色的端口才能连接 |
| 类型匹配 | 输出类型必须与输入类型兼容 |
| 单向连接 | 只能从输出端口连到输入端口 |

**端口颜色说明：**

| 颜色 | 数据类型 | 说明 |
|-----|---------|------|
| 紫色 | MODEL | 模型数据 |
| 黄色 | CLIP | 文本编码器 |
| 粉色 | VAE | 变分自编码器 |
| 橙色 | CONDITIONING | 条件数据 |
| 深红 | LATENT | 潜空间数据 |
| 蓝色 | IMAGE | 图像数据 |

#### 删除节点

**方法一：选中删除**

1. 点击选中节点
2. 按 `Delete` 键删除

**方法二：右键删除**

1. 右键点击节点
2. 选择 "Remove"

**删除多个节点：**

1. 按住 `Ctrl` 点击多个节点
2. 按 `Delete` 键批量删除

#### 移动和缩放

| 操作 | 方法 |
|-----|------|
| 移动画布 | 按住空格键拖拽 / 鼠标中键拖拽 |
| 缩放 | 鼠标滚轮 |
| 移动节点 | 拖拽节点标题栏 |
| 复制节点 | 选中后 `Ctrl+C` / `Ctrl+V` |
| 撤销 | `Ctrl+Z` |
| 重做 | `Ctrl+Y` |

## 第一个工作流详解

### 文生图工作流

#### 功能描述
最基础的图像生成工作流，从文本描述生成图像。

#### 完整步骤

**步骤1：添加节点**

按顺序添加以下节点：

1. **Load Checkpoint** - 加载模型
   - 双击空白处
   - 输入 "Load Checkpoint"
   - 回车添加

2. **CLIP Text Encode (Positive)** - 正面提示词
   - 双击空白处
   - 输入 "CLIP Text Encode"
   - 回车添加
   - 在节点标题上右键 → Rename → 改为 "Positive Prompt"

3. **CLIP Text Encode (Negative)** - 负面提示词
   - 重复上述步骤
   - 改名为 "Negative Prompt"

4. **Empty Latent Image** - 空白潜空间
   - 双击空白处
   - 输入 "Empty Latent Image"
   - 回车添加

5. **KSampler** - 采样器
   - 双击空白处
   - 输入 "KSampler"
   - 回车添加

6. **VAE Decode** - 解码
   - 双击空白处
   - 输入 "VAE Decode"
   - 回车添加

7. **Save Image** - 保存图像
   - 双击空白处
   - 输入 "Save Image"
   - 回车添加

**步骤2：连接节点**

按照以下顺序连接：

```
Load Checkpoint
    ├── MODEL 输出 → KSampler 的 model 输入
    ├── CLIP 输出 → Positive Prompt 的 clip 输入
    ├── CLIP 输出 → Negative Prompt 的 clip 输入
    └── VAE 输出 → VAE Decode 的 vae 输入

Positive Prompt
    └── CONDITIONING 输出 → KSampler 的 positive 输入

Negative Prompt
    └── CONDITIONING 输出 → KSampler 的 negative 输入

Empty Latent Image
    └── LATENT 输出 → KSampler 的 latent_image 输入

KSampler
    └── LATENT 输出 → VAE Decode 的 latent 输入

VAE Decode
    └── IMAGE 输出 → Save Image 的 images 输入
```

**步骤3：配置参数**

| 节点 | 参数 | 设置值 |
|-----|------|-------|
| Load Checkpoint | ckpt_name | 选择下载的模型 |
| Positive Prompt | text | `a beautiful landscape, masterpiece, best quality` |
| Negative Prompt | text | `low quality, blurry, distorted` |
| Empty Latent | width | `512` |
| Empty Latent | height | `512` |
| KSampler | seed | 随机 |
| KSampler | steps | `20` |
| KSampler | cfg | `7` |
| KSampler | sampler_name | `euler_a` |
| KSampler | scheduler | `normal` |
| KSampler | denoise | `1.0` |

**步骤4：运行生成**

1. 点击右上角 `Queue Prompt` 按钮
2. 观察右侧队列状态
3. 等待生成完成
4. 在 Save Image 节点查看结果

#### 参数详解

**KSampler 参数说明：**

| 参数 | 说明 | 推荐值 | 效果 |
|-----|------|-------|------|
| seed | 随机种子 | 任意整数 | 相同种子生成相同图像 |
| steps | 采样步数 | 20-30 | 步数越多细节越好，但耗时增加 |
| cfg | CFG引导强度 | 6-8 | 值越高越遵循提示词，但可能过饱和 |
| sampler_name | 采样器 | euler_a | euler_a速度快，dpm++质量高 |
| scheduler | 调度器 | normal | normal通用，karras适合高步数 |
| denoise | 去噪强度 | 1.0 | 1.0完全重绘，0.0保持原图 |

## 常见问题解决

### 问题1：显存不足

**错误信息：**
```
CUDA out of memory
```

**解决方案：**

**方案A：使用低显存模式**

```bash
# Windows 便携版
# 编辑 run_nvidia_gpu.bat，添加参数：
python main.py --lowvram

# Python 环境
python main.py --lowvram
```

**方案B：降低分辨率**

1. 将 Empty Latent Image 的分辨率降低
2. SD 1.5: 512×512 → 384×384
3. SDXL: 1024×1024 → 768×768

**方案C：减少批量大小**

1. 将 batch_size 设置为 1
2. 避免同时生成多张图像

**显存需求参考：**

| 分辨率 | 最低显存 | 推荐显存 |
|-------|---------|---------|
| 512×512 | 4GB | 6GB |
| 768×768 | 6GB | 8GB |
| 1024×1024 | 8GB | 12GB |

### 问题2：节点找不到

**问题描述：**
工作流加载后，某些节点显示红色，提示找不到。

**解决方案：**

**步骤1：检查节点是否安装**

1. 打开 ComfyUI Manager
2. 点击 "Installed" 标签
3. 搜索节点名称

**步骤2：安装缺失节点**

1. 在 ComfyUI Manager 中点击 "Install Missing Nodes"
2. 等待自动安装
3. 重启 ComfyUI

**步骤3：手动安装**

```bash
# 进入 custom_nodes 目录
cd ComfyUI\custom_nodes

# 克隆节点仓库
git clone [节点仓库地址]

# 重启 ComfyUI
```

### 问题3：模型加载失败

**错误信息：**
```
FileNotFoundError: [模型文件名]
```

**解决方案：**

**步骤1：检查文件位置**

确认模型文件在正确目录：
```
ComfyUI\models\checkpoints\[模型文件名].safetensors
```

**步骤2：检查文件名**

- 文件名不要包含中文
- 文件名不要包含特殊字符
- 确保扩展名正确

**步骤3：刷新模型列表**

1. 点击菜单栏的 "Refresh" 按钮
2. 或重启 ComfyUI

### 问题4：生成速度慢

**原因分析：**

| 原因 | 解决方案 |
|-----|---------|
| 采样步数过多 | 降低 steps 到 20-25 |
| 分辨率过高 | 降低分辨率 |
| 未启用优化 | 启用 xFormers |
| CPU 运行 | 使用 GPU 加速 |

**启用 xFormers：**

```bash
# 安装 xFormers
pip install xformers

# 启动时启用
python main.py --use-xformers
```

### 问题5：图像质量差

**原因和解决方案：**

| 问题 | 原因 | 解决方案 |
|-----|------|---------|
| 模糊 | 采样步数太少 | 增加 steps 到 20-30 |
| 变形 | 分辨率不合适 | 使用模型推荐分辨率 |
| 色彩异常 | VAE 问题 | 使用独立 VAE 模型 |
| 细节不足 | CFG 值不当 | 调整 CFG 到 6-8 |

## 常见问题 FAQ

### Q1：如何保存常用的工作流配置？

**解决方案：**

1. 配置好工作流后，点击 `Save` 按钮
2. 选择保存位置（建议保存到团队共享目录）
3. 使用有意义的文件名，如 `txt2img_portrait_v1.json`

### Q2：如何快速找到需要的节点？

**解决方案：**

1. **使用搜索功能**
   - 双击空白处打开搜索
   - 输入节点名称关键词

2. **使用分类浏览**
   - 右键点击空白处
   - 选择 "Add Node" → 分类 → 节点

3. **查看节点库**
   - 点击侧边栏 "Node Library"
   - 浏览或搜索节点

### Q3：生成的图像保存在哪里？

**默认位置：**
```
ComfyUI\output\
```

**修改保存位置：**

1. 在 Save Image 节点中设置 `filename_prefix`
2. 使用子目录格式：`projectA/portrait_`

### Q4：如何批量生成图像？

**方法一：使用批量大小**

1. 在 Empty Latent Image 节点设置 `batch_size`
2. 设置为 2-4，一次生成多张

**方法二：使用队列**

1. 配置好参数后，按 `Ctrl+Enter` 添加到队列
2. 修改参数，再次添加
3. 队列会依次执行

**方法三：使用批量插件**

1. 安装批量生成插件
2. 配置参数矩阵
3. 批量运行

### Q5：如何提高生成质量？

**优化建议：**

1. **选择合适的模型**
   - 写实风格：Realistic Vision, Juggernaut
   - 动漫风格：Anything, DreamShaper
   - 艺术风格：Deliberate, RevAnimated

2. **优化提示词**
   - 使用质量标签：`masterpiece, best quality`
   - 添加风格描述
   - 使用负面提示词排除不需要的元素

3. **调整参数**
   - 增加采样步数（25-30）
   - 调整 CFG 值（6-8）
   - 使用更好的采样器（dpm++ 2m）
