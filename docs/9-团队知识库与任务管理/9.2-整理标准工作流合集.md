## 概述

### 什么是标准工作流？

**标准工作流**是经过验证、可复用的 ComfyUI 节点配置方案。它定义了节点之间的连接关系、参数设置和生成流程，是团队知识沉淀的核心载体。

**核心价值：**
- 🔄 **可复用**：一次配置，多次使用
- 📋 **标准化**：统一团队生成流程
- 📚 **知识沉淀**：将经验固化为模板
- 🚀 **效率提升**：减少重复配置时间

### 为什么需要整理工作流合集？

| 问题场景 | 无标准工作流 | 有标准工作流 |
|---------|-------------|-------------|
| 新项目启动 | 每次从头搭建，耗时数小时 | 加载模板，5分钟完成配置 |
| 结果不一致 | 每人配置不同，结果差异大 | 统一模板，结果可复现 |
| 经验流失 | 人员离职，经验随之流失 | 工作流保留，知识传承 |
| 培训新人 | 需要手把手教学 | 提供模板自学，效率更高 |

## 基础工作流模板详解

### 文生图基础模板

#### 功能描述
最基础的图像生成工作流，从文本提示词生成图像。适合初学者理解 ComfyUI 的核心流程。

#### 使用场景
- 快速验证模型效果
- 简单的创意图像生成
- 学习 ComfyUI 基础操作

#### 节点结构图

```
┌─────────────────┐
│ Load Checkpoint │
└────────┬────────┘
         │
    ┌────┴────┬──────────┐
    ↓         ↓          ↓
┌───────┐ ┌───────┐  ┌───────┐
│ CLIP  │ │ CLIP  │  │ Empty │
│ Text  │ │ Text  │  │ Latent│
│ (正)  │ │ (负)  │  │ Image │
└───┬───┘ └───┬───┘  └───┬───┘
    │         │          │
    └────┬────┴────┬─────┘
         ↓         ↓
    ┌─────────────────┐
    │    KSampler     │
    └────────┬────────┘
             ↓
    ┌─────────────────┐
    │   VAE Decode    │
    └────────┬────────┘
             ↓
    ┌─────────────────┐
    │   Save Image    │
    └─────────────────┘
```

#### 节点详解

| 节点名称 | 功能 | 输入参数 | 输出 |
|---------|------|---------|------|
| Load Checkpoint | 加载主模型 | ckpt_name | model, clip, vae |
| CLIP Text Encode | 编码提示词 | clip, text | conditioning |
| Empty Latent Image | 创建空白潜空间 | width, height, batch_size | latent |
| KSampler | 采样生成 | model, positive, negative, latent | latent |
| VAE Decode | 解码为图像 | vae, latent | image |
| Save Image | 保存图像 | image, filename_prefix | - |

#### 参数配置详解

**Empty Latent Image 参数：**

| 参数 | 说明 | 推荐值 | 范围 |
|-----|------|-------|------|
| width | 图像宽度 | 512 | 256-1024 |
| height | 图像高度 | 512 或 768 | 256-1024 |
| batch_size | 批量大小 | 1 | 1-4 |

**KSampler 参数：**

| 参数 | 说明 | 推荐值 | 范围 |
|-----|------|-------|------|
| seed | 随机种子 | 随机 | 任意整数 |
| steps | 采样步数 | 20-25 | 15-50 |
| cfg | CFG引导强度 | 7.0 | 5.0-15.0 |
| sampler_name | 采样器 | euler_a | 多种可选 |
| scheduler | 调度器 | normal | normal, karras |
| denoise | 去噪强度 | 1.0 | 0.0-1.0 |

#### 操作步骤

**步骤1：添加节点**

1. 双击空白处，打开节点搜索
2. 依次添加以下节点：
   - `Load Checkpoint`（加载模型）
   - `CLIP Text Encode`（添加2个，分别用于正面和负面提示词）
   - `Empty Latent Image`（空白潜空间）
   - `KSampler`（采样器）
   - `VAE Decode`（解码）
   - `Save Image`（保存图像）

**步骤2：连接节点**

按照节点结构图连接各节点：

1. `Load Checkpoint` → `model` 输出连接到 `KSampler` 的 `model` 输入
2. `Load Checkpoint` → `clip` 输出连接到两个 `CLIP Text Encode` 的 `clip` 输入
3. `Load Checkpoint` → `vae` 输出连接到 `VAE Decode` 的 `vae` 输入
4. 正面 `CLIP Text Encode` → `conditioning` 输出连接到 `KSampler` 的 `positive` 输入
5. 负面 `CLIP Text Encode` → `conditioning` 输出连接到 `KSampler` 的 `negative` 输入
6. `Empty Latent Image` → `latent` 输出连接到 `KSampler` 的 `latent_image` 输入
7. `KSampler` → `latent` 输出连接到 `VAE Decode` 的 `latent` 输入
8. `VAE Decode` → `image` 输出连接到 `Save Image` 的 `images` 输入

**步骤3：配置参数**

```
模型：选择已下载的模型（如 realistic_vision_v5.safetensors）
正面提示词：a beautiful landscape, masterpiece, best quality
负面提示词：low quality, blurry, distorted
宽度：512
高度：512
采样步数：20
CFG：7.0
采样器：euler_a
```

**步骤4：运行生成**

点击右侧 `Queue Prompt` 按钮，等待生成完成。

#### 注意事项

1. **分辨率选择**
   - SD 1.5 推荐：512×512 或 512×768
   - SDXL 推荐：1024×1024 或 1024×1344
   - 非标准分辨率可能导致图像变形

2. **采样步数**
   - 步数太少（<15）：图像质量差，细节不足
   - 步数太多（>40）：提升有限，耗时增加
   - 推荐范围：20-30

3. **CFG 值**
   - 值太低（<5）：图像偏离提示词
   - 值太高（>12）：图像过饱和、不自然
   - 推荐范围：6-8

### 图生图基础模板

#### 功能描述
基于参考图像生成新图像，保留原图的部分特征。适合风格迁移、图像修改等场景。

#### 使用场景
- 风格迁移：将照片转换为艺术风格
- 图像修改：调整图像细节
- 草图上色：为线稿添加颜色

#### 节点结构图

```
┌─────────────┐     ┌─────────────┐
│ Load Image  │────→│ VAE Encode  │
└─────────────┘     └──────┬──────┘
                           │
┌──────────────────────────┼──────────────────────────┐
│                          ↓                          │
│  ┌─────────────────────────────────────────────┐   │
│  │              KSampler (img2img)             │   │
│  └──────────────────────┬──────────────────────┘   │
│                         │                          │
│  ┌──────────────────────┼──────────────────────┐   │
│  │ Load Checkpoint → CLIP Text Encode (正/负)  │   │
│  └──────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────┘
                          ↓
              ┌─────────────────────┐
              │     VAE Decode      │
              └──────────┬──────────┘
                         ↓
              ┌─────────────────────┐
              │     Save Image      │
              └─────────────────────┘
```

#### 参数配置详解

**KSampler 特有参数：**

| 参数 | 说明 | 推荐值 | 效果 |
|-----|------|-------|------|
| denoise | 重绘强度 | 0.5-0.7 | 0.3=保留更多原图，0.9=几乎重绘 |

**denoise 参数详解：**

| 值 | 效果 | 适用场景 |
|---|------|---------|
| 0.1-0.3 | 轻微修改 | 调整细节、修复瑕疵 |
| 0.4-0.6 | 中等修改 | 风格迁移、部分重绘 |
| 0.7-0.9 | 大幅修改 | 完全重绘、风格转换 |

#### 操作步骤

**步骤1：准备参考图**

将参考图像放入 `input/` 目录，或直接拖拽到界面。

**步骤2：构建工作流**

1. 添加 `Load Image` 节点，选择参考图
2. 添加 `VAE Encode` 节点
3. 连接 `Load Image` → `VAE Encode`
4. 按文生图模板添加其他节点
5. 将 `VAE Encode` 输出连接到 `KSampler` 的 `latent_image` 输入

**步骤3：配置参数**

```
denoise: 0.6  # 中等重绘强度
steps: 25
cfg: 7.0
```

**步骤4：运行生成**

#### 注意事项

1. **参考图分辨率**
   - 建议与目标分辨率一致
   - 不一致时会自动缩放

2. **denoise 值选择**
   - 保留原图特征：0.3-0.5
   - 风格迁移：0.5-0.7
   - 完全重绘：0.7-0.9

### 高清修复模板

#### 功能描述
将低分辨率图像放大到高分辨率，同时增强细节和质量。

#### 使用场景
- 打印输出前的图像放大
- 细节增强和质量提升
- 低分辨率图像修复

#### 节点结构图

```
┌─────────────────┐
│   生成图像      │
│  (低分辨率)     │
└────────┬────────┘
         ↓
┌─────────────────────┐
│ Upscale Model Loader│
└────────┬────────────┘
         ↓
┌─────────────────────┐
│ Image Upscale Model │
└────────┬────────────┘
         ↓
┌─────────────────────┐
│    Save Image       │
└─────────────────────┘
```

#### 参数配置

| 参数 | 说明 | 推荐值 |
|-----|------|-------|
| upscale_model | 放大模型 | 4x-UltraSharp, RealESRGAN |
| upscale_by | 放大倍数 | 2 或 4 |

#### 操作步骤

**步骤1：添加放大节点**

1. 添加 `Upscale Model Loader` 节点
2. 选择放大模型（如 `4x-UltraSharp.pth`）

**步骤2：连接工作流**

1. 将生成图像的输出连接到 `Image Upscale With Model` 节点
2. 连接放大模型输出
3. 设置放大倍数

**步骤3：运行放大**

#### 注意事项

1. **放大倍数选择**
   - 2x：适合中等放大，速度快
   - 4x：适合大幅放大，细节更好

2. **显存需求**
   - 放大操作需要较多显存
   - 大图像可能需要分块处理

## 进阶工作流模板详解

### ControlNet 深度控制模板

#### 功能描述
使用深度图控制图像生成，保持场景的空间结构和层次关系。

#### 使用场景
- 建筑渲染：保持建筑结构
- 室内设计：保持空间布局
- 场景重建：基于深度信息生成

#### 节点结构图

```
┌─────────────┐     ┌─────────────────────┐
│ Load Image  │────→│ Depth Preprocessor  │
└─────────────┘     └──────────┬──────────┘
                               │
                               ↓
                    ┌─────────────────────┐
                    │ Load ControlNet     │
                    │ Model (Depth)       │
                    └──────────┬──────────┘
                               │
                               ↓
                    ┌─────────────────────┐
                    │ Apply ControlNet    │
                    └──────────┬──────────┘
                               │
┌──────────────────────────────┼──────────────────────────────┐
│                              ↓                              │
│  ┌───────────────────────────────────────────────────────┐  │
│  │                    KSampler                           │  │
│  └───────────────────────────┬───────────────────────────┘  │
│                              ↓                              │
│  ┌───────────────────────────────────────────────────────┐  │
│  │ Load Checkpoint → CLIP Text Encode → VAE Decode       │  │
│  └───────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────┘
                               ↓
                    ┌─────────────────────┐
                    │     Save Image      │
                    └─────────────────────┘
```

#### 参数配置详解

**ControlNet 参数：**

| 参数 | 说明 | 推荐值 | 范围 |
|-----|------|-------|------|
| control_net | ControlNet模型 | control_depth_sd15 | - |
| strength | 控制强度 | 0.7-0.9 | 0.0-1.0 |
| preprocessor | 预处理器 | DepthAnything | - |

**strength 参数效果：**

| 值 | 效果 | 适用场景 |
|---|------|---------|
| 0.3-0.5 | 轻微引导 | 保持大致结构，允许自由发挥 |
| 0.6-0.8 | 中等引导 | 平衡结构和创意 |
| 0.9-1.0 | 强引导 | 严格遵循深度图 |

#### 操作步骤

**步骤1：准备深度图**

有两种方式：
- 方式A：使用预处理器自动生成
- 方式B：手动准备深度图

**步骤2：构建工作流**

1. 添加 `Load Image` 节点，加载参考图
2. 添加 `Depth Anything Preprocessor` 节点
3. 添加 `Load ControlNet Model` 节点
4. 添加 `Apply ControlNet` 节点
5. 连接节点并配置参数

**步骤3：配置参数**

```
ControlNet Model: control_depth_sd15
Strength: 0.8
Preprocessor: DepthAnything
```

**步骤4：运行生成**

#### 注意事项

1. **深度图质量**
   - 清晰的深度图效果更好
   - 避免使用模糊或低质量的参考图

2. **模型版本匹配**
   - SD 1.5 使用 sd15 版本 ControlNet
   - SDXL 使用 sdxl 版本 ControlNet

1. 添加放大节点
2. 设置放大倍数为 2x

**步骤5：运行生成**

#### 注意事项

1. **面部修复**
   - 必须安装 ComfyUI-Impact-Pack
   - 检测阈值默认即可

2. **提示词技巧**
   - 使用权重语法：`(keyword:1.2)` 增强权重
   - 使用降权语法：`(keyword:0.8)` 降低权重

## 视频工作流模板详解

### AnimateDiff 基础模板

#### 功能描述
使用 AnimateDiff 生成 AI 动画，让静态图像动起来。

#### 使用场景
- AI 动画制作
- 动态表情包
- 短视频创作

#### 节点结构图

```
┌─────────────────┐
│ Load Checkpoint │
└────────┬────────┘
         ↓
┌─────────────────────┐
│ AnimateDiff Loader  │
└────────┬────────────┘
         ↓
┌─────────────────┐
│    KSampler     │
└────────┬────────┘
         ↓
┌─────────────────────┐
│    VAE Decode       │
└────────┬────────────┘
         ↓
┌─────────────────────┐
│   Video Combine     │
└────────┬────────────┘
         ↓
┌─────────────────────┐
│   Save Video/GIF    │
└─────────────────────┘
```

#### 参数配置

| 参数 | 推荐值 | 说明 |
|-----|-------|------|
| frame_count | 16 | 帧数（16帧约1秒） |
| motion_scale | 1.0 | 运动强度 |
| fps | 8 | 帧率 |
| context_length | 16 | 上下文长度 |

#### 操作步骤

**步骤1：安装 AnimateDiff**

```bash
cd custom_nodes
git clone https://github.com/Kosinkadink/ComfyUI-AnimateDiff-Evolved.git
```

**步骤2：下载运动模型**

下载 `mm_sd_v15_v2.ckpt` 放入 `models/animatediff_models/` 目录。

**步骤3：构建工作流**

1. 添加 `AnimateDiff Loader` 节点
2. 选择运动模型
3. 设置帧数和参数
4. 连接到 KSampler

**步骤4：生成视频**

运行后会在 `output/` 目录生成 GIF 或视频文件。

#### 注意事项

1. **显存需求**
   - 16帧需要约 8GB 显存
   - 32帧需要约 12GB 显存

2. **帧数选择**
   - 8帧：简单动画
   - 16帧：标准动画
   - 32帧：较长动画

### 视频转绘模板

#### 功能描述
将现有视频转换为不同风格，保持视频的时间一致性。

#### 使用场景
- 视频风格化
- 动画转绘
- 视频特效

#### 节点结构图

```
┌─────────────┐     ┌─────────────────┐
│ Load Video  │────→│ Extract Frames  │
└─────────────┘     └────────┬────────┘
                             │
                             ↓
                  ┌─────────────────────┐
                  │  Batch Processing   │
                  │  (逐帧 img2img)     │
                  └──────────┬──────────┘
                             │
                             ↓
                  ┌─────────────────────┐
                  │   Video Combine     │
                  └──────────┬──────────┘
                             │
                             ↓
                  ┌─────────────────────┐
                  │   Save Video        │
                  └─────────────────────┘
```

#### 参数配置

| 参数 | 推荐值 | 说明 |
|-----|-------|------|
| denoise | 0.4-0.6 | 降低闪烁 |
| seed | 固定值 | 保持一致性 |
| batch_size | 1-4 | 批处理帧数 |

#### 注意事项

1. **闪烁问题**
   - 使用较低的 denoise 值
   - 固定随机种子
   - 使用帧间混合

2. **处理时间**
   - 视频转绘耗时较长
   - 建议使用批处理

## 常见问题 FAQ

### Q1：工作流加载后节点显示红色怎么办？

**原因：** 缺少必要的自定义节点。

**解决方案：**

1. 打开 ComfyUI Manager
2. 点击 `Install Missing Nodes`
3. 等待安装完成
4. 重启 ComfyUI

### Q2：如何快速找到适合的工作流？

**解决方案：**

1. **按场景搜索**
   - 查看工作流标签和分类
   - 阅读用途说明

2. **查看示例效果**
   - 查看工作流附带的示例图
   - 判断是否符合需求

3. **查看难度等级**
   - 入门：基础模板
   - 中级：ControlNet、IP-Adapter
   - 高级：视频、批量处理

### Q3：工作流参数如何调整？

**调整原则：**

1. **保守调整**
   - 每次只调整一个参数
   - 小幅度调整（±10%）

2. **记录变化**
   - 记录调整前后效果
   - 建立参数调优日志

3. **参考推荐值**
   - 查看工作流文档中的推荐值
   - 从推荐值开始微调

### Q4：如何创建自己的工作流模板？

**创建步骤：**

1. **从基础开始**
   - 先使用现有模板
   - 理解节点连接逻辑

2. **逐步添加功能**
   - 添加需要的节点
   - 测试每个新增功能

3. **优化参数**
   - 找到最佳参数组合
   - 记录参数说明

4. **编写文档**
   - 按照文档模板编写
   - 添加使用说明和示例

### Q5：工作流版本升级后不兼容怎么办？

**解决方案：**

1. **保留旧版本**
   - 不要删除旧版本工作流
   - 使用版本号区分

2. **查看更新日志**
   - 了解变更内容
   - 按指南迁移配置

3. **逐步迁移**
   - 先在新版本中复现旧配置
   - 确认效果后再全面切换
