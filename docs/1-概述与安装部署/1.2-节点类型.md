## 一、什么是节点？

**简单理解：** 节点就像是工厂流水线上的"工作站"，每个节点负责完成一个特定的任务。比如：

- 有的节点负责"加载模型"（相当于准备材料）
- 有的节点负责"写提示词"（相当于下达指令）
- 有的节点负责"生成图片"（相当于加工生产）
- 有的节点负责"保存图片"（相当于包装出货）

**节点之间通过"连线"传递数据**，就像流水线上的传送带一样。

## 二、模型加载类节点

### 2.1 Load Checkpoint（加载模型）

#### 🔍 功能描述

这个节点用来加载"大模型"（Checkpoint），大模型是 AI 画图的核心，决定了图片的整体风格。

**通俗理解：** 就像选择不同的画家，不同的画家有不同的画风：

- Realistic Vision = 写实派画家
- DreamShaper = 综合派画家
- Anything V4 = 动漫派画家

#### 📌 使用场景

- **文生图**：从零开始生成图片
- **图生图**：基于参考图生成新图片
- **风格迁移**：使用特定风格的模型

#### 📥 输入端口

| 端口名称 | 数据类型 | 说明       |
| ---- | ---- | -------- |
| 无    | -    | 此节点不需要输入 |

#### 📤 输出端口

| 端口名称  | 数据类型  | 颜色  | 说明            |
| ----- | ----- | --- | ------------- |
| MODEL | MODEL（模型） | 紫色  | UNet 模型，用于采样器 |
| CLIP  | CLIP（文本编码器） | 黄色  | 文本编码器，用于提示词节点 |
| VAE   | VAE（变分自编码器） | 粉色  | 变分自编码器，用于编解码  |

#### ⚙️ 参数详解

| 参数名       | 类型   | 说明     | 推荐值    |
| --------- | ---- | ------ | ------ |
| ckpt_name（模型文件名） | 下拉选择 | 选择模型文件 | 根据需求选择 |

#### 💡 使用示例

```
1. 双击画布，搜索 "Load Checkpoint（加载模型）"
2. 点击 ckpt_name（模型文件名）下拉框
3. 选择你下载的模型，如 "Realistic Vision V5.safetensors"
4. 将 MODEL 输出连接到 KSampler（K采样器）的 model 输入
5. 将 CLIP 输出连接到 CLIP Text Encode（CLIP文本编码器）的 clip 输入
```

#### ⚠️ 注意事项

- **模型必须放在正确位置**：`ComfyUI/models/checkpoints/`
- **模型不显示？** 检查文件格式（.safetensors 或 .ckpt）
- **模型太大？** 选择 FP16 版本可以节省显存

### 2.2 Load LoRA（加载LoRA）

#### 🔍 功能描述

LoRA 是一种"小模型"，可以在不改变大模型的情况下，给图片添加特定的风格或特征。

**通俗理解：** 就像给画家一副"特殊眼镜"，让他能看到并画出特定的效果：

- Detail Tweaker LoRA = 让画家更注重细节
- Anime LoRA = 让画家画出动漫风格
- Lighting LoRA = 让画家擅长光影效果

#### 📌 使用场景

- **增强细节**：使用 Detail Tweaker LoRA
- **风格迁移**：使用特定风格的 LoRA
- **角色一致性**：使用角色 LoRA

#### 📥 输入端口

| 端口名称  | 数据类型  | 说明                        |
| ----- | ----- | ------------------------- |
| model（模型） | MODEL（模型） | 从 Load Checkpoint 来的模型    |
| clip（文本编码器） | CLIP（文本编码器） | 从 Load Checkpoint 来的 CLIP |

#### 📤 输出端口

| 端口名称  | 数据类型  | 说明              |
| ----- | ----- | --------------- |
| MODEL | MODEL（模型） | 加载 LoRA 后的模型    |
| CLIP  | CLIP（文本编码器） | 加载 LoRA 后的 CLIP |

#### ⚙️ 参数详解

| 参数名            | 类型   | 说明           | 推荐值       |
| -------------- | ---- | ------------ | --------- |
| lora_name（LoRA文件名）      | 下拉选择 | 选择 LoRA 文件   | 根据需求选择    |
| strength_model（模型影响强度） | 数值   | 对模型的影响强度     | 0.5 - 1.0 |
| strength_clip（CLIP影响强度）  | 数值   | 对 CLIP 的影响强度 | 0.5 - 1.0 |

#### 💡 使用示例

```
1. 从 Load Checkpoint 连接 MODEL 和 CLIP 到 Load LoRA（加载LoRA）
2. 选择 LoRA 文件
3. 设置 strength_model（模型影响强度） = 0.8
4. 将 Load LoRA 的输出连接到后续节点
```

#### ⚠️ 注意事项

- **强度不要太高**：超过 1.0 可能导致图片变形
- **可以叠加多个 LoRA**：但要注意显存占用
- **LoRA 必须与大模型兼容**：SD 1.5 的 LoRA 只能用于 SD 1.5 的模型

### 2.3 Load VAE（加载VAE）

#### 🔍 功能描述

VAE 负责图片的编码和解码，影响图片的颜色和细节。

**通俗理解：** 就像画家的"调色板"，不同的 VAE 会让图片呈现不同的色彩效果。

#### 📌 使用场景

- **颜色偏灰**：使用 sd-vae-ft-mse 修复
- **SDXL 模型**：需要使用专门的 SDXL VAE
- **动漫模型**：有些动漫模型需要专门的 VAE

#### 📥 输入端口

| 端口名称 | 数据类型 | 说明       |
| ---- | ---- | -------- |
| 无    | -    | 此节点不需要输入 |

#### 📤 输出端口

| 端口名称 | 数据类型  | 说明     |
| ---- | ---- | ------ |
| VAE  | VAE（变分自编码器） | VAE 模型 |

#### ⚙️ 参数详解

| 参数名      | 类型   | 说明        | 推荐值           |
| -------- | ---- | --------- | ------------- |
| vae_name（VAE文件名） | 下拉选择 | 选择 VAE 文件 | sd-vae-ft-mse |

#### 💡 使用示例

```
1. 添加 Load VAE（加载VAE）节点
2. 选择 vae-ft-mse.safetensors
3. 将 VAE 输出连接到 VAE Decode（VAE解码）的 vae 输入
```

#### ⚠️ 注意事项

- **很多模型自带 VAE**：不需要额外加载
- **颜色问题优先检查 VAE**：偏灰、偏黄通常是 VAE 问题

### 2.4 Load ControlNet Model（加载ControlNet模型）

#### 🔍 功能描述

ControlNet 可以精确控制图片的生成，比如控制姿势、深度、边缘等。

**通俗理解：** 就像给画家一个"参考骨架"，让他按照骨架来画画：

- OpenPose ControlNet = 按照人物姿势画
- Depth ControlNet = 按照深度关系画
- Canny ControlNet = 按照边缘轮廓画

#### 📌 使用场景

- **姿势控制**：使用 OpenPose ControlNet
- **深度控制**：使用 Depth ControlNet
- **边缘控制**：使用 Canny ControlNet

#### 📥 输入端口

| 端口名称 | 数据类型 | 说明       |
| ---- | ---- | -------- |
| 无    | -    | 此节点不需要输入 |

#### 📤 输出端口

| 端口名称        | 数据类型        | 说明            |
| ----------- | ----------- | ------------- |
| CONTROL_NET | CONTROL_NET（ControlNet模型） | ControlNet 模型 |

#### ⚙️ 参数详解

| 参数名              | 类型   | 说明               | 推荐值    |
| ---------------- | ---- | ---------------- | ------ |
| control_net_name（ControlNet文件名） | 下拉选择 | 选择 ControlNet 文件 | 根据需求选择 |

#### 💡 使用示例

```
1. 添加 Load ControlNet Model（加载ControlNet模型）节点
2. 选择 control_v11p_sd15_openpose.safetensors
3. 将 CONTROL_NET 输出连接到 Apply ControlNet 节点
```

#### ⚠️ 注意事项

- **ControlNet 需要配合预处理器**：通常需要添加预处理器节点
- **版本要匹配**：SD 1.5 用 sd15 版本，SDXL 用 sdxl 版本

## 三、提示词类节点

### 3.1 CLIP Text Encode（CLIP文本编码器）

#### 🔍 功能描述

将你写的文字（提示词）转换成 AI 能理解的信息。

**通俗理解：** 就像"翻译官"，把你写的中文/英文翻译成 AI 能理解的"机器语言"。

#### 📌 使用场景

- **正向提示词**：描述你想要的内容
- **负向提示词**：描述你不想要的内容

#### 📥 输入端口

| 端口名称 | 数据类型 | 说明                              |
| ---- | ---- | ------------------------------- |
| clip（文本编码器） | CLIP（文本编码器） | 从 Load Checkpoint 或 Load LoRA 来 |
| text（提示词文本） | 字符串  | 提示词文本                           |

#### 📤 输出端口

| 端口名称         | 数据类型         | 说明                |
| ------------ | ------------ | ----------------- |
| CONDITIONING | CONDITIONING（条件编码） | 条件编码，连接到 KSampler |

#### ⚙️ 参数详解

| 参数名  | 类型  | 说明    | 推荐值   |
| ---- | --- | ----- | ----- |
| text（提示词） | 文本框 | 输入提示词 | 见下方示例 |

#### 💡 使用示例

**正向提示词示例：**

```
a beautiful sunset over the ocean, golden hour, peaceful, professional photography, 8k, highly detailed
```

**负向提示词示例：**

```
low quality, blurry, ugly, distorted, text, watermark, bad anatomy
```

#### ⚠️ 注意事项

- **正向提示词连接 positive**：连接到 KSampler 的 positive 输入
- **负向提示词连接 negative**：连接到 KSampler 的 negative 输入
- **提示词用英文**：大部分模型对英文支持更好

## 四、采样类节点

### 4.1 KSampler（K采样器）

#### 🔍 功能描述

这是 AI 画图的核心节点，负责"想象"和"绘制"图片。

**通俗理解：** 就像"画家的大脑"，根据你的提示词，一步步把图片"画"出来。

#### 📌 使用场景

- **文生图**：从零开始生成图片
- **图生图**：基于参考图生成新图片

#### 📥 输入端口

| 端口名称         | 数据类型         | 说明                                  |
| ------------ | ------------ | ----------------------------------- |
| model（模型）        | MODEL（模型）        | 从 Load Checkpoint 或 Load LoRA 来     |
| positive（正向条件）     | CONDITIONING（条件编码） | 正向条件，从正向提示词节点来                      |
| negative（负向条件）     | CONDITIONING（条件编码） | 负向条件，从负向提示词节点来                      |
| latent_image（潜空间图像） | LATENT（潜空间数据）       | 从 Empty Latent Image 或 VAE Encode 来 |

#### 📤 输出端口

| 端口名称   | 数据类型   | 说明       |
| ------ | ------ | -------- |
| LATENT | LATENT（潜空间数据） | 生成的潜空间图像 |

#### ⚙️ 参数详解

| 参数名          | 类型   | 说明              | 推荐值             |
| ------------ | ---- | --------------- | --------------- |
| seed（随机种子）         | 整数   | 随机种子，相同种子生成相同图片 | 任意数字            |
| steps（采样步数）        | 整数   | 采样步数，越多越精细      | 20-30           |
| cfg（提示词引导强度）          | 浮点数  | 提示词引导强度         | 7-8             |
| sampler_name（采样器名称） | 下拉选择 | 采样器名称           | euler_ancestral |
| scheduler（调度器）    | 下拉选择 | 调度器             | normal          |
| denoise（去噪强度）      | 浮点数  | 去噪强度            | 1.0（文生图）        |

#### 💡 使用示例

```
1. 连接 model、positive、negative、latent_image 输入
2. 设置 seed（随机种子） = 123456789
3. 设置 steps（采样步数） = 25
4. 设置 cfg（提示词引导强度） = 7
5. 设置 sampler_name（采样器名称） = euler_ancestral
6. 设置 denoise（去噪强度） = 1.0
```

#### ⚠️ 注意事项

- **steps 不是越多越好**：超过 50 通常没有明显提升
- **denoise = 1.0 表示完全重新生成**：图生图时可以调低
- **seed 相同则结果相同**：想变化就改变 seed

### 4.2 KSampler Advanced（高级K采样器）

#### 🔍 功能描述

比标准采样器提供更多控制选项，适合高级用户。

#### 📌 使用场景

- **分步生成**：从中间某步开始或结束
- **精细控制**：需要更多参数调整

#### ⚙️ 额外参数详解

| 参数名                        | 类型  | 说明       | 推荐值     |
| -------------------------- | --- | -------- | ------- |
| add_noise（是否添加噪声）                  | 布尔  | 是否添加噪声   | true    |
| start_at_step（起始步数）              | 整数  | 起始步数     | 0       |
| end_at_step（结束步数）                | 整数  | 结束步数     | steps 值 |
| return_with_leftover_noise（是否返回剩余噪声） | 布尔  | 是否返回剩余噪声 | false   |

---

### 4.3 Empty Latent Image（空Latent图像）

#### 🔍 功能描述

创建一个"空白画布"，AI 会在这个画布上"画"出图片。

**通俗理解：** 就像准备一张白纸，让画家在上面作画。

#### 📌 使用场景

- **文生图**：创建空白画布
- **设置图片尺寸**：决定生成图片的大小

#### 📥 输入端口

| 端口名称 | 数据类型 | 说明       |
| ---- | ---- | -------- |
| 无    | -    | 此节点不需要输入 |

#### 📤 输出端口

| 端口名称   | 数据类型   | 说明      |
| ------ | ------ | ------- |
| LATENT | LATENT（潜空间数据） | 空白潜空间图像 |

#### ⚙️ 参数详解

| 参数名        | 类型  | 说明       | 推荐值            |
| ---------- | --- | -------- | -------------- |
| width（宽度）      | 整数  | 图片宽度（像素） | 512, 768, 1024 |
| height（高度）     | 整数  | 图片高度（像素） | 512, 768, 1024 |
| batch_size（批量大小） | 整数  | 批量生成数量   | 1              |

#### 💡 使用示例

```
1. 设置 width（宽度） = 512
2. 设置 height（高度） = 768（竖图）
3. 设置 batch_size（批量大小） = 1
```

#### ⚠️ 注意事项

- **尺寸要是 64 的倍数**：如 512, 576, 640, 704, 768, 832, 896, 960, 1024
- **尺寸越大显存占用越高**：显存小就减小尺寸
- **SDXL 推荐尺寸**：1024x1024

## 五、解码类节点

### 5.1 VAE Decode（VAE解码）

#### 🔍 功能描述

将 AI 生成的"潜空间图像"转换成我们能看到的"真实图片"。

**通俗理解：** 就像"显影"，把底片（潜空间图像）冲洗成照片（真实图片）。

#### 📌 使用场景

- **生成图片后**：必须使用此节点才能看到图片

#### 📥 输入端口

| 端口名称    | 数据类型   | 说明                 |
| ------- | ------ | ------------------ |
| samples（潜空间样本） | LATENT（潜空间数据） | 从 KSampler 来的潜空间图像 |
| vae（变分自编码器）     | VAE（变分自编码器）    | VAE 模型             |

#### 📤 输出端口

| 端口名称  | 数据类型  | 说明   |
| ----- | ----- | ---- |
| IMAGE | IMAGE（图像数据） | 真实图片 |

#### 💡 使用示例

```
1. 连接 KSampler 的 LATENT 输出到 samples（潜空间样本）
2. 连接 Load Checkpoint 的 VAE 输出到 vae（变分自编码器）
3. 将 IMAGE 输出连接到 Save Image（保存图像）节点
```

---

### 5.2 VAE Encode（VAE编码）

#### 🔍 功能描述

将真实图片转换成"潜空间图像"，用于图生图。

**通俗理解：** 就像"扫描"，把照片扫描成底片。

#### 📌 使用场景

- **图生图**：基于参考图生成新图片
- **图片重绘**：修改已有图片

#### 📥 输入端口

| 端口名称   | 数据类型  | 说明     |
| ------ | ----- | ------ |
| pixels（像素数据） | IMAGE（图像数据） | 输入图片   |
| vae（变分自编码器）    | VAE（变分自编码器）   | VAE 模型 |

#### 📤 输出端口

| 端口名称   | 数据类型   | 说明    |
| ------ | ------ | ----- |
| LATENT | LATENT（潜空间数据） | 潜空间图像 |

## 六、输出类节点

### 6.1 Save Image（保存图像）

#### 🔍 功能描述

将生成的图片保存到电脑上。

**通俗理解：** 就像"拍照保存"，把生成的图片存到硬盘。

#### 📌 使用场景

- **保存最终结果**：生成完成后保存图片

#### 📥 输入端口

| 端口名称   | 数据类型  | 说明                |
| ------ | ----- | ----------------- |
| images（图像数据） | IMAGE（图像数据） | 从 VAE Decode 来的图片 |

#### ⚙️ 参数详解

| 参数名             | 类型  | 说明    | 推荐值     |
| --------------- | --- | ----- | ------- |
| filename_prefix（文件名前缀） | 文本  | 文件名前缀 | ComfyUI |

#### 💡 使用示例

```
1. 连接 VAE Decode 的 IMAGE 输出到 images（图像数据）
2. 设置 filename_prefix（文件名前缀） = "my_image"
3. 图片会保存到 ComfyUI/output/my_image_001.png
```

## 八、快速添加节点的方法

### 方法 1：双击添加

1. **双击画布空白处**
2. **输入节点名称搜索**
3. **点击或回车添加**

### 方法 2：右键菜单

1. **右键点击画布**
2. **选择 Add Node**
3. **浏览分类找到节点**

### 方法 3：搜索节点

1. **按 Ctrl+F（Windows）或 Cmd+F（Mac）**
2. **输入节点名称**
3. **点击搜索结果添加**

## 九、常见问题

### Q1：节点连接不上？

**原因：** 数据类型不匹配

**解决：** 检查端口颜色是否一致，只有相同颜色的端口才能连接

### Q2：节点显示红色？

**原因：** 节点有错误或缺少输入

**解决：** 检查所有必需的输入是否已连接

### Q3：找不到某个节点？

**原因：** 可能是自定义节点，需要安装

**解决：** 使用 ComfyUI-Manager 安装对应的自定义节点包
