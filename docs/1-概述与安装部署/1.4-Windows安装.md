# Windows 安装教程

> **文档版本：** 2026.05
> **更新日期：** 2026-05-11
> **相关官方文档：** [ComfyUI 官方文档](https://docs.comfy.org/) | [中文安装指南](https://docs.comfy.org/zh/installation/desktop/windows)
> **适合人群：** Windows 用户，零基础初学者
> **预计时间：** 30-60 分钟

---

## 一、前置检查

### 硬件要求

> ⚠️ **时效性提示：** 以下内容可能随软件版本更新而变化，请以官方最新文档为准。

| 配置 | 能否运行 | 体验如何 |
|-----|---------|---------|
| NVIDIA RTX 3060 (6GB VRAM) | ✅ 可以 | 基本功能可用 |
| NVIDIA RTX 3090/4080 (10GB+ VRAM) | ✅ 可以 | 体验很好 |
| NVIDIA RTX 4090 (24GB VRAM) | ✅ 可以 | 体验最佳 |
| 没有 NVIDIA GPU | ⚠️ 困难 | 速度很慢 |

### 软件要求
- Windows 10 或 Windows 11（64位）
- 至少 50GB 可用存储空间
- 稳定的网络连接

---

## 二、安装 Git

1. 打开浏览器，访问 [Git 官网](https://git-scm.com/download/win)
2. 点击"Download for Windows"按钮
3. 运行下载的安装程序
4. 按照安装向导的提示进行安装（全部使用默认选项即可）
5. 安装完成后，按 `Win + R`，输入 `cmd`，打开命令提示符
6. 输入 `git --version`，如果显示版本号说明安装成功

---

## 三、安装 Python

1. 打开浏览器，访问 [Python 官网](https://www.python.org/downloads/windows/)
2. 下载 Python 3.13.x 版本（推荐 3.13，如遇兼容问题可尝试 3.12）
3. 运行安装程序
4. **重要：勾选"Add Python to PATH"选项**
5. 点击"Install Now"进行安装
6. 安装完成后，打开命令提示符，输入 `python --version`，如果显示版本号说明安装成功

---

## 四、下载 ComfyUI

1. 打开命令提示符
2. 输入以下命令，创建一个新文件夹并进入：
   ```
   mkdir ComfyUI
   cd ComfyUI
   ```
3. 输入以下命令下载 ComfyUI：
   ```
   git clone https://github.com/comfyanonymous/ComfyUI.git
   ```
4. 等待下载完成（可能需要几分钟）

---

## 五、安装依赖

1. 进入 ComfyUI 文件夹：
   ```
   cd ComfyUI
   ```
2. 安装基础依赖：
   ```
   pip install torch torchvision torchaudio --extra-index-url https://download.pytorch.org/whl/cu130
   ```
3. 安装其他依赖：
   ```
   pip install -r requirements.txt
   ```
4. 安装 xFormers（可选但推荐）：
   ```
   pip install xformers
   ```

---

## 六、下载模型

### 方法 1：使用 ComfyUI-Manager（推荐）

1. 启动 ComfyUI（参考第五步）
2. 在界面中找到 `ComfyUI-Manager` 按钮
3. 点击进入后，搜索你想要的模型
4. 点击下载按钮

### 方法 2：手动下载

1. 打开浏览器，访问 [Civitai](https://civitai.com/)
2. 注册账号并登录
3. 搜索你想要的模型（比如 "Realistic Vision"）
4. 点击下载按钮
5. 将下载的模型文件（.safetensors 或 .ckpt）放到 `ComfyUI/models/checkpoints/` 文件夹中

---

## 七、启动 ComfyUI

1. 在 ComfyUI 文件夹中，找到 `run_nvidia_gpu.bat` 文件
2. 双击运行它
3. 等待命令行窗口显示 "Server started"
4. 打开浏览器，访问 `http://localhost:8188`
5. 如果能看到 ComfyUI 的界面，说明安装成功！

---

## 八、测试生成

1. 在界面右上角点击 `Load` 按钮
2. 选择 `txt2img.json` 示例工作流
3. 在 `CheckpointLoaderSimple` 节点中选择你下载的模型
4. 修改提示词为你想要的内容
5. 点击 `Queue Prompt` 按钮
6. 等待生成完成

---

## 九、常见问题

### Q1：启动时提示"找不到 CUDA"
**解决：**
1. 确保你安装的是 NVIDIA 的显卡
2. 安装最新的 NVIDIA 显卡驱动
3. 确认使用的是 `run_nvidia_gpu.bat`

### Q2：安装依赖时出现错误
**解决：**
1. 确保网络连接稳定
2. 尝试使用国内镜像：
   ```
   pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
   ```

### Q3：模型下载很慢
**解决：**
1. 使用国内镜像网站
2. 使用下载工具加速下载
3. 考虑使用云盘分享的模型

### Q4：生成时显存不足
**解决：**
1. 减小图片尺寸（比如从 1024 改为 512）
2. 减少 batch size
3. 使用 `--lowvram` 启动参数

## 十、启动参数说明

你可以创建一个自定义的启动脚本，添加以下参数：

| 参数 | 说明 | 示例 |
|-----|------|-----|
| --lowvram | 低显存模式 | 适合 4-6GB VRAM |
| --normalvram | 正常显存模式 | 适合 8-12GB VRAM |
| --highvram | 高显存模式 | 适合 16GB+ VRAM |
| --port | 指定端口 | --port 8189 |
| --listen | 允许外网访问 | --listen 0.0.0.0 |

---

## 十一、卸载方法

如果你想卸载 ComfyUI：
1. 关闭运行中的 ComfyUI
2. 删除整个 ComfyUI 文件夹
3. 使用控制面板卸载 Python 和 Git（可选）
