## 1.8.1 系统要求

> ⚠️ **时效性说明：** Python 和 PyTorch 版本要求可能随时间变化，请以官方文档为准。

### 硬件要求

| 组件 | 最低要求 | 推荐配置 |
|------|----------|----------|
| GPU | GTX 1060 6GB | RTX 3060 12GB+ |
| 内存 | 16GB | 32GB+ |
| 硬盘 | 50GB SSD | 200GB+ SSD |

### 软件要求

| 组件 | 版本要求 |
|------|----------|
| Python | 3.9+（推荐 3.13） |
| PyTorch | 2.4+（推荐最新版） |
| Git | 最新版 |

**Python 版本说明：**
- Python 3.13：非常稳定，推荐使用
- Python 3.14：可用但某些自定义节点可能有问题
- Python 3.12：如果 3.13 有问题可尝试

## 1.8.2 安装方式

### 方式一：桌面应用程序（推荐新手）

> 最简单的入门方式，支持 Windows 和 macOS。

1. 访问 [ComfyUI 官方网站](https://www.comfy.org/)
2. 下载桌面应用程序
3. 安装并运行

### 方式二：Windows 便携版（推荐）

> 完全便携，包含最新提交。

1. 访问 [ComfyUI Releases](https://github.com/comfyanonymous/ComfyUI/releases)
2. 下载 `ComfyUI_windows_portable` 压缩包
3. 使用 7-Zip 或 Windows 资源管理器解压
4. 运行 `run_nvidia_gpu.bat`（NVIDIA 显卡）

**便携版说明：**
- 当前版本包含 Python 3.13 和 PyTorch CUDA 13.0
- 如果无法启动，请更新 NVIDIA 驱动

**替代下载：**
- AMD GPU 便携版
- Intel GPU 实验性便携版
- PyTorch CUDA 12.6 + Python 3.12 版本（支持 NVIDIA 10 系列及更早 GPU）

### 方式三：使用 comfy-cli 安装（推荐开发者）

```bash
# 安装 comfy-cli
pip install comfy-cli

# 安装 ComfyUI（会自动安装 ComfyUI-Manager）
comfy install
```

### 方式四：手动安装

**步骤 1：克隆仓库**

```bash
git clone https://github.com/comfyanonymous/ComfyUI.git
cd ComfyUI
```

**步骤 2：安装 PyTorch**

> ⚠️ **时效性说明：** CUDA 版本会更新，请以官方文档为准。

**NVIDIA GPU：**

```bash
# 稳定版（推荐）
pip install torch torchvision torchaudio --extra-index-url https://download.pytorch.org/whl/cu130

# 每日构建版（可能有性能提升）
pip install --pre torch torchvision torchaudio --index-url https://download.pytorch.org/whl/nightly/cu132
```

**AMD GPU (Linux + ROCm)：**

```bash
# 稳定版
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/rocm7.2
```

**Intel GPU：**

```bash
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/xpu
```

**Apple Mac Silicon：**

```bash
pip install --pre torch torchvision torchaudio --index-url https://download.pytorch.org/whl/nightly/cpu
```

**步骤 3：安装依赖**

```bash
pip install -r requirements.txt
```

**步骤 4：运行 ComfyUI**

```bash
python main.py
```

## 1.8.4 启动参数

> ⚠️ **时效性说明：** 启动参数可能随版本更新变化，请以官方文档为准。

### 基本参数

| 参数 | 说明 |
|------|------|
| `--listen 0.0.0.0` | 允许外部访问 |
| `--port 8188` | 指定端口 |
| `--cpu` | CPU 模式 |

### 显存模式

| 参数 | 说明 | 适用显存 |
|------|------|----------|
| `--lowvram` | 低显存模式 | 4-6 GB |
| `--normalvram` | 正常模式 | 8+ GB |
| `--highvram` | 高显存模式 | 16+ GB |

### 预览参数

| 参数 | 说明 |
|------|------|
| `--preview-method auto` | 自动选择预览方法 |
| `--preview-method taesd` | 使用 TAESD 高质量预览 |

### Manager 参数

| 参数 | 说明 |
|------|------|
| `--enable-manager` | 启用 ComfyUI-Manager |
| `--user-directory <PATH>` | 指定用户目录 |

### 前端参数

| 参数 | 说明 |
|------|------|
| `--front-end-version Comfy-Org/ComfyUI_frontend@latest` | 使用最新前端 |
| `--front-end-version Comfy-Org/ComfyUI_frontend@1.2.2` | 使用指定版本 |

## 1.8.5 快捷键

> ⚠️ **时效性说明：** 快捷键可能随版本更新变化。

## 1.8.6 常见问题排查

| 问题 | 解决方案 |
|------|----------|
| "Torch not compiled with CUDA enabled" | 卸载 torch 后重新安装 |
| 无法访问界面 | 检查防火墙设置 |
| 显存不足 | 使用 `--lowvram` 参数 |
| 模型加载失败 | 检查模型路径和格式 |
| 解压失败（Windows） | 右键文件 → 属性 → 解除阻止 |
| SSL 错误 | 在 Manager 的 config.ini 中添加 `bypass_ssl = True` |
