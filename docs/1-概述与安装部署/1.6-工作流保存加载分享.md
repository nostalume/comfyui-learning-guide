## 1.6.1 工作流格式

ComfyUI 工作流以 **JSON 格式**保存，包含：

- 节点信息（类型、位置、参数）
- 连接关系
- 版本信息

---

## 1.6.2 保存工作流

### 菜单操作

| 操作        | 方法                       | 快捷键      |
| --------- | ------------------------ | -------- |
| 保存工作流     | 菜单 → Save                | Ctrl + S |
| 导出 API 格式 | 菜单 → Export (API Format) | -        |

### API 格式说明

API 格式用于程序化调用，包含：

- 节点 ID 映射
- 输入参数结构
- 执行顺序

---

## 1.6.3 加载工作流

### 菜单操作

| 操作      | 方法                | 快捷键      |
| ------- | ----------------- | -------- |
| 加载工作流   | 菜单 → Load         | Ctrl + O |
| 加载默认工作流 | 菜单 → Load Default | Ctrl + D |

### 拖拽加载

1. 将 `.json` 文件拖入浏览器窗口
2. 自动加载工作流

---

## 1.6.4 从生成图片恢复工作流

ComfyUI 支持从生成的图片中恢复完整工作流。

### 支持的格式

- PNG
- WebP
- FLAC

### 操作方法

1. 将生成的图片拖入 ComfyUI 界面
2. 自动加载完整工作流（包括种子）

---

## 1.6.5 工作流分享方式

### 方式一：JSON 文件

```
步骤：
1. 保存工作流为 .json 文件
2. 发送文件给他人
3. 对方拖入浏览器即可加载
```

### 方式二：截图分享（推荐）

```
步骤：
1. 菜单 → Save as Image
2. 导出包含工作流数据的截图
3. 分享截图
4. 对方拖入浏览器即可加载
```

**优点：**

- 可视化展示工作流结构
- 自动嵌入完整 JSON 数据
- 便于在社交平台分享

### 方式三：在线平台

| 平台             | 网址                 | 特点      |
| -------------- | ------------------ | ------- |
| ComfyWorkflows | comfyworkflows.com | 专业工作流平台 |
| OpenArt        | openart.ai         | 资源丰富    |
| Civitai        | civitai.com        | 模型+工作流  |

## 1.6.6 工作流版本管理

### 使用 Git 管理

```bash
# 初始化仓库
git init

# 添加工作流目录
git add workflows/

# 提交更改
git commit -m "feat: add portrait workflow"

# 版本回退
git checkout HEAD~1 -- workflows/portrait.json
```

### 命名规范建议

```
[场景]_[功能]_[版本].json

示例：
portrait_basic_v1.json
landscape_hires_v2.json
product_photo_v1.json
```
