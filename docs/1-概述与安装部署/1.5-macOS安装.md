# macOS 安装教程

> **文档版本：** 2026.05
> **更新日期：** 2026-05-11
> **相关官方文档：** [ComfyUI 官方文档](https://docs.comfy.org/) | [中文安装指南](https://docs.comfy.org/zh/installation/desktop/macos)
> **适合人群：** macOS 用户，零基础初学者
> **预计时间：** 30-60 分钟

---

## 一、前置检查

### 硬件要求

> ⚠️ **时效性提示：** 以下内容可能随软件版本更新而变化，请以官方最新文档为准。

| 配置 | 能否运行 | 体验如何 |
|-----|---------|---------|
| Apple Silicon (M1/M2/M3) | ✅ 可以 | 原生支持，体验良好 |
| Intel Mac + NVIDIA GPU | ✅ 可以 | 需要配置 CUDA |
| Intel Mac (无独显) | ⚠️ 困难 | 速度很慢 |

### 软件要求
- macOS 12.0 (Monterey) 或更高版本
- 至少 50GB 可用存储空间
- 稳定的网络连接

---

## 二、安装 Homebrew

1. 打开"终端"应用（在应用程序/实用工具中）
2. 输入以下命令并按回车：
   ```
   /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
   ```
3. 按照提示输入密码
4. 等待安装完成

---

## 三、安装 Git

1. 在终端中输入：
   ```
   brew install git
   ```
2. 等待安装完成
3. 输入 `git --version` 确认安装成功

---

## 四、安装 Python

1. 在终端中输入：
   ```
   brew install python@3.13
   ```
2. 等待安装完成
3. 输入 `python3 --version` 确认安装成功

---

## 五、下载 ComfyUI

1. 在终端中输入：
   ```
   mkdir ~/ComfyUI
   cd ~/ComfyUI
   ```
2. 克隆 ComfyUI 仓库：
   ```
   git clone https://github.com/comfyanonymous/ComfyUI.git
   ```
3. 等待下载完成

---

## 六、安装依赖

1. 进入 ComfyUI 文件夹：
   ```
   cd ComfyUI
   ```
2. 安装 PyTorch（Apple Silicon）：
   ```
   pip3 install --pre torch torchvision torchaudio --index-url https://download.pytorch.org/whl/nightly/cpu
   ```
   （Intel Mac + NVIDIA GPU 请参考官方文档安装带 CUDA 的 PyTorch）
3. 安装其他依赖：
   ```
   pip3 install -r requirements.txt
   ```
4. 安装 xFormers（推荐）：
   ```
   pip3 install xformers
   ```

---

## 七、下载模型

### 方法 1：使用 ComfyUI-Manager（推荐）

1. 启动 ComfyUI（参考第八步）
2. 在界面中找到 `ComfyUI-Manager` 按钮
3. 点击进入后，搜索你想要的模型
4. 点击下载按钮

### 方法 2：手动下载

1. 打开浏览器，访问 [Civitai](https://civitai.com/)
2. 注册账号并登录
3. 搜索你想要的模型（比如 "Realistic Vision"）
4. 点击下载按钮
5. 将下载的模型文件（.safetensors 或 .ckpt）放到 `~/ComfyUI/ComfyUI/models/checkpoints/` 文件夹中

---

## 八、启动 ComfyUI

1. 在终端中输入：
   ```
   cd ~/ComfyUI/ComfyUI
   python3 main.py
   ```
2. 等待终端显示 "Server started"
3. 打开浏览器，访问 `http://localhost:8188`
4. 如果能看到 ComfyUI 的界面，说明安装成功！

---

## 九、测试生成

1. 在界面右上角点击 `Load` 按钮
2. 选择 `txt2img.json` 示例工作流
3. 在 `CheckpointLoaderSimple` 节点中选择你下载的模型
4. 修改提示词为你想要的内容
5. 点击 `Queue Prompt` 按钮
6. 等待生成完成

---

## 十、创建启动脚本

为了方便启动，可以创建一个启动脚本：

1. 在终端中输入：
   ```
   nano ~/ComfyUI/start.sh
   ```
2. 输入以下内容：
   ```
   #!/bin/bash
   cd ~/ComfyUI/ComfyUI
   python3 main.py
   ```
3. 按 `Ctrl+X`，然后按 `Y` 保存
4. 输入以下命令赋予执行权限：
   ```
   chmod +x ~/ComfyUI/start.sh
   ```
5. 以后启动时只需输入：
   ```
   ~/ComfyUI/start.sh
   ```

## 十一、常见问题

### Q1：启动时提示"找不到 torch"
**解决：**
1. 确保使用的是 `python3` 而不是 `python`
2. 重新安装 PyTorch：
   ```
   pip3 install torch torchvision torchaudio
   ```

### Q2：模型下载很慢
**解决：**
1. 使用国内镜像网站
2. 使用下载工具加速下载
3. 考虑使用云盘分享的模型

### Q3：生成时提示内存不足
**解决：**
1. 减小图片尺寸（比如从 1024 改为 512）
2. 关闭其他占用内存的应用
3. 在启动命令中添加 `--lowvram` 参数

---

## 十二、启动参数说明

你可以在启动时添加以下参数：

| 参数 | 说明 | 示例 |
|-----|------|-----|
| --lowvram | 低显存模式 | 适合显存较小的设备 |
| --port | 指定端口 | --port 8189 |
| --listen | 允许外网访问 | --listen 0.0.0.0 |

---

## 十三、卸载方法

如果你想卸载 ComfyUI：
1. 关闭运行中的 ComfyUI
2. 在终端中输入：
   ```
   rm -rf ~/ComfyUI
   ```
3. 卸载 Homebrew（可选）：参考 Homebrew 官方文档
