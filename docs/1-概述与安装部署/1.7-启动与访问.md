## 一、启动 ComfyUI

### Windows 用户

1. 打开文件资源管理器
2. 找到你安装 ComfyUI 的文件夹
3. 双击 `run_nvidia_gpu.bat` 文件
4. 会弹出一个命令行窗口，请不要关闭它

### macOS 用户

1. 打开终端应用
2. 输入以下命令：
   ```
   cd ~/ComfyUI/ComfyUI
   python3 main.py
   ```
3. 终端会显示启动信息，请不要关闭终端窗口

### 启动成功的标志

当命令行窗口显示以下内容时，说明启动成功：

```
Server started
Open your browser and go to: http://localhost:8188
```

---

## 二、访问 ComfyUI

1. 打开你的浏览器（推荐使用 Chrome 或 Firefox）
2. 在地址栏输入：`http://localhost:8188`
3. 按下回车键
4. 如果一切正常，你会看到 ComfyUI 的界面

---

## 三、界面介绍

### 第一次打开

当你第一次打开 ComfyUI 时，界面应该是空白的，这是正常的。你需要：

1. 加载一个示例工作流
2. 或者自己创建一个工作流

### 界面布局

| 区域 | 说明 |
|-----|------|
| **左侧面板** | 节点菜单，包含所有可用的节点 |
| **中间区域** | 工作区，用于放置和连接节点 |
| **右侧上方** | 属性面板，显示选中节点的参数 |
| **右侧下方** | 队列和历史记录 |
| **顶部工具栏** | 包含保存、加载、运行等按钮 |

---

## 四、加载示例工作流

1. 点击右上角的 `Load` 按钮
2. 在下拉菜单中选择一个示例：
   - `txt2img.json` - 文生图示例
   - `img2img.json` - 图生图示例
   - 其他示例...
3. 工作区会显示已经连接好的节点

---

## 五、运行工作流

1. 确保你已经选择了一个模型（在 `CheckpointLoaderSimple` 节点中）
2. 点击右上角的 `Queue Prompt` 按钮
3. 右侧的队列会显示正在处理
4. 等待生成完成
5. 生成的图片会显示在右侧的历史记录中

## 六、常见启动问题

### Q1：命令行窗口一闪而过
**原因：** 启动脚本执行失败

**解决方法：**
1. 不要双击 `.bat` 文件
2. 打开命令提示符，进入 ComfyUI 文件夹
3. 手动运行 `run_nvidia_gpu.bat`
4. 查看错误信息

### Q2：提示"CUDA out of memory"
**原因：** 显存不足

**解决方法：**
1. 关闭其他占用显存的程序
2. 使用 `--lowvram` 参数启动
3. 减小图片尺寸

### Q3：无法访问 `http://localhost:8188`
**原因：** ComfyUI 没有启动成功

**解决方法：**
1. 检查命令行窗口是否有错误信息
2. 确保端口 8188 没有被其他程序占用
3. 尝试使用其他端口启动

### Q4：提示"找不到模型"
**原因：** 没有下载模型或模型位置不对

**解决方法：**
1. 下载至少一个模型
2. 将模型放到 `ComfyUI/models/checkpoints/` 文件夹中
3. 重新启动 ComfyUI

## 七、关闭 ComfyUI

### Windows 用户
1. 切换到命令行窗口
2. 按 `Ctrl + C` 组合键
3. 或者直接关闭命令行窗口

### macOS 用户
1. 切换到终端窗口
2. 按 `Ctrl + C` 组合键
3. 或者直接关闭终端窗口

---

## 八、设置开机自启动（可选）

### Windows 用户

1. 右键点击 `run_nvidia_gpu.bat` 文件
2. 选择"创建快捷方式"
3. 将快捷方式拖到"开始菜单"的"启动"文件夹中

### macOS 用户

1. 打开"系统设置"
2. 点击"通用" > "登录项"
3. 点击 "+" 按钮
4. 选择你创建的 `start.sh` 脚本
