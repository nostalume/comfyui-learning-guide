## 1.3.1 什么是连线？

### 功能描述

在ComfyUI中，"连线"是连接不同节点之间的"管道"，用于传递数据。就像水管连接水龙头和水桶一样，连线将一个节点的输出数据传递到另一个节点的输入端口。

**核心概念：**
- **节点（Node）**：一个功能模块，如"加载模型"、"输入提示词"、"生成图片"等
- **端口（Port）**：节点上的连接点，分为输入端口（左侧）和输出端口（右侧）
- **连线（Connection）**：连接两个端口的数据传输通道

### 使用场景

- 将模型数据从"加载模型"节点传递到"提示词编码"节点
- 将编码后的提示词传递到"采样器"节点
- 将生成的图片传递到"保存图片"节点

### 示例

最简单的文生图工作流连线：

```
Load Checkpoint ──→ CLIP Text Encode ──→ KSampler ──→ VAE Decode ──→ Save Image
   (加载模型)         (编码提示词)        (采样生成)     (解码图片)     (保存图片)
```

### 注意事项

- 连线是单向的，数据只能从输出端口流向输入端口
- 连线有颜色区分，不同颜色代表不同数据类型
- 错误的连接会导致工作流无法执行

## 1.3.2 数据流向规则

### 功能描述

ComfyUI采用**从左到右**的数据流向，就像阅读中文书籍一样，数据从左侧节点流向右侧节点。

**基本规则：**
```
输入节点（左侧）→ 处理节点（中间）→ 输出节点（右侧）
```

### 使用场景

理解数据流向可以帮助你：
- 正确排列节点的位置
- 理解数据处理的先后顺序
- 排查工作流中的问题

### 示例

**典型文生图工作流数据流：**

```
                    ┌──→ CLIP Text Encode (Positive) ──┐
                    │        (正向提示词编码)            │
Load Checkpoint ────┤                                    ├──→ KSampler ──→ VAE Decode ──→ Save Image
   (加载模型)        │                                    │    (采样器)      (解码)         (保存)
                    └──→ CLIP Text Encode (Negative) ──┘
                             (负向提示词编码)
                              ↑
                        Empty Latent Image
                           (空白潜空间)
```

**数据流向详解：**

1. **Load Checkpoint（加载模型）**：加载AI模型，输出三个数据
   - MODEL：模型权重数据
   - CLIP：文本编码器
   - VAE：图像解码器

2. **CLIP Text Encode（提示词编码）**：将文字转换为AI能理解的数字
   - 输入：CLIP（文本编码器）+ 提示词文字
   - 输出：CONDITIONING（条件数据）

3. **Empty Latent Image（空白潜空间）**：创建一个空白的"画布"
   - 输出：LATENT（潜空间数据）

4. **KSampler（采样器）**：核心生成节点
   - 输入：MODEL + 正向条件 + 负向条件 + 潜空间
   - 输出：LATENT（生成的潜空间数据）

5. **VAE Decode（解码）**：将潜空间数据转换为可见图片
   - 输入：LATENT + VAE
   - 输出：IMAGE（图片数据）

6. **Save Image（保存图片）**：将图片保存到文件
   - 输入：IMAGE

### 注意事项

- 数据必须按正确顺序流动，否则无法生成正确结果
- 缺少任何必要的数据输入，节点会显示错误
- 可以通过观察连线颜色判断数据类型是否正确

## 1.3.3 类型匹配规则

### 功能描述

ComfyUI使用**颜色编码**来区分不同的数据类型。只有**相同颜色**的端口才能连接，这就像拼图一样，形状相同的才能拼在一起。

### 常见数据类型及颜色

| 数据类型 | 颜色 | 说明 | 常见来源节点 |
|----------|------|------|--------------|
| MODEL | 薰衣草色 | AI模型权重数据 | Load Checkpoint |
| CLIP | 黄色 | 文本编码器 | Load Checkpoint |
| VAE | 玫瑰色 | 图像编解码器 | Load Checkpoint |
| CONDITIONING | 橙色 | 条件数据（编码后的提示词） | CLIP Text Encode |
| LATENT | 粉色 | 潜空间数据 | Empty Latent Image, KSampler |
| IMAGE | 蓝色 | 图片数据 | VAE Decode, Load Image |
| MASK | 绿色 | 遮罩数据 | Load Image (mask) |
| INT | 浅绿色 | 整数数字 | Primitive节点 |
| FLOAT | 浅绿色 | 浮点数字 | Primitive节点 |
| STRING | 浅绿色 | 文本字符串 | Primitive节点 |

### 使用场景

- 判断两个节点是否可以连接
- 理解数据在节点间传递时的类型变化
- 排查"无法连接"的问题

### 基本规则

1. **相同颜色端口才能连接**
   - 正确：薰衣草色MODEL端口 → 薰衣草色MODEL端口
   - 错误：薰衣草色MODEL端口 → 黄色CLIP端口

2. **输出端口（右侧）→ 输入端口（左侧）**
   - 数据从节点的右侧输出端口流出
   - 数据流入节点的左侧输入端口

3. **一个输出可连接多个输入**
   - 一个Load Checkpoint的MODEL输出可以同时连接到多个KSampler

4. **一个输入只能连接一个输出**
   - 一个KSampler的MODEL输入只能接收一个模型数据

### 类型转换

某些情况下可以自动转换数据类型：

| 原类型 | 目标类型 | 转换方式 | 说明 |
|--------|----------|----------|------|
| IMAGE | MASK | 自动转换 | 图像可转为遮罩（黑白图像） |
| MASK | IMAGE | 自动转换 | 遮罩可转为图像 |

### 示例

**正确连接示例：**

```
Load Checkpoint
    │
    ├── MODEL (薰衣草色) ──────→ KSampler (薰衣草色输入)
    │
    ├── CLIP (黄色) ──→ CLIP Text Encode (黄色输入)
    │
    └── VAE (玫瑰色) ────→ VAE Decode (玫瑰色输入)
```

**错误连接示例：**

```
❌ 错误：MODEL (薰衣草色) ──→ CLIP输入 (黄色)
   原因：颜色不匹配，类型不兼容

❌ 错误：从输入端口拖线到另一个输入端口
   原因：输入端口只能接收数据，不能输出数据
```

### 注意事项

- 如果端口颜色不同，连线会失败
- 某些自定义节点可能使用特殊颜色
- 悬停在端口上可以看到数据类型名称

## 1.3.4 连线操作详解

### 功能描述

掌握连线的各种操作方法，可以更高效地构建和编辑工作流。

### 基本操作

| 操作 | 方法 | 详细说明 |
|------|------|----------|
| **创建连接** | 从输出端口拖拽到输入端口 | 按住鼠标左键，从右侧端口拖到左侧端口后松开 |
| **断开连接** | 右键点击连线 → Delete | 或者拖拽连线到空白处松开 |
| **移动连线** | 拖拽连线端点到新端口 | 可以将已连接的线拖到另一个兼容端口 |
| **批量断开** | Ctrl + Alt + 左键点击端口 | 断开该端口的所有连接 |

### 使用场景

- 构建新的工作流
- 修改现有工作流
- 调试和优化工作流

### 示例

**创建连接步骤：**
1. 找到源节点的输出端口（节点右侧的小圆点）
2. 鼠标左键按住输出端口
3. 拖动鼠标到目标节点的输入端口（节点左侧的小圆点）
4. 当端口高亮时松开鼠标
5. 连线创建成功

**断开连接步骤：**
1. 找到要断开的连线
2. 右键点击连线
3. 在弹出菜单中选择"Delete"
4. 连线被删除

**移动连线步骤：**
1. 鼠标左键按住连线的端点（靠近端口的位置）
2. 拖动到新的目标端口
3. 松开鼠标
4. 连线移动成功

### 快捷操作

| 快捷操作 | 方法 | 说明 |
|----------|------|------|
| **Shift + 拖拽连线** | 按住Shift拖动连线端点 | 同时移动连接到同一端口的多条连线 |
| **Ctrl + 点击节点** | 按住Ctrl点击节点 | 添加节点到选择（多选） |
| **Delete/Backspace** | 选中后按键 | 删除选中的节点和连线 |
| **双击画布** | 双击空白区域 | 打开节点搜索面板 |

### 注意事项

- 拖动连线到不兼容的端口时，端口不会高亮，表示无法连接
- 删除节点会同时删除与该节点相关的所有连线
- 使用Ctrl+Z可以撤销误操作

## 1.3.5 节点操作快捷键

### 功能描述

使用快捷键可以大幅提高工作流编辑效率，减少鼠标操作。

### 快捷键列表

> ⚠️ **时效性提示：** 以下内容可能随软件版本更新而变化，请以官方最新文档为准。

| 快捷键 | 功能 | 详细说明 |
|--------|------|----------|
| **双击画布** | 打开节点搜索面板 | 快速搜索和添加节点 |
| **Ctrl + C** | 复制节点 | 复制选中的节点到剪贴板 |
| **Ctrl + V** | 粘贴节点 | 粘贴剪贴板中的节点 |
| **Ctrl + Shift + V** | 粘贴并保持外部连接 | 粘贴节点时保持与外部节点的连接 |
| **Delete/Backspace** | 删除选中节点 | 删除选中的节点和连线 |
| **Ctrl + M** | 静音/取消静音节点 | 静音的节点会被跳过执行 |
| **Ctrl + B** | 绕过节点 | 绕过该节点，直接传递输入到输出 |
| **Alt + C** | 折叠/展开节点 | 隐藏或显示节点的详细参数 |
| **Ctrl + G** | 节点分组 | 将选中的节点放入一个组框中 |
| **P** | 固定/取消固定节点 | 固定的节点不会被自动排列 |
| **Ctrl + A** | 全选 | 选择所有节点 |
| **Ctrl + D** | 复制选中的节点 | 快速复制节点 |
| **Ctrl + Z** | 撤销 | 撤销上一步操作 |
| **Ctrl + Y** | 重做 | 重做被撤销的操作 |

**macOS用户：** Ctrl 可替换为 Cmd

### 使用场景

- 快速添加新节点（双击画布）
- 批量复制节点（Ctrl+C/V）
- 调试工作流（Ctrl+M静音节点）
- 整理工作流（Ctrl+G分组）

### 示例

**快速添加节点：**
1. 双击画布空白处
2. 在搜索框输入节点名称（如"load"）
3. 点击搜索结果中的节点
4. 节点被添加到画布

**复制节点组：**
1. 按住Ctrl，点击多个节点进行多选
2. 按Ctrl+C复制
3. 按Ctrl+V粘贴
4. 新节点组出现在原位置旁边

**静音节点调试：**
1. 选中要跳过的节点
2. 按Ctrl+M静音
3. 执行工作流，该节点被跳过
4. 再次按Ctrl+M取消静音

### 注意事项

- 静音节点时，其输出数据将使用上次执行的结果
- 绕过节点时，数据会直接传递，可能导致错误
- 折叠节点可以节省画布空间，但不影响执行

## 1.3.6 批量处理

### 功能描述

批量处理允许你一次性生成多张图片，而不需要重复点击执行按钮。

### 使用场景

- 生成大量图片用于筛选最佳结果
- 测试不同种子下的生成效果
- 批量处理一组图片

### 方法一：Batch Size 方式

**功能描述：**
在 Empty Latent Image 节点设置 batch_size 参数，一次生成多张图片。

**参数说明：**

| 参数 | 说明 | 建议值 |
|------|------|--------|
| batch_size | 同时生成的图片数量 | 1-4（取决于显存大小） |
| width | 图片宽度（像素） | 512, 768, 1024 |
| height | 图片高度（像素） | 512, 768, 1024 |

**示例：**
1. 添加 Empty Latent Image 节点
2. 设置 batch_size = 4
3. 设置 width = 512, height = 512
4. 执行工作流
5. 一次性生成4张图片

**注意事项：**
- batch_size 越大，显存占用越高
- 如果显存不足，尝试减小 batch_size
- 建议根据显卡显存大小调整：4GB显存建议batch_size=1-2

### 方法二：种子批量

**功能描述：**
使用相同参数，不同种子批量生成图片。

**操作步骤：**
1. 在 KSampler 节点取消勾选 "control_after_generate"
2. 点击 "Queue Prompt" 按钮旁边的数字输入框
3. 设置生成数量（如10）
4. 点击执行
5. ComfyUI会自动使用不同种子生成10张图片

**示例：**
```
设置：
- 种子：固定值（如12345）
- control_after_generate：取消勾选
- 批量数量：10

结果：生成10张图片，每张使用不同的种子
```

**注意事项：**
- 这种方式会依次执行，不是并行
- 每张图片使用相同的其他参数，只有种子不同
- 适合测试不同随机效果

### 方法三：队列批量

**功能描述：**
将多个任务加入队列，依次执行。

**操作步骤：**
1. 设置好工作流参数
2. 多次点击 "Queue Prompt" 按钮
3. 观察右侧队列计数增加
4. 任务会依次执行

**示例：**
```
操作：
1. 设置提示词："a cat"
2. 点击 Queue Prompt 5次
3. 队列显示 5 个任务
4. 依次生成5张图片
```

**注意事项：**
- 队列中的任务会按顺序执行
- 可以点击队列数字查看任务列表
- 可以在执行过程中取消队列中的任务

## 1.3.7 常见连线问题排查

### 功能描述

当工作流无法正常执行时，学会排查连线问题。

### 常见问题及解决方案

| 问题 | 可能原因 | 解决方法 |
|------|----------|----------|
| 节点显示红色边框 | 缺少必要输入 | 检查所有输入端口是否已连接 |
| 无法连接两个端口 | 类型不匹配 | 检查端口颜色是否相同 |
| 执行后无输出 | 连线顺序错误 | 检查数据流向是否正确 |
| 显存不足错误 | batch_size过大 | 减小batch_size或使用低显存模式 |
| 图片全黑或全白 | VAE未正确连接 | 检查VAE连接是否正确 |

### 示例

**问题：KSampler节点显示红色**
1. 检查MODEL输入是否已连接
2. 检查正向条件（positive）是否已连接
3. 检查负向条件（negative）是否已连接
4. 检查潜空间（latent）是否已连接
5. 补充缺失的连接

**问题：生成的图片是噪点**
1. 检查采样步数（steps）是否过少（建议20+）
2. 检查CFG值是否合理（建议7-15）
3. 检查模型是否正确加载
4. 检查提示词是否有效

### 注意事项

- 执行前检查所有节点是否有红色边框
- 使用预览功能检查中间结果
- 保存工作流备份，方便回滚
