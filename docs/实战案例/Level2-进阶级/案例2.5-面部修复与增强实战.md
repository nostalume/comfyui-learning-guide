## 📖 核心概念：什么是面部修复？

### 🎓 面部修复简介

**面部修复**（Face Restoration）是一种图像处理技术，可以改善低质量人脸图像的细节和质量。

**通俗理解：**
- 输入一张模糊、低质量的人脸照片
- AI 会识别面部区域并重新生成高质量细节
- 输出一张清晰、细节丰富的人脸图像

### 🎓 FaceDetailer 工作原理

```
输入图像 → 面部检测 → 提取面部区域 → 重绘面部 → 融合回原图 → 输出图像
```

**关键步骤：**
1. **面部检测**：识别图像中的人脸位置
2. **区域提取**：裁剪出面部区域
3. **重绘处理**：使用 AI 重新生成面部细节
4. **融合输出**：将修复后的面部融合回原图

### 🎓 修复模型对比

| 模型 | 特点 | 适用场景 | 推荐指数 |
|-----|------|---------|---------|
| CodeFormer | 效果平衡，通用性好 | 大多数场景 | ⭐⭐⭐⭐⭐ |
| GFPGAN | 细节增强效果好 | 需要更多细节 | ⭐⭐⭐⭐ |
| RestoreFormer | 高质量修复 | 专业修复 | ⭐⭐⭐⭐ |

### 🎓 应用场景

| 场景 | 说明 | 效果 |
|-----|------|------|
| 低分辨率修复 | 提升模糊图像清晰度 | 清晰化 |
| 生成图像优化 | 修复 AI 生成图像的面部问题 | 提升质量 |
| 老照片修复 | 修复老旧照片的面部 | 恢复细节 |
| 批量处理 | 处理多张人物图像 | 批量优化 |

### 步骤 1: 安装 Impact Pack

**方法一：通过 ComfyUI Manager（推荐新手）**

1. 打开 ComfyUI
2. 点击右侧面板的 `Manager` 按钮
3. 点击 `Install Custom Nodes`
4. 搜索 `Impact Pack`
5. 找到 `ComfyUI-Impact-Pack`，点击 `Install`
6. 重启 ComfyUI

**方法二：手动安装**

```bash
cd ComfyUI/custom_nodes
git clone https://github.com/ltdrdata/ComfyUI-Impact-Pack.git
cd ComfyUI-Impact-Pack
git submodule update --init --recursive
pip install -r requirements.txt
```

### 步骤 2: 准备需要修复的图像

**适合修复的图像类型：**

| ✅ 适合修复 | ❌ 不适合修复 |
|-----------|-------------|
| 低分辨率人脸 | 无人脸图像 |
| 模糊的人脸 | 人脸过小（<50px） |
| AI 生成的面部问题 | 严重遮挡的人脸 |
| 老旧照片 | 多人重叠严重 |

**图像要求：**
- 图像中至少有一张可识别的人脸
- 人脸尺寸建议大于 50 像素
- 支持格式：PNG、JPG、WEBP

### 步骤 3: 搭建面部修复工作流

**方法一：使用 FaceDetailer（推荐）**

**操作步骤：**

1. **清空工作区**
   - 点击菜单 `Edit` → `Clear` 或按 `Ctrl+Delete`

2. **逐个添加以下节点**（双击空白处搜索节点名称）：

| 序号 | 节点名称 | 搜索关键词 | 数量 |
|-----|---------|-----------|------|
| 1 | Load Checkpoint（加载模型） | checkpoint | 1 |
| 2 | Load Image（加载图像） | image | 1 |
| 3 | FaceDetailer | facedetailer | 1 |
| 4 | Save Image（保存图像） | save image | 1 |

### 步骤 4: 配置 FaceDetailer 参数

**加载模型（Load Checkpoint） 节点：**
```
ckpt_name: v1-5-pruned-emaonly.safetensors
```

**加载图像（Load Image） 节点：**
```
点击 "choose file to upload" 上传需要修复的图像
```

**FaceDetailer 节点（核心参数）：**

```
【基本参数】
image: 来自 Load Image
model: 来自 Load Checkpoint
guide_size: 512           ← 修复区域大小
guide_size_for: bbox      ← 尺寸参考类型
max_size: 1024            ← 最大处理尺寸

【采样参数】
seed: 随机（点击右侧骰子图标）
steps: 20                 ← 采样步数
cfg: 7.0                  ← CFG 强度
sampler_name: euler_ancestral
scheduler: normal
denoise: 0.5              ← 重绘强度（关键参数）

【检测参数】
bbox_threshold: 0.5       ← 面部检测阈值
bbox_dilation: 10         ← 边界扩展像素
```

### 步骤 5: 连接节点

**连接顺序（按输出端口 → 输入端口）：**

```
【模型连接】
Load Checkpoint → MODEL 输出 → FaceDetailer → model 输入
Load Checkpoint → CLIP 输出 → FaceDetailer → clip 输入
Load Checkpoint → VAE 输出 → FaceDetailer → vae 输入

【图像连接】
Load Image → IMAGE 输出 → FaceDetailer → image 输入

【输出连接】
FaceDetailer → IMAGE 输出 → Save Image → images 输入
```

### 步骤 6: 运行修复

**操作步骤：**

1. 检查所有节点是否正确连接（无红色警告）
2. 点击右侧面板的 `Queue Prompt` 按钮
3. 等待修复完成（约 10-30 秒）
4. 在 Save Image 节点查看结果

## 📊 参数详解

### 核心参数：denoise（重绘强度）

**参数含义：**
- 控制面部重绘的程度
- 值越大，修复效果越强，但可能偏离原图

**参数对照表：**

| denoise 值 | 效果描述 | 适用场景 | 推荐指数 |
|-----------|---------|---------|---------|
| 0.2 - 0.3 | 轻微修复 | 质量较好的原图，只需微调 | ⭐⭐⭐ |
| 0.4 - 0.5 | 中等修复 | 一般质量问题，标准使用 | ⭐⭐⭐⭐⭐ |
| 0.6 - 0.7 | 强力修复 | 严重质量问题 | ⭐⭐⭐⭐ |
| 0.8+ | 可能变形 | 极端情况，谨慎使用 | ⭐⭐ |

**调整建议：**
- 初学者从 **0.5** 开始尝试
- 如果修复效果不明显，提高到 0.6
- 如果面部变形，降低到 0.3-0.4

### 检测参数：bbox_threshold（检测阈值）

**参数含义：**
- 控制面部检测的灵敏度
- 值越高，检测越严格（只检测明显的面部）

**参数对照表：**

| threshold 值 | 效果描述 | 适用场景 |
|-------------|---------|---------|
| 0.3 - 0.4 | 高灵敏度 | 检测小尺寸人脸 |
| 0.5 | 标准灵敏度 | 通用场景 |
| 0.6 - 0.7 | 低灵敏度 | 只检测明显人脸 |

### 检测参数：bbox_dilation（边界扩展）

**参数含义：**
- 扩展检测到的面部边界
- 值越大，修复区域越大

**调整建议：**
- 默认值 **10** 适合大多数场景
- 如果修复区域太小，增加到 20-30
- 如果修复区域太大，减少到 5-10

### 采样参数：guide_size（修复区域大小）

**参数含义：**
- 面部区域的处理尺寸
- 值越大，细节越丰富，但处理越慢

**调整建议：**
- 默认值 **512** 适合大多数场景
- 需要更多细节时，提高到 768 或 1024
- 显存不足时，降低到 384

## ❓ 常见问题（FAQ）

### Q1: 面部检测失败怎么办？

**可能原因：**
1. 图像中人脸太小
2. 人脸被遮挡严重
3. 检测阈值过高

**解决方案：**
```
方案1：降低 bbox_threshold 值到 0.3-0.4
方案2：确保人脸尺寸大于 50 像素
方案3：使用更清晰的源图像
方案4：检查图像是否包含可识别的人脸
```

### Q2: 修复后面部变形怎么办？

**可能原因：**
1. denoise 值过高
2. 模型不兼容
3. 提示词冲突

**解决方案：**
```
方案1：降低 denoise 值到 0.3-0.4
方案2：使用推荐的 SD 1.5 模型
方案3：在 FaceDetailer 中设置合适的提示词
方案4：尝试不同的 seed 值
```

### Q3: 修复效果不明显怎么办？

**可能原因：**
1. denoise 值过低
2. 原图质量已经很好
3. 修复区域太小

**解决方案：**
```
方案1：提高 denoise 值到 0.6-0.7
方案2：增加 bbox_dilation 值扩大修复区域
方案3：提高 guide_size 到 768 或 1024
方案4：增加采样步数 steps 到 25-30
```

### Q4: 处理速度太慢怎么办？

**可能原因：**
1. 图像尺寸过大
2. guide_size 设置过高
3. 显存不足

**解决方案：**
```
方案1：降低图像尺寸
方案2：降低 guide_size 到 384 或 256
方案3：在启动参数中添加 --lowvram
方案4：关闭其他占用显存的程序
```

### Q5: 如何处理多人图像？

**方法：**
```
FaceDetailer 会自动检测图像中的所有人脸
并逐一进行修复处理

注意事项：
1. 确保所有人脸都大于 50 像素
2. 可能需要降低 bbox_threshold 以检测所有人脸
3. 处理时间会随人脸数量增加
```
