## 🚀 详细步骤

### 步骤 1: 理解节点结构

**目标：** 理解 ComfyUI 节点的核心组成部分

#### 1.1 节点的五大核心组件

每个 ComfyUI 节点都必须包含以下组件：

| 组件 | 类型 | 说明 | 是否必须 |
|-----|------|------|---------|
| `INPUT_TYPES` | 类方法 | 定义输入参数 | ✅ 必须 |
| `RETURN_TYPES` | 元组 | 定义输出类型 | ✅ 必须 |
| `FUNCTION` | 字符串 | 指定执行函数名 | ✅ 必须 |
| `CATEGORY` | 字符串 | 定义菜单分类 | ✅ 必须 |
| 执行函数 | 方法 | 实现节点逻辑 | ✅ 必须 |

#### 1.2 最简单的节点模板

```python
class MyFirstNode:
    """
    最简单的节点示例
    """
    
    @classmethod
    def INPUT_TYPES(cls):
        return {
            "required": {
                "input_value": ("INT", {"default": 1}),
            }
        }
    
    RETURN_TYPES = ("INT",)
    FUNCTION = "execute"
    CATEGORY = "my_nodes"
    
    def execute(self, input_value):
        result = input_value * 2
        return (result,)
```

#### 1.3 节点执行流程图

```
用户添加节点到工作流
        ↓
ComfyUI 调用 INPUT_TYPES() 获取输入定义
        ↓
用户在界面填写参数
        ↓
用户点击执行
        ↓
ComfyUI 调用 FUNCTION 指定的函数
        ↓
函数处理数据并返回结果
        ↓
结果传递给下一个节点
```

### 步骤 3: 开发第一个节点 - 图像亮度调整

**目标：** 创建一个实用的图像亮度调整节点

#### 3.1 编写节点代码

打开 `my_nodes.py`，写入以下代码：

```python
import torch

class BrightnessAdjustNode:
    """
    图像亮度调整节点
    
    功能：调整输入图像的亮度
    
    输入：
        - image: 输入图像张量 [B, H, W, C]
        - brightness: 亮度系数 (0.1-3.0)
    
    输出：
        - 调整后的图像张量
    """
    
    @classmethod
    def INPUT_TYPES(cls):
        return {
            "required": {
                "image": ("IMAGE",),
                "brightness": (
                    "FLOAT",
                    {
                        "default": 1.0,
                        "min": 0.1,
                        "max": 3.0,
                        "step": 0.1,
                        "display": "slider"
                    }
                ),
            }
        }
    
    RETURN_TYPES = ("IMAGE",)
    FUNCTION = "adjust_brightness"
    CATEGORY = "image/adjustments"
    
    def adjust_brightness(self, image: torch.Tensor, brightness: float):
        """
        调整图像亮度
        
        参数：
            image: 输入图像，形状 [B, H, W, C]，值范围 [0, 1]
            brightness: 亮度系数，1.0 为原始亮度
        
        返回：
            调整后的图像张量
        """
        result = image * brightness
        result = torch.clamp(result, 0.0, 1.0)
        return (result,)
```

#### 3.2 代码详解

**INPUT_TYPES 详解：**

```python
{
    "required": {           # 必须参数
        "image": ("IMAGE",),  # 参数名: (类型,)
        "brightness": (       # 参数名
            "FLOAT",          # 数据类型
            {                 # 参数配置
                "default": 1.0,    # 默认值
                "min": 0.1,        # 最小值
                "max": 3.0,        # 最大值
                "step": 0.1,       # 步进值
                "display": "slider" # 显示方式
            }
        ),
    },
    "optional": {           # 可选参数（本例没有）
        # "mask": ("MASK", {"default": None}),
    }
}
```

**参数配置选项：**

| 配置项 | 适用类型 | 说明 |
|-------|---------|------|
| `default` | 所有 | 默认值 |
| `min` | INT, FLOAT | 最小值 |
| `max` | INT, FLOAT | 最大值 |
| `step` | INT, FLOAT | 步进值 |
| `display` | INT, FLOAT | 显示方式："slider" 或 "number" |

class ImageCropNode:
    """
    图像裁剪节点
    
    功能：从指定位置裁剪图像
    
    输入：
        - image: 输入图像
        - x: 起始 X 坐标
        - y: 起始 Y 坐标
        - width: 裁剪宽度
        - height: 裁剪高度
    
    输出：
        - 裁剪后的图像
    """
    
    @classmethod
    def INPUT_TYPES(cls):
        return {
            "required": {
                "image": ("IMAGE",),
                "x": ("INT", {
                    "default": 0,
                    "min": 0,
                    "max": 4096,
                    "step": 1
                }),
                "y": ("INT", {
                    "default": 0,
                    "min": 0,
                    "max": 4096,
                    "step": 1
                }),
                "width": ("INT", {
                    "default": 512,
                    "min": 1,
                    "max": 4096,
                    "step": 1
                }),
                "height": ("INT", {
                    "default": 512,
                    "min": 1,
                    "max": 4096,
                    "step": 1
                }),
            }
        }
    
    RETURN_TYPES = ("IMAGE",)
    FUNCTION = "crop_image"
    CATEGORY = "image/transform"
    
    def crop_image(self, image: torch.Tensor, x: int, y: int, width: int, height: int):
        """
        裁剪图像
        
        参数：
            image: 输入图像 [B, H, W, C]
            x, y: 起始坐标
            width, height: 裁剪尺寸
        
        返回：
            裁剪后的图像
        """
        _, orig_height, orig_width, _ = image.shape
        
        x = max(0, min(x, orig_width - 1))
        y = max(0, min(y, orig_height - 1))
        width = min(width, orig_width - x)
        height = min(height, orig_height - y)
        
        cropped = image[:, y:y+height, x:x+width, :]
        
        return (cropped,)
```

class ImageStatsNode:
    """
    图像统计节点
    
    功能：计算图像的统计信息
    
    输入：
        - image: 输入图像
    
    输出：
        - mean: 平均值
        - std: 标准差
        - min: 最小值
        - max: 最大值
    """
    
    @classmethod
    def INPUT_TYPES(cls):
        return {
            "required": {
                "image": ("IMAGE",),
            }
        }
    
    RETURN_TYPES = ("FLOAT", "FLOAT", "FLOAT", "FLOAT")
    RETURN_NAMES = ("mean", "std", "min", "max")
    FUNCTION = "calculate_stats"
    CATEGORY = "image/analysis"
    
    def calculate_stats(self, image: torch.Tensor):
        """计算图像统计信息"""
        mean = float(image.mean())
        std = float(image.std())
        min_val = float(image.min())
        max_val = float(image.max())
        
        return (mean, std, min_val, max_val)
```

### 步骤 6: 开发带下拉选择的节点

**目标：** 创建一个带下拉选项的节点

#### 6.1 添加颜色滤镜节点

```python
class ColorFilterNode:
    """
    颜色滤镜节点
    
    功能：应用不同颜色滤镜效果
    """
    
    @classmethod
    def INPUT_TYPES(cls):
        return {
            "required": {
                "image": ("IMAGE",),
                "filter_type": (
                    "COMBO",
                    {
                        "choices": ["grayscale", "sepia", "invert", "warm", "cool"],
                        "default": "grayscale"
                    }
                ),
                "intensity": ("FLOAT", {
                    "default": 1.0,
                    "min": 0.0,
                    "max": 1.0,
                    "step": 0.1
                }),
            }
        }
    
    RETURN_TYPES = ("IMAGE",)
    FUNCTION = "apply_filter"
    CATEGORY = "image/effects"
    
    def apply_filter(self, image: torch.Tensor, filter_type: str, intensity: float):
        """应用颜色滤镜"""
        result = image.clone()
        
        if filter_type == "grayscale":
            gray = 0.299 * image[..., 0] + 0.587 * image[..., 1] + 0.114 * image[..., 2]
            gray = gray.unsqueeze(-1).expand(-1, -1, -1, 3)
            result = image * (1 - intensity) + gray * intensity
        
        elif filter_type == "sepia":
            sepia = torch.tensor([
                [0.393, 0.769, 0.189],
                [0.349, 0.686, 0.168],
                [0.272, 0.534, 0.131]
            ], device=image.device)
            result = torch.einsum('bhwc,cf->bhwf', image, sepia)
            result = torch.clamp(result, 0, 1)
            result = image * (1 - intensity) + result * intensity
        
        elif filter_type == "invert":
            result = image * (1 - intensity) + (1 - image) * intensity
        
        elif filter_type == "warm":
            warm_tint = torch.tensor([1.1, 1.0, 0.9], device=image.device)
            result = image * warm_tint
            result = torch.clamp(result, 0, 1)
            result = image * (1 - intensity) + result * intensity
        
        elif filter_type == "cool":
            cool_tint = torch.tensor([0.9, 1.0, 1.1], device=image.device)
            result = image * cool_tint
            result = torch.clamp(result, 0, 1)
            result = image * (1 - intensity) + result * intensity
        
        return (result,)
```

### Q2: 节点执行时报错 "AttributeError" 怎么办？

**常见原因：**

1. **FUNCTION 名称不匹配**

   ```python
   # 错误示例
   FUNCTION = "execute"        # 声明的函数名
   def run(self, ...):         # 实际函数名不匹配
       pass
   
   # 正确示例
   FUNCTION = "execute"
   def execute(self, ...):     # 名称必须匹配
       pass
   ```

2. **返回值格式错误**

### Q5: 如何在节点中使用其他节点的输出？

**方法：直接作为输入类型**

```python
class MyNode:
    @classmethod
    def INPUT_TYPES(cls):
        return {
            "required": {
                "model": ("MODEL",),      # 接收模型
                "clip": ("CLIP",),        # 接收 CLIP
                "latent": ("LATENT",),    # 接收潜在空间
            }
        }
    
    RETURN_TYPES = ("LATENT",)
    FUNCTION = "execute"
    
    def execute(self, model, clip, latent):
        # 使用这些输入
        return (latent,)
```

### Q6: 节点可以返回多个不同类型的数据吗？

**可以！示例：**

```python
class MultiOutputNode:
    RETURN_TYPES = ("IMAGE", "MASK", "FLOAT")
    RETURN_NAMES = ("image", "mask", "value")
    
    def execute(self, input_image):
        # 处理图像
        output_image = input_image * 1.2
        
        # 生成掩码
        mask = (input_image > 0.5).float()
        
        # 计算数值
        value = float(input_image.mean())
        
        return (output_image, mask, value)
```
