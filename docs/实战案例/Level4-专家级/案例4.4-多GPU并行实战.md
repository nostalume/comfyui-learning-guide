### 步骤 2: 理解多 GPU 模式

**目标：** 理解不同的多 GPU 使用方式

#### 2.1 多 GPU 模式对比

| 模式 | 原理 | 优点 | 缺点 | 适用场景 |
|-----|------|------|------|---------|
| **多实例模式** | 每个 GPU 运行独立实例 | 简单可靠、易扩展 | 需要管理多个端口 | 推荐，适合大多数场景 |
| **模型并行** | 单个模型分布到多 GPU | 支持超大模型 | 性能不稳定、通信开销 | 超大模型推理 |
| **数据并行** | 批量数据分配到多 GPU | 高吞吐量 | 需要修改代码 | 批量训练 |

#### 2.2 多实例模式工作原理

```
                    ┌─────────────────────────────────────┐
                    │           负载均衡客户端             │
                    │    (自动选择空闲 GPU 提交任务)        │
                    └───────────────┬─────────────────────┘
                                    │
                    ┌───────────────┼───────────────┐
                    ↓               ↓               ↓
            ┌───────────┐   ┌───────────┐   ┌───────────┐
            │  GPU 0    │   │  GPU 1    │   │  GPU 2    │
            │ 端口 8188 │   │ 端口 8189 │   │ 端口 8190 │
            │ ComfyUI   │   │ ComfyUI   │   │ ComfyUI   │
            │ 实例 1    │   │ 实例 2    │   │ 实例 3    │
            └───────────┘   └───────────┘   └───────────┘
```

#### 2.3 为什么推荐多实例模式？

1. **简单可靠**：每个实例独立运行，互不影响
2. **易于扩展**：增加 GPU 只需启动新实例
3. **故障隔离**：单个实例崩溃不影响其他实例
4. **灵活配置**：不同实例可以使用不同模型

### 步骤 4: 实现负载均衡客户端

**目标：** 创建自动分配任务的客户端

#### 4.1 创建负载均衡脚本

创建文件 `multigpu_client.py`：

```python
import requests
import json
import time
from typing import List, Dict, Any, Optional

class MultiGPUClient:
    """
    多 GPU 负载均衡客户端
    
    功能：
    - 自动检测可用服务器
    - 基于队列长度的负载均衡
    - 自动故障恢复
    """
    
    def __init__(self, servers: List[str]):
        """
        初始化客户端
        
        参数：
            servers: 服务器地址列表
            例如: ["http://localhost:8188", "http://localhost:8189"]
        """
        self.servers = servers
        self.queue_status = {server: 0 for server in servers}
        self.last_check = 0
        self.check_interval = 5
    
    def _update_queue_status(self):
        """更新各服务器的队列状态"""
        now = time.time()
        if now - self.last_check >= self.check_interval:
            for server in self.servers:
                try:
                    response = requests.get(f"{server}/queue", timeout=5)
                    if response.status_code == 200:
                        queue_info = response.json()
                        pending = len(queue_info.get("pending", []))
                        self.queue_status[server] = pending
                except Exception as e:
                    print(f"无法连接到 {server}: {e}")
                    self.queue_status[server] = float('inf')
            self.last_check = now
    
    def _get_best_server(self) -> str:
        """选择队列最短的服务器"""
        self._update_queue_status()
        
        available = [(server, status) for server, status in self.queue_status.items() 
                    if status != float('inf')]
        
        if not available:
            raise RuntimeError("没有可用的服务器")
        
        best_server = min(available, key=lambda x: x[1])[0]
        return best_server
    
    def queue_prompt(self, workflow: Dict[str, Any]) -> Dict[str, Any]:
        """
        提交工作流到最佳服务器
        
        参数：
            workflow: API 格式的工作流
        
        返回：
            包含 prompt_id 和 server 的结果
        """
        server = self._get_best_server()
        
        try:
            response = requests.post(
                f"{server}/prompt",
                json={"prompt": workflow},
                timeout=30
            )
            response.raise_for_status()
            result = response.json()
            result["server"] = server
            return result
        except Exception as e:
            print(f"提交失败: {e}")
            self.queue_status[server] = float('inf')
            return self.queue_prompt(workflow)
    
    def get_history(self, prompt_id: str, server: str = None) -> Dict[str, Any]:
        """获取工作流历史"""
        if server:
            servers_to_try = [server]
        else:
            servers_to_try = self.servers
        
        for s in servers_to_try:
            try:
                response = requests.get(f"{s}/history/{prompt_id}", timeout=10)
                if response.status_code == 200 and prompt_id in response.json():
                    return response.json()[prompt_id]
            except Exception as e:
                print(f"从 {s} 获取历史失败: {e}")
        
        raise RuntimeError(f"无法找到 prompt_id {prompt_id}")
    
    def wait_for_completion(self, prompt_id: str, server: str = None, 
                           timeout: int = 300) -> Dict[str, Any]:
        """等待工作流完成"""
        start = time.time()
        
        while time.time() - start < timeout:
            try:
                history = self.get_history(prompt_id, server)
                status = history.get("status", {})
                
                if status.get("completed", False):
                    return history
                
                if status.get("error", False):
                    raise RuntimeError(f"生成失败: {status.get('error_message')}")
            except RuntimeError:
                pass
            
            time.sleep(1)
        
        raise TimeoutError(f"超时 ({timeout}秒)")
    
    def get_status(self) -> Dict[str, Any]:
        """获取所有服务器状态"""
        status = {}
        for server in self.servers:
            try:
                response = requests.get(f"{server}/queue", timeout=5)
                if response.status_code == 200:
                    queue_info = response.json()
                    status[server] = {
                        "available": True,
                        "pending": len(queue_info.get("pending", [])),
                        "running": len(queue_info.get("running", []))
                    }
                else:
                    status[server] = {"available": False}
            except:
                status[server] = {"available": False}
        return status


def print_status(client: MultiGPUClient):
    """打印服务器状态"""
    status = client.get_status()
    print("\n" + "="*60)
    print("GPU 服务器状态")
    print("="*60)
    for server, info in status.items():
        if info["available"]:
            print(f"{server}: 可用 | 待处理: {info['pending']} | 运行中: {info['running']}")
        else:
            print(f"{server}: 不可用")
    print("="*60)


if __name__ == "__main__":
    client = MultiGPUClient([
        "http://localhost:8188",
        "http://localhost:8189",
    ])
    
    print_status(client)
```

### 步骤 5: 批量任务分发

**目标：** 实现自动分发批量任务到多个 GPU

#### 5.1 创建批量处理脚本

创建文件 `batch_generate.py`：

```python
import json
import time
from multigpu_client import MultiGPUClient, print_status

def batch_generate(prompts: list, workflow_path: str, output_dir: str = "output"):
    """
    批量生成图像
    
    参数：
        prompts: 提示词列表
        workflow_path: 工作流文件路径
        output_dir: 输出目录
    """
    client = MultiGPUClient([
        "http://localhost:8188",
        "http://localhost:8189",
    ])
    
    with open(workflow_path, "r") as f:
        base_workflow = json.load(f)
    
    tasks = []
    
    print(f"\n开始批量生成 {len(prompts)} 张图像...")
    print_status(client)
    
    for i, prompt in enumerate(prompts):
        print(f"\n[{i+1}/{len(prompts)}] 提交任务: {prompt[:50]}...")
        
        workflow = json.loads(json.dumps(base_workflow))
        
        for node_id, node_data in workflow.items():
            if node_data.get("class_type") == "CLIPTextEncode":
                if "positive" in node_id.lower() or node_data["inputs"].get("text", ""):
                    node_data["inputs"]["text"] = prompt
                    break
        
        result = client.queue_prompt(workflow)
        tasks.append({
            "prompt_id": result["prompt_id"],
            "server": result["server"],
            "prompt": prompt
        })
        print(f"  → 已提交到 {result['server']}")
        
        time.sleep(0.5)
    
    print(f"\n所有任务已提交，等待完成...")
    
    completed = 0
    for task in tasks:
        try:
            client.wait_for_completion(task["prompt_id"], task["server"])
            completed += 1
            print(f"[{completed}/{len(tasks)}] 完成: {task['prompt'][:30]}...")
        except Exception as e:
            print(f"任务失败: {e}")
    
    print(f"\n批量生成完成！成功: {completed}/{len(tasks)}")
    print_status(client)


if __name__ == "__main__":
    prompts = [
        "a beautiful sunset over the ocean, 4k, detailed",
        "a majestic mountain landscape with snow peaks",
        "a cozy cottage in the forest, warm lighting",
        "a futuristic city skyline at night, neon lights",
        "a cute cat playing in the garden, soft sunlight",
        "a peaceful lake at sunrise, misty morning"
    ]
    
    batch_generate(prompts, "workflow_api.json")
```

### 步骤 6: 监控多 GPU 状态

**目标：** 实时监控所有 GPU 的运行状态

#### 6.1 创建监控脚本

创建文件 `monitor_multigpu.py`：

```python
import subprocess
import time
import os

def clear_screen():
    os.system('cls' if os.name == 'nt' else 'clear')

def get_gpu_info():
    """获取所有 GPU 信息"""
    try:
        result = subprocess.run(
            ["nvidia-smi", "--query-gpu=index,name,temperature.gpu,utilization.gpu,memory.used,memory.total", 
             "--format=csv,noheader,nounits"],
            capture_output=True, text=True
        )
        
        gpus = []
        for line in result.stdout.strip().split('\n'):
            parts = [p.strip() for p in line.split(',')]
            if len(parts) >= 6:
                gpus.append({
                    "index": int(parts[0]),
                    "name": parts[1],
                    "temp": int(parts[2]),
                    "util": int(parts[3]),
                    "mem_used": int(parts[4]),
                    "mem_total": int(parts[5])
                })
        return gpus
    except:
        return []

def get_comfyui_status(port):
    """获取 ComfyUI 实例状态"""
    import requests
    try:
        response = requests.get(f"http://localhost:{port}/queue", timeout=2)
        if response.status_code == 200:
            data = response.json()
            return {
                "pending": len(data.get("pending", [])),
                "running": len(data.get("running", []))
            }
    except:
        pass
    return {"pending": "?", "running": "?"}

def monitor():
    """实时监控"""
    ports = [8188, 8189]
    
    print("多 GPU 监控工具 (按 Ctrl+C 退出)")
    
    try:
        while True:
            clear_screen()
            print("="*70)
            print("ComfyUI 多 GPU 监控")
            print("="*70)
            
            gpus = get_gpu_info()
            
            for gpu in gpus:
                port = ports[gpu["index"]] if gpu["index"] < len(ports) else "?"
                status = get_comfyui_status(port) if port != "?" else {"pending": "?", "running": "?"}
                
                mem_percent = gpu["mem_used"] / gpu["mem_total"] * 100
                
                print(f"\nGPU {gpu['index']}: {gpu['name']}")
                print(f"  温度: {gpu['temp']}°C | 利用率: {gpu['util']}%")
                print(f"  显存: {gpu['mem_used']}/{gpu['mem_total']} MB ({mem_percent:.1f}%)")
                print(f"  端口: {port} | 待处理: {status['pending']} | 运行中: {status['running']}")
                
                bar_length = 30
                mem_bar = int(mem_percent / 100 * bar_length)
                bar = "█" * mem_bar + "░" * (bar_length - mem_bar)
                print(f"  [{bar}] {mem_percent:.1f}%")
            
            print("\n" + "="*70)
            print(f"更新时间: {time.strftime('%H:%M:%S')}")
            print("="*70)
            
            time.sleep(2)
    except KeyboardInterrupt:
        print("\n监控已停止")

if __name__ == "__main__":
    monitor()
```

#### 6.2 运行监控

```bash
python monitor_multigpu.py
```

## ❓ 常见问题

### Q1: 启动时报错 "Address already in use"

**原因：** 端口被占用

**解决方案：**

```bash
# Windows 查看端口占用
netstat -ano | findstr :8188

# 结束占用进程
taskkill /PID 进程ID /F

# 或使用其他端口
python main.py --port 8190
```

### Q2: 某个 GPU 无法识别

**原因：** CUDA 配置问题或驱动问题

**解决方案：**

```bash
# 检查 GPU 是否被识别
nvidia-smi

# 检查 PyTorch GPU 数量
python -c "import torch; print(torch.cuda.device_count())"

# 重新安装 CUDA 驱动
```

### Q3: 负载不均衡，某个 GPU 负载过高

**原因：** 任务分配策略问题

**解决方案：**

1. 检查负载均衡逻辑
2. 确保所有 GPU 性能相近
3. 调整任务提交间隔

### Q4: 多实例之间模型不同步

**原因：** 每个实例独立运行

**解决方案：**

1. 使用共享模型目录
2. 手动同步模型文件
3. 使用相同的配置文件

### Q5: 如何实现跨机器的分布式部署？

**方法：**

1. 在每台机器上启动 ComfyUI
2. 使用 `--listen 0.0.0.0` 允许外部访问
3. 客户端配置所有机器的 IP 地址

```python
client = MultiGPUClient([
    "http://192.168.1.100:8188",
    "http://192.168.1.101:8188",
])
```

### Q6: 模型并行模式如何使用？

**说明：** 模型并行目前是实验性功能

```bash
# 启用模型并行（实验性）
CUDA_VISIBLE_DEVICES=0,1 python main.py --split-memory --use-xformers
```

> ⚠️ **注意：** 模型并行性能不稳定，推荐使用多实例模式
