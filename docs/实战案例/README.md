## ❓ 常见问题

### Q1: 我应该从哪个 Level 开始？

**判断方法：**
- 从未使用过 ComfyUI → 从 Level 1 开始
- 会基础文生图但不懂 ControlNet → 从 Level 2 开始
- 会 ControlNet 但没做过视频 → 从 Level 3 开始
- 想做企业级应用 → 完成前 4 个 Level 后进入 Level 5

### Q2: 每个 Level 必须全部完成吗？

**建议：**
- Level 1-2：建议全部完成，打好基础
- Level 3-4：根据需求选择相关案例
- Level 5：有企业需求时学习

### Q3: 学习过程中遇到报错怎么办？

**排查步骤：**
1. 检查模型文件是否正确放置
2. 检查节点包是否正确安装
3. 查看 [技术清单](./技术清单.md) 确认版本兼容性
4. 搜索社区是否有类似问题

### Q4: 没有显卡可以学习吗？

**解决方案：**
- 使用 Google Colab 运行 ComfyUI
- 使用云端 GPU 服务（如 AutoDL、恒源云）
- 使用 ComfyUI 在线平台

### Q5: 显存不够怎么办？

**解决方案：**
- 学习 Level 4 案例 4.2 低显存优化
- 使用 `--lowvram` 参数启动
- 使用 FP8 量化模型

### Q6: 如何保持学习进度？

**建议：**
1. 使用 [学习检查清单](../学习检查清单.md) 记录进度
2. 每完成一个案例就打勾
3. 定期回顾已学内容

### Q7: 案例中的模型从哪里下载？

**下载渠道：**
- 查看 [技术清单](./技术清单.md) 中的直接下载链接
- Civitai：https://civitai.com/
- HuggingFace：https://huggingface.co/

### Q8: 学习完成后如何进一步提升？

**进阶方向：**
- 参与社区贡献，提交 PR
- 开发自己的节点包
- 分享工作流到社区
- 探索新的模型和技术
