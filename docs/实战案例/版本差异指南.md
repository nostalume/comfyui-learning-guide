# ComfyUI 版本差异指南

> **最后更新：** 2026-05-11  
> **适用版本：** ComfyUI v0.3.0+ / 桌面端 v0.4.x

---

## 📋 功能描述

本文档详细对比 ComfyUI GitHub 版与桌面端的差异，帮助用户：
- 选择适合自己的安装版本
- 理解两个版本的功能差异
- 掌握不同版本的模型放置路径
- 解决版本相关的常见问题

**适用人群：**
- 正在选择安装版本的新用户
- 需要在两个版本间迁移的用户
- 遇到路径问题的桌面端用户
- 想要了解版本差异的开发者

## 📁 详细内容

### 一、版本选择建议

#### 1.1 选择 GitHub 版如果：

| 条件 | 说明 |
|-----|------|
| ✅ 你是开发者或高级用户 | 需要访问源码进行定制开发 |
| ✅ 需要高度自定义和扩展 | 完全控制安装和配置 |
| ✅ 需要使用命令行参数 | 如 `--lowvram`、`--cpu` 等 |
| ✅ 需要频繁更新到最新功能 | 通过 `git pull` 即可更新 |
| ✅ 需要完整的 API 支持 | 进行二次开发或集成 |

#### 1.2 选择桌面端如果：

| 条件 | 说明 |
|-----|------|
| ✅ 你是新手，不想配置环境 | 一键安装，无需配置 Python |
| ✅ 只需要基本功能 | 满足日常使用需求 |
| ✅ 希望一键安装和使用 | 双击启动，简单便捷 |
| ✅ 不熟悉命令行操作 | 图形界面操作更友好 |
| ✅ 使用 Windows 系统 | 桌面端对 Windows 优化更好 |

#### 1.3 版本对比总结

| 维度 | GitHub 版 | 桌面端 |
|-----|----------|--------|
| **上手难度** | ⭐⭐⭐⭐ 需要配置环境 | ⭐ 一键安装 |
| **功能完整度** | ⭐⭐⭐⭐⭐ 完整功能 | ⭐⭐⭐⭐ 大部分功能 |
| **扩展性** | ⭐⭐⭐⭐⭐ 高度可扩展 | ⭐⭐⭐ 受限扩展 |
| **更新频率** | ⭐⭐⭐⭐⭐ 实时更新 | ⭐⭐⭐⭐ 定期更新 |
| **适合人群** | 开发者、高级用户 | 新手、普通用户 |

### 二、目录结构差异

#### 2.1 GitHub 版目录结构

```
ComfyUI/                              # 安装目录
├── models/                           # 模型目录（所有模型都在这里）
│   ├── checkpoints/                  # 大模型 (SD 1.5/SDXL)
│   ├── vae/                          # VAE 模型
│   ├── controlnet/                   # ControlNet 模型
│   ├── lora/                         # LoRA 模型
│   ├── clip_vision/                  # CLIP Vision 模型
│   ├── ipadapter/                    # IP-Adapter 模型
│   ├── instantid/                    # InstantID 模型
│   ├── animatediff/                  # AnimateDiff 运动模型
│   └── upscale_models/               # 放大模型
├── custom_nodes/                     # 自定义节点包
├── output/                           # 输出目录
├── main.py                           # 启动文件
├── run_nvidia_gpu.bat                # Windows NVIDIA 启动脚本
├── run_cpu.bat                       # Windows CPU 启动脚本
├── requirements.txt                  # Python 依赖
└── config.yaml                       # 配置文件（可选）
```

#### 2.2 桌面端目录结构

```
ComfyUI/                              # 安装目录
├── ComfyUI/                          # 核心程序目录
│   ├── models/                       # 模型目录
│   │   ├── checkpoints/              # 大模型
│   │   ├── vae/                      # VAE 模型
│   │   ├── controlnet/               # ControlNet 模型
│   │   └── ...                       # 其他模型目录
│   └── custom_nodes/                 # 自定义节点包
├── output/                           # 输出目录（部分版本在这里）
├── ComfyUI.exe                       # 启动程序
└── resources/                        # 资源文件夹（部分版本）
    └── ComfyUI/                      # 实际程序目录（部分版本）
        └── models/                   # 模型目录（部分版本）
```

> 💡 **提示：** 桌面端的模型目录可能在 `ComfyUI/ComfyUI/models/` 或 `ComfyUI/resources/ComfyUI/models/`，请以实际设置为准！

#### 2.3 关键差异说明

| 差异点 | GitHub 版 | 桌面端 |
|-------|----------|--------|
| 模型目录深度 | 1 层 (`models/`) | 2-3 层 (`ComfyUI/models/` 或 `resources/ComfyUI/models/`) |
| 启动文件 | `main.py` | `ComfyUI.exe` |
| 配置方式 | 编辑配置文件 | 图形界面设置 |
| 输出目录 | `output/` | `output/` 或 `ComfyUI/output/` |

### 五、桌面端模型安装详细指南

#### 5.1 步骤 1: 找到模型目录

1. 打开桌面端
2. 点击菜单 `Settings > Directories`
3. 查看 `Models` 路径，通常是：
   - Windows: `C:\Users\你的用户名\ComfyUI\ComfyUI\models\`
   - Mac: `/Users/你的用户名/ComfyUI/ComfyUI/models\`

#### 5.2 步骤 2: 创建子目录

根据需要创建以下子目录：
- `checkpoints` - 大模型
- `vae` - VAE 模型
- `controlnet` - ControlNet 模型
- `lora` - LoRA 模型

#### 5.3 步骤 3: 放置模型文件

将下载的模型文件放入对应的目录：
- `xxx.safetensors` → `checkpoints/`
- `vae-xxx.safetensors` → `vae/`
- `control_v11xxx.pth` → `controlnet/`
- `lora-xxx.safetensors` → `lora/`

#### 5.4 步骤 4: 验证安装

1. 重启 ComfyUI 桌面端
2. 添加 `Load Checkpoint` 节点
3. 点击 `ckpt_name` 下拉框
4. 如果能看到你的模型文件名，说明安装成功

### 六、GitHub 版模型安装详细指南

#### 6.1 步骤 1: 进入安装目录

```bash
cd ComfyUI
```

#### 6.2 步骤 2: 创建目录

```bash
mkdir -p models/checkpoints models/vae models/controlnet models/lora
```

#### 6.3 步骤 3: 放置模型文件

```bash
# 将模型复制到对应目录
cp ~/Downloads/v1-5-pruned-emaonly.safetensors models/checkpoints/
cp ~/Downloads/vae-ft-mse.safetensors models/vae/
```

#### 6.4 步骤 4: 验证安装

```bash
# 启动 ComfyUI
python main.py
```

然后在界面中验证模型是否加载成功。

### 七、版本兼容性矩阵

#### 7.1 功能兼容性

| 功能 | GitHub 版 | 桌面端 | 说明 |
|-----|----------|--------|------|
| 基础文生图 | ✅ | ✅ | 完全相同 |
| ControlNet | ✅ | ✅ | 模型放置路径不同 |
| InstantID | ✅ | ✅ | 需要额外安装 |
| IP-Adapter | ✅ | ✅ | 需要额外安装 |
| AnimateDiff | ✅ | ✅ | 需要额外安装 |
| 自定义节点 | ✅ | ⚠️ | 部分支持 |
| 命令行参数 | ✅ | ❌ | 桌面端不支持 |
| API 服务 | ✅ | ⚠️ | 有限支持 |
| 多 GPU | ✅ | ⚠️ | 有限支持 |
| 低显存模式 | ✅ | ⚠️ | 通过设置配置 |

#### 7.2 命令行参数对照

| 参数 | GitHub 版 | 桌面端 | 说明 |
|-----|----------|--------|------|
| `--lowvram` | ✅ 支持 | ⚠️ 设置界面 | 低显存模式 |
| `--normalvram` | ✅ 支持 | ⚠️ 设置界面 | 正常显存模式 |
| `--highvram` | ✅ 支持 | ⚠️ 设置界面 | 高显存模式 |
| `--cpu` | ✅ 支持 | ⚠️ 设置界面 | CPU 模式 |
| `--port` | ✅ 支持 | ⚠️ 设置界面 | 指定端口 |
| `--listen` | ✅ 支持 | ⚠️ 设置界面 | 允许外部访问 |
| `--cuda-device` | ✅ 支持 | ❌ 不支持 | 指定 GPU |
| `--disable-xformers` | ✅ 支持 | ❌ 不支持 | 禁用 xFormers |

## 🎯 使用场景

### 场景 1：新手选择安装版本

**推荐：** 选择桌面端
- 一键安装，无需配置环境
- 图形界面操作更友好
- 自动更新更便捷

### 场景 2：开发者需要 API 集成

**推荐：** 选择 GitHub 版
- 完整的 API 支持
- 可以使用命令行参数
- 方便二次开发

### 场景 3：低显存用户

**推荐：** 选择 GitHub 版
- 可以使用 `--lowvram` 参数
- 更多显存控制选项
- 灵活配置

### 场景 4：需要安装自定义节点

**推荐：** 选择 GitHub 版
- 完全支持所有自定义节点
- 安装更简单
- 兼容性更好

### 场景 5：从桌面端迁移到 GitHub 版

**步骤：**
1. 安装 GitHub 版
2. 复制模型文件
3. 复制自定义节点
4. 重新配置工作流

## ❓ 常见问题

### Q1: 桌面端模型放进去不显示？

**原因：** 放错目录了

**解决方案：**
- 确认放在 `ComfyUI/models/` 目录下，不是根目录的 `models/`
- 重启 ComfyUI 桌面端
- 检查文件名是否正确（`.safetensors` 或 `.ckpt`）

### Q2: GitHub 版启动报错找不到模型？

**原因：** 模型目录不对

**解决方案：**
- 确认模型放在 `ComfyUI/models/` 目录下
- 检查目录权限
- 确认文件名没有特殊字符

### Q3: 桌面端如何安装自定义节点？

**步骤：**
1. 打开文件资源管理器
2. 进入 `ComfyUI/ComfyUI/custom_nodes/` 目录
3. 将节点包文件夹复制进去
4. 重启 ComfyUI

### Q4: 如何确认自己使用的是哪个版本？

**GitHub 版：**
- 启动时会显示版本信息
- 或运行：`git log -1 --format="%h %ci"`
- 文件夹里有 `main.py`

**桌面端：**
- 菜单 `Help > About ComfyUI`
- 有 `ComfyUI.exe` 文件

### Q5: 两个版本可以同时安装吗？

**可以，但需要注意：**
- 安装在不同目录
- 使用不同端口
- 模型可以共享（使用符号链接）

### Q6: 桌面端如何使用低显存模式？

**方法：**
1. 打开设置界面
2. 找到显存相关选项
3. 选择低显存模式

### Q7: GitHub 版如何更新？

```bash
cd ComfyUI
git pull
pip install -r requirements.txt
```

### Q8: 桌面端更新后模型丢失？

**原因：** 更新可能重置了目录

**解决方案：**
- 检查模型是否还在原位置
- 查看设置中的目录配置
- 如丢失，重新放置模型
