### 步骤 3: 搭建基础 AnimateDiff 工作流

#### 3.1 所需节点清单

| 序号 | 节点名称 | 节点路径 | 功能说明 |
|-----|---------|---------|---------|
| 1 | Load Checkpoint（加载模型） | comfy/loaders | 加载 Stable Diffusion 模型 |
| 2 | AnimateDiff Loader | animatediff | 加载运动模型，注入运动信息 |
| 3 | CLIP Text Encode（CLIP文本编码器） (正向) | comfy/conditioning | 正向提示词编码 |
| 4 | CLIP Text Encode (负向) | comfy/conditioning | 负向提示词编码 |
| 5 | Empty Latent Image（空Latent图像） | comfy/latent | 创建初始潜在图像（设置尺寸和帧数） |
| 6 | KSampler（K采样器） | comfy/sampling | 采样生成图像 |
| 7 | VAE Decode（VAE解码） | comfy/decoding | 将潜在图像解码为像素图像 |
| 8 | AnimateDiff Combine | animatediff | 将多帧图像合成为视频 |

#### 3.2 节点添加方法

**方法一：双击添加**
1. 在空白处**双击**
2. 在搜索框输入节点名称
3. 点击或回车添加

**方法二：右键菜单**
1. 在空白处**右键**
2. 选择 **Add Node** → 对应分类 → 节点名称

### 步骤 4: 节点连接详解

请按照以下顺序**逐步连接**节点：

#### 第一部分：模型加载（核心）

```
┌─────────────────┐
│ Load Checkpoint │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ AnimateDiff     │
│ Loader          │
└─────────────────┘
```

**连接步骤：**
1. 拖入 `Load Checkpoint` 节点
2. 选择模型：`v1-5-pruned-emaonly.safetensors`
3. 拖入 `AnimateDiff Loader` 节点
4. **连接 MODEL**：`Load Checkpoint` 的 MODEL 输出 → `AnimateDiff Loader` 的 MODEL 输入
5. **连接 CLIP**：`Load Checkpoint` 的 CLIP 输出 → `AnimateDiff Loader` 的 CLIP 输入

#### 第二部分：提示词处理

```
┌─────────────────┐
│ Load Checkpoint │
└────────┬────────┘
         │ CLIP
         ├──────────────┐
         ▼              ▼
┌─────────────────┐  ┌─────────────────┐
│ CLIP Text Encode│  │ CLIP Text Encode│
│ (正向提示词)     │  │ (负向提示词)     │
└─────────────────┘  └─────────────────┘
```

**连接步骤：**
1. 拖入两个 `CLIP Text Encode` 节点
2. 将 `Load Checkpoint` 的 **CLIP** 输出连接到两个节点的 **CLIP** 输入
3. 第一个节点输入正向提示词
4. 第二个节点输入负向提示词

#### 第三部分：潜在图像准备

**参数设置：**

| 参数 | 推荐值 | 说明 |
|-----|-------|------|
| width | 512 | 视频宽度（像素） |
| height | 512 | 视频高度（像素） |
| batch_size | 16 | **帧数**（关键参数） |

> 💡 **重要：** `batch_size` 决定生成的视频帧数。设置为 16 将生成 16 帧的视频。

#### 第四部分：采样生成

**完整连接图：**

```
AnimateDiff Loader ──MODEL──► KSampler
                              ▲
正向 CLIP Text Encode ──POS───┤
                              │
负向 CLIP Text Encode ──NEG───┤
                              │
Empty Latent Image ──LATENT───┘
```

**连接步骤：**
1. 拖入 `KSampler` 节点
2. **连接 MODEL**：`AnimateDiff Loader` 的 MODEL 输出 → `KSampler` 的 MODEL 输入
3. **连接 POSITIVE**：正向 `CLIP Text Encode` 的 CONDITIONING 输出 → `KSampler` 的 POSITIVE 输入
4. **连接 NEGATIVE**：负向 `CLIP Text Encode` 的 CONDITIONING 输出 → `KSampler` 的 NEGATIVE 输入
5. **连接 LATENT**：`Empty Latent Image` 的 LATENT 输出 → `KSampler` 的 LATENT 输入

#### 第五部分：解码与合成

```
KSampler ──LATENT──► VAE Decode ──IMAGE──► AnimateDiff Combine
                           ▲
Load Checkpoint ──VAE──────┘
```

**连接步骤：**
1. 拖入 `VAE Decode` 节点
2. **连接 LATENT**：`KSampler` 的 LATENT 输出 → `VAE Decode` 的 LATENT 输入
3. **连接 VAE**：`Load Checkpoint` 的 VAE 输出 → `VAE Decode` 的 VAE 输入
4. 拖入 `AnimateDiff Combine` 节点
5. **连接 IMAGE**：`VAE Decode` 的 IMAGE 输出 → `AnimateDiff Combine` 的 IMAGE 输入

### 步骤 5: 详细参数配置

#### 5.1 Empty Latent Image 参数

| 参数 | 推荐值 | 范围 | 说明 |
|-----|-------|------|------|
| width | 512 | 512-1024 | 视频宽度，建议 512 或 768 |
| height | 512 | 512-1024 | 视频高度，建议与宽度相同 |
| batch_size | 16 | 8-32 | **帧数**，8GB 显存建议 8-12 |

> 💡 **技巧：** batch_size 就是视频帧数。例如设置为 16 将生成 16 帧的视频，帧率 8fps 时约 2 秒。

#### 5.2 AnimateDiff Loader 参数

| 参数 | 说明 | 推荐值 | 范围 |
|-----|------|-------|------|
| model_name | 选择运动模型 | mm_sd_v15_v2 | - |
| motion_scale | **运动强度** | 1.0 | 0.3-1.5 |
| frame_rate | 输出帧率 | 8 | 6-24 |

**motion_scale 参数详解：**

| 值 | 效果 | 适用场景 |
|---|------|---------|
| 0.3-0.5 | 极轻微运动 | 人物肖像、静物 |
| 0.5-0.8 | 轻微运动 | 风景、平静场景 |
| 0.8-1.2 | 标准运动（推荐） | 大多数场景 |
| 1.2-1.5 | 强烈运动 | 动作场景 |
| 1.5+ | 剧烈运动（可能失真） | 特殊效果 |

#### 5.3 KSampler 参数

| 参数 | 推荐值 | 说明 |
|-----|-------|------|
| seed | -1（随机）或固定值 | 固定种子可重复生成 |
| steps | 25 | 采样步数，20-30 即可 |
| cfg | 7 | 分类器指导系数 |
| sampler_name | euler_ancestral | 推荐采样器 |
| scheduler | normal | 默认调度器 |
| denoise | 1.0 | 完全生成 |

#### 5.4 提示词建议

**正向提示词示例：**
```
a beautiful woman with long hair, gentle smile, soft lighting, cinematic, 4k, high quality
```

**负向提示词示例：**
```
blurry, low quality, distorted face, ugly, text, watermark, bad anatomy
```

## 📊 参数详解

| motion_scale 值 | 效果描述 | 适用场景 | 示例效果 |

## ❌ 常见问题与解决方案

### 问题 1: 视频卡顿不流畅

**症状：** 生成的视频看起来一卡一卡的，不连贯

**可能原因：**
- 帧率过低
- 帧数太少
- motion_scale 设置不当

**解决方案：**

| 解决方法 | 具体操作 |
|---------|---------|
| 提高帧率 | 将 frame_rate 从 6 提高到 8-12 |
| 增加帧数 | 将 batch_size 从 8 增加到 16 |
| 调整 motion_scale | 尝试 0.8-1.2 范围 |

### 问题 2: 显存不足错误

**症状：** 生成时出现 CUDA out of memory 错误

**可能原因：**
- batch_size 过大
- 分辨率过高
- 显存不足

**解决方案：**

| 显存 | 推荐 batch_size | 推荐分辨率 |
|-----|----------------|-----------|
| 8GB | 8-12 | 512×512 |
| 12GB | 12-16 | 768×768 |
| 16GB+ | 16-24 | 1024×1024 |

**具体操作：**
1. 降低 batch_size（如从 24 降到 16）
2. 降低分辨率（如从 768×768 降到 512×512）
3. 关闭其他占用显存的程序

### 问题 3: 生成的视频没有运动

**症状：** 视频看起来像静态图片，没有任何动画效果

**可能原因：**
- 运动模型未正确加载
- AnimateDiff Loader 未正确连接
- motion_scale 值过低

**解决方案：**

1. **检查模型加载：**
   - 确认运动模型已放入 `models/animatediff/` 目录
   - 在 AnimateDiff Loader 节点中正确选择模型

2. **检查节点连接：**
   - 确保 `AnimateDiff Loader` 在 `Load Checkpoint` 和 `KSampler` 之间
   - 连接顺序：`Load Checkpoint` → `AnimateDiff Loader` → `KSampler`

3. **调整 motion_scale：**
   - 将 motion_scale 从 0.5 提高到 1.0

### 问题 4: 人物面部扭曲

**症状：** 动画中人物面部变形、扭曲

**可能原因：**
- motion_scale 值过大
- 运动模型与 SD 模型不兼容

**解决方案：**
1. 降低 motion_scale（从 1.5 降到 0.8-1.0）
2. 尝试更换运动模型（v2 或 v3）
3. 使用更适合人物的提示词

### 问题 5: 模型加载失败

**症状：** 提示找不到运动模型或加载失败

**解决方案：**

1. **检查文件路径：**
   ```
   正确路径: ComfyUI/models/animatediff/mm_sd_v3.ckpt
   错误路径: ComfyUI/models/animatediff_models/mm_sd_v3.ckpt
   ```

2. **检查文件完整性：**
   - 确认文件大小约 3.2GB
   - 如果文件过小，重新下载

3. **重启 ComfyUI：**
   - 放置模型后需要重启 ComfyUI

## 🎮 扩展练习

### 练习 1: 参数对比实验

**目标：** 理解 motion_scale 参数的影响

**步骤：**
1. 使用相同的提示词和种子
2. 分别设置 motion_scale 为 0.5、1.0、1.5
3. 对比三段视频的运动效果
4. 记录最适合当前场景的值

### 练习 2: 长视频生成

**目标：** 生成超过 32 帧的长视频

**提示：**
1. 使用 `AnimateDiff Context Options` 节点
2. 设置 `context_length: 16`
3. 设置 `context_overlap: 4`
4. 设置 `method: sliding_window`

### 练习 3: 结合 ControlNet

**目标：** 使用 ControlNet 控制动画

**步骤：**
1. 添加 ControlNet 节点
2. 使用 OpenPose 或 Depth 控制人物动作
3. 对比有无 ControlNet 的效果差异

### 练习 4: 制作循环动画

**目标：** 创建无缝循环的 GIF 动画

**配置：**
- pingpong: true
- loop_count: -1
- 选择对称场景（如旋转物体）

### 练习 5: 风格对比

**目标：** 测试不同风格提示词的效果

**风格建议：**
- 写实风格：`photorealistic, 8k, detailed`
- 动漫风格：`anime style, cel shading`
- 油画风格：`oil painting, impressionist`
