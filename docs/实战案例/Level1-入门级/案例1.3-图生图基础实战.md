## 🚀 实战步骤

### 步骤 1: 理解图生图工作流结构

**与文生图的区别：**

| 对比项 | 文生图 | 图生图 |
|-------|-------|-------|
| 输入 | 空白 Latent | 编码后的图像 Latent |
| 起点 | 随机噪声 | 参考图像特征 |
| denoise | 固定为 1.0 | 0.1-1.0 可调 |
| 用途 | 从零创作 | 风格迁移、图像修改 |

**所需节点：**

| 序号 | 节点名称 | 功能 | 必要性 |
|-----|---------|------|-------|
| 1 | 加载模型（Load Checkpoint） | 加载模型 | 必需 |
| 2 | 加载图像（Load Image） | 加载参考图 | 必需 |
| 3 | CLIP文本编码器（CLIP Text Encode） (x2) | 正负提示词 | 必需 |
| 4 | K采样器（KSampler） | 采样器 | 必需 |
| 5 | VAE Encode | 编码图像到 Latent | 必需 |
| 6 | VAE解码器（VAE Decode） | 解码 Latent 到图像 | 必需 |
| 7 | 保存图像（Save Image） | 保存图像 | 必需 |

### 步骤 2: 搭建图生图工作流

**节点连接方式：**

```
Load Checkpoint
    ├── MODEL → KSampler.model
    ├── CLIP → CLIP Text Encode (正/负)
    └── VAE → VAE Encode.vae / VAE Decode.vae

Load Image → VAE Encode.pixels

VAE Encode → KSampler.latent_image

CLIP Text Encode (正) → KSampler.positive
CLIP Text Encode (负) → KSampler.negative

KSampler → VAE Decode
VAE Decode → Save Image
```

**详细搭建步骤：**

1. **添加 Load Checkpoint 节点**
   - 双击空白处
   - 搜索 `Load Checkpoint`
   - 选择已安装的模型

2. **添加 Load Image 节点**
   - 双击空白处
   - 搜索 `Load Image`
   - 点击 `choose file to upload` 上传参考图片

3. **添加 VAE Encode 节点**
   - 双击空白处
   - 搜索 `VAE Encode`
   - 连接 Load Image 的输出到 pixels 输入
   - 连接 Load Checkpoint 的 VAE 输出到 vae 输入

4. **添加 CLIP Text Encode 节点（两个）**
   - 一个用于正向提示词
   - 一个用于负向提示词
   - 连接 Load Checkpoint 的 CLIP 输出到 clip 输入

5. **添加 KSampler 节点**
   - 连接 MODEL、positive、negative、latent_image

6. **添加 VAE Decode 节点**
   - 连接 KSampler 的输出到 samples 输入
   - 连接 VAE 到 vae 输入

7. **添加 Save Image 节点**
   - 连接 VAE Decode 的输出到 images 输入

### 步骤 3: 加载参考图片

**方法一：上传图片**
1. 在 Load Image 节点点击 `choose file to upload`
2. 选择本地图片文件
3. 图片会自动上传并显示

**方法二：使用已存在的图片**
1. 将图片放入 `ComfyUI/input/` 目录
2. 在 Load Image 节点的下拉框中选择图片

> 💡 **提示：** 方法二适合重复使用同一张图片，无需每次上传。

### 步骤 4: 理解并设置 denoise 参数

**denoise 是图生图的核心参数！**

#### 什么是 denoise？

- **全称：** Denoising Strength（去噪强度）
- **作用：** 控制新生成内容的比例
- **范围：** 0.0 - 1.0
- **位置：** KSampler 节点的 denoise 参数

#### denoise 值详解

| denoise 值 | 保留原图 | 新生成 | 效果描述 | 适用场景 |
|-----------|---------|-------|---------|---------|
| 0.1-0.2 | 80-90% | 10-20% | 几乎不变，仅微调细节 | 图像修复、轻微优化 |
| 0.3-0.4 | 60-70% | 30-40% | 轻微变化，保留主要结构 | 细节增强、颜色调整 |
| 0.5-0.6 | 40-50% | 50-60% | 中等变化，风格开始显现 | 轻度风格迁移 |
| 0.7-0.8 | 20-30% | 70-80% | 明显变化，风格强烈 | 风格迁移、创意重绘 |
| 0.9-1.0 | 0-10% | 90-100% | 几乎完全重绘 | 接近文生图效果 |

#### denoise 选择指南

| 需求 | 推荐 denoise | 说明 |
|-----|-------------|------|
| 修复模糊照片 | 0.2-0.3 | 保留原图，增强清晰度 |
| 改变照片风格 | 0.5-0.7 | 平衡原图与新风格 |
| 照片转绘画 | 0.6-0.8 | 明显的风格转换 |
| 创意重绘 | 0.8-0.9 | 大幅改变，保留构图 |
| 完全重新生成 | 1.0 | 等同于文生图 |

## 📊 参数配置详解

### denoise 参数深度解析

#### denoise 的工作原理

```
原图 → VAE Encode → Latent（含原图信息）
                          ↓
                    添加噪声（由 denoise 控制强度）
                          ↓
                    KSampler 去噪生成
                          ↓
                    VAE Decode → 新图像
```

**关键理解：**
- denoise = 0：不添加噪声，输出 = 原图
- denoise = 1：完全添加噪声，输出 ≈ 文生图
- denoise = 0.5：一半原图信息 + 一半新生成

#### 不同 denoise 值的视觉效果

| denoise | 人物变化 | 背景变化 | 细节变化 | 构图变化 |
|---------|---------|---------|---------|---------|
| 0.2 | 几乎不变 | 微调 | 增强 | 不变 |
| 0.4 | 轻微变化 | 部分改变 | 明显变化 | 基本不变 |
| 0.6 | 明显变化 | 大部分改变 | 全新细节 | 可能微调 |
| 0.8 | 大幅变化 | 全新背景 | 全新细节 | 可能改变 |

### 图像尺寸建议

| 参考图尺寸 | 推荐设置 | 说明 |
|-----------|---------|------|
| 512x512 | 保持原尺寸 | 标准设置 |
| 768x512 | 保持原比例 | 宽幅图像 |
| 1024x1024 | 缩小到 512x512 | 大图需缩小 |
| 非标准比例 | 保持原比例 | 避免变形 |

### 采样步数建议

| denoise | 推荐 steps | 说明 |
|---------|-----------|------|
| 0.1-0.3 | 15-20 | 变化小，步数可少 |
| 0.4-0.6 | 20-25 | 标准步数 |
| 0.7-0.9 | 25-30 | 变化大，需要更多步数 |
| 1.0 | 20-30 | 等同于文生图 |

## ❓ 常见问题（FAQ）

### Q1: denoise 设置多少合适？变化太小或太大怎么办？

**问题描述：** 生成的图像要么变化太小几乎看不出区别，要么变化太大完全不像原图。

**解决方案：**

| 问题 | 原因 | 解决方案 |
|-----|------|---------|
| 变化太小 | denoise 过低 | 逐步提高 denoise（每次 +0.1） |
| 变化太大 | denoise 过高 | 逐步降低 denoise（每次 -0.1） |
| 效果不理想 | denoise 不匹配 | 参考下表选择合适的值 |

**按需求选择 denoise：**

| 需求 | 推荐 denoise | 测试范围 |
|-----|-------------|---------|
| 轻微优化 | 0.2 | 0.15-0.25 |
| 细节增强 | 0.3 | 0.25-0.35 |
| 轻度风格化 | 0.4-0.5 | 0.35-0.55 |
| 明显风格迁移 | 0.6-0.7 | 0.55-0.75 |
| 创意重绘 | 0.8-0.9 | 0.75-0.95 |

**调试技巧：**
1. 从 denoise = 0.5 开始
2. 根据效果调整：变化小则 +0.1，变化大则 -0.1
3. 记录最佳值供下次使用

### Q2: 风格迁移后图像质量下降怎么办？

**问题描述：** 风格迁移后图像变得模糊、细节丢失或出现噪点。

**可能原因：**
1. denoise 设置不当
2. 采样步数不足
3. 提示词不够精确
4. 参考图质量不佳

**解决方案：**

| 方案 | 操作 | 效果 |
|-----|------|------|
| 方案1 | 提高采样步数 | 从 20 提高到 25-30 |
| 方案2 | 添加质量标签 | 添加 `masterpiece, best quality` |
| 方案3 | 使用更强的负向词 | 添加 `(low quality:1.4), (blurry:1.3)` |
| 方案4 | 调整 denoise | 尝试 0.4-0.6 范围 |
| 方案5 | 更换模型 | 使用更适合风格的模型 |

### Q3: 生成的图像构图改变或变形怎么办？

**问题描述：** 风格迁移后图像的构图发生变化，或者出现变形。

**可能原因：**
1. denoise 过高
2. 图像尺寸与参考图不匹配
3. 提示词与原图冲突

**解决方案：**

| 方案 | 操作 | 说明 |
|-----|------|------|
| 方案1 | 降低 denoise | 尝试 0.3-0.5 范围 |
| 方案2 | 保持原图比例 | 确保输出尺寸与参考图一致 |
| 方案3 | 简化提示词 | 减少与构图相关的描述 |
| 方案4 | 使用 ControlNet | 高级方案，精确控制构图 |

**尺寸匹配检查：**
- 参考图尺寸：在 Load Image 节点查看
- 输出尺寸：由 VAE Encode 的输入决定
- 建议：保持一致，避免变形

### Q4: 如何让风格迁移效果更明显？

**问题描述：** 设置了风格提示词，但生成的图像风格变化不明显。

**解决方案：**

| 方案 | 操作 | 效果 |
|-----|------|------|
| 方案1 | 提高 denoise | 从 0.5 提高到 0.7 |
| 方案2 | 增强风格权重 | 使用 `(style:1.4)` |
| 方案3 | 添加风格负向词 | 排除原图风格 |
| 方案4 | 更换风格化模型 | 使用专门的风格模型 |
| 方案5 | 提高 cfg | 从 7 提高到 10-12 |

**示例：增强油画风格**

```
正向：(oil painting:1.5), (impressionist:1.3), brush strokes
负向：photograph, realistic, camera, digital art
```

### Q5: 参考图片太大或太小怎么办？

**问题描述：** 参考图片尺寸不适合，导致生成效果不佳。

**解决方案：**

| 问题 | 解决方案 | 操作方法 |
|-----|---------|---------|
| 图片太大 | 预先缩小 | 使用图片编辑工具缩小到 512-768px |
| 图片太小 | 不建议放大 | 使用原始尺寸或寻找更高清版本 |
| 比例不对 | 保持比例 | 调整输出尺寸匹配参考图比例 |

**推荐尺寸：**
- SD 1.5 模型：512x512, 768x512, 512x768
- 最大不超过：768x768
