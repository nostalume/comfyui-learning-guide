## 🚀 实战步骤

### 步骤 1: 理解提示词基础结构

**推荐结构：**

```
[主体描述] + [场景环境] + [风格修饰] + [质量标签]
```

**结构详解：**

| 组成部分 | 说明 | 示例 |
|---------|------|------|
| 主体描述 | 画面的主要内容 | a young woman, a cat |
| 场景环境 | 背景和氛围 | in a flower garden, sunset |
| 风格修饰 | 艺术风格或效果 | portrait photography, cinematic lighting |
| 质量标签 | 提升图像质量 | masterpiece, best quality, 8k |

**完整示例：**

```
a young woman (主体), standing in a flower garden (场景), 
soft sunlight, bokeh background (氛围), 
portrait photography, cinematic lighting (风格),
masterpiece, best quality, 8k (质量)
```

### 步骤 2: 权重语法实战

**基本权重语法：**

| 语法 | 效果 | 示例 | 说明 |
|-----|------|------|------|
| `(word)` | 增强 1.1 倍 | `(beautiful)` | 轻微增强 |
| `(word:1.5)` | 增强 1.5 倍 | `(beautiful:1.5)` | 明显增强 |
| `[word]` | 减弱 0.9 倍 | `[ugly]` | 轻微减弱 |
| `(word:0.8)` | 减弱到 0.8 倍 | `(detailed:0.8)` | 精确控制 |

**权重叠加：**

| 语法 | 效果 | 示例 |
|-----|------|------|
| `((word))` | 增强 1.1 × 1.1 = 1.21 倍 | `((beautiful))` |
| `(((word)))` | 增强 1.1³ = 1.33 倍 | `(((beautiful)))` |

**实战练习：**

1. 创建新工作流（或使用案例1.1的工作流）
2. 在正向提示词中输入：

```
a (beautiful:1.3) woman with (long hair:1.2), 
standing in a (flower garden:1.1), 
soft sunlight, (masterpiece:1.4), best quality
```

3. 生成并观察效果
4. 尝试修改权重值，对比效果差异

### 步骤 3: 负向提示词技巧

**通用负向提示词模板：**

```
(worst quality:1.4), (low quality:1.4), 
(medium quality:1.4), lowres, bad anatomy, 
bad hands, normal quality, ((monochrome)), 
((grayscale)), watermark, signature
```

**针对性负向提示词：**

| 场景 | 负向提示词 | 说明 |
|-----|-----------|------|
| 人物 | bad anatomy, bad hands, missing fingers, extra limbs, extra fingers | 避免人体结构错误 |
| 风景 | people, humans, buildings | 如需纯自然风景 |
| 产品 | background, watermark, text, logo | 干净的产品图 |
| 动漫 | realistic, photorealistic, 3d | 保持动漫风格 |

**负向提示词权重建议：**

| 元素 | 推荐权重 | 示例 |
|-----|---------|------|
| 质量问题 | 1.3-1.5 | `(low quality:1.4)` |
| 结构问题 | 1.2-1.4 | `(bad anatomy:1.3)` |
| 风格冲突 | 1.1-1.3 | `(realistic:1.2)` |

### 步骤 4: 提示词组合技巧

**AND 语法（组合多个概念）：**

```
a landscape AND a portrait
```

**效果：** 将两个概念融合在同一张图像中

**交替语法（步数间切换）：**

```
[landscape:portrait:0.5]
```

**效果：**
- 前 50% 步数使用 landscape
- 后 50% 步数使用 portrait

**实战练习：**

```
[cat:dog:0.3] sitting on a chair
```

**效果：** 前 30% 步数生成猫的特征，后 70% 步数生成狗的特征，产生混合效果

**交替语法参数说明：**

| 参数 | 说明 | 示例 |
|-----|------|------|
| 第一个词 | 开始时使用 | `[cat:dog:0.3]` 中的 cat |
| 第二个词 | 切换后使用 | `[cat:dog:0.3]` 中的 dog |
| 切换点 | 切换的步数比例 | `0.3` 表示 30% 处切换 |

### 步骤 5: Embedding 使用

**什么是 Embedding：**
- 预训练的提示词向量
- 可快速应用特定风格或效果
- 文件较小（通常几 MB）

**常用 Embedding：**

| 名称 | 用途 | 文件大小 | 下载地址 |
|-----|------|---------|---------|
| EasyNegative | 通用负向优化 | ~5MB | [Civitai](https://civitai.com/models/7808/easynegative) |
| badhandv4 | 手部优化 | ~5MB | [Civitai](https://civitai.com/models/16993/badhandv4) |
| ng_deepnegative_v1_75t | 深度负向优化 | ~5MB | [Civitai](https://civitai.com/models/4629/deep-negative) |

**安装位置：** `ComfyUI/models/embeddings/`

**安装步骤：**

1. 从 Civitai 下载 Embedding 文件（.pt 或 .bin 格式）
2. 将文件放入 `ComfyUI/models/embeddings/` 目录
3. 重启 ComfyUI（或点击 Refresh）

**使用方法：**

在提示词中输入：

```
embedding:easynegative
```

或使用权重：

```
(embedding:easynegative:1.2)
```

## 📊 参数配置详解

### 提示词权重对照表

| 权重值 | 效果强度 | 适用场景 | 注意事项 |
|-------|---------|---------|---------|
| 0.5-0.8 | 轻微减弱 | 次要元素、背景元素 | 不会完全消失 |
| 0.9-1.0 | 正常 | 默认权重 | - |
| 1.1-1.3 | 轻微增强 | 重要元素、关键特征 | 推荐范围 |
| 1.4-1.6 | 明显增强 | 核心元素、主要风格 | 可能影响其他元素 |
| 1.7+ | 强烈增强 | 特殊效果 | 可能过拟合，谨慎使用 |

### 权重使用建议

| 场景 | 推荐权重 | 示例 |
|-----|---------|------|
| 主体人物 | 1.2-1.4 | `(woman:1.3)` |
| 重要特征 | 1.1-1.3 | `(blue eyes:1.2)` |
| 风格标签 | 1.2-1.5 | `(anime style:1.4)` |
| 质量标签 | 1.3-1.5 | `(masterpiece:1.4)` |
| 次要元素 | 0.7-0.9 | `(clouds:0.8)` |

### 提示词长度建议

| 长度 | 字数 | 效果 | 建议 |
|-----|-----|------|------|
| 短 | < 20 词 | 模型自由发挥空间大 | 适合探索创意 |
| 中 | 20-50 词 | 平衡控制与创意 | 推荐日常使用 |
| 长 | 50-100 词 | 精确控制 | 可能需要更多调试 |
| 超长 | > 100 词 | 可能被截断 | 不推荐 |

## ❓ 常见问题（FAQ）

### Q1: 权重设置过高，图像效果反而变差怎么办？

**问题描述：** 设置了较高的权重值（如 1.8 或更高），但生成的图像出现扭曲、过饱和等问题。

**可能原因：**
1. 权重值过高导致过拟合
2. 多个高权重元素相互冲突
3. 模型对特定词汇敏感

**解决方案：**

| 方案 | 操作 | 说明 |
|-----|------|------|
| 方案1 | 降低权重值 | 尝试 1.1-1.4 范围 |
| 方案2 | 减少高权重元素数量 | 每个提示词最多 2-3 个高权重元素 |
| 方案3 | 使用渐进式调整 | 从 1.1 开始，逐步增加 |
| 方案4 | 检查元素冲突 | 避免相互矛盾的描述 |

**最佳实践：**
- 核心元素权重：1.2-1.4
- 重要元素权重：1.1-1.3
- 次要元素权重：0.8-1.0

### Q2: 提示词不生效或效果不明显怎么办？

**问题描述：** 输入了提示词，但生成的图像与描述不符，或效果变化很小。

**可能原因：**
1. 提示词格式错误（括号、冒号使用不当）
2. 提示词被其他元素覆盖
3. cfg 值设置过低
4. 模型不支持某些词汇

**解决方案：**

| 步骤 | 操作 | 说明 |
|-----|------|------|
| 1 | 检查语法 | 确保括号和冒号正确配对 |
| 2 | 提高权重 | 将关键词权重提高到 1.3-1.5 |
| 3 | 提高 cfg | 将 cfg 从 7 提高到 10-12 |
| 4 | 简化提示词 | 减少元素数量，突出重点 |
| 5 | 更换模型 | 某些模型对特定词汇支持更好 |

**语法检查清单：**
- ✅ `(word:1.3)` - 正确
- ✅ `((word))` - 正确
- ❌ `(word:1.3` - 缺少右括号
- ❌ `word:1.3)` - 缺少左括号
- ❌ `(word:1.3))` - 多余右括号

### Q3: Embedding 不生效或报错怎么办？

**问题描述：** 安装了 Embedding，但在提示词中使用时无效或报错。

**可能原因：**
1. 文件放置位置错误
2. 文件名与调用名不匹配
3. Embedding 与模型版本不兼容
4. ComfyUI 未刷新

**解决方案：**

| 步骤 | 操作 | 说明 |
|-----|------|------|
| 1 | 检查文件位置 | 必须在 `models/embeddings/` 目录 |
| 2 | 检查调用语法 | 使用 `embedding:文件名`（不含扩展名） |
| 3 | 刷新模型列表 | 点击界面上的 Refresh 按钮 |
| 4 | 重启 ComfyUI | 添加新文件后重启 |
| 5 | 检查兼容性 | SD1.5 的 Embedding 不能用于 SDXL |

**正确的调用方式：**

| 文件名 | 正确调用 | 错误调用 |
|-------|---------|---------|
| `EasyNegative.pt` | `embedding:EasyNegative` | `embedding:easynegative.pt` |
| `badhandv4.pt` | `embedding:badhandv4` | `embedding:badhandv4.pt` |

### Q4: 负向提示词太长，影响生成速度怎么办？

**问题描述：** 为了避免各种问题，负向提示词写得非常长，导致生成速度变慢。

**解决方案：**

| 方案 | 操作 | 效果 |
|-----|------|------|
| 方案1 | 使用 Embedding | 用 `embedding:EasyNegative` 替代长串负向词 |
| 方案2 | 精简负向词 | 只保留最关键的 5-10 个 |
| 方案3 | 分类使用 | 根据场景选择针对性负向词 |

**精简负向提示词模板：**

```
(worst quality:1.4), (low quality:1.4), bad anatomy, bad hands
```

### Q5: 如何让提示词更精准地控制生成内容？

**问题描述：** 提示词描述很详细，但生成的图像总是偏离预期。

**解决方案：**

| 技巧 | 说明 | 示例 |
|-----|------|------|
| 使用具体词汇 | 避免模糊描述 | `red dress` 而非 `colorful clothes` |
| 添加位置描述 | 指定元素位置 | `a cat on the left, a dog on the right` |
| 使用权重区分 | 强调重要元素 | `(main subject:1.4), (background:0.8)` |
| 参考艺术家风格 | 指定艺术风格 | `in the style of Van Gogh` |
| 使用数字描述 | 精确控制数量 | `two cats`, `three flowers` |
